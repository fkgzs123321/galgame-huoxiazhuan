## 多AI分工架构(8AI 细粒度方案)

参考凡人修仙传独立前端卡,采用多API分工架构。每个AI作为独立 Executable Profile,有自己的模型端点、Prompt组装、输出协议和上下文预算。职责隔离提升精确度。

| AI职责 | 触发时机 | 输出格式 | 调用频率 | 说明 |
|---|---|---|---|---|
| **主聊天AI** | 每轮 | 叙事正文+`<StatusPlaceHolderImpl/>` | 每轮必调 | 核心叙事,对应原卡剧情AI([mvu_plot]前缀条目) |
| **变量AI** | 每轮 | `<UpdateVariable>`+`<UpdateTable>` | 每轮必调 | MVU+SP数据库,对应原卡变量AI([mvu_update]前缀条目) |
| **开局AI** | 开局身份选择时 | 开场场景叙事 | 仅开局1次 | P1-P6身份对应的开场场景(鸣泽家/川尻家/长冈家/西御寺家/天道家/自定义) |
| **剧情演化AI** | 阶段切换/关键事件时 | 剧情推进指令+摘要 | 按触发 | 寒假前奏/核心/尾声/结局阶段切换,关键事件触发 |
| **NPC视角AI** | 多女角同场时 | NPC内心戏/反应 | 按触发 | 群像立体化,20女角独立视角,避免机械降神 |
| **战斗结算AI** | 战斗触发时 | 战斗HTML结算页 | 按触发 | LCG骰子判定的战斗场景,独立HTML结算 |
| **双修结算AI** | NSFW触发时 | 双修HTML结算页 | 按触发 | NSFW场景的独立结算,阶段3-5内容 |
| **世界观AI** | 场景切换时 | 场景描写+地理注入 | 按触发 | 7地理(自宅/学园/商业区/海岸/温泉乡/医院/保育园)+3节日事件 |

### 调用频率与成本控制

- **每轮基础成本**:2个API(主聊天AI + 变量AI),与原卡双AI一致
- **按需触发**:其他6个AI仅在特定触发条件时调用,不增加基础成本
- **并行优化**:主聊天AI与变量AI可并行调用;触发型AI可与主聊天AI并行
- **模型分级**:变量AI/开局AI/世界观AI可用更便宜模型(如 GPT-4o-mini);主聊天AI/战斗结算AI/双修结算AI用更强模型

### 回合内核协调

- 主聊天AI输出叙事正文 → 变量AI输出候选变量变更 → Kernel 聚合裁定 → 原子提交
- 触发型AI输出 → 作为候选事实注入 Kernel → 与主聊天AI输出协调 → 统一提交
- 冲突裁定规则:变量AI的数值变更优先于主聊天AI的叙事数值描写;NPC视角AI的内心戏作为补充不覆盖主聊天AI叙事

## ST 运行时特性调研结果(已完成)

### 实际使用的特性集(有限且清晰)

**EJS 装饰器**:仅 `@@generate_before` 一种(41处声明,覆盖100+文件)。未使用 @@if/@@each/@@const/@@private 等复杂装饰器。

**EJS 标签**(4196处,100文件):`<% %>`(执行块)、`<%- %>`(未转义输出,专用于 await getwi)、`<%/* */%>`(注释)、`<%= %>`(转义输出,少量)。未使用 `<%_` `_%>` 空白控制。

**ST 宏**(仅2个):`{{user}}`(60+处,玩家姓名)、`{{format_message_variable::stat_data}}`(状态栏 iframe 与 MVU 数据桥接命脉)。

**MVU API**:`getvar('stat_data.*', {scope:'local'})`(大量)、`setvar` (少量)、`await getwi('EJS预处理/xxx')`(条目互载)、`registerMvuSchema(Schema)`(1处,Zod schema 注册)。

**外部脚本依赖4个**(jsdelivr CDN):
- MVU bundle:`MagicalAstrogy/MagVarUpdate/artifact/bundle.js`
- SP 数据库:`AlbusKen/shujuku@spv7.9/index.js`
- LCG 骰子:`jerryzmtz/my-tavern-scripts/dist/骰子系统/stable.js`
- MVU Zod:`StageDog/tavern_resource/dist/util/mvu_zod.js`

**iframe 状态栏**:postMessage + 宿主探测(window.parent/top)+ eventOn 事件总线(GENERATION_ENDED/MESSAGE_EDITED/mag_variable_update_ended)。

**LCG 骰子**:完全确定性,自定义 LCG 公式 `_s = (_s * 1664525 + 1013904223) | 0`,种子 `_s = _day * 5 + _pi + _hid * 7919 + _chi * 13`。无 crypto/Math.random。

**辅助工具脚本**(`scripts/` 19个 .cjs/.mjs):均为离线开发工具,不参与运行时。
