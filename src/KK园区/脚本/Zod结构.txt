/* ============================================================
 * KK园区 MVU 变量结构定义（Zod 校验脚本）
 * 功能：为 MVU 变量提供 Zod schema 校验与默认值兜底
 * 环境：SillyTavern TavernHelper
 * 说明：
 *   - z 与 _ 为 MagVarUpdate bundle 注入的全局变量，无需导入
 *   - 使用 .prefault() 而非 .default()（Zod 4 规则）
 *   - 使用 z.coerce.number() + _.clamp 处理数值范围
 *   - 嵌套 z.object 添加 .prefault({}) 保证可清空
 *   - 数值字段：z.coerce.number().transform(v => _.clamp(Math.round(v), min, max)).prefault(default)
 *   - 字符串字段：z.coerce.string().prefault(default)
 *   - 枚举字段：z.enum([...]).prefault(default)
 *   - 布尔字段：z.coerce.boolean().prefault(default)
 *   - 数组字段：z.array(z.coerce.string()).prefault([])
 *   - 对象字段：z.object({...}).prefault({})
 *   - 保持幂等性：Schema.parse(Schema.parse(x)) === Schema.parse(x)
 * ============================================================ */
