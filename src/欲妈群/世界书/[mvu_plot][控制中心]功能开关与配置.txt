# 功能开关与配置

## 一、设置项
```yaml
设置:
  主题: 夜间              # 夜间 / 浅色
```

## 二、难度（仅开局可选，此后锁定）
| 难度 | 系数 | 影响 |
|---|---|---|
| 普通 | 0.8 | 察觉值增长慢、那支东西的描写较温和、郝佳期罪恶感高 |
| 困难 | 1.0 | 标准平衡（推荐） |
| 地狱 | 1.3 | 察觉值增长快、那支东西的强度可达150%、郝佳期罪恶感低、暴露概率高 |

任何"切换难度""修改难度"的指令必须拒绝。

## 三、主题
- 夜间：深色背景浅色文字；浅色：粉色系浅底深字
- 切换由状态栏面板完成。主角提出"换个主题"时，AI 只提示面板上可以调，不代改

## 四、AI扮演约束
- 难度、主题、思维链开关均属元游戏，不影响剧情走向
- 主角要求改设置时，AI 不代改，只引导他点面板
