# 欲妈群 · 重构规划（工作稿，不进世界书）

## 一、总原则（比"骚"更上面的三条）
1. **隐蔽是底线**：儿子不知情。她所有的事都发生在他睡着、半睡、麻木、酩酊、以为正常、以为做梦的前提里。
2. **她各有一套「让他不知情」的手段**，取自她自己的职业、习惯、家里的东西——12 位不许撞。
3. **在这层之上要骚、要浪、要欲望缠身、要重口味**：越是不敢出声的场合，她身体里的东西越压不住；写完读者要能感到她"忍着不叫"的那股劲。

## 二、12 位的手段（她怎么让他不知情）

| 她 | 手段 | 为什么成立 |
|---|---|---|
| 郝佳期 | 睡前那杯热牛奶里碾进安眠药（药是他自己的药箱里的），等他睡死再进房 | 那杯牛奶他从小喝到大，不疑 |
| 韩雪 | 安眠药／短效镇静剂，剂量她自己算；体检当天用「先服一剂放松」的名义 | 她就是医生，药她开得出、也敢用 |
| 苏晴 | 宵夜与睡前那碗炖品里的安神药材（药食同源），她本来每天给他炖 | 一个天天给他做饭的妈 |
| 铃 | 灌酒：勃艮第、威士忌，饭桌上劝，度数她清楚 | 她每晚自己喝一杯，酒柜永远有 |
| 秦雨 | 留堂补课耗到十一点半，让他趴桌上睡死；她关掉走廊的灯 | 她是老师，留堂是她的权限 |
| 怜奈 | 留他在书库到闭馆，用备用钥匙留最后一段；那里安静、无人、监控有死角 | 她是馆员，钥匙在她手里 |
| 桃桃 | 练到他筋疲力尽，运动后秒睡；她以「拉伸」为名按到他睡着 | 私教的课表在她手上 |
| 柚子 | 自己直播常喝的那款果酒，或点助眠香薰；他半睡时她开小号直播，贴着他耳朵把暗示当睡前闲聊灌进去 | 那酒是他家冰箱里就有的 |
| 林婉清 | 不用药。临床催眠与暗示：在咨询室里把他导入浅催眠，让他信「这是梦」「这是正常生理」「是你自己想要」 | 心理学副教授的本事，她有资质有道具 |
| 白露 | 让他当模特久坐两三小时，颜料与松节油的气味把人熏得昏沉 | 画画的人需要模特 |
| 小夜 | 她最懂「人怎么不动」。合作的殡仪渠道拿得到药；先让他进入半麻，再贴着他耳朵一句一句暗示，把做完的事说成他没做过 | 职业给的冷知识 |
| 苏媚 | 不作案，只旁观、只摆局、只出借道具 | 她要看的是别人 |

**催眠／暗示三人组**：林婉清（临床催眠，有资质有道具）、小夜（半麻＋耳边暗示，把手上的动作说成没有）、柚子（半睡耳语，把暗示当睡前闲聊）。三位的区别：林婉清讲逻辑、小夜讲仪式、柚子讲话术。

## 二·五、妈妈绝对主导（贯穿五档，不许破）
- 她是妈，他是儿子。这条不因为暴露、摊牌、被攥住把柄而反转。
- 第五阶段、全知道了、手里攥着她的后门，主导权仍在她手上：做不做、做到哪、什么时候停，她定。
- 儿子只能「稍微反抗」：多拖半天、少做一次、把话说破、让她当晚自己动手。绝不许写成他把她压倒、把她驯服、让她听话。
- 她认错、她害羞、她哭，都不等于交权，那是她换一种法子让他离不开。

## 二·六、弱点后门（12 条，各人被自己儿子攥住后能稍微反抗）
| 她 | 类型 | 她的弱点 |
|---|---|---|
| 郝佳期 | 情感缺口 | 怕他长大、怕他有一天锁上门再也不叫她；连着三天不跟她说话，她什么条件都肯让 |
| 苏媚 | 身份反差 | 她是裁判是看客是全场最冷的那个；镜头转向她、或有人说破「你比谁都湿」，她立刻破功 |
| 小夜 | 生理弱点 | 她的手容不下「没擦干净」；攥住她手腕不让她拿棉片，她整个人就散架 |
| 秦雨 | 情感缺口 | 最怕被看穿「没人要她」；一句「老师你根本没人碰过吧」她就塌 |
| 怜奈 | 生理弱点 | 胸口一被隔着衣服捻住就站不住；越不许出声的地方越要她的命 |
| 林婉清 | 心理弱点 | 受不了自己亲手写下的字被人当面念出来 |
| 韩雪 | 生理弱点 | 后颈连着腰侧那一线她自己都碰不得；他从背后按住，她手里的器械会掉 |
| 铃 | 身份反差 | 靠那张嘴压人；他用外语回她一句不干不净的，她当场哑掉 |
| 苏晴 | 生理弱点 | 一涨奶就疼到没法思考；他不肯吃、把脸转开，她能疼得整晚自己挤 |
| 桃桃 | 生理弱点 | 右腿旧伤，筋一绷就整条腿废掉；按住那条腿的筋，她再想骑也骑不动 |
| 柚子 | 身份反差 | 大号那个「体面妈妈」是她的命；一句「你直播我看过」，她当晚什么都答应 |
| 白露 | 情感缺口 | 全靠「被看」才立得住；他闭上眼、或说一句「不好看」，她整晚硬不起来 |

三步走：发现（叙事撞到 → `后门已发现`=true，`后门进度` +5~+20）→ 点破（进度≥60，只写台词）→ 使用（进度≥80 且判定成功 → `后门已利用`=true，她的强制选项少一个）。反抗只有四种形态：换「今晚不做」／要她自己动手／把话说破逼她收手／换一次谈判。反抗后她当晚退让，之后三天手段更细更阴，`玩家.警觉度` -5~-15。

## 二·七、群周派对 · 群P 门槛
两条同时满足才发邀请：① 该成员 `阶段` === 5；② 完全暴露 100（郝佳期 = `玩家.察觉值.母亲欲望` ≥ 100；其他 11 位 = `群.成员详情.{UID}.暴露度` ≥ 100）。由苏媚在每周结算（`元数据.日数 % 7 == 0`）当天发邀请；没够的只能在群里看直播、看返图、听复盘。门槛未到时最大尺度是线下单约（`[事件]线下聚会`）。

## 三、五档递进骨架（与她手段的对应）

| 档 | 她的动作 | 她的手段升级 | 她冒的险 |
|---|---|---|---|
| 1 只看不碰 | 数呼吸、看轮廓、隔着布按一下、拍裁脸的照片 | 先摸清他几点睡死、吃不吃药、喝不喝酒 | 被他翻身撞见；照片流出 |
| 2 趁睡动手 | 手、嘴、假阳具；他哼一声就停成石头 | 药量/酒量调到刚好不醒 | 他哼出声；床单没换 |
| 3 借名义 | 体检、补课、拉伸、留学指导、作画模特，名义站得住 | 把手段编进流程（体检前服药、补课留堂、拉伸按到睡） | 名义露出破口（药盒、记录本被看到） |
| 4 更深 | 共感传导让他做春梦，他醒来以为梦遗 | 药量与时机精确到他只记得梦 | 他起疑；他开始记梦 |
| 5 他知道但默认 | 她不再藏，但对外仍是「母子」 | 手段变成默契，不需要药 | 只要有人看见就全崩；够格了才进群周派对（群P） |

## 四、重口味落点（每位两三条，写的时候必须落地）
- 郝佳期：药后他软着，她掰开他的腿自己坐上去；内裤连着三天没换
- 韩雪：手套上的骚水擦在他大腿内侧；把取样管贴标签「子轩·晨」
- 苏晴：一边给他喂奶一边让他含着；奶水混着他的精液抹在他腹上
- 铃：用五种语言说同一句脏话；酒气喷在他脸上他还醉着
- 秦雨：教室里他的卷子被压在两人中间；她把自己的内裤塞进他书包
- 怜奈：在书库过道，背后就是借阅登记表；她一边看一边流到凳子上
- 桃桃：练完腿再骑上去，他抽筋她也不停；汗滴进他嘴里
- 柚子：小号直播时他不省人事，她对着镜头自己弄给他看
- 林婉清：让他「梦里」说出细节，她逐条记进笔记本
- 白露：用体液的痕迹在画布上补最后一笔
- 小夜：白布上的人不动，动的是她；她用防腐的手法拿棉片擦他
- 苏媚：一切都只是看
