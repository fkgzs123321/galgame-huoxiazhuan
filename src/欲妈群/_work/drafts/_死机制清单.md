# 欲妈群 · 死机制 / 死描述清单（工作稿，不进世界书）

> 判据：一条机制要闭环，必须四件齐——① 有变量 ② 有更新规则（谁写）③ 有执行者（D0/状态栏/变量AI）④ 有人读（AI 或玩家）。缺任一件即为「死」。

## B. 死描述（只有文字，没有对应变量或钩子）
- 群成员 `在线/上次活跃时`：UI 只显示在线点，`上次活跃时` 无人读
- `群.联盟`（盟友/对手/中立）：有规则、有存储，**界面上没有任何展示**，玩家看不见
- `群.周竞赛历史`：有写入规则，界面上不显示，玩家看不见
- `玩家.性经历.女友/性伴侣数`：有规则，无人读（NTL 张力没接上）
- `D20历史`：现在 UI 显示了，但**事件池/觉醒值变化**没写进去

## C. 半闭环（有条件但没人算）
- 「最近 7 日无擦边」（好结局·理性）：无字段，AI 自判 —— 建议用 `_本轮判定` 或 日数 近似
- 「高考日 Day100 终局判定」：高考倒计时条目写了，但 `变量更新规则._ending_rules` **没有 Day100 这一条** → 到日子不会自动触发
- 成员 `阶段起始日`：**本轮刚补上**（A 方案），D0 已输出「本阶段第 N 天」
