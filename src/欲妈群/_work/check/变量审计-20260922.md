# 变量审计 · 欲妈群（2026-09-22）

**判据（你定过的过审判据）**：每个数值问三句 —— ① 玩家看得见吗 ② 能拿它做决策吗 ③ 会改变叙事走向吗；三否 → 删。
再反问一句：**这数值是帮玩家玩，还是替 AI 记账？**

**方法**：人工读（不用脚本判定 —— 脚本只会按词表捞关键词，今天已经证明会误报）。

---

## 一、先定"本卡玩法"，再谈变量

玩家 = 儿子，**不知情**。他实际能做的动作只有四个：

| 玩法 | 靠什么数值 | 需要什么 |
|---|---|---|
| **① 察觉**（从异常里拼真相） | `察觉值.{假阳具真相,群存在,母亲欲望,幻触}` | 进度条 —— 玩家看得见、能据此判断"我查到哪一步了" |
| **② 拒绝**（拒掉她摆的选项） | `_本轮判定` ＋ 判定结果 | 按钮当场跑、结果念给他听 |
| **③ 后门反抗**（攥住弱点换退让） | `后门已发现/后门进度/后门已利用` | 条件可见、代价可见 |
| **④ 承受**（身体后果） | 他自己的身体状态 | **叙事就能写**，不需要存数值 |

＋ 时间压力：`距高考 = 高考日 − 日数`。

**⇒ 真正"服务玩法"的数值只有十来项。** 其余大部分是**替 AI 记账**。

---

## 二、三个硬问题（按严重度）

### 🔴 1. 状态栏把她的内心显示给玩家了 —— 与保密设定直接冲突

`正则/状态栏.html` L284-287：

```js
lab("兴奋",心理.兴奋)+lab("润滑",心理.润滑)+lab("理智",心理.理智)+
lab("痴迷",心理.痴迷)+lab("罪恶感",心理.罪恶感)+lab("勇气",心理.勇气)+
lab("暴露恐惧",心理.暴露恐惧)+lab("叛逆恐惧",…)
```

本卡的铁律是「他**完全不知情**」「群、群名、她手机里的东西一律看不见」——
但面板直接告诉他「妈妈现在很兴奋、罪恶感在往下掉」。

**这是设计层选择，必须你定**：

- **A. 面板只留他观察得到的**（她的表情／留下的痕迹／他自己的身体）→ 把她那 8 个心理数值从面板撤掉，变量可留（只服务 AI 判断）
- **B. 承认面板是上帝视角 HUD** → 那"他不知情"这条在 HUD 层要写成例外（沉浸感会受损）

### 🔴 2. `兴奋／润滑／此刻想法` 与卡自己的规则打架

`[mvu_plot]私密通用规范` §三 明写：

> 身体状态一律由叙事直接写出来（奶头挺到什么程度、湿到哪一层、失神在哪一句），**不查变量**

但 schema 里存了：她的 `兴奋/润滑/此刻想法`（＋ `成员详情` 里 11 位各一份）、玩家的 `心理.欲望/兴奋`。
**规则说不查变量，那就别存**——存了 AI 就会去读它再写身体，正好违反规则。

### 🟡 3. 同一个概念两套命名

| 郝佳期 | 其他 11 位 | 同一件事 |
|---|---|---|
| `郝佳期.统计.偷抚次数` | `成员详情.X.累计偷抚` | 偷抚次数 |
| `郝佳期.统计.诱导射精` | `成员详情.X.累计诱导射精` | 诱导射精 |
| `郝佳期.统计.假阳具使用` | `成员详情.X.累计假阳具` | 道具使用次数 |
| `郝佳期.统计.暴露次数` | `成员详情.X.累计暴露` | 暴露次数 |
| `郝佳期.关系.亲密度/信任度/边界` | `成员详情.X.与儿子亲密度/…` | 母子关系 |

同一个人两套名字 → 读的人（AI）会写错（今天已经因为"中文名当键"报过一次错）。

## 三、可以砍的（"替 AI 记账"型）

| 项 | 为什么 |
|---|---|
| `玩家.D20历史`（字符串，留 10 条） | 日志。面板当场显示本轮结果就够，历史没人用 |
| `玩家.心理.欲望` / `兴奋` | 与 `身体.性欲` 重合，且他不能拿它决策（`欲望` 只被"意志判定修正"用一次） |
| `假阳具.绑定目标`（固定"主角"）／`是否激活`（固定 true） | 常量 |
| `假阳具.备注` | 无读者 |
| `群.成员数` / `在线数` / `活跃度` | 面板显示用；这三个只服务"热度"观感，不影响任何判定 |
| `成员详情` 的 33 字段 | 真正影响下一轮的只有 6~8 个：`UID/姓名/角色/等级/阶段/暴露度/本轮活跃/儿子在场`；其余（兴奋/润滑/罪恶感/痴迷/勇气/暴露恐惧/与儿子×3/此刻想法/累计×4/后门×6/专属）多是记账或叙事本该写的 |
| `郝佳期.心理.理智` / `勇气` / `暴露恐惧` | 只被判定当修正用；叙事本来就要写"她还敢不敢" |

**不建议砍的**：`难度`（`[控制中心]` 写了"仅开局可选、此后锁定" —— 有设计，只是**缺开局入口**）、
`技能 5 项`（更新规则里有成长：`对应行为 +1~+3`）。

## 四、要你拍板的三件（设计层，我不自己裁）

1. **面板要不要显示她的心理数值？**（决定后面能砍多少）
2. **判定靠什么？** 现在 5 个技能各带 DC（洞察12／冥想10／伪装10／意志12／调查15）；技能成长是 `对应行为 +1~+3`，100 封顶 → 长期几乎不动，**实际决定成败的是 DC 不是技能**。你说过卡的主题是「关键」、而技能卡的"有／无"跟它冲突 —— 那判定该换成什么？
3. **记账类要不要全下沉到面板？** 今天已连爆两次写入错（数组、uid），说明"让 AI 写数值"这条路本身脆。计数／排名／历史／轮换这类，面板算得又快又不会错。
