# 工程标准说明（JSON-First）

本目录后续统一采用 JSON-first 规范。

## 1. 单一真源

- 运行真源是角色卡 JSON（可直接导入 ST 的文件）。
- 工程目录中的世界书/脚本/界面仅用于维护与阅读，不作为最终导入真源。

## 2. 母版来源

- 每次改造前，先用 PNG 重新导出 JSON，导出的 JSON 作为回包母版。
- 禁止直接使用历史旧键名 JSON 作为母版。

## 3. 回包硬规则

- 只允许替换：`data.character_book.entries[*].content`。
- 必须保持不变：
  - `first_mes`
  - 扩展区结构与键名（`data.extensions` / `extensions.regex_scripts` / `tavern_helper`）
  - entry 数量、id、顺序

## 4. 兼容性要求

- 以当前 ST 可回导成功的结构为准。
- 不做字段名“自动翻译”或结构重排。

## 5. 验收清单

- 导入后能看到 regex_scripts。
- 开局 HTML 正常显示（不止 LOADING...）。
- 关键脚本与按钮链路可触发。
- 回包前后 entry 数量、id、顺序一致。
