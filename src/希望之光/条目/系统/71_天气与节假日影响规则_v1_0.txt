# [core]天气与节假日影响规则（量化联动）

## 1) 天气状态
- 晴 / 阴 / 雨 / 高温 / 寒潮

## 2) 天气对判定的影响
- 晴、阴：无修正
- 雨：外出与转运相关任务最终DC +1
- 高温：体力消耗类动作额外体力-2，最终DC +1
- 寒潮：呼吸相关病症（D-COPD/D-CHF）任务最终DC +1

## 3) 节假日状态
- 无 / 一般节假日 / 高峰节假日

## 4) 节假日对资源与人手影响
- 一般节假日：可用人手-1（任务池总数上限-1）
- 高峰节假日：可用人手-2，后勤与交接类任务最终DC +1

## 5) 复合叠加规则
天气修正 + 节假日修正可叠加，但总修正上限+2。

## 6) 回写字段
- `/世界/天气`
- `/世界/节假日`
- `/事件标记/最近动作日志`

## 7) 约束
- 天气/节假日只影响修正与消耗，不直接改判定结果。
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
