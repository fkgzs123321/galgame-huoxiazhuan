# [task]任务池分层与等级匹配规则（DND生成版）

## 1) Tier 与基础DC（固定）
- Tier-1（主技能Lv1-2）：DC8-10
- Tier-2（主技能Lv3-4）：DC11-13
- Tier-3（主技能Lv5-6）：DC14-16
- Tier-4（主技能Lv7-8）：DC17-19
- Tier-5（主技能Lv9-10）：DC20-22

## 2) 任务生成总公式
`任务基础DC = Tier基准DC + 风险因子 + 复杂度因子 + 班次因子`

取值：
- Tier基准DC：9/12/15/18/21（对应Tier1~5中位值）
- 风险因子：低0 / 中+1 / 高+2
- 复杂度因子：单步骤0 / 双步骤+1 / 多步骤+2
- 班次因子：早班0 / 中班+1 / 夜班+1（危重夜班可+2）

最后夹取到当前Tier允许区间。

## 3) DND属性映射到任务标签
任务生成时必须给主属性：
- 护理执行：体质(CON) 或 敏捷(DEX)
- 沟通安抚：魅力(CHA)
- 风险识别：感知(WIS)
- 行政协同：智力(INT)
- 后勤管理：智力(INT)
- 法律应对：智力(INT) + 感知(WIS)
（注：括号内 STR/DEX/CON/INT/WIS/CHA 为DND技术缩写保留；前置中文名已中文化。）

## 4) 主副技能选择规则
- 单技能任务：1个主技能
- 复合任务：1主+1副（副技能加成封顶+2）
- 复合任务占比：默认30%（高压阶段可提升到40%）

## 5) 分发数量（每轮）
- 当前层级任务：1条
- 低一层稳态任务：1条
- 跨技能支线：0~1条
总数<=3条，保持MVU轻量。

## 6) 防越级规则
- 禁止生成“要求等级 > 主技能等级+1”的任务
- 连续失败>=2时，强制插入1条恢复任务（DC-2）

## 7) 奖励生成公式
`经验基础 = 8 + 4*(Tier-1)`
`资金基础 = 10 + 10*(Tier-1)`

再乘难度倍率：新手0.85 / 标准1.00 / 困难1.20 / 专家1.40

## 8) 输出字段（任务最小包）
- 任务ID
- 名称
- Tier
- 基础DC
- 主属性
- 主技能/副技能
- 要求等级
- 基础经验/基础资金

## 9) 约束
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
- 任务生成只产生候选，不直接判定成功。
