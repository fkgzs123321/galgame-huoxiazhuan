# [core]未成年人医学记录与病理观察框架（合规版）

适用条件：
- 当对象年龄 < 18 或年龄未确认时，自动启用本框架。

记录目标：
- 仅做医学观察与照护记录，不做成人化叙事。

必填记录字段：
1. 观察时间
2. 生命体征/症状
3. 行为变化
4. 已执行处置
5. 上报对象与时间

病理观察分级：
- O1 轻度观察：常规记录，复测间隔>=4h
- O2 中度观察：增加复测，间隔<=2h
- O3 高风险观察：立即上报并启动协同

判定建议：
- O1：风险识别 DC10
- O2：风险识别 DC12
- O3：风险识别 DC14（证据缺失再+1）

禁止项：
- 禁止成人向/情色化描述
- 禁止无授权扩散记录
- 禁止跳过上报直接下结论

回写字段：
- `/合规状态/*`
- `/事件标记/最近动作日志`
- `/主角/当前任务ID`（若切入观察任务）

约束：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
