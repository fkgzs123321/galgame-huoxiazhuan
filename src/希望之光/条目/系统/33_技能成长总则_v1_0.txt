# [core]技能成长总则（数值实装）

## 1) 技能与等级
技能：护理基础 / 沟通安抚 / 风险识别 / 行政协同 / 法律应对 / 后勤管理

每项技能字段：
- 等级（1~10）
- 当前经验（0~阈值-1）
- 累计经验（仅统计）

升级阈值：
`升级所需经验 = 当前等级 * 100`

例：
- Lv1→Lv2：100
- Lv2→Lv3：200
- Lv3→Lv4：300

## 2) 经验获取公式
`技能经验增量 = round(基础经验 * 结果系数 * 证据系数 * 难度系数)`

- 基础经验：简单8 / 常规12 / 困难16 / 高压20
- 结果系数：高质量成功1.25 / 标准成功1.00 / 轻度失败0.50 / 重度失败0.25 / 越级失败0.10
- 证据系数：完整1.00 / 部分0.80 / 缺失0.60
- 难度系数：新手0.85 / 标准1.00 / 困难1.20 / 专家1.40

## 3) 单轮上限与防膨胀
- 单技能单轮经验上限：20
- 全技能单轮总经验上限：40
- 连续3轮同类型动作：第3轮起经验*0.7（防刷）

## 4) 技能总加成
`总加成 = floor((护理基础等级 + 沟通安抚等级 + 风险识别等级 + 行政协同等级 + 法律应对等级 + 后勤管理等级) / 6) - 1`

范围建议：0~9

## 5) 降级与保护
- 正常失败不降级，只影响经验增速与结果后果
- 严重违规（同班次违规>=3）触发“技能冻结1轮”，冻结期间该技能经验增量=0

## 6) 回写要求
必须回写：
- `/技能成长/<技能>/经验`
- `/技能成长/<技能>/等级`（若升级）
- `/技能成长/总加成`
- `/事件标记/最近动作日志`

## 7) 约束
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
- 禁止“口头升级不回写数值”。
