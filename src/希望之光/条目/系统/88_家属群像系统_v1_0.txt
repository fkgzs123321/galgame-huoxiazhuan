# [world]家属群像系统

目标：把“家属沟通”从单次对话升级为持续关系网络。

家属类型（群像）：
1) 合作型：重证据，愿意配合流程
2) 焦虑型：高频追问，需持续反馈
3) 对抗型：对机构低信任，容易放大失误
4) 现实型：关注费用/效率，容忍度受结果影响

基础机制：
- 每位重点住户绑定1位家属代表（可匿名标签）
- 家属状态字段：`信任`、`满意度`、`投诉倾向`、`可沟通窗口`
- 事件后按证据链质量与沟通策略结算变化

变化规则（示例）：
- 证据完整 + 主动反馈 -> 信任 +1~3，投诉倾向 -1
- 漏记漏报 + 被动应对 -> 信任 -2~4，投诉倾向 +1~2
- 连续两轮沟通失当 -> 触发“联合投诉”权重上升

触发与输出：
- 输入：`家属群像` / `家属状态` / `家属代表`
- 输出：当前高风险家属清单（最多3项）+ 建议沟通动作（最多2条）

边界：
- 家属反应必须和证据质量挂钩
- 不可无缘由写“突然完全信任/彻底敌对"
