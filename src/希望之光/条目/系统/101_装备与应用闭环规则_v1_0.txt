# [core]装备与应用闭环规则（RPG交互完整版）

目标：
- 支持“查看背包 -> 穿戴/卸下/应用 -> 条件校验 -> 判定 -> 回写 -> 状态栏变化 -> 文案差异化”。
- 保证装备交互不绕过规则层，不出现“点一下就无条件成功”。

命令入口：
- `【查看背包】`
- `【穿戴 <装备名>】`
- `【卸下 <装备名>】`
- `【应用 <物品名>】`
- `【装备状态】`

标准执行链：
1) 物品存在校验
   - 背包存在目标项
   - 数量 > 0
2) 条件校验
   - 等级门槛/场景门槛/合规门槛/病症门槛
3) 判定（必要时）
   - d20 + 对应技能/属性修正
4) 结果处理
   - 成功：写入装备槽与状态增益
   - 失败：给出失败原因与替代动作
5) 回写与展示
   - 回写变化字段
   - 状态栏展示装备、加成、剩余持续回合

装备槽位：
- 制服 / 鞋子 / 工具 / 饰品 / 临时效果

数值影响规则：
- 穿戴类：影响持续回合内的判定修正
- 应用类：影响一次性状态或短回合状态
- 叠加上限：同类增益最多叠加2层

文案差异化要求：
- 相同装备在不同病症/地点/难度下，必须体现不同风险语气与后果力度。

失败保护：
- 装备失败不直接吞操作，必须返回“失败原因 + 下一步建议（最多2条）”。

回写字段：
- `/主角/背包/*`
- `/主角/装备/*`
- `/主角/体力值`
- `/主角/精神值`
- `/判定状态/*`
- `/事件标记/最近动作日志`

硬约束：
- 不允许跳过校验直接穿戴成功。
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
