# [core]法律与责任后果系统（硬连接）

## 1) 核心变量
- 当前案件数（>=0）
- 合规处罚级别（无/警告/罚款/停业整顿）
- 赔付压力（0~100）

## 2) 事故到法律映射
- 轻度事故 + 流程完整：案件数不变或+0
- 中度事故 + 流程缺失：案件数 +1，处罚级别>=警告
- 重度事故 + 流程缺失：案件数 +1，处罚级别>=罚款

## 3) 处罚升级规则
- 案件数>=2 且 最近违规次数>=2：处罚升级1级
- 案件数>=3 或 重度事故连续2次：处罚至少为停业整顿

## 4) 赔付压力计算
`赔付压力增量 = 事故等级系数 + 证据缺口系数 + 舆情系数`
- 事故等级系数：轻10 / 中20 / 重35
- 证据缺口系数：完整0 / 部分8 / 缺失15
- 舆情系数：低0 / 中5 / 高10

## 5) 联动后果
- 赔付压力>70：经济账本进入高支出模式（每班次+30）
- 处罚级别>=罚款：主线推进必须先完成法律应对任务

## 6) 回写字段
- `/外部系统/法律风险/*`
- `/合规状态/*`
- `/经济账本/*`

## 7) 约束
- 严重事故不得写成“无后果”。
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
