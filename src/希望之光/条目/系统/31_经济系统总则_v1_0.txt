# [world]经济系统总则（厚写实量化版）

目标：把“资金变化”从概念描述升级为可追溯账本系统，确保每班次都可复盘。

## 一、账本字段（必须可回写）
- 当班收入 / 当班支出 / 当班净额
- 累计收入 / 累计支出 / 累计净额
- 事故成本 / 法律成本 / 舆情应对成本
- 罚款次数 / 补贴次数 / 连续亏损班次

## 二、收入模型（按班次）
1) 基础收入：
- 完成常规任务：每项 +30
- 完成高压任务：每项 +50
- 完成复盘闭环：+10（每班最多1次）

2) 质量加成：
- 当班合规等级 A：总收入 *1.10
- 合规等级 B：总收入 *1.00
- 合规等级 C：总收入 *0.90

3) 声望加成（封顶）：
- 声望 >= 60：+20
- 声望 >= 30：+10
- 声望 < 30：+0
- 单班次总加成封顶 +30

## 三、支出模型（按班次）
1) 固定支出：
- 人员与常规补给：20~40（根据班次压力）
2) 事故支出：
- 轻度：20
- 中度：60
- 重度：120
- 危重链触发额外：+80
3) 法律支出：
- 每个在途案件：+80
- 处罚级别 L2/L3/L4 额外：+40/+90/+160
4) 舆情支出：
- 舆情热度 >= 60：+30
- 舆情热度 >= 80：+70

## 四、处罚与补贴
处罚：
- 一般违规：-20
- 漏报/越级：-50
- 严重违规：-100 且处罚级别+1

补贴（防死局）：
- 条件：资金<100 且连续亏损>=2班
- 额度：+120
- 限制：每3班最多触发1次
- 代价：声望 -3，治理阻力 +1

## 五、风险阈值与经营状态
- 资金 >= 800：稳态（经营修正 +1）
- 300 <= 资金 < 800：警戒（无修正）
- 资金 < 300：紧缩（任务资源受限，部分高压任务DC +1）
- 资金 < 120：危机（触发“紧急经营措施”建议）

## 六、输出与回写要求
- 必须输出：收入分项、支出分项、净额、累计净额
- UpdateVariable 仅写变化字段，不整包覆盖
- 当出现异常跳变（>±300）必须附证据说明来源
