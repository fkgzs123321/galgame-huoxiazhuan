# [world]主线阶段压力源细化

目标：把主线推进从“任务列表”升级为“在外部压力下做决策”。

阶段压力源：
1) 阶段一（入职适应）
- 压力源：人手紧缺 + 新考核制度试运行
- 直接影响：任务生成时“高负荷条目”权重上调；夜班失误容错下降
- 证据字段：交接完整度、漏记次数、加班时长

2) 阶段二（冲突累积）
- 压力源：家属联合投诉 + staff协作分歧
- 直接影响：沟通类DC +1（默认）；证据链完整可抵消
- 证据字段：家属满意度、协作度、冲突值、投诉计数

3) 阶段三（外部审查）
- 压力源：监管抽检 + 舆情发酵风险
- 直接影响：合规缺口后果升级一级；复盘质量影响处罚级别
- 证据字段：程序合法性、证据质量、整改完成度

触发与回写：
- 输入：`主线压力` / `阶段压力` / `外部压强`
- 输出：当前阶段压力源 + 可执行缓解动作（最多2条）
- 回写：`主线阶段.当前压力源`、`主线阶段.压力等级`（L/M/H）

边界：
- 压力源只改变权重和后果，不直接判定任务成败
- 不可无证据直接跳阶段
