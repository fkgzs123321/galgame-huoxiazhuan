# [core]属性现实上限与判定映射（DND六维硬规则）

## 1) 六维范围与角色生成
属性：力量(STR) / 敏捷(DEX) / 体质(CON) / 智力(INT) / 感知(WIS) / 魅力(CHA)

- 全局允许范围：1~30（常人常规上限20）
- 主角开局允许范围：8~14（避免超模）
- NPC常规范围：6~18（模板生成后夹取）
- 21~30 仅用于特殊剧情/临时状态/极端事件，必须附来源说明

## 1.1) 最终有效属性值（用于触发）
`最终有效属性值 = clamp(基础属性 + 后天状态修正 + 场景修正 + 临时修正, 1, 30)`

- 所有属性细则触发必须读取“最终有效属性值”
- 常规流程下最终有效属性值不应长期高于20

## 2) 属性修正公式
`属性修正 = floor((属性值 - 10) / 2)`

映射表：
- 6~7 => -2
- 8~9 => -1
- 10~11 => 0
- 12~13 => +1
- 14~15 => +2
- 16~17 => +3
- 18~19 => +4
- 20 => +5

## 3) 任务类型主属性映射
- 护理执行/转移：CON 或 DEX
- 沟通安抚/家属解释：CHA
- 风险识别/预警：WIS
- 行政协同/记录：INT
- 法律应对：INT（主）+WIS（副）
- 后勤调配：INT

## 4) 双属性任务计算
若任务要求双属性（主+副）：
`属性贡献 = 主属性修正 + floor(副属性修正 / 2)`
副属性最多提供 +2 / 最低 -2。

## 5) 现实边界
- 属性只影响成功率，不可突破职业权限
- 属性不直接改写剧情结论
- 属性极端结果必须输出：原因 + 后果 + 补救动作

## 6) 回写约束
- 先天属性仅开局写入；常规流程不得改写
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
