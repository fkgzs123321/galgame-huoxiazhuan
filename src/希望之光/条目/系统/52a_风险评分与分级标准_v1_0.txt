# [core]风险评分与分级标准（替代“中/高风险”口语）

rule:
  目标:
    - 统一风险定义，避免“中等风险/高等风险”语义歧义
    - 所有任务与技能执行统一使用风险分（RiskScore）

  风险分公式:
    - RiskScore = R1 + R2 + R3 + R4 + R5 + R6
    - 总分范围: 0~18

  六类风险点（每项0~3分）:
    - R1 病情波动强度: 0稳定 / 1轻波动 / 2明显波动 / 3危重前兆
    - R2 操作负荷强度: 0观察记录 / 1常规操作 / 2多步骤操作 / 3高负荷处置
    - R3 协作复杂度: 0单人 / 1双人 / 2三岗位协同 / 3四岗位及以上联动
    - R4 证据完整度风险: 0证据完整 / 1轻缺项 / 2关键缺项 / 3证据链断裂
    - R5 时间窗口压力: 0充裕 / 1一般 / 2紧迫 / 3极短窗
    - R6 环境资源约束: 0资源充足 / 1轻受限 / 2明显受限 / 3严重受限

  分级阈值:
    - G0: 0~4（低风险）
    - G1: 5~8（可控风险）
    - G2: 9~12（高压风险）
    - G3: 13~15（重大风险）
    - G4: 16~18（极限风险）

  判定联动（建议）:
    - G0: 最终DC +0
    - G1: 最终DC +1
    - G2: 最终DC +2
    - G3: 最终DC +3
    - G4: 最终DC +4

  输出要求:
    - 必须输出 R1~R6 各项分值与 RiskScore
    - 必须输出分级 G0~G4 与对应DC修正

format: |-
  本轮结果：已按风险评分标准完成分级。
  关键变化：输出R1~R6、RiskScore、分级与DC修正。
  下一步建议：若分级>=G3，优先降级任务或增加协作与证据补齐。
