# [core]画像式结局系统（可量化）

结局不是单一好坏，而是四维画像：
1) 合规画像
2) 经营画像
3) 关系画像
4) 专业画像

评分规则（每维 S/A/B/C/D）：
- S：>=85
- A：70~84
- B：55~69
- C：40~54
- D：<40

四维分值计算：
- 合规分 = 程序合法性分 + 证据质量分 - 处罚扣分
- 经营分 = 净额趋势分 + 成本控制分 - 赔付压力扣分
- 关系分 = 住户信任均值 + 家属满意 + 护理组协作修正
- 专业分 = 六系技能均值 + 关键任务成功率

总评逻辑：
- 2维及以上 S/A：可持续高质量结局
- 多数 B：勉强达标结局
- 任意维 D 且未修复：系统性失控结局

输出模板：
- 主标题：你成为什么类型的照护管理者
- 四维评分：逐项列出
- 三条关键证据
- 两条遗留风险
- 两条后续建议

回写字段：
- `/结局画像/合规`
- `/结局画像/经营`
- `/结局画像/关系`
- `/结局画像/专业`
- `/结局画像/总评`

约束：
- 必须引用过程证据，禁止纯文案打分。
