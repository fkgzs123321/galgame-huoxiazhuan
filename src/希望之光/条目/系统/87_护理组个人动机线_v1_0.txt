# [world]staff个人动机线

目标：让staff从“功能角色”升级为“有偏好与代价的决策角色”。

核心staff动机：
- 何护士长：优先保住科室评级与流程合规
- 王护工：优先降低一线体力透支与冲突频率
- 陈社工：优先稳住家属关系与投诉面
- 赵医生：优先医疗风险可控与责任边界清晰
- 李后勤：优先预算平衡与关键物资不断供
- 张安宁：优先安全事件归零与秩序稳定

执行规则：
1) 同一事件下，staff会给出不同优先方案（可能冲突）
2) 玩家每轮最多采纳1个主方案 + 1个补救方案
3) 未被采纳方可能累积“潜在阻力”

回写字段建议：
- `staff状态.<姓名>.动机满足度`（0~100）
- `staff状态.<姓名>.阻力`（0~100）
- `staff状态.协作度` / `staff状态.冲突值`

触发与输出：
- 输入：`staff动机` / `动机冲突` / `谁支持这个方案`
- 输出：各staff立场 + 代价比较 + 推荐折中动作

边界：
- 不允许staff越权替代法律/医疗结论
- 不允许把“动机”写成纯人设闲聊，必须给执行影响
