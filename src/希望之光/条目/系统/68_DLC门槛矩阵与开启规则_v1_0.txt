# [core]DLC门槛矩阵与开启规则（矩阵化）

## 1) DLC-A 医疗事故追责线
开启门槛：
- 主线阶段 >= 2
- 证据质量 >= 初核
- 最近违规次数 >= 1
- 风险识别等级 >= 3

## 2) DLC-B 家属与舆情线
开启门槛：
- 舆情热度 >= 50 或 媒体关注=高
- 沟通安抚等级 >= 3
- 家属关键关系均值 >= 40

## 3) DLC-C 治理与法律攻防线
开启门槛：
- 当前案件数 >= 1
- 监管关注度 >= 60
- 法律应对等级 >= 4
- 行政协同等级 >= 3

## 4) 门槛判定输出
未达标时必须列出缺失项，如：
- `缺少：证据质量>=初核`
- `缺少：法律应对等级>=4`

## 5) 开启后的统一规则
- `DLC状态.可用=true`
- 写入 `DLC状态.当前章节`
- 写入 `DLC状态.最近存档点`

## 6) 禁止强开
- 任一关键门槛未满足，不得硬进入DLC。
- 只能提示补足条件路线。

## 7) 约束
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
