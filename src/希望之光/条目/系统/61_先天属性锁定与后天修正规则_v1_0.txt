# [core]先天属性锁定与后天修正规则（判定分层）

## 1) 先天层（锁定）
- 六维先天属性写在：`/先天属性/*`
- `先天属性.锁定=true` 时，训练/升级/剧情都不得改写该层
- 违规改写视为非法回写，直接拒绝

## 2) 后天层（可变）
后天修正来自状态与环境：
- 正面：体力充沛(+1)、专注(+1)、团队协同(+1)
- 负面：疲劳(-1)、压力过高(-2)、受伤(-2)

`后天总修正 = 正面修正值 + 负面修正值`
范围夹取：`[-4, +3]`

## 3) 完整判定公式
`判定总值 = d20 + 属性修正(先天) + 技能修正 + 后天总修正 + 场景修正 + 合规修正 + staff修正 + 联动修正`

## 4) 状态阈值触发
- 体力<20 或 精神<20：高压任务禁入
- 体力<10 且精神<10：仅允许休息/求援
- 连续高压2轮：自动追加“疲劳=true”

## 5) 恢复规则
- 休息动作优先恢复体力/精神
- 医疗处置可移除“受伤”负面标记（需证据）
- 复盘成功可降低“压力过高”

## 6) 回写字段
- `/状态修正/*`
- `/主角/体力值`
- `/主角/精神值`
- `/事件标记/最近动作日志`

## 7) 约束
- 禁止通过“升级”提高先天属性。
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
