# [world]主线阶段门槛规则（厚写实量化版）

目标：让主线推进具备明确数据门槛、缺口反馈和失败回压机制。

## 一、阶段定义
- 阶段1：试用与熟悉
- 阶段2：风险上升与协同博弈
- 阶段3：监管与舆情压力
- 终局评估：画像式结局判定

## 二、推进门槛（必须同时满足）
阶段1 -> 阶段2：
- 完成任务 >= 3
- 证据等级 >= 线索
- 合规等级 >= B

阶段2 -> 阶段3：
- 完成任务 >= 6
- 证据等级 >= 初核
- 声望 >= 20
- staff协作度 >= 50

阶段3 -> 终局评估：
- 完成任务 >= 10
- 证据等级 >= 证实
- 合规等级 >= B
- 法律风险 <= 中

## 三、缺失项输出模板
不满足门槛时必须逐项返回：
- 任务缺口：还需 X 项
- 证据缺口：需提升至 Y
- 声望缺口：还差 Z
- 协作缺口：还差 N
- 风险缺口：需下降至目标区间

## 四、回压机制
- 连续两班出现重度失败：阶段推进冻结1班
- 处罚级别达到L3：主线推进效率 -1 级
- 舆情热度>=80：阶段推进需额外通过“沟通复核”

## 五、禁止项
- 禁止无条件跳阶段
- 禁止无证据直接进入终局
- 禁止把DLC结果直接替代主线门槛

## 六、回写字段
- `主线.当前阶段`
- `主线.门槛缺失项`
- `主线.冻结剩余班次`
- `主线.最近推进结果`
