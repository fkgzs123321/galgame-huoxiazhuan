# [core]UI交互控制与RPG面板规则（点击-应用-变化）

面板分区：
1. 任务区：查看任务/推进任务/班次结算
2. 地图区：查看地图/前往地点/查看当前任务
3. 人物病症区：人物详情/病症索引/病症映射
4. 技能区：技能树/技能成长/升级
5. 系统区：难度设置/DLC设置/NSFW设置/NSFW扩展开关/NSFW语料库开关/MVU设置
6. 装备区：查看背包/穿戴/卸下/应用

点击交互规则：
- 按钮只发命令，不直接改变量
- 变量改动必须经对应路由与判定链

穿戴/应用闭环（通用到其他系统）：
- `查看背包` -> 列出可用项
- `穿戴 <装备>` 或 `应用 <物品>` -> 进入判定/条件检查
- 成功后回写状态并触发描述变化
- 状态栏必须反映：当前装备、加成、持续回合

描述差异化：
- 同一动作在不同病症/地点/难度下，描述需不同
- 至少体现：风险语气、结果力度、后果入口

地图详细模式（参考四方世界）：
- 显示楼层/房间/当前坐标/可达节点
- 每个节点显示：风险等级、可互动动作、关键NPC
- 点击节点发送“前往命令”而非直接传送

约束：
- UI只是操作层，不替代规则层
- `<UpdateVariable>` 每轮仅1块，仅变化字段。
