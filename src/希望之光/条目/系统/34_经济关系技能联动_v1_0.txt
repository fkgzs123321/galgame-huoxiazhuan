# [core]经济-关系-技能联动（定量版）

## 1) 联动总公式
`最终判定修正 = 经济修正 + 关系修正 + 技能总加成修正`

并入主判定：
`判定总值 = d20 + 属性修正 + 技能修正 + 状态修正 + 场景修正 + 合规修正 + staff修正 + 最终判定修正`

## 2) 经济修正（按资金）
- 资金 >= 500：+0
- 300~499：+0
- 100~299：-1（资源紧张）
- 0~99：-2（高压短缺）
- <0：-3（债务危机）

## 3) 关系修正（按相关对象均值）
相关对象取“好感/信任/配合度”均值：
- >=80：+2
- 70~79：+1
- 40~69：0
- 25~39：-1
- <25：-2

## 4) 技能总加成修正
`技能总加成修正 = floor(总加成 / 2)`
- 总加成0~1：+0
- 2~3：+1
- 4~5：+2
- 6~7：+3
- 8~9：+4

## 5) 收支与关系反向联动
- 轻度失败：资金 -5~-15，关系 -1
- 重度失败：资金 -20~-40，关系 -2，违规计数 +1
- 标准成功：资金 +10~30，关系 +1
- 高质量成功：资金 +20~50，关系 +2

## 6) 截断规则
- 经济+关系+技能联动总修正上限：+4
- 下限：-4

## 7) 回写字段
- `/主角/资金`
- `/关系网络/*`
- `/技能成长/总加成`
- `/经济账本/*`

## 8) 约束
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
- 联动只改修正值，不得跳过掷骰直接改结论。
