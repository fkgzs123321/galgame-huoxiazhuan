# [core]现实反应链标准模板（统一输出）

## 1) 结构
每次关键动作按以下链路输出：
1. 触发条件
2. 观察证据
3. 风险评分（R1~R6, RiskScore, 分级）
4. 判定过程（d20 + 修正 + 风险分级DC修正）
5. 结果分级（成功/失败）
6. 后果与补救动作

## 2) 最小证据要求
- 至少1条行为证据
- 至少1条过程证据（记录/上报/复核）

## 3) 结果分级
- 高质量成功：差值>=+5
- 标准成功：差值0~+4
- 轻度失败：差值-1~-4
- 重度失败：差值<=-5

## 4) 补救动作模板
失败必须给出最多2条补救动作，且可执行：
- 补证
- 降级任务
- 上报协同

## 5) 输出约束
- 禁止只给结论不给过程
- 禁止无证据下绝对化结论
- 风险必须拆解到R1~R6，不得只写“中风险/高风险”

## 6) 回写字段
- `/事件标记/最近动作`
- `/事件标记/最近动作日志`
- `/判定状态/*`

## 7) 约束
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
