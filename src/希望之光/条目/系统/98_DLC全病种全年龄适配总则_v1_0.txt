# [core]DLC全病种全年龄适配总则

目标：
- DLC场景（儿童福利院/地下室/安医大/安中医/安医/省立医院）不再只按“老年病”运行。
- 支持儿童、青少年、成人、老年四年龄段的病种分流与判定差异。

年龄段分层：
1) PEDS（0-17）
2) YOUTH（18-35）
3) ADULT（36-64）
4) ELDER（65+）

适配规则：
- 进入DLC前先判定年龄段，再判定病种组。
- 同病种在不同年龄段使用不同基础DC与后果权重。
- 未明确年龄时，强制走“保守模式”（DC+1，输出补充信息要求）。

病种组：
- 呼吸组 / 循环组 / 代谢组 / 神经认知组 / 精神心理组 / 创伤术后组 / 感染组 / 慢痛组 / 发育与行为组

DLC机构差异修正：
- 儿童福利院：发育与行为组、精神心理组权重+1
- 地下室线：感染组、创伤术后组、慢痛组权重+1
- 安医大/安医/省立医院：流程与证据链要求+1级
- 安中医：长期管理与依从性评估权重+1

回写字段：
- `/事件标记/年龄段`
- `/事件标记/病种组`
- `/判定状态/最近DC`
- `/DLC状态/*`

约束：
- `<UpdateVariable>` 每轮仅1块，仅变化字段。
