# [core]DC判定最小模板（数值实装版）

## 1) 判定总公式
`判定总值 = d20 + 属性修正 + 技能修正 + 状态修正 + 场景修正 + 合规修正 + staff修正`

成功条件：`判定总值 >= 目标DC`

## 2) 目标DC分级（固定）
- DC 8：极易（教程级）
- DC 10：简单（日常低风险）
- DC 12：常规（标准流程）
- DC 14：偏难（多步骤）
- DC 16：困难（高压班次）
- DC 18：很难（高风险处置）
- DC 20：专业高压（跨岗联动）
- DC 22+：极限（仅少数场景）

## 3) 各修正项计算
### 3.1 属性修正
`属性修正 = floor((最终有效属性值 - 10) / 2)`

最终有效属性值计算：
`最终有效属性值 = clamp(基础属性 + 后天状态修正 + 场景修正 + 临时修正, 1, 30)`

说明：
- 常人常规上限20；21~30为非常态扩展档
- 判定时必须先计算最终有效属性值，再取属性修正

### 3.2 技能修正（等级1~10）
- Lv1=0, Lv2=+1, Lv3=+2, Lv4=+3, Lv5=+4,
- Lv6=+5, Lv7=+6, Lv8=+7, Lv9=+8, Lv10=+9

### 3.3 状态修正
- 体力充沛：+1
- 专注：+1
- 团队协同：+1
- 疲劳：-1
- 压力过高：-2
- 受伤：-2
- 状态修正总和上限：`[-4, +3]`

### 3.4 场景修正
- 夜班高压：-1
- 恶劣天气：-1
- 地点高风险标签：-1
- 设备/流程充分：+1
- 场景修正总和上限：`[-3, +2]`

### 3.5 合规修正
- 证据链完整 + 复核完成：+1
- 记录缺失或越级操作：-2

### 3.6 staff修正
- 协作度 >= 70：+1
- 协作度 <= 30：-1
- 冲突值 >= 60：-1

## 4) 掷骰规则
- 默认：strict_d20（1d20）
- 优势：2d20取高
- 劣势：2d20取低
- 同时存在时互相抵消
- 自然20：大成功（仅在授权边界内增强）
- 自然1：大失败（触发失败后果加重）

## 5) 越级失败规则
若技能等级 `< 任务要求等级`，直接越级失败，不掷骰。

## 6) 输出模板（必须全给）
- 任务ID/动作
- d20结果
- 目标DC
- 修正分解（属性/技能/状态/场景/合规/staff）
- 判定总值
- 结果（成功/失败/越级失败）
- 证据1~2条

## 7) 回写约束
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
- 白名单外字段拒绝回写并提示“字段越界未生效”。
