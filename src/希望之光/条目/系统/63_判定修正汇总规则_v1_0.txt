# [core]判定修正汇总规则（统一顺序）

## 1) 预检查（不通过即中止）
1. 是否已选择开局难度（未选择则中止）
2. 是否满足技能门槛（不满足=越级失败）
3. 是否满足最小证据（不满足=补证流程）
4. 是否已计算主副属性的最终有效属性值（未计算则先计算）

## 2) 固定计算顺序
`判定总值 = 掷骰结果 + 属性修正 + 技能修正 + 状态修正 + 场景修正 + 合规修正 + staff修正 + 联动修正`

`最终DC = 任务基础DC + 场景DC修正 + 开局难度DC修正`

成功条件：`判定总值 >= 最终DC`

属性修正前置：
- `最终有效属性值 = clamp(基础属性 + 后天状态修正 + 场景修正 + 临时修正, 1, 30)`
- 再计算 `属性修正 = floor((最终有效属性值 - 10) / 2)`
- 常规流程 1~20；21~30 仅特殊来源

## 3) 各修正建议范围
- 属性修正：[-3, +4]
- 技能修正：[0, +9]
- 状态修正：[-4, +3]
- 场景修正：[-3, +2]
- 合规修正：[-2, +1]
- staff修正：[-3, +2]
- 联动修正：[-4, +4]

## 4) 骰子模式
- strict_d20：1d20
- 优势：2d20取高
- 劣势：2d20取低
- 自然20：大成功（权限内）
- 自然1：大失败

## 5) 输出最小集（必须显示）
- d20
- 各修正项分解
- 判定总值
- 基础DC / 难度修正 / 最终DC
- 成功或失败

## 6) 回写字段
- `/判定状态/最近骰点`
- `/判定状态/最近判定总值`
- `/判定状态/最近DC`
- `/判定状态/最近判定结果`
- `/判定状态/有效属性/*`

## 7) 约束
- 不得跳步骤，必须按顺序。
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
