    - 技能修正: +8
    - 主关联属性: 魅力

    - R2 操作负荷强度（0~3）
    - R3 协作复杂度（0~3）

    - R6 环境资源约束（0~3）

  执行门槛:
    - 可主导高风险，必须完整证据链与上报
    - 当前技能等级 < 任务要求等级: 直接越级失败，不掷骰

  分级DC修正建议: G0:+0 / G1:+1 / G2:+2 / G3:+3 / G4:+4

  判定举例:
    - 假设主属性修正 +3，任务DC=14
    - 公式: d20 + 技能修正(+8) + 属性修正(+3) >= 14
    - 最低目标骰点: 3（近似成功率 90%）

  失败影响:
    - 本技能失败会导致对应风险链上升，且必须给出1~2条补救动作
