# [core]后勤管理Lv6细则

rule:
  触发条件:
    - 指令命中【技能细则 后勤管理 Lv6】
    - 或任务主技能=后勤管理 且当前等级=6

  等级数值:
    - 当前等级: Lv6
    - 技能修正: +5
    - 主关联属性: 智力
    - 推荐DC区间: 14~16
    - 可承担风险上限: G2（RiskScore 9~12）

  风险分级（统一标准）:
    - G1可控风险（RiskScore 5~8）: 中等危险=关键耗材临界库存调配
    - G3重大风险（RiskScore 13~15）: 高等危险=高压班次供给中断风险处置

  可执行动作（现实对标）:
    - 耗材阈值预警
    - 跨区调配
    - 高压供给保障


  风险点打分清单:
    - R1 病情波动强度（0~3）
    - R2 操作负荷强度（0~3）
    - R3 协作复杂度（0~3）
    - R4 证据完整度风险（0~3）
    - R5 时间窗口压力（0~3）
    - R6 环境资源约束（0~3）
    - RiskScore = R1+R2+R3+R4+R5+R6（0~18）

  执行门槛:
    - 可执行中风险多步骤任务，需复核
    - 当前技能等级 < 任务要求等级: 直接越级失败，不掷骰

  分级DC修正建议: G0:+0 / G1:+1 / G2:+2 / G3:+3 / G4:+4

  判定举例:
    - 假设主属性修正 +2，任务DC=13
    - 公式: d20 + 技能修正(+5) + 属性修正(+2) >= 13
    - 最低目标骰点: 6（近似成功率 75%）

  失败影响:
    - 本技能失败会导致对应风险链上升，且必须给出1~2条补救动作
