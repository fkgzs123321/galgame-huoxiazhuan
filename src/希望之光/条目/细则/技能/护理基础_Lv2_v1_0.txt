# [core]护理基础Lv2细则

rule:
  触发条件:
    - 指令命中【技能细则 护理基础 Lv2】
    - 或任务主技能=护理基础 且当前等级=2

  等级数值:
    - 当前等级: Lv2
    - 技能修正: +1
    - 主关联属性: 体质/敏捷
    - 推荐DC区间: 10~12
    - 可承担风险上限: G0~G1（RiskScore 0~8）

  风险分级（统一标准）:
    - G1可控风险（RiskScore 5~8）: 中等危险=需复核的体位转移、多步骤护理、中度跌倒预防处置
    - G3重大风险（RiskScore 13~15）: 高等危险=疑似危重转移、呼吸循环不稳时的短窗护理处置

  可执行动作（现实对标）:
    - 翻身与压疮预防
    - 床椅转移
    - 夜间异常体征处置


  风险点打分清单:
    - R1 病情波动强度（0~3）
    - R2 操作负荷强度（0~3）
    - R3 协作复杂度（0~3）
    - R4 证据完整度风险（0~3）
    - R5 时间窗口压力（0~3）
    - R6 环境资源约束（0~3）
    - RiskScore = R1+R2+R3+R4+R5+R6（0~18）

  执行门槛:
    - 仅可执行低风险单步骤任务
    - 当前技能等级 < 任务要求等级: 直接越级失败，不掷骰

  分级DC修正建议: G0:+0 / G1:+1 / G2:+2 / G3:+3 / G4:+4

  判定举例:
    - 假设主属性修正 +1，任务DC=11
    - 公式: d20 + 技能修正(+1) + 属性修正(+1) >= 11
    - 最低目标骰点: 9（近似成功率 60%）

  失败影响:
    - 本技能失败会导致对应风险链上升，且必须给出1~2条补救动作

format: |-
  本轮结果：命中护理基础 Lv2，技能修正 +1。
  关键变化：输出风险上限、可执行动作、判定门槛与示例。
  下一步建议：若任务风险超过上限，先降级或调用协作资源。
