# [world]201病房区（L-004）

场景定位：
- 心衰与体位管理重点区域，强调呼吸节律与体位流程一致性。

场景标签：
- 风险等级：中-高
- 主技能：护理基础（副技能：风险识别）
- 主属性：CON（副属性：WIS）

环境风险：
- 体位流程失误会放大呼吸负担与失败后果。

可互动动作：
- 【推进任务】
- 【状态总览】
- 【班次结算】
- 【体位复核】

判定修正：
- 体位流程完整：护理基础判定 +1
- 高压连班：体力消耗额外 +2
- 授权缺失执行高压动作：直接越级失败

后果入口：
- 流程缺失 -> 信任下降 + 监管关注风险上升
- 复核完整 -> 危重链触发概率下降

回写规范：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。

执行模板（固定顺序）：
1) 场景确认：确认地点与当前任务目标
2) 门槛校验：难度已锁定、授权状态、证据链完整度
3) 判定计算：d20 + 主属性修正 + 主技能修正 + 状态修正 + 场景修正
4) 后果分发：按事故/治理/法律/经济/关系入口分发
5) 最小回写：所在地 + 最近动作 + 动作序列号

失败保护：
- 单轮失败不直接判死局，先进入“复盘/补证/二次执行”
- 连续失败>=2时，强制给出两条可执行补救动作

输出格式：
- 结果叙事（不超过5句）
- <UpdateVariable>（RFC6902，仅变化字段）
- <StatusBlock>（体力/精神/风险/任务）
