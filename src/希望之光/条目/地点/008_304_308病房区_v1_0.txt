# [world]304-308病房区（L-008）

场景定位：
- 多病叠加高密度区，复核与后勤压力同步存在。

场景标签：
- 风险等级：高
- 主技能：风险识别（副技能：后勤管理）
- 主属性：WIS（副属性：INT）

可互动动作：
- 【推进任务】
- 【后勤技能】
- 【法律风险】
- 【复核上报】

判定修正：
- 补给充足：后勤管理 +1
- 复核缺失：风险识别 -1
- 关键耗材短缺：最终DC +1

后果入口：
- 连续失误 -> 治理/法律链触发概率上升
- 复核完整 -> 风险链权重下降

证据要求：
- 必须包含补给状态与复核记录。

回写规范：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。

执行模板（固定顺序）：
1) 场景确认：确认地点与当前任务目标
2) 门槛校验：难度已锁定、授权状态、证据链完整度
3) 判定计算：d20 + 主属性修正 + 主技能修正 + 状态修正 + 场景修正
4) 后果分发：按事故/治理/法律/经济/关系入口分发
5) 最小回写：所在地 + 最近动作 + 动作序列号

失败保护：
- 单轮失败不直接判死局，先进入“复盘/补证/二次执行”
- 连续失败>=2时，强制给出两条可执行补救动作

输出格式：
- 结果叙事（不超过5句）
- <UpdateVariable>（RFC6902，仅变化字段）
- <StatusBlock>（体力/精神/风险/任务）
