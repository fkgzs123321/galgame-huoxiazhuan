# [world]走廊与交接点（L-006）

场景定位：
- 班次交接与突发分流核心节点，影响信息完整性与执行连贯性。

场景标签：
- 风险等级：中
- 主技能：行政协同（副技能：沟通安抚）
- 主属性：INT（副属性：CHA）

环境风险：
- 交接拥堵、信息遗漏、口头传递失真。

可互动动作：
- 【交接上报】
- 【推进任务】
- 【状态总览】
- 【关系总览】

判定修正：
- 交接记录完整：行政协同 +1
- 仅口头交接无记录：合规修正 -2
- 高峰拥堵时段：场景修正 -1

后果入口：
- 交接缺失 -> 任务错漏率上升，冲突值+1
- 分层交接完成 -> 协作度+1，后续任务DC -1（仅下一轮）

回写规范：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。

执行模板（固定顺序）：
1) 场景确认：确认地点与当前任务目标
2) 门槛校验：难度已锁定、授权状态、证据链完整度
3) 判定计算：d20 + 主属性修正 + 主技能修正 + 状态修正 + 场景修正
4) 后果分发：按事故/治理/法律/经济/关系入口分发
5) 最小回写：所在地 + 最近动作 + 动作序列号

失败保护：
- 单轮失败不直接判死局，先进入“复盘/补证/二次执行”
- 连续失败>=2时，强制给出两条可执行补救动作

输出格式：
- 结果叙事（不超过5句）
- <UpdateVariable>（RFC6902，仅变化字段）
- <StatusBlock>（体力/精神/风险/任务）
