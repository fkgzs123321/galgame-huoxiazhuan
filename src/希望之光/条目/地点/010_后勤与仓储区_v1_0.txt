# [world]后勤与仓储区（L-010）

场景定位：
- 物资调配、成本控制、补给审批核心区。

场景标签：
- 风险等级：中
- 主技能：后勤管理（副技能：行政协同）
- 主属性：INT（副属性：WIS）

可互动动作：
- 【后勤技能】
- 【经济状态】
- 【外部环境】
- 【补给申请】

判定修正：
- 申请字段完整：后勤管理 +1
- 申请缺字段：后勤管理 -1
- 通胀=高：支出倍率 +20%

后果入口：
- 关键短缺未处置 -> 中高压事件权重上升
- 调配成功 -> 成本压力下降，供给稳定度上升

证据要求：
- 申请单至少包含用途、优先级、数量、审批人。

回写规范：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。

执行模板（固定顺序）：
1) 场景确认：确认地点与当前任务目标
2) 门槛校验：难度已锁定、授权状态、证据链完整度
3) 判定计算：d20 + 主属性修正 + 主技能修正 + 状态修正 + 场景修正
4) 后果分发：按事故/治理/法律/经济/关系入口分发
5) 最小回写：所在地 + 最近动作 + 动作序列号

失败保护：
- 单轮失败不直接判死局，先进入“复盘/补证/二次执行”
- 连续失败>=2时，强制给出两条可执行补救动作

输出格式：
- 结果叙事（不超过5句）
- <UpdateVariable>（RFC6902，仅变化字段）
- <StatusBlock>（体力/精神/风险/任务）
