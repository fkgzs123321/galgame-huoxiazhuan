# [world]101-103病房区（L-002）

场景定位：
- 认知/运动/代谢问题集中区，任务密度高。

环境风险：
- 沟通失误与转移动作冲突导致失败率上升。
- 高峰时段交接拥堵，遗漏风险提高。

可互动动作：
- 【推进任务】
- 【巡查】
- 【关系总览】
- 【风险复核】

判定修正：
- 白天常规时段：沟通安抚判定 +1
- 连续高压后：护理基础判定 -1
- 交接完整度>=80：合规修正 +1

后果入口：
- 巡查缺失 -> 跌倒与冲突事件权重上升
- 分步执行 -> 配合度与信任小幅上升
- 连续漏记 -> 触发 staff治理节点

证据要求：
- 至少1条巡查证据（时间戳/观察项）
- 至少1条处置证据（动作/结果）

回写规范：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
- 必须回写：`/主角/所在地` `/事件标记/最近动作`。

执行模板（固定顺序）：
1) 场景确认：确认地点与当前任务目标
2) 门槛校验：难度已锁定、授权状态、证据链完整度
3) 判定计算：d20 + 主属性修正 + 主技能修正 + 状态修正 + 场景修正
4) 后果分发：按事故/治理/法律/经济/关系入口分发
5) 最小回写：所在地 + 最近动作 + 动作序列号

失败保护：
- 单轮失败不直接判死局，先进入“复盘/补证/二次执行”
- 连续失败>=2时，强制给出两条可执行补救动作

输出格式：
- 结果叙事（不超过5句）
- <UpdateVariable>（RFC6902，仅变化字段）
- <StatusBlock>（体力/精神/风险/任务）
