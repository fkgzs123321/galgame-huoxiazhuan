# [world]护士站（L-001）

场景定位：
- 调度、记录、交接、任务派发核心点。

场景标签：
- 风险等级：中
- 主技能：行政协同（副技能：法律应对）
- 主属性：INT（副属性：WIS）

可互动动作：
- 【查看任务】
- 【班次结算】
- 【状态总览】
- 【时间校验】
- 【交接上报】

判定修正：
- 早班记录完整：行政协同 +1
- 夜班交接拥堵：行政协同 -1
- 缺少上报对象字段：合规修正 -1

后果入口：
- 漏登记 -> 合规风险+1
- 交接完整 -> 协作度 +1
- 连续漏报 -> 治理/法律链权重上升

证据要求：
- 交接记录必须含：时间、责任人、观察项、处置、上报对象。

回写规范：
- 必写：`/主角/所在地` `/事件标记/最近动作`
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。

执行模板（固定顺序）：
1) 场景确认：确认地点与当前任务目标
2) 门槛校验：难度已锁定、授权状态、证据链完整度
3) 判定计算：d20 + 主属性修正 + 主技能修正 + 状态修正 + 场景修正
4) 后果分发：按事故/治理/法律/经济/关系入口分发
5) 最小回写：所在地 + 最近动作 + 动作序列号

失败保护：
- 单轮失败不直接判死局，先进入“复盘/补证/二次执行”
- 连续失败>=2时，强制给出两条可执行补救动作

输出格式：
- 结果叙事（不超过5句）
- <UpdateVariable>（RFC6902，仅变化字段）
- <StatusBlock>（体力/精神/风险/任务）

交接字段白名单：时间、责任人、观察项、处置、上报对象、复核人。
