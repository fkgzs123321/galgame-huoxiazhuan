# [world]303病房区（L-005）

场景定位：
- 慢阻肺高风险点，夜间波动明显。

场景标签：
- 风险等级：高
- 主技能：风险识别（副技能：护理基础）
- 主属性：WIS（副属性：CON）

环境风险：
- 夜班 + 低温天气叠加时风险显著上升。

可互动动作：
- 【推进任务】
- 【天气影响】
- 【危重状态】
- 【复核上报】

判定修正：
- 高温/寒潮：后天状态修正额外 -1
- 评估完整：风险识别 +1
- 夜班且证据不足：合规修正 -1

后果入口：
- 评估缺失 -> 高压事件概率上升
- 连续复核成功 -> 事故链风险下降

回写规范：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。

执行模板（固定顺序）：
1) 场景确认：确认地点与当前任务目标
2) 门槛校验：难度已锁定、授权状态、证据链完整度
3) 判定计算：d20 + 主属性修正 + 主技能修正 + 状态修正 + 场景修正
4) 后果分发：按事故/治理/法律/经济/关系入口分发
5) 最小回写：所在地 + 最近动作 + 动作序列号

失败保护：
- 单轮失败不直接判死局，先进入“复盘/补证/二次执行”
- 连续失败>=2时，强制给出两条可执行补救动作

输出格式：
- 结果叙事（不超过5句）
- <UpdateVariable>（RFC6902，仅变化字段）
- <StatusBlock>（体力/精神/风险/任务）

低氧预警阈值：出现连续异常征象时，下一轮自动触发危重协同检查。
