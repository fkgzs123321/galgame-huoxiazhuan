# [world]护理组工作区（L-009）

场景定位：
- 治理、合规、法律协同核心节点。

场景标签：
- 风险等级：中-高
- 主技能：行政协同（副技能：法律应对）
- 主属性：INT（副属性：WIS）

可互动动作：
- 【护理组状态】
- 【治理生态】
- 【法律风险】
- 【DLC状态】
- 【动机冲突】

判定修正：
- 流程完整：行政协同 +1
- 流程缺失：法律应对 -1
- 冲突值>=60：下轮判定 -1

后果入口：
- 复盘不足 -> 舆情与监管压力持续
- 协调成功 -> 协作度 +1，冲突值 -1

证据要求：
- 必须给出冲突焦点与方案代价。

回写规范：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。

执行模板（固定顺序）：
1) 场景确认：确认地点与当前任务目标
2) 门槛校验：难度已锁定、授权状态、证据链完整度
3) 判定计算：d20 + 主属性修正 + 主技能修正 + 状态修正 + 场景修正
4) 后果分发：按事故/治理/法律/经济/关系入口分发
5) 最小回写：所在地 + 最近动作 + 动作序列号

失败保护：
- 单轮失败不直接判死局，先进入“复盘/补证/二次执行”
- 连续失败>=2时，强制给出两条可执行补救动作

输出格式：
- 结果叙事（不超过5句）
- <UpdateVariable>（RFC6902，仅变化字段）
- <StatusBlock>（体力/精神/风险/任务）
