# [world]106病房区（L-003）

场景定位：
- 呼吸风险高发区，需高频观察与复核。

环境风险：
- 夜班低氧征象漏检风险高。
- 处置顺序错误会放大急性加重风险。

可互动动作：
- 【推进任务】
- 【危重状态】
- 【随机事件】
- 【复核上报】

判定修正：
- 夜班：风险识别判定 -1
- 复核完整：风险识别判定 +1
- 多岗协同成功：合规修正 +1

后果入口：
- 漏检 -> 危重链触发概率上升
- 分步评估 -> 事故链风险下降
- 连续复核失败 -> 法律风险链权重上升

证据要求：
- 行为证据：观察项变化（呼吸/意识/活动）
- 过程证据：复核记录、上报记录、时间线

回写规范：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
- 必须回写：`/主角/所在地` `/事件标记/*` `/合规状态/*`

执行模板（固定顺序）：
1) 场景确认：确认地点与当前任务目标
2) 门槛校验：难度已锁定、授权状态、证据链完整度
3) 判定计算：d20 + 主属性修正 + 主技能修正 + 状态修正 + 场景修正
4) 后果分发：按事故/治理/法律/经济/关系入口分发
5) 最小回写：所在地 + 最近动作 + 动作序列号

失败保护：
- 单轮失败不直接判死局，先进入“复盘/补证/二次执行”
- 连续失败>=2时，强制给出两条可执行补救动作

输出格式：
- 结果叙事（不超过5句）
- <UpdateVariable>（RFC6902，仅变化字段）
- <StatusBlock>（体力/精神/风险/任务）
