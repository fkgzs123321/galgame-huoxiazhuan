# [world]202-204病房区（L-007）

场景定位：
- 卒中后遗/骨关节/抑郁混合区，转移风险与情绪风险并行。

场景标签：
- 风险等级：中-高
- 主技能：护理基础（副技能：沟通安抚）
- 主属性：DEX（副属性：CHA）

可互动动作：
- 【推进任务】
- 【护理技能】
- 【沟通技能】
- 【风险复核】

判定修正：
- 主副技能匹配：复合判定 +1
- 忽略沟通节律：沟通安抚判定 -1
- 连续高压班次：体力消耗额外 +2

后果入口：
- 处置失衡 -> 跌倒或冲突链上升
- 分步沟通 + 分步转移 -> 配合度小幅上升

证据要求：
- 至少1条行为证据 + 1条过程证据（记录/上报）。

回写规范：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。

执行模板（固定顺序）：
1) 场景确认：确认地点与当前任务目标
2) 门槛校验：难度已锁定、授权状态、证据链完整度
3) 判定计算：d20 + 主属性修正 + 主技能修正 + 状态修正 + 场景修正
4) 后果分发：按事故/治理/法律/经济/关系入口分发
5) 最小回写：所在地 + 最近动作 + 动作序列号

失败保护：
- 单轮失败不直接判死局，先进入“复盘/补证/二次执行”
- 连续失败>=2时，强制给出两条可执行补救动作

输出格式：
- 结果叙事（不超过5句）
- <UpdateVariable>（RFC6902，仅变化字段）
- <StatusBlock>（体力/精神/风险/任务）
