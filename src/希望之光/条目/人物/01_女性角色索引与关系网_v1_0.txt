# [npc]女性角色索引与关系网（全员入口）

说明：
- 除 user 外，全角色默认为女性。
- 本索引用于“全员关系查看 + 自动生成角色接入”。

固定角色分组：
1) 老人住户（101~308）
2) 护理组与管理组（401~406）
3) 家属与外部关联角色（按剧情解锁）

自动生成角色：
- 命令：`【生成NPC 护工|社工|医生|后勤|保安】`
- 生成后自动写入：
  - `/模板引擎/最近生成NPC`
  - `/模板引擎/已生成数量`
  - `/老人关系列表/<姓名>/核心病症`（如适用）

关系查看命令：
- `【关系总览】`：显示全员分组统计与风险分层
- `【关系详情 <姓名>】`：显示单人关系值、最近互动证据、可执行下一步
- `【女性角色索引】`：显示可点名名单（分页）

分页规则：
- 每页最多显示10名，避免状态栏爆长
- 可用命令：`【女性角色索引 第1页】` / `第2页` ...

约束：
- 路由层只分发，不承载长正文
- `<UpdateVariable>` 每轮仅1块，仅变化字段
