# [npc]NPC单文件索引（兼容入口）

用途：
- 兼容旧调用名，统一转发到正式人物条目。

正式入口：
- 主索引：`00_人物索引_v1_0.txt`
- 单人条目：`101~406_*_v1_0.txt`

转发规则：
1. 输入 `NPC索引` / `人物索引` -> 转发到 `00_人物索引_v1_0.txt`
2. 输入人物姓名 -> 转发到对应人物条目（命中人物路由）
3. legacy别名 -> 先归一化到现名再转发

输出规范：
- 仅返回“目标条目 + 可执行下一步”，不承载长正文。
- 人物正文统一在目标条目输出“触发-证据-反应-后果”。

约束：
- 本文件不直接承载判定公式与剧情正文。
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。

执行模板（固定顺序）：
1) 场景确认：确认地点与当前任务目标
2) 门槛校验：难度已锁定、授权状态、证据链完整度
3) 判定计算：d20 + 主属性修正 + 主技能修正 + 状态修正 + 场景修正
4) 后果分发：按事故/治理/法律/经济/关系入口分发
5) 最小回写：所在地 + 最近动作 + 动作序列号

失败保护：
- 单轮失败不直接判死局，先进入“复盘/补证/二次执行”
- 连续失败>=2时，强制给出两条可执行补救动作

输出格式：
- 结果叙事（不超过5句）
- <UpdateVariable>（RFC6902，仅变化字段）
- <StatusBlock>（体力/精神/风险/任务）

路由优先级：精确姓名 > 房号+姓名 > legacy别名。冲突时返回候选列表，不做猜测。
