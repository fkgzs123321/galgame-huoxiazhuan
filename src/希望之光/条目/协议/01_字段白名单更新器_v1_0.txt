# [core]字段白名单更新器（统一版）

rule:
  - 仅执行白名单路径 patch
  - 越界 patch 丢弃并记录

format:
  - 通过：执行最小合法 patch
  - 不通过：仅保留合法 patch，必要时写 no-op

仅允许更新以下路径前缀：
- /世界
- /主角
- /任务日志
- /判定状态
- /经济账本
- /关系网络
- /技能成长
- /合规状态
- /主线状态
- /叙事控制
- /模板引擎
- /外部系统
- /DLC状态
- /主角/NSFW状态
- /老人关系列表
- /病症映射
- /事件标记

病症与模板专项：
- 允许 `/老人关系列表/<姓名>/核心病症` 写入病症ID（如 D-POSTOP-IMPAIR）
- 允许 `/病症映射/<病症ID>/关联老人` 维护映射关系
- 允许 `/模板引擎/*` 记录模板生成与入库状态

拒绝策略：
- 命中白名单外字段时：忽略该patch并记录“字段越界”
- 若同轮混入越界字段：仅执行合法patch，越界项进入日志

约束：
- `<UpdateVariable>` 每轮仅1块
- 仅变化字段，禁止整树覆盖

风险评分专项：
- 当命中任务推进/判定细节相关指令时，必须允许并优先保留以下路径：
  - `/判定状态/风险评分/R1病情波动强度`
  - `/判定状态/风险评分/R2操作负荷强度`
  - `/判定状态/风险评分/R3协作复杂度`
  - `/判定状态/风险评分/R4证据完整度风险`
  - `/判定状态/风险评分/R5时间窗口压力`
  - `/判定状态/风险评分/R6环境资源约束`
  - `/判定状态/风险评分/RiskScore`
  - `/判定状态/风险评分/风险分级`
  - `/判定状态/风险评分/分级DC修正`
