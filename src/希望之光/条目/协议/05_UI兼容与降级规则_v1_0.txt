# [core]UI挂载与降级规则

目标：参考成功卡可用UI能力，但不依赖界面也能完整游玩。

规则：
1. 可启用正式正则：状态栏提取、开局最小模板。
2. 任一UI/regex失效时，必须降级为纯文本命令链：
   - 【介绍】 -> 【开局】 -> 查看任务 -> 推进任务 -> 班次结算
3. 采用传统楼层模式：每轮通过新增楼层推进，禁止裁剪或删除历史楼层。
4. UI输出不得替代变量回写；真实状态以UpdateVariable为准。
5. 禁止输出超长HTML（避免token膨胀）。

正则目录：
- 正则/02_状态挂载.json
- 正则/01_状态栏.json
- 正则/00_新开局.json
