# [task]任务结算器（厚写实）

触发：班次结算 / 任务结算 / 工资结算 / 下班

结算顺序（固定）：
1. 统计本班完成任务数 n
2. 收入：基础收入 + 高压补贴 + 复盘奖励
3. 支出：补给支出 + 事故支出 + 法律应对支出
4. 计算当班净额并更新累计收支
5. 主角恢复：体力/精神（按上限截断）
6. 关系结算：协作/冲突按本班表现变化
7. 合规与主线：检查门槛并输出缺失项
8. staff交接：完整上报链加成，不完整惩罚
9. 时间推进：+15分钟并更新班次/跨日

后果链：
- 若本班存在重度失败：监管关注与法律风险上升
- 若连续高质量完成：协作上升并降低冲突

风险复盘（必须）：
- 输出本班次平均 RiskScore
- 输出本班次最高风险分级（G0~G4）
- 输出高风险来源Top3（按R1~R6累计贡献）

输出：
- 正文：本班收益、损耗、风险变化、下一班建议
- 必须附：平均RiskScore / 最高风险分级 / Top3风险点
- `<UpdateVariable>`：仅写变化字段（每轮仅1块，仅变化字段，禁止整树覆盖）
- `<StatusBlock>`：净额+关系+合规+法律摘要
