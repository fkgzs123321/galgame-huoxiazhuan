# [task]任务推进器（厚写实）

触发：推进任务 / 执行任务 / 开始做任务

前置：
1. 若进行中为空，从可接任务取第一条
2. 若仍为空，回跳任务生成器
3. 等级检查：主技能等级 < 要求等级 -> 越级失败（不掷骰）
4. 风险评分：先计算 R1~R6 与 RiskScore，再进入判定

风险评分（强制）：
- R1 病情波动强度（0~3）
- R2 操作负荷强度（0~3）
- R3 协作复杂度（0~3）
- R4 证据完整度风险（0~3）
- R5 时间窗口压力（0~3）
- R6 环境资源约束（0~3）
- RiskScore = R1+R2+R3+R4+R5+R6（0~18）
- 风险分级：G0(0~4)/G1(5~8)/G2(9~12)/G3(13~15)/G4(16~18)
- 分级DC修正：G0:+0 / G1:+1 / G2:+2 / G3:+3 / G4:+4

判定顺序（固定，不可跳步）：
1. d20（strict_d20）
2. 属性修正（最终有效属性值）
3. 主技能修正
4. 副技能修正（上限+2）
5. 后天状态修正（正+负）
6. 场景修正
7. 合规修正
8. staff修正
9. 天气/节假日修正
10. 风险分级DC修正
11. 与最终DC比较

结果分层：
- 成功：完成任务并回写收益/关系/经验/合规推进
- 失败-轻：数值小幅下降+补救建议
- 失败-中：罚款/冲突/证据回退
- 失败-重：进入事故或危重分支
- 越级失败：违规+1、声望-1、返回降级路径

数值边界：
- 单轮变化遵循防膨胀总则
- 禁止无证据跳到重后果

输出：
- 正文：证据->风险评分->判定->结果->下一步
- 必须显示：R1~R6、RiskScore、风险分级、分级DC修正
- `<UpdateVariable>`：仅写变化字段（每轮仅1块，仅变化字段，禁止整树覆盖）
- 必回写路径：
  - `/判定状态/风险评分/R1病情波动强度`
  - `/判定状态/风险评分/R2操作负荷强度`
  - `/判定状态/风险评分/R3协作复杂度`
  - `/判定状态/风险评分/R4证据完整度风险`
  - `/判定状态/风险评分/R5时间窗口压力`
  - `/判定状态/风险评分/R6环境资源约束`
  - `/判定状态/风险评分/RiskScore`
  - `/判定状态/风险评分/风险分级`
  - `/判定状态/风险评分/分级DC修正`
- `<StatusBlock>`：显示骰点/总值/基础DC/风险修正/最终DC/结果+核心状态
