# [task]任务生成器（厚写实）

触发：查看任务 / 可接任务 / 任务池 / 今日安排

MVU最小注入：
- 仅注入最多3条任务
- 每条任务字段固定：
  - 任务ID
  - 名称
  - 基础DC
  - 预计耗时分钟
  - 经济奖励
  - 技能侧重
  - 副技能（可空）
  - 要求等级（1~10）
  - 风险等级（低/中/高）

分发规则：
1. 若可接任务非空：直接返回当前任务池
2. 若为空：按主技能等级生成 Tier 匹配任务
3. 连续失败>=2：强制加入1条降级恢复任务
4. 禁止生成超过主技能等级+1的任务

现实约束：
- 高风险任务必须包含“需协同”标记
- 法律/治理压力高时，优先插入复核与记录任务

输出：
- 正文：本轮任务池摘要（不超过5行）
- `<UpdateVariable>`：仅写任务池变化与最近动作（每轮仅1块，仅变化字段，禁止整树覆盖）
- `<StatusBlock>`：任务计数+当前资源摘要
