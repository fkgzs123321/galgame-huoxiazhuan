# [task]任务异常与失败（厚写实）

触发：任务失败 / 任务异常 / 越级操作 / 流程违规

失败分类：
1. 证据不足（记录不全/观察不足）
2. 流程违规（漏报/漏复核/越权）
3. 技能不足（等级不达标）
4. 状态崩溃（体力/精神/生理阈值过低）

后果分级：
- 轻度：体力/精神/关系小幅下降
- 中度：罚款、冲突上升、证据质量回退
- 重度：事故分支（创伤/危重/死亡规则联动）

强制流程：
1. 给出失败证据
2. 标记失败级别
3. 写明数值变化
4. 给补救动作（最多2条）

硬约束：
- 禁止无证据“突然死亡”
- 禁止跳过上报协同继续普通叙事
- 保底补贴仅防死局，不清除事故后果

输出：
- 正文：失败结论+证据+后果+补救
- `<UpdateVariable>`：仅写变化字段
- `<StatusBlock>`：失败级别与风险摘要
