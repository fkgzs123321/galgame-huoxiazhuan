# [disease]慢阻肺

风险分层：
- 轻度：活动后短促不适
- 中度：日常活动受限，夜间波动
- 重度：低氧风险高，急性加重概率大

主判定映射：
- 主技能：风险识别
- 副技能：护理基础
- 主属性：WIS（副属性：CON）

判定公式（本病症场景）：
- `病症判定总值 = d20 + WIS修正 + 风险识别修正 + 护理基础折算 + 状态修正 + 场景修正`

基础DC：
- 呼吸状态评估：12
- 分步转移协助：13
- 急性加重预警与上报：15

附加修正：
- 夜班：DC +1
- 寒潮/高温：DC +1
- 评估记录完整：DC -1

触发条件（任意2项）：
1) 高压动作前未评估呼吸状态
2) 夜班巡查间隔过长
3) 感染预警信号未复核
4) 连续任务导致体力下降

行为证据：
- 呼吸频率增快、语句缩短
- 夜间不适与焦虑同步上升
- 活动后恢复显著延长

成功后果：
- 风险等级维持或下调
- 配合度 +1~2
- 护理基础/风险识别经验增加

失败后果：
- 风险等级上调
- 事故分支权重上升
- 连续失败触发危重链

禁忌：
- 忽略低氧征象
- 用情绪解释替代呼吸风险判断

回写约束：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
