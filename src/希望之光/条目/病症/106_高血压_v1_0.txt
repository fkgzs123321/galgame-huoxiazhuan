# [disease]高血压

风险分层：
- 轻度：波动可控
- 中度：波动频繁，需复测
- 重度：持续高风险，需协同干预

主判定映射：
- 主技能：风险识别
- 副技能：沟通安抚
- 主属性：WIS（副属性：CHA）

判定公式（本病症场景）：
- `病症判定总值 = d20 + WIS修正 + 风险识别修正 + 沟通折算 + 状态修正 + 场景修正`

基础DC：
- 波动复测与记录：11
- 高风险复核上报：13
- 并发风险协同：15

附加修正：
- 情绪激惹未降压：DC +1
- 复测时间线完整：DC -1
- 夜班连班：DC +1

触发条件（任意2项）：
1) 情绪波动 + 睡眠差
2) 连续连班未复测
3) 记录缺失或延迟
4) 合并头晕不适

行为证据：
- 头晕、烦躁、注意力下降
- 波动复测差值异常

成功后果：
- 风险等级维持或下调
- 信任 +1
- 风险识别经验 +8~12

失败后果：
- 风险等级上调
- 合规风险 +1
- 连续失败触发治理关注

禁忌：
- 单次观察替代连续复测
- 缺证据给稳定结论

回写约束：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
