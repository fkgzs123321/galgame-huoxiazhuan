# [disease]血管性痴呆

风险分层：
- 轻度：日常可控，需要常规观察
- 中度：波动明显，需要持续复核
- 重度：高风险，必须协同上报

主判定映射：
- 主技能：风险识别
- 副技能：沟通安抚
- 主属性：WIS（副属性：INT）

判定公式（本病症）：
- 病症判定总值 = d20 + 主属性修正 + 主技能修正 + floor(副技能修正/2) + 状态修正 + 场景修正 + 合规修正
- 成功条件：病症判定总值 >= 最终DC

基础DC：
- 功能波动识别：DC12
- 任务分步引导：DC13
- 升级协同：DC15

附加修正：
- 夜班：最终DC +1
- 证据链完整且复核完成：最终DC -1
- 连续疲劳或情绪高压：最终DC +1

触发条件（任意2项）：
1) 关键观察项缺失或记录延迟
2) 高风险动作前未做预评估
3) 连续班次导致状态下滑
4) 同类风险事件在24小时内重复出现

行为证据：
- 体征/行为波动有时间线记录
- 处置动作与上报节点可追溯
- 结果与复盘结论一致

成功后果：
- 风险等级维持或下调1级
- 相关关系值 +1~2
- 主技能经验 +10~14，副技能经验 +4~6

失败后果：
- 风险等级上调1级
- 合规状态.最近违规次数 +1（若漏记/漏报）
- 连续失败2轮触发事故或危重链

禁忌：
- 无证据直接下确定性结论
- 跳过上报流程直接宣布稳定

回写约束：
- <UpdateVariable> 每轮仅1块，仅变化字段，禁止整树覆盖。
