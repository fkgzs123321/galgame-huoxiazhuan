# [disease]截瘫长期照护

风险分层：
- 轻度：功能受限可补偿，需要常规支持
- 中度：功能受限明显，需要持续协助与复核
- 重度：高依赖状态，需要多专业协同与保护流程

主判定映射：
- 主技能：护理基础
- 副技能：风险识别
- 主属性：CON（副属性：WIS）

判定公式（本病症）：
- 病症判定总值 = d20 + 主属性修正 + 主技能修正 + floor(副技能修正/2) + 状态修正 + 场景修正 + 合规修正
- 成功条件：病症判定总值 >= 最终DC

基础DC：
- 压疮与感染风险识别：DC14
- 体位与减压执行：DC15
- 恶化上报协同：DC17

附加修正：
- 夜班/高压连续班次：最终DC +1
- 证据链完整且复核完成：最终DC -1
- 辅具缺失或场景不适配：最终DC +1

触发条件（任意2项进入中高压链）：
1) 功能评估缺失或记录延迟
2) 支持动作前未做风险预评估
3) 同类异常在24小时内重复出现
4) 协同计划与执行出现明显偏差

行为证据要求：
- 至少1条功能变化或行为变化证据
- 至少1条过程证据（处置/上报/复核）
- 结论必须与证据方向一致，禁止跳步定性

成功后果：
- 风险维持或下降1级
- 配合度与信任小幅提升
- 主技能经验 +10~14，副技能经验 +4~6

失败后果：
- 风险上调1级
- 合规状态.最近违规次数 +1（若漏记/漏报）
- 连续失败2轮触发事故/舆情/法律压力链

DLC适配：
- 儿童福利院/地下室/安医大/安中医/安医/省立医院场景按机构规则提高审查强度
- 跨机构协同时优先校验来源链与合法性

回写约束：
- <UpdateVariable> 每轮仅1块，仅变化字段，禁止整树覆盖。
