# [disease]慢性肾病

风险分层：
- 轻度：慢性管理为主
- 中度：波动风险上升
- 重度：并发风险明显，需严密复核

主判定映射：
- 主技能：风险识别
- 副技能：后勤管理（资源与饮食执行）
- 主属性：WIS（副属性：INT）

判定公式（本病症场景）：
- `病症判定总值 = d20 + WIS修正 + 风险识别修正 + 后勤折算 + 状态修正 + 合规修正`

基础DC：
- 日常风险观察与记录：12
- 波动复核与分级上报：14
- 并发风险协同处置：16

附加修正：
- 饮食/补给执行断档：DC +1
- 记录完整且复核到位：DC -1
- 连续高压班次：DC +1

触发条件（任意2项）：
1) 饮食管理中断
2) 关键记录缺失
3) 连班疲劳叠加
4) 合并症状未复核

行为证据：
- 乏力、食欲差、状态波动
- 观察项连续异常

成功后果：
- 风险等级可下调
- 信任 +1~2
- 风险识别/后勤经验增加

失败后果：
- 风险等级上调
- 合规风险 +1
- 连续失败触发法律后果链权重上升

禁忌：
- 忽略连续趋势只看单点
- 无证据写“维持稳定”

回写约束：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
