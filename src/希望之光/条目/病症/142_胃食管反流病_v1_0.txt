# [disease]胃食管反流病

风险分层：
- 轻度：日常可控，需要规律观察与记录
- 中度：波动明显，需要复核与协同
- 重度：高风险，需优先上报并进入保护流程

主判定映射：
- 主技能：护理基础
- 副技能：沟通安抚
- 主属性：CON（副属性：CHA）

判定公式（本病症）：
- 病症判定总值 = d20 + 主属性修正 + 主技能修正 + floor(副技能修正/2) + 状态修正 + 场景修正 + 合规修正
- 成功条件：病症判定总值 >= 最终DC

基础DC：
- 诱因与时段识别：DC11
- 姿势与饮食干预：DC12
- 反复发作协同：DC14

附加修正：
- 夜班/高压班次：最终DC +1
- 证据链完整与复核完成：最终DC -1
- 连续失败后再次尝试：最终DC +1

触发条件（任意2项触发中高压链）：
1) 关键观察项缺失或记录延迟
2) 动作前未做风险评估
3) 同类异常24h内重复出现
4) 上报与处置时间线不一致

行为证据要求：
- 至少1条体征或行为变化证据
- 至少1条过程证据（处置/上报/复核）
- 结论必须与证据方向一致，禁止跳步定性

成功后果：
- 风险维持或下调1级
- 关系值 +1~2（依从提高）
- 主技能经验 +10~14，副技能经验 +4~6

失败后果：
- 风险上调1级
- 合规状态.最近违规次数 +1（若漏记/漏报）
- 连续失败2轮触发事故/舆情/法律压力链

DLC适配：
- 儿童福利院/地下室/安医大/安医/安中医/省立医院场景按机构规则提高审查强度
- 跨机构协同时优先校验来源链与合法性

回写约束：
- <UpdateVariable> 每轮仅1块，仅变化字段，禁止整树覆盖。
