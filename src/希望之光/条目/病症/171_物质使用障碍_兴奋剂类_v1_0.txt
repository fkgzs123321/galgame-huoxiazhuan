# [disease]物质使用障碍_兴奋剂类

风险分层：
- 轻度：可控波动，需要规范观察与记录
- 中度：风险升高，需要持续复核与协同
- 重度：高风险，需优先上报并进入保护链

主判定映射：
- 主技能：风险识别
- 副技能：沟通安抚
- 主属性：WIS（副属性：CHA）

判定公式（本病症）：
- 病症判定总值 = d20 + 主属性修正 + 主技能修正 + floor(副技能修正/2) + 状态修正 + 场景修正 + 合规修正
- 成功条件：病症判定总值 >= 最终DC

基础DC：
- 使用迹象识别：DC14
- 急性行为风险降压：DC15
- 危机协同上报：DC17

附加修正：
- 夜班/高压连续班次：最终DC +1
- 证据链完整且复核完成：最终DC -1
- 同类异常24h内重复：最终DC +1

触发条件（任意2项进入中高压链）：
1) 关键观察项缺失或记录延迟
2) 动作前未做风险评估
3) 上报与处置时间线不一致
4) 当前场景存在并发风险（感染/过量/冲突）

行为证据要求：
- 至少1条体征或行为变化证据
- 至少1条过程证据（处置/上报/复核）
- 结论必须与证据方向一致，禁止跳步定性

成功后果：
- 风险维持或下降1级
- 关系值 +1~2（依从提升）
- 主技能经验 +10~14，副技能经验 +4~6

失败后果：
- 风险上调1级
- 合规状态.最近违规次数 +1（若漏记/漏报）
- 连续失败2轮触发事故/舆情/法律压力链

合规与隐私约束：
- 涉及敏感健康信息时必须最小披露，避免越权传播
- 未经授权不得扩散身份识别信息

DLC适配：
- 地下室/儿童福利院/医院联动线中，证据链与合法性审查等级提高

回写约束：
- <UpdateVariable> 每轮仅1块，仅变化字段，禁止整树覆盖。
