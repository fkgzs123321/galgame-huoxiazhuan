# [disease]慢性心力衰竭

风险分层：
- 轻度：活动后气短，休息可缓解
- 中度：夜间呼吸不适，耐力明显下降
- 重度：静息仍不适，急性恶化风险高

主判定映射：
- 主技能：风险识别
- 副技能：护理基础
- 主属性：WIS（副属性：CON）

判定公式（本病症场景）：
- `病症判定总值 = d20 + WIS修正 + 风险识别修正 + 护理基础折算 + 状态修正 + 合规修正`

基础DC：
- 体位与节律管理：12
- 夜间风险复核：13
- 急性恶化早识别协同：15

附加修正：
- 未完成体位复核：DC +1
- 有完整体征时间线：DC -1
- 焦虑叠加且睡眠差：DC +1

触发条件（任意2项）：
1) 连续活动负荷过高
2) 夜班未做体位与呼吸复核
3) 体征记录缺失或延迟
4) 合并情绪紧张与睡眠差

行为证据：
- 夜间端坐呼吸主诉
- 活动后恢复明显延长
- 疲劳与水肿加重

成功后果：
- 风险等级可下调1级
- 信任 +1~2
- 风险识别经验 +10~14

失败后果：
- 风险等级 +1级
- 信任 -1~3
- 连续失败2轮触发危重分支

禁忌：
- 只安抚不做复核
- 无证据写“完全稳定”

回写约束：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
