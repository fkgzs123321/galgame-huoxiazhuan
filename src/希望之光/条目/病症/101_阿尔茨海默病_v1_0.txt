# [world]阿尔茨海默病

病症分层：
- 轻度：近事遗忘、重复提问
- 中度：时地混淆、拒护/激越波动
- 重度：识人困难、高依赖护理

触发条件（满足任意2条进入病症事件）：
1. 当前处于黄昏窗口（15:00-19:00）
2. 当轮发生争辩式纠错
3. 环境刺激升高（噪声/陌生人/流程突变）
4. 目标对象情绪张力 >= 60

行为证据（至少1条）：
- 重复同一问题 >=3次
- 明显找人/找物并伴随焦虑
- 走向出口或持续要求离开病区
- 指责“被拿走东西”并出现对抗言语

判定建议（掷骰）：
- 安抚沟通：DC12（黄昏窗口 +1）
- 激越降级：DC13（噪声环境 +1）
- 安全围护组织：DC14（多人协同时可 -1）

成功后果：
- 情绪张力 -10~20
- 配合度 +5~10
- 走失风险可下调一级（最低低）
- 关系网络：好感 +1~2，信任 +1

失败后果：
- 情绪张力 +10~15
- 配合度 -5~10
- 走失风险上调一级（最高高）
- 若连续失败2轮：触发“重点巡查”标记

禁忌：
- 强行争辩“你记错了”
- 激越高峰直接推进侵入性动作
- 无证据直接写“重度恶化”

叙事边界：
- 不可写“瞬间恢复正常”
- 不可写“完全失智且无波动”
- 必须体现诱因-反应-处理链
