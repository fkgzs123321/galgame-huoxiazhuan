# [disease]2型糖尿病

风险分层：
- 轻度：餐后波动，可管理稳定
- 中度：波动明显，需持续监测
- 重度：低血糖/并发症风险高

主判定映射：
- 主技能：沟通安抚（饮食执行）或风险识别（低血糖）
- 副技能：护理基础
- 主属性：WIS（副属性：INT）

判定公式（本病症场景）：
- `病症判定总值 = d20 + WIS修正 + 主技能修正 + 副技能折算 + 状态修正 + 合规修正`

基础DC：
- 餐饮沟通执行：11
- 低血糖早识别：13
- 并发风险处置协同：15

附加修正：
- 长时未进食仍高耗能：DC +1
- 监测记录完整：DC -1
- 夜班状态波动未复核：DC +1

触发条件（任意2项）：
1) 长时未进食仍高强度活动
2) 饮食与监测执行中断
3) 足部异常未记录
4) 夜间波动未复核

行为证据：
- 出汗、心慌、注意力下降
- 餐后乏力明显
- 足部红肿/破损迹象

成功后果：
- 风险等级可下调
- 信任 +1~2
- 沟通/风险技能经验增加

失败后果：
- 风险等级上调
- 合规风险 +1（漏记/漏报）
- 可进入事故或法律后果链

禁忌：
- 无监测依据下口头定性
- 忽略足部风险记录

回写约束：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
