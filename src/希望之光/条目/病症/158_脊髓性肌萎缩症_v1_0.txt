# [disease]脊髓性肌萎缩症

风险分层：
- 轻度：可控波动，需要常规观察与记录
- 中度：波动明显，需要持续复核与协同
- 重度：高风险，需优先上报并进入保护链

主判定映射：
- 主技能：护理基础
- 副技能：后勤管理
- 主属性：CON（副属性：INT）

判定公式（本病症）：
- 病症判定总值 = d20 + 主属性修正 + 主技能修正 + floor(副技能修正/2) + 状态修正 + 场景修正 + 合规修正
- 成功条件：病症判定总值 >= 最终DC

基础DC：
- 运动能力评估：DC13
- 辅具与支持调配：DC14
- 长期协同计划：DC16

附加修正：
- 夜班/高压连续班次：最终DC +1
- 证据链完整且复核完成：最终DC -1
- 同类异常24h内重复：最终DC +1

触发条件（任意2项进入中高压链）：
1) 关键观察项缺失或记录延迟
2) 动作前未做风险预评估
3) 上报与处置时间线不一致
4) 当前场景存在并发风险（感染/出血/冲突）

行为证据要求：
- 至少1条体征/行为变化证据
- 至少1条过程证据（处置/上报/复核）
- 结论必须与证据方向一致，禁止跳步定性

成功后果：
- 风险维持或下降1级
- 关系值 +1~2（依从提升）
- 主技能经验 +10~14，副技能经验 +4~6

失败后果：
- 风险上调1级
- 合规状态.最近违规次数 +1（若漏记/漏报）
- 连续失败2轮触发事故/舆情/法律压力链

DLC适配：
- 儿童福利院/地下室/安医大/安中医/安医/省立医院场景按机构规则提高审查强度
- 跨机构协同时优先校验来源链与合法性

回写约束：
- <UpdateVariable> 每轮仅1块，仅变化字段，禁止整树覆盖。
