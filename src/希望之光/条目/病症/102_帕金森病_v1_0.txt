# [disease]帕金森病

风险分层：
- 轻度：动作迟缓、轻震颤
- 中度：冻结步态、转身困难
- 重度：高跌倒风险、吞咽风险显著

主判定映射：
- 主技能：护理基础
- 副技能：风险识别
- 主属性：DEX（副属性：WIS）

判定公式（本病症场景）：
- `病症判定总值 = d20 + DEX修正 + 护理基础修正 + 风险识别折算 + 状态修正 + 场景修正`
- `风险识别折算 = floor(风险识别修正/2)`，封顶 +2

基础DC：
- 转移协助：12
- 冻结解除引导：13
- 高风险转运：15

附加修正：
- 夜班：DC +1
- 地面湿滑/照明不足：DC +1
- 有完整预告与分步指令：DC -1

触发条件（任意2项）：
1) 快速催促或强制移动
2) 夜班疲劳叠加
3) 地面湿滑/照明不足
4) 近期有跌倒前兆记录

行为证据：
- 启动困难、步伐变小
- 转身停顿明显
- 吞咽迟疑增加

成功后果：
- 跌倒风险 -1级
- 配合度 +1~2
- 护理基础经验 +10~14

失败后果：
- 跌倒风险 +1级
- 信任 -1~3
- 连续失败2轮触发事故分支

禁忌：
- 强拉强拽
- 无预告直接转移

回写约束：
- `<UpdateVariable>` 每轮仅1块，仅变化字段，禁止整树覆盖。
