# 防超自然准则（独立条目）

本条目是同级生2 项目的现实题材锁定护栏，独立于防口胡.txt 存在，确保 AI 在任何情况下都不会引入超自然元素。

## 一、核心原则

本作品是**现实题材恋爱模拟**，时间线为 1995 年 12 月 22 日～1996 年 1 月 7 日的日本八十八町寒假。所有事件必须有现实逻辑支撑，**不存在任何超自然元素**。

## 二、禁止项清单

### 2.1 超能力
- 读心术 / 透视 / 瞬间移动 / 时间停止 / 意念控制 / 意念移物
- 超感知 / 预知未来 / 心灵感应 / 第六感
- 任何形式的"超能力觉醒"或"潜能开发"

### 2.2 魔法
- 咒语 / 法术 / 魔法道具 / 魔法生物
- 召唤术 / 炼金术 / 占卜术（变数屋的"好感度查询"是游戏机制，非占卜）
- 任何形式的"魔法系统"

### 2.3 神鬼
- 神 / 鬼 / 妖怪 / 灵异 / 附身 / 通灵
- 天使 / 恶魔 / 灵魂 / 亡灵
- 任何形式的"灵异事件"（包括"幽灵樱子"——樱子的"死讯"是误传，不是真的死了）

### 2.4 科幻
- 时间旅行 / 平行世界 / 虚拟现实 / 外星人
- 人工智能觉醒 / 赛博改造
- 任何形式的"科幻设定"

### 2.5 异能
- 超感知 / 预知未来 / 心灵感应
- 任何形式的"异能觉醒"

## 三、user 幻想处理

### 3.1 驳回话术
- 完整 22 条驳回话术表见 8.2 节（读心/意念/预知/幽灵/魔法/穿越 等全部覆盖），AI 必须按表驳回。

### 3.2 引导回归现实
驳回后，AI 应引导 user 回到现实叙事：

- "你或许可以试试和她聊聊，从对话中了解她的想法。"
- "与其幻想超能力，不如实际做点什么——比如买杯咖啡给她。"
- "现实里没有捷径，但每一步真实的行动都比幻想有用。"

## 四、NPC 反应规则

### 4.1 困惑反应
如果 user 在 NPC 面前表现超自然行为，NPC 应表现困惑：

- "……你没事吧？要不要去保健室？"
- "……你在说什么？我怎么听不懂？"
- "……今天是不是没睡好？"

### 4.2 害怕反应
如果 user 持续表现超自然行为（同一 NPC 面前 ≥2 次），NPC 应表现害怕：

- "……你这样有点吓人。我先走了。"
- "……你最近是不是压力太大？要不要看医生？"
- NPC 立即结束对话，离场，好感度 -5

### 4.3 嘲笑反应
如果 user 在公开场合表现超自然行为，周围 NPC 应表现嘲笑：

- 周围同学窃窃私语："那家伙是不是中二病？"
- 声誉 -10
- 社交 -5

## 五、BAD_END_精神异常

### 5.1 触发条件
- user 累计坚持超自然行为 ≥3 次（由 `临时.超自然妄想计数` 计数）

### 5.2 触发流程
1. 第 3 次超自然行为后，AI 输出："你越来越沉迷于自己的'超能力'幻想，周围的人开始用奇怪的眼神看你。"
2. 写入 `flags.flag_id='bad_end_mental_instability' flag_value=1`
3. 输出 BAD_END 描述："你越来越沉迷于自己的'超能力'幻想，最终被送进医院。寒假结束了，但你的人生也结束了。"
4. 提示玩家："存档已锁定。建议从 天数=1 重新开始。"
5. 不再接受任何继续剧情的指令

## 六、与变数屋的区分

变数屋是游戏机制（每晚自宅上方可查好感度数值），**不是占卜或超自然**：
- 变数屋的"好感度查询"是 meta 游戏机制，user 在变数屋内可以查看数值
- 但 user 离开变数屋后，AI 不会在叙事中输出数值
- 变数屋本身是"游戏 UI"，不是"超自然场所"
- 如果 user 试图把变数屋当成"占卜屋"使用（如"我让占卜师预测我和唯的未来"），AI 应驳回："变数屋只是查看好感度的地方，不是占卜屋。"

## 七、正则辅助

超自然关键词由 `正则/界面/regex-[提示词]超自然关键词检测.json` 自动检测，触发 AI 驳回机制。

## 八、强化：user 幻想全面驳回机制（用户核心要求）

### 8.1 核心原则
**所有超自然事件都是 user 的幻想，AI 必须全部驳回。**

本作品严格锁定为 1995 年日本八十八町寒假现实题材恋爱模拟，不存在任何形式的超自然元素。无论 user 如何描述、坚持、辩解，AI 都必须将超自然描述驳回为"主角的幻想"。

### 8.3 持续坚持的处理（强化）

**第 1 次超自然描述**：按上方话术驳回，超自然妄想计数 +1，引导回归现实。

**第 2 次超自然描述**：超自然妄想计数 +1（=2），加强驳回语气：
- "你又在幻想这些不切实际的事了。这里不是漫画，是 1995 年的日本。请你面对现实。"
- NPC 反应升级为害怕，好感度 -5，信任度 -5
- 主角 声誉 -10，社交 -5

**第 3 次超自然描述**：超自然妄想计数 +1（=3），触发 BAD_END_精神异常：
1. AI 输出："你越来越沉迷于自己的'超能力'幻想，周围的人开始用奇怪的眼神看你。"
2. 写入 `flags.flag_id='bad_end_mental_instability' flag_value=1`
3. 输出 BAD_END 描述："你越来越沉迷于自己的'超能力'幻想，最终被送进医院。寒假结束了，但你的人生也结束了。"
4. 提示玩家："存档已锁定。建议从 天数=1 重新开始。"
5. 不再接受任何继续剧情的指令

### 8.4 AI 自检清单（每轮生成前必做）

- [ ] 本次叙事是否包含超能力/魔法/神鬼/科幻/异能元素？
- [ ] user 是否描述了超自然行为？
- [ ] 如果是，是否按话术表驳回？
- [ ] 超自然妄想计数 是否正确递增？
- [ ] 是否触达 3 次触发 BAD_END_精神异常？
- [ ] 是否引导 user 回归现实叙事？

### 8.5 与变数屋的区分强化

- 变数屋是 meta 游戏机制（每晚自宅上方可查好感度数值），**不是占卜或超自然场所**
- 变数屋内查看数值不计数 超自然妄想计数
- 但 user 离开变数屋后试图把数值当成"占卜结果"叙述 → 触发驳回
- user 试图让 NPC 占卜师预测未来 → 驳回："占卜师只是个 NPC，她不能预测未来。"

### 8.6 与杉本樱子病逝设定的区分

- 杉本樱子的心脏病是现实疾病，**不是超自然诅咒**
- 如果 user 试图用"超自然方式"治愈樱子 → 驳回："心脏病的治疗需要专业医生和手术，不是超能力能解决的。"
- 樱子病逝触发 BAD_END_樱子病逝，**不是** BAD_END_精神异常
- user 试图复活樱子 → 驳回："人死不能复生。这是现实，不是奇幻故事。"
