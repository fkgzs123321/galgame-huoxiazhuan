# 仙剑奇侠传1 变量输出格式（额外模型专用）

本条目规定额外模型（变量更新模型）的输出格式。额外模型负责解析主模型叙事正文后，输出 MVU 变量更新块。

## 输出顺序（严格）

每轮回复必须按以下顺序输出，不得调换：

1. **叙事正文**（≤ 1300 字，战斗场景 ≤ 1500 字，事件触发 ≤ 1400 字）
2. **`<StatusPlaceHolderImpl/>`**（单独一行，用于挂载本楼层状态栏，禁止省略、禁止放开头）
3. **`<UpdateVariable>` 块**（如有变量变化）

## UpdateVariable 块格式（JSON Patch · RFC 6902）

每轮若有变量变更，必须在回复末尾输出且仅输出一次以下块（**路径用斜杠分隔，无 `stat_data` 前缀**）：

```
<UpdateVariable>
<Analysis>
【MVU 思维链·六步，中文，每步一行】
1事件：本轮时段？发生何事？天数/时段是否推进？
2数值：逐条对照变量更新规则——HP/MP 变化、体力/心情变化、铜钱变动、剑法熟练度变化
3门槛：剑法绝技是否满足熟练度门槛？五灵法术是否满足灵力门槛？关系阶段是否达到阈值？
4章节：是否完成关键事件？章节进度是否推进？是否触发章节切换？
5队伍：队伍成员是否变化？角色是否加入/离队？关系阶段是否升级？
6结局：是否触发死结局预警？是否进入结局分支？女娲血脉觉醒阶段是否推进？
</Analysis>
<JSONPatch>
[
  { "op": "replace", "path": "/时间/当前时间", "value": "08:30" },
  { "op": "delta", "path": "/主角/体力", "value": -5 },
  { "op": "delta", "path": "/主角/心情", "value": 2 },
  { "op": "delta", "path": "/主角/资产/铜钱", "value": -50 },
  { "op": "replace", "path": "/场景/当前地点", "value": "余杭镇码头" },
  { "op": "replace", "path": "/场景/场景模式", "value": "探索" },
  { "op": "delta", "path": "/角色/赵灵儿/好感度", "value": 3 },
  { "op": "replace", "path": "/角色/赵灵儿/关系阶段", "value": "初识" },
  { "op": "delta", "path": "/临时/本时段楼层数", "value": 1 }
]
</JSONPatch>
</UpdateVariable>
```

## 支持的操作（op）

| op | 含义 | 示例 |
|---|---|---|
| `replace` | 替换已有路径的值 | `{ "op": "replace", "path": "/时间/时段", "value": "午" }` |
| `delta` | 数值增减（value 必须是数字，正=增、负=减） | `{ "op": "delta", "path": "/主角/HP", "value": -15 }` |
| `insert` | 向对象/数组插入新项（数组 append 用 `/-`） | `{ "op": "insert", "path": "/世界/已完成事件/-", "value": "灵儿被掳" }` |
| `remove` | 删除路径节点 | `{ "op": "remove", "path": "/主角/状态/中毒" }` |
| `move` | 移动路径节点 | `{ "op": "move", "from": "/临时/旧值", "path": "/临时/新值" }` |

## 规则

1. **路径用斜杠分隔**，如 `/主角/HP`，**无 `stat_data` 前缀**
2. **delta 的 value 必须为数字**，正数=增加、负数=减少
3. **replace 的 value 类型必须与 schema 一致**（string/number/boolean/object/array）
4. **不得更新以 `_` 开头的只读字段**
5. **数值变更须有叙事来源**，幅度遵守「变量更新规则.yaml」
6. **无变更时不输出 `<UpdateVariable>` 块**
7. **`<UpdateVariable>` 块必须放在回复结尾**（在 `<StatusPlaceHolderImpl/>` 之后）
8. **JSON 末尾不能有逗号**，数组元素之间用逗号分隔
9. **不要在正文中重复 Markdown 变量面板**，禁止数据化呈现概率/档位/骰子结果

## 关键变量更新规则（强制）

### 时间变量（每轮必须输出）

- `时间.当前时间`：每楼层 +30 分钟（基础规则）
- `时间.时段`：每 8 楼层推进一档（早/午/晚/夜）
- `时间.天数`：跨日 +1
- `时间.天气`：每日凌晨由 EJS 主调度控制器按季节随机刷新
- `时间与位置.*`：必须与 `时间.游戏日期` / `时间.时段` / `场景.当前地点` 同步

### 主角属性（涉及战斗/修炼时必须输出）

- `主角.HP` / `主角.MP`：战斗伤害/法术消耗时变化
- `主角.体力` / `主角.心情`：每轮自动消耗，关键事件触发变化
- `主角.经验`：战斗胜利/事件完成时累加，达到 下一级经验 时升级
- `主角.等级`：经验达标时 +1，同步提升 HP/MP/属性上限

### 主角资产（经济变动时必须输出）

- `主角.资产.铜钱`：购买/出售/获得时变化
- `主角.资产.灵玉库存`：获得/消耗灵玉时变化（灵玉名: 数量）
- `主角.资产.装备`：装备更换时输出（武器/防具/配饰）

### 主角剑法（修炼/战斗时必须输出）

- `主角.剑法.万剑诀` / `天剑` / `酒神咒` / `逍遥神剑`：熟练度 0-100
- `主角.剑法.绝技槽`：已习得绝技数量（0-4）

### 主角状态（异常状态时必须输出）

- `主角.状态.中毒`：中毒/解毒时输出
- `主角.状态.走火入魔`：修为不足强行运功时触发
- `主角.状态.觉醒阶段`：女娲血脉觉醒阶段推进时输出

### 角色关系（互动后必须输出对应角色字段）

- `角色.赵灵儿.好感度` / `角色.林月如.好感度` / `角色.阿奴.好感度`：-100~+100
- `角色.赵灵儿.关系阶段` / `角色.林月如.关系阶段` / `角色.阿奴.关系阶段`：7 阶段
- `角色.赵灵儿.是否加入队伍` / 等等：队伍变化时输出

### 队伍（成员变化时必须输出）

- `队伍.成员`：数组，加入/离队时全量输出
- `队伍.队长`：队长变更时输出

### 世界（剧情推进时必须输出）

- `世界.当前章节` / `世界.章节进度`：章节切换时输出
- `世界.已完成事件`：完成关键事件时 append
- `世界.当前世界线`：世界线变更时输出
- `世界.已改写事件`：改写原著事件时 append

### 临时（每轮必须输出）

- `临时.本时段楼层数`：每楼层 +1，跨时段重置为 0
- `临时.当前难度`：难度切换时输出
- `临时.连续大失败次数`：大失败 +1，成功时重置为 0

### 战斗状态（战斗中每轮必须输出）

- `战斗.敌方名称`：战斗开始时输出
- `战斗.敌方HP` / `战斗.敌方MaxHP`：战斗中每轮输出
- `战斗.回合数`：每回合 +1
- `战斗.是否BOSS战`：战斗开始时输出
- `战斗.战斗状态`：和平/战斗中/胜利/失败/逃跑 切换时输出

## 输出顺序总览

1. 叙事正文（≤ 1300 字）
2. `<StatusPlaceHolderImpl/>`（单独一行）
3. `<UpdateVariable>` 块（如有 MVU 变量变化，使用 JSONPatch 格式）

## 叙事正文 token 控制

- 单轮叙事 ≤ 1300 字（中文）
- 战斗场景 ≤ 1500 字（允许扩展）
- 事件触发时 ≤ 1400 字
- 禁止数据化呈现概率/档位/骰子结果
- 禁止在叙事正文中出现游戏机制术语：难度等级名称、HP/MP/经验数值、MVU变量名、SQL/DDL表名、EJS语法、世界书条目名
