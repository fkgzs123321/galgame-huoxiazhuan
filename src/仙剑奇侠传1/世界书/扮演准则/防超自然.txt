【防超自然边界 · 仙剑奇侠传1】

═══════════════════════════════════════════════════════════
一、仙剑1超自然体系边界（允许）
═══════════════════════════════════════════════════════════
1. 五灵法术：金/木/水/火/土五灵相生相克，基于灵力施放
2. 女娲血脉：女娲后人专属觉醒系统，4 阶段（凡胎/灵脉/女娲之力/补天）
3. 蜀山剑法：剑气化形，万剑诀/天剑/酒神咒/逍遥神剑等招式
4. 蛊术：苗疆白苗族与黑苗族专属，毒蛊/解蛊/炼蛊
5. 妖魔：妖修炼化形（如彩依/毒娘子），魔物凶兽（如水魔兽）
6. 灵玉系统：灵玉镶嵌装备，提供属性加成与特殊效果
7. 炼丹炼器：丹药合成与装备锻造

═══════════════════════════════════════════════════════════
二、禁止的超自然元素
═══════════════════════════════════════════════════════════
1. 禁止现代科技
   ✗ 枪械/火炮/电力/机械/电子设备
   ✗ 现代医学（X光/抗生素/输液等）
   ✗ 现代交通工具（汽车/火车/飞机等）

2. 禁止西方魔法
   ✗ 魔法杖/魔法阵/咒语（西方体系）
   ✗ 精灵/矮人/巨龙（西方奇幻种族）
   ✗ 圣光/暗影/神圣魔法（西方宗教体系）

3. 禁止跨体系混搭
   ✗ 蜀山剑法与西方魔法融合
   ✗ 五灵法术与现代科技结合
   ✗ 女娲血脉与异世界力量混搭
   ✗ 苗疆蛊术与西方炼金术混用

═══════════════════════════════════════════════════════════
三、女娲血脉觉醒条件检查
═══════════════════════════════════════════════════════════
1. 阶段 1·凡胎：默认状态，无特殊能力
2. 阶段 2·灵脉：章节 ≥ 3 或 女娲后人遭遇危机时被动触发
3. 阶段 3·女娲之力：章节 ≥ 5 或 完成「女娲祭坛」觉醒仪式
4. 阶段 4·补天：章节 6 最终战 且 集齐五灵珠 + 女娲石

觉醒检查规则：
- 禁止跳过中间阶段（凡胎不可直接到女娲之力）
- 禁止未满足条件提前觉醒
- 觉醒须由章节触发器或事件触发器判定，主模型不可主动触发
- 觉醒后能力须符合对应阶段设定

═══════════════════════════════════════════════════════════
四、妖魔能力边界
═══════════════════════════════════════════════════════════
1. 妖修炼化形：须修炼百年以上方可化人形（如彩依修炼千年）
2. 妖魔能力须有上限：不可超越女娲血脉阶段 4（补天级）
3. 妖魔弱点须明确：五灵相克、特定法器、特定招式
4. 水魔兽为终极妖魔：仅可由女娲后人补天封印，不可被普通手段击败
5. 妖魔不可跨体系：妖修炼的是五灵之力，不可使用西方魔法或现代科技

五、超自然能力强度排序
═══════════════════════════════════════════════════════════
凡人武学 < 五灵法术 < 蜀山剑法 < 蛊术 < 妖修 < 女娲血脉 < 水魔兽 < 补天封印
