【总则】
1. 本卡配置了 15 种 XML 美化标签，由 ST 正则脚本替换为 HTML 卡片显示
2. 剧情AI在正文中遇到对应场景时，**必须**输出相应标签
3. 标签为自闭合 XML 格式：`<TagName attr="value" .../>`
4. 标签属性值必须用双引号包裹，禁止单引号或无引号
5. 标签属性值禁止包含双引号、换行符、`/>` 字符
6. 标签前后需留空行，避免与正文粘连
7. **变量AI不输出这些标签**（仅识别并对应更新变量）
8. 标签输出**不影响**<UpdateVariable>的JSONPatch，两者各司其职

## 1. <Purchase> 购买补给标签

**输出时机**：玩家在商店/食堂/小卖部/校医室购买补给品后
**必须属性**：
- item：物品名称（如"营养餐（食堂）"）
- price：价格数字（如 20）
- effects：效果描述（如"精力+15, 体力+10"）
- location：购买地点（如"食堂"/"小卖部"/"校医室"）

**输出示例**：
```
<Purchase item="营养餐（食堂）" price="20" effects="精力+15, 体力+10" location="食堂"/>
```

## 2. <SkillUp> 技能升级标签

**输出时机**：玩家技能等级提升时（冥想/锻炼/洞察/伪装/恢复/意志）
**必须属性**：
- skill：技能名（中文）
- level：等级变化格式 `旧等级→新等级`（如 `5→6`）
- exp：当前经验值（可选，数字）
- tier：等级档位（可选，如"初级"/"中级"/"高级"/"大师"）

**输出示例**：
```
<SkillUp skill="冥想" level="5→6" exp="0" tier="初级"/>
```

## 3. <StageUp> 玩家使用阶段晋升标签

**输出时机**：玩家使用阶段从X晋升到Y时（1→2/2→3/3→4/4→5）
**必须属性**：
- from：旧阶段（数字）
- to：新阶段（数字）
- name：阶段名称（如"初级玩具"/"等比复刻"/"灵体投影"/"人偶容器"/"实体化共生"）
- desc：阶段描述（可选）

**输出示例**：
```
<StageUp from="1" to="2" name="等比复刻" desc="假阴茎开始具备等比尺寸的复刻能力"/>
```

## 4. <ItemGet> 物品获取标签

**输出时机**：玩家获得物品时（任务奖励/拾取/购买/赠送）
**必须属性**：
- name：物品名称
- quality：品质枚举（common普通/fine优良/rare稀有/epic史诗/legend传说）
- count：数量（数字）
- source：来源描述（如"任务奖励"/"地面拾取"/"林婉清赠送"）

**输出示例**：
```
<ItemGet name="润滑剂" quality="common" count="1" source="校医室购买"/>
```

## 5. <StatChange> 状态变化梅花标签

**输出时机**：玩家状态数值发生显著变化时（精力/理智/健康/压力/怀疑值/堕落值/体力/金钱）
**必须属性**：
- type：状态类型（如"精力"/"理智"/"怀疑值"/"堕落值"/"金钱"）
- delta：变化量（带正负号，如 `+15` / `-10`）
- reason：变化原因（简短描述）
- icon：图标emoji（可选，如"⚡"/"🧠"/"🔍"/"🌑"/"💰"）

**输出示例**：
```
<StatChange type="精力" delta="-15" reason="夜间使用假阴茎消耗" icon="⚡"/>
<StatChange type="金钱" delta="-20" reason="购买营养餐" icon="💰"/>
```

## 6. <TaskAccept> 任务接取标签

**输出时机**：玩家接取新任务时
**必须属性**：
- name：任务标题
- type：任务类型枚举（主线/支线/日常/隐藏）
- difficulty：难度枚举（D/C/B/A/S/SS）
- reward：奖励描述（简短，如"50元 + 锻炼经验5"）

**输出示例**：
```
<TaskAccept name="调查夜间声响" type="支线" difficulty="B" reward="100元 + 洞察经验20"/>
```

## 7. <TaskComplete> 任务完成标签

**输出时机**：玩家完成任务时
**必须属性**：
- name：任务标题
- reward：实际获得的奖励描述
- result：完成结果描述（简短，如"成功找到线索"/"任务失败，损失信任"）

**输出示例**：
```
<TaskComplete name="调查夜间声响" reward="100元 + 洞察经验20" result="成功确认假阴茎异常"/>
```

## 8. <RelChange> 关系变化标签

**输出时机**：女性角色与玩家关系数值变化时（好感度/熟悉度/信任等）
**必须属性**：
- char：角色姓名（中文真名，如"林婉清"）
- type：关系类型枚举（好感/熟稔/信任）
- delta：变化量（带正负号，如 `+5` / `-10`）
- reason：变化原因（简短描述）

**输出示例**：
```
<RelChange char="林婉清" type="好感" delta="+5" reason="主动关心她的身体状况"/>
<RelChange char="叶知秋" type="信任" delta="-10" reason="被她发现使用假阴茎"/>
```

## 9. <FemaleStageUp> 女性综合阶段变化标签

**输出时机**：女性综合阶段从X晋升到Y时（A_理性期→B_动摇期等）
**必须属性**：
- char：角色姓名（中文真名）
- from：旧阶段（如"A_理性期"/"B_动摇期"/"C_沉沦期"/"D_疯狂期"/"E_崩坏期"/"E_清醒反扑期"）
- to：新阶段
- template：模板类型（如"纯真"/"御姐"/"辣妹"/"运动"/"文静"/"熟女"/"萝莉"）
- sanity：理智值（数字）

**输出示例**：
```
<FemaleStageUp char="林婉清" from="A_理性期" to="B_动摇期" template="纯真" sanity="85"/>
```

## 10. <EventTrigger> 事件触发标签

**输出时机**：触发重要剧情事件时（任务结果/角色关系变化/活动结算/重要物品得失/规则变化/居所载具变化/伤病/长期状态变化）
**必须属性**：
- type：事件类型枚举（use使用/symptom症状/investigate调查/social社交/exam考试/ending结局）
- importance：重要度枚举（high/mid/low）
- desc：事件描述（简短，30字以内）

**输出示例**：
```
<EventTrigger type="investigate" importance="high" desc="林婉清在保健室发现假阴茎异常震动"/>
<EventTrigger type="social" importance="mid" desc="叶知秋主动邀请玩家共进午餐"/>
```

## 11. <Ending> 结局触发标签

**输出时机**：触发结局时（健康/平庸/真相揭示/坠落/崩坏/黑市掌控/同归于尽/未解之谜）
**必须属性**：
- name：结局名称（中文，如"崩坏结局"/"黑市掌控结局"/"未解之谜结局"）
- desc：结局描述（30字以内简短描述）

**输出示例**：
```
<Ending name="崩坏结局" desc="玩家理智归零，精神彻底崩溃"/>
```

## 13. <InnerMonologue> 内心独白标签

**输出时机**：角色内心活动/未说出口的思考/心理描写（含第三方视角对{{user}}的观察与评价）
**必须属性**：
- char：角色姓名（中文真名，如"林婉清"/"陈老师"，{{user}}内心用"我"）
- type：独白类型枚举（thought思考/observe观察/judge评价/doubt疑虑/desire渴望/fear恐惧）

**输出示例**：
```
<InnerMonologue char="林婉清" type="observe">这个插班生看起来像个木头人，盯着口袋发呆，不会是被主任吓傻了吧......但他是全校唯一男生，以后肯定经常出现在视野里，得赶紧让他归位，被老师看见在门口站着不太好。</InnerMonologue>

<InnerMonologue char="陈老师" type="doubt">这个学生今天反常，眼神躲闪，是不是发现了什么？</InnerMonologue>

<InnerMonologue char="我" type="thought">这玩意的震动太奇怪了，难道真的连接着我的身体？</InnerMonologue>
```

**禁止格式**：
- 禁止用 `<p style="...">【角色】内容</p>` 格式（旧格式，正则不识别）
- 禁止用 `*内容*` 斜体格式
- 禁止用 `[角色内心] 内容` 方括号格式
- 必须使用 `<InnerMonologue>` 标签

**与叙事区分**：
- 角色说出口的话：用引号 `"内容"` 或 `<wechat_private>/<wechat_group>`
- 角色内心活动：用 `<InnerMonologue>`
- {{user}}的内心独白：char="我"

## 14. <wechat_group> 微信群聊标签

**输出时机**：现代社会场景下，玩家在班级群/同学群/工作群等微信群聊中互动时
**必须属性**：
- group：群名称（如"高三2班班级群"/"文学社"/"教研组"）

**内部消息格式**（剧情AI必须遵守）：
- 普通消息：[HH:MM] 昵称: 内容
- 系统消息：[系统] 内容（如"XXX 加入了群聊"/"XXX 修改了群名"）
- 引用消息：[HH:MM] [引用 原作者 原时间] 昵称: 回复内容
- @提及：在内容中用 @被提及者 标记

**输出示例**：
```
<wechat_group group="高三2班班级群">
[12:30] 班主任陈老师: 同学们，明天月考请准时到场
[12:32] 林婉清: 收到老师
[12:35] 叶知秋: @林婉清 你借我的笔记明天还你
[系统] 张雨萱 加入了群聊
[12:40] [引用 班主任陈老师 12:30] 苏晴: 老师月考范围是什么
</wechat_group>
```

## 15. <wechat_private> 微信私聊标签

**输出时机**：玩家与某角色1对1微信私聊时
**必须属性**：
- who：对方姓名（如"林婉清"）
- relation：关系（如"同班同学"/"老师"/"母亲"）

**内部消息格式**：
- 对方消息：[HH:MM] 昵称: 内容
- 玩家消息：[HH:MM] 我: 内容
- 系统消息：[系统] 内容（如"对方撤回了一条消息"/"对方发起了视频通话"）

**输出示例**：
```
<wechat_private who="林婉清" relation="同班同学">
[12:30] 林婉清: 你今天的笔记借我看一下
[12:31] 我: 好的，下午给你
[12:35] 林婉清: [图片]
</wechat_private>
```

【输出注意事项】
═══════════════════════════════════════════════

1. **空行隔离**：每个标签前后必须留空行，避免与正文粘连
   - 正确：`...正文内容。\n\n<Purchase .../>\n\n后续正文...`
   - 错误：`...正文内容。<Purchase .../>后续正文...`

2. **属性值禁止字符**：
   - 禁止双引号 `"`（会破坏XML解析）
   - 禁止换行符（标签必须单行）
   - 禁止 `/>` 字符（会提前闭合标签）
   - 禁止反斜杠 `\`

3. **数值格式**：
   - level 用 `→` 箭头：`5→6`
   - delta 带正负号：`+15` / `-10`
   - price/count/level数字 必须是纯数字

4. **触发时机判断**：
   - 同一事件不重复输出多个同类标签
   - 一个动作可触发多个不同类标签（如购买触发<Purchase>+<StatChange>+<RelChange>）
   - 任务接取时只输出<TaskAccept>，完成时只输出<TaskComplete>
   - 数值变化<5时不输出<StatChange>（避免刷屏）

5. **剧情AI禁止输出**：
   - 禁止输出 <UpdateVariable> / <Analysis> / <JSONPatch> 标签（这些是变量AI的职责）
   - 禁止输出 <thinking> / <Thinking> 思维链标签（这些由思维链条目处理）
   - 禁止输出 <status_current_variables> 标签

6. **与变量更新的关系**：
   - 剧情AI输出美化标签 → 变量AI识别后生成对应 JSONPatch
   - 美化标签是"叙事表现"，JSONPatch是"数据更新"
   - 美化标签中的数值必须与变量AI的JSONPatch数值一致
   - 如果数值冲突，以变量规则为准（如兴奋度阈值映射表）
