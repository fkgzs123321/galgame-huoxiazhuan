【跨天条件】
当 时间.小时 从 23 跳转至 0 时（模拟时钟推进），触发新的一天。
同时更新：时间.天数 += 1, 时间.星期 按序推进（周→周二→...→日→周一）

【重置列表——跨天时执行以下所有操作】

1. /技能/下所有 今日已用 归零
   - /技能/冥想/今日已用 = 0
   - /技能/锻炼/今日已用 = 0
   - /技能/洞察/今日已用 = 0
   - /技能/伪装/今日已用 = 0
   - /技能/恢复/今日已用 = 0
   - /技能/意志/今日已用 = 0
   上限不变（今日上限保持不变）

2. /使用阶段/今日使用 = 0
   每天的使用次数重新计数

3. stat_data.状态.精力 夜间自然恢复 +20
   若入睡前采取了额外休息/早睡等行为，额外恢复 +10~20
   恢复不超出 精力上限

4. stat_data.状态.理智 夜间自然恢复 +10
   若进行了睡前冥想，额外恢复 +5~10

5. stat_data.状态.体力 夜间自然恢复 +20
   按8小时睡眠，体力消耗更慢所以略高于精力
   恢复不超出 体力上限（由难度决定：普通100/困难80/地狱60）
   若理智<=20（精神萎靡），恢复效率减半 +10（详见 精力消耗计算.txt VII.体力联动规则）

6. 所有女性使用者的 stat_data.女性角色.{uid}.NSFW.当日统计.今日已用 = 0
   今日已用 用于限制同一女性每日使用频率

7. stat_data.学业.今日学习次数 = 0
   每天的学习次数重新计数

8. stat_data.隐藏层.近期事件 清空（如果存在）
   [注意] 事件 数组不空，它保持累计

9. 重置女性使用者的 每日榨取精力 = 0
   （可选跟踪字段，用于传播倾向判定）

=== 下次考试倒计时 ===
- /学业/考试倒计时 每日减1
  - 当前倒计时：下次考试还有 ? 天（周考/月考/季考/模拟考）
  - 当 考试倒计时 <= 0 时：考试触发，次日重置为下一周期
    - 周考：重置为 7
    - 月考：重置为 30
    - 季考：重置为 90
    - 模拟考：按日历设定
  - 考试期间影响：精力消耗×1.3、使用频率上升、角色焦虑度增加

=== 高考倒计时 ===
- /时间/距高考天数 每日减1
  - 当前倒计时：距高考还有 ? 天（需要读取实际变量）
  - 当 距高考天数 <= 0 时：触发学业结局判定
  - 学业结局判定：
    - 若 学业.阶段 >= 4: 健康结局候选
    - 若 学业.阶段 >= 3: 平庸结局候选
    - 若 学业.阶段 < 3: 坠落结局候选
