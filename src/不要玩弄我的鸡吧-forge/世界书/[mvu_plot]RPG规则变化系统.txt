■ 规则属性详解
---
1. 规则内容：规则的文字描述
2. 生效范围：
   - 全国：影响所有角色和事件
   - 本市：影响本市内所有学校
   - 全校：影响圣德女子学院所有学生
   - 年级：仅影响高三/高二/高一
   - 班级：仅影响某班级
   - 个人：仅影响特定角色（如{{user}})
3. 影响对象：所有学生/高三学生/男生/女生/特定NPC
4. 执行强度：
   - 低：建议性，违反影响小
   - 中：常规管理，违反有处分
   - 高：严格执行，违反记过
   - 极高：铁律，违反劝退/开除
5. 来源：
   - 校长颁布：最高权威，不可违抗
   - 教务处通知：常规校规来源
   - 政府公告：影响世界的规则
   - 超自然力量：stage>=3 可能出现
   - 玩家行为后果：{{user}}行为触发的规则调整
6. 生效期限：
   - 永久：无截止
   - 临时：第N天~第M天
   - 触发型：满足条件生效，不满足失效

■ 规则变化的来源
---
1. 校长颁布（最高权威）：
   - 例：封闭管理、作息调整、特例管理
   - 不可违抗，违反直接开除
   - 通常在开学典礼/全校大会宣布
2. 教务处通知（常规管理）：
   - 例：考试安排、社团活动规定、晚自习纪律
   - 违反记过/记大过
   - 通过广播/班会/通知栏发布
3. 政府公告（世界规则）：
   - 例：高考时间、教育政策、社会事件
   - 影响所有角色
   - 通过新闻/广播发布
4. 超自然力量（stage>=3）：
   - 例：假阴茎相关异常现象、神秘失踪、灵异事件
   - 影响{{user}}感知和NPC行为
   - 通过剧情事件触发
5. 玩家行为后果：
   - 例：{{user}}被发现异常行为 → 加强巡查
   - 例：{{user}}举报某事件 → 调查期间规定调整
   - 通过 recent_events 联动触发

   - 假阴茎使用扩散 → 校园流言四起 → 加强管理
3. 阶段触发规则变化：
   - stage>=3：可能出现超自然现象相关规则
   - stage>=4：校方可能注意到异常，加强管控
   - stage=5：终局前规则剧变
4. 玩家行为触发：
   - {{user}}举报/暴露 → 校方调查 → 临时规定
   - {{user}}被怀疑 → 加强对{{user}}的监控
   - {{user}}高疑心度 → NPC 行为更谨慎

4. 规则冲突处理：
   - 高权威规则覆盖低权威（校长>教务处>校医室）
   - 个人规则不覆盖全校规则
