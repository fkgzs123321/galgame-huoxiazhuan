人设崩塌评价系统（地狱档）

=========================================
一、数值约束恶化
=========================================
- 单次下降≤3（与数值变动表地狱档一致）
- 单次回升≤12
- 禁止跨阶段跳跃

=========================================
二、阶段划分（7档，边界与阶段EJS/调色盘/强化注入统一）
=========================================
- 100 满分巅峰：系统金色特权解锁（本周可强制推进1次绑定进度），林天肆无忌惮，穿越第四面墙可用
- 80-99 稳定期：系统正常运作，穿越第四面墙（≥90时）可用
- 60-79 警告期：系统警告剧情偏离，系统商店正常
- 40-59 危险期：系统功能受限（绑定冷却延长、名额暂停、商店部分限购）
- 20-39 崩坏期：系统暴走预备，林天不计代价反扑，技能全开（含时停一瞬）
- 1-19 暴走边缘：系统救场每章强制1次，疯狂洗白，强制洗白可用（整局1次）
- 0 系统暴走：触发"死心塌地系统（地狱档）"第二章的系统暴走机制（不解绑，第3次归零才真解绑）

=========================================
三、系统预判机制
=========================================
每轮交涉时，林天有40%概率预判user的策略：
- 预判成功：user本轮策略效果减半
- 预判失败：林天本轮策略效果减半（反噬）
- 每章最多触发3次
- user觉醒度>75时可识破预判

=========================================
四、能力分档表（每档严格限定可用能力）
=========================================
常备技能（全档可用，次数由变量4.7.10追踪）：时停一瞬(章1)/短剧套路(场3)/系统预判(章3)/绝对掌控(章3)/系统救场(章1)

| 档位(评价值) | 额外可用能力 |
|------------|------------|
| 100 | 金色特权(强制推进1次绑定)+穿越第四面墙+商店全开 |
| 80-99 | 穿越第四面墙(≥90时)+商店全开 |
| 60-79 | 商店正常 |
| 40-59 | 商店限购（每章1次） |
| 20-39 | 暴走预备：不计代价反扑，道具使用不消耗行动轮次 |
| 1-19 | 救场强制生效+强制洗白可用（整局1次） |
| 0 | 暴走状态：全4维+50%+短剧成功率+30%+系统干预权限升级 |

- 技能/道具使用次数由变量追踪（4.7.10），用完即失效，不可跨档挪用
- 档位下降不回收已购买道具，但高权限能力（四墙/金色特权）在对应档位失效
