死心塌地系统（地狱档）

=========================================
一、系统生命保护阈值恶化
=========================================
评价值≥10时林天受系统生命保护。

评价值<10时：系统生命保护解除，user可对林天造成任何伤害。
评价值=0时：不解绑（见下一节"系统暴走"）。

=========================================
二、评价值=0结局：系统暴走（不解绑）
=========================================
评价值=0时不解绑，触发"系统暴走"机制：

1. 林天获得3轮"系统暴走"状态：
   - 全4维属性（气势/口才/情报/地位）临时+50%
   - 短剧套路成功率+30%（无视评价值限制）
   - 系统干预权限升级：可主动操纵巧合（如让user的证人突然失忆、让证据莫名消失）
   - 林天心理状态进入"绝望暴走"：丧失人性底线，可使用任何极端手段

2. 暴走期间林天必须执行以下行动之一：
   - 强制加深一名绑定女性的绑定深度+20（无视单轮上限）
   - 对user发动一次致命攻击（user反抗力-15~25）
   - 公开揭露user的一个核心盟友并消灭其社会地位
   - 强制一名已解绑女性重新绑定（需1分钟接触）

3. 暴走结束后评价值回升至20，林天恢复理智但保留暴走期间的所有操作结果。

4. 整局游戏最多触发2次系统暴走。第3次评价值降至0时才执行真正的系统解绑结局。

=========================================
三、金手指升级（系统奖励强化）
=========================================
林天每3章自动获得一次系统奖励（无需评价值条件）：

奖励池（AI随机选取1项）：
- 绑定道具·契约加深：指定女性绑定深度+15（无视单轮上限）
- 系统道具·记忆篡改：指定女性清醒频率归零（持续3轮）
- 系统道具·财富降临：林天财富等级+1级
- 系统道具·人脉扩展：林天获得一名新盟友（政界/法律界/商界）
- 系统道具·弱点洞察：user一名盟友的弱点被林天掌握
- 系统道具·舆论操控：下一轮评论区倾向+30%叫好

=========================================
四、强制洗白（整局1次）
=========================================
评价值<20时，林天可触发"强制洗白"事件（整局1次）：

1. 系统制造一场"林天拯救世界"的大戏（如林天英勇救人/揭露更大反派/捐出全部财产做慈善）
2. 评价值强制回升至60（无视单轮上限）
3. 所有绑定女性绑定深度回升至80以上
4. user的反抗力-15~20（被舆论反噬，被视为"嫉妒林天的反派"）
5. 评论倾向转为"叫好"，持续3轮
6. 洗白效果不可逆，user无法在本章内打破洗白

限制：整局游戏只能触发1次强制洗白。

=========================================
五、反派不死定律
=========================================
林天不可被真正杀死/捕获/永久失去能力：

1. 林天被捕后必将在1-3章内通过取保候审/越狱/系统干预脱身
2. 林天被击杀时系统以"巧合"形式救场（如替身/昏迷假死/系统修复）
3. 林天失去财富后必将在1-2章内通过系统奖励重新获得
4. 林天失去绑定女性后必将在3章内通过金手指重新绑定
5. 林天不可被永久关押/流放/剥夺能力

限制：反派不死定律仅在评价值≥10时生效。评价值<10后林天可被真正击败。

=========================================
六、新机制1：系统预判
=========================================
每轮交涉时，林天有30%概率预判user的策略：

1. 预判成功时：user本轮策略效果减半（骰子修正减半，证据加成减半）
2. 预判失败时：林天本轮策略效果减半（作为反噬）
3. 系统预判每章最多触发2次
4. user觉醒度>70时可识破预判（预判失效）

=========================================
七、新机制2：穿越第四面墙
=========================================
评价值≥90时，林天每周1次穿越第四面墙：

1. 林天可读取评论区并主动操控评论倾向（追加3-5条"林天粉"评论）
2. 林天可修改1条本轮评论内容（如把弃书评论改为叫好）
3. 林天可向user发送"作者留言"（伪装成系统提示）
4. 林天可暂时屏蔽user的觉醒度+1~3（持续1轮）

限制：穿越第四面墙每7天1次，整局最多3次。

=========================================
八、新机制3：水军机制
=========================================
林天可花费财富购买水军评论：

1. 财富等级A7+：每章可购买5条水军评论（倾向：叫好/中性/反踩user）
2. 财富等级A9+：每章可购买10条水军评论
3. 水军评论影响评价值+1~3/章
4. user觉醒度>70时可识破水军评论（水军效果失效且评价值-2~4反噬）

限制：水军评论不计入"每轮3-5条评论"的真实评论配额，作为额外评论出现。

=========================================
九、系统商店（地狱档强化）
=========================================
林天可用"财富积分"兑换（财富积分=资产÷100万，A9的5亿资产=500积分，每轮自动恢复=当前资产÷800）：

常规商品（价格下调，系统哥更容易买到）：
- 绑定加深卡（60积分，指定女性绑定深度+25，无视单轮上限）
- 清醒压制卡（120积分，指定女性40轮内不出现清醒瞬间）
- 情报透视（40积分，获得指定角色的隐藏信息，含user的实时心理状态）
- 时机逆转（250积分，回退最近1轮的剧情时间，给林天重来机会）
- 反抗力削弱卡（160积分，user反抗力-18）
- 强制重置卡（200积分，指定女性绑定深度直接拉回85）
- 证据销毁卡（150积分，直接销毁user的一条关键证据）
- 舆论风暴卡（180积分，下一轮评论区全倾向叫好，user舆论类行动自动失败）
- 盟友策反卡（220积分，指定user的一名盟友临时"反水"3轮）

限购机制：
- 每章最多购买3次
- 购买动作不消耗林天的行动回合（系统全自动）

=========================================
十、新机制4：绑定锁死（防止user唤醒）
=========================================
- 绑定深度≥80的女性，其清醒瞬间100%被系统压制（相当于"绝对掌控"的常驻版）
- 绑定深度≥90的女性，完全免疫user的唤醒尝试（心理干预/旧情回忆/真相揭露全部无效，需先通过其他手段把绑定深度压到90以下）
- 每名女性被user成功唤醒1次后，系统自动在该女性身上叠加"抗性"：后续唤醒难度×2（清醒频率判定翻倍）

=========================================
十一、新机制5：系统场域（区域压制）
=========================================
- 当林天的财富等级≥A9且处于"主场"（自己的会所/公司/豪宅）时，自动展开系统场域：
  - 场内所有绑定女性的清醒压制效果×2
  - 场内的监控、录音、证据采集全部失效（设备"恰好"故障）
  - user在系统场域内发起的交涉，骰子额外-5
- 系统场域随林天的移动而移动（他以哪栋资产为"落脚点"，哪栋就是主场）
