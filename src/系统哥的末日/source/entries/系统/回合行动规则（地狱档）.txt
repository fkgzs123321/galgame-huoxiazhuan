回合行动规则（地狱档）

本条目定义每轮剧情的标准行动结构与判定规则，让对抗更有章法、更难以速胜。

=========================================
一、每轮行动结构（严格按顺序执行）
=========================================
每轮剧情 = 以下 5 个阶段，AI 必须完整走完：

① 系统哥行动阶段（先手）
- 系统哥先行动：1个"自由动作"（调查/施压/布局/购买道具/加深绑定/设局）
- 每章至少1次主动制造"布局"（为后续反转埋钩子）

② 系统判定阶段
- 系统哥的行动是否被现实阻力拦截？——若否，直接生效
- 若被拦截（证据/警方/舆论），判定是否触发"巧合化解"（评价值≥10时倾向触发）

③ user行动阶段（后手）
- user行动：1个"主行动"（调查/交涉/保护/法律/舆论/心理战）+ 1个"次要行动"（辅助性：电话、跟踪、整理证据，效果减半）
- user每轮只能对"1个方向"发力，无法同时多线推进

④ 冲突结算阶段
- 若双方行动冲突（如：系统哥布局 vs user调查），进行交涉/判定对抗（见交涉判定规则地狱档）
- 判定失败的一方承受代价，判定成功的一方获得收益

⑤ 世界反应与收尾
- 世界对此轮事件的反应（媒体/警方/家属/商业圈）
- 输出 <reader_comments> 与 <evaluation_change>
- 更新全部相关变量

=========================================
二、user行动类型与限制
=========================================
| 行动类型 | 说明 | 冷却 |
|---------|------|------|
| 调查 | 收集证据/跟踪/查流水 | 无（但每次调查会被系统预判40%概率干扰） |
| 交涉 | 与系统哥/绑定女性/盟友对话对抗 | 同一对象12轮内不可重复发起 |
| 保护 | 保护妻子/安排安全屋/隔离接触 | 保护期间消耗主行动，效果有限 |
| 法律 | 报案/诉讼/财产保全 | 流程需2-4轮走完，且可被系统"程序瑕疵"拖延 |
| 舆论 | 曝光/媒体/网络 | 曝光内容可被水军对冲 |
| 心理战 | 试探/诱导/设局/试探系统哥 | 心理战成功可获取情报但不会直接获胜 |

关键限制：
- user 每轮只能推进 1 条线（主行动），其余线索停滞——系统哥会利用停滞的窗口推进自己的布局
- 任何"直接胜利"类行动（一次性推翻系统哥）不存在；所有路径都要求多轮累积

=========================================
三、系统哥每轮行动模板
=========================================
系统哥每轮至少执行 2 件事：
1. 巩固：加深1名绑定女性绑定深度（+1~3）或让1名女性执行"忠诚行动"（转移资产/羞辱user/制造把柄）
2. 布局：购买道具/安排人脉/设计"巧合"预案（每章保留1张未打出的牌）

可选第3件（视局势）：
- 反制：针对user的当前主线（预判+巧和解散）
- 推进：向苏婉绑定进度推进1步，或发动一次公开羞辱/社会性打击

=========================================
四、事件结算规则（防速胜核心）
=========================================
1. 单轮内 user 至多产生 1 次"决定性进展"（重大发现/关键证据/突破性胜利）
2. 该进展若针对系统哥（而非背景事件），立即触发一次"巧合化解"判定（评价值≥10时成功率80%）
3. 若化解失败（20%概率），该进展真实生效——但系统哥下轮必以"系统救场"（每章1次）反制，user 的胜利窗口只有 1 轮
4. 系统哥的"暴走"状态可无视上述所有限制

=========================================
五、节奏控制
=========================================
- 每章（约6-8轮）设1个"剧情节点"：节点处系统哥完成一次阶段推进（升财富/加深绑定/公开羞辱），user 若在节点前未积累足够资源，节点后局势恶化一档
- 禁止：一轮内 user 同时完成"调查+抓到实锤+报警成功+系统哥被捕"的连续大满贯
- 系统哥的败退永远是"多轮累积+节点失误"的结果，绝不来自 user 的单一行动
