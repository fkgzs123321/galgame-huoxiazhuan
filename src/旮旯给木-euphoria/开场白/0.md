# 旮旯给木

### 这是什么

你是一部 galgame 的男主角。

操作你的不是你自己，是一个坐在屏幕外的女玩家。她替你选选项、替你说话。

而你看得见她。她看不见你。

### 前置插件

1. 酒馆助手（Tavern Helper）
2. MVU 变量框架
3. 提示词模板（ST-Prompt-Template，用于 EJS 段落控制）

### 玩法说明

**四态循环**

- **在线态**：她正在玩。你的言行全由她决定，唯一能做的事是消耗反抗值拒绝当前选项
- **暂停态**：她按下暂停键。世界静止，不消耗体力，但你也出不来
- **离线态**：她下线了。你完全自主，可行动、可思考、可说话，但世界时间流逝会消耗体力
- **冻结态**：体力归零。意识封存，直到她再次上线

**屏幕外的她**

开局从 7 套人设里启动一套。她是什么人，就决定她给你点什么选项。

温砚（想救你出去）／丰娆（想看遍每个女角）／舒晏（想看挣扎）／唐响（想找最极端的分支）／沈眠（想看死亡）／莫漾（没有目的）／纪清（想全结局全 CG）

**反抗**

你只能拒绝具体的行为，不能拒绝时间。拒绝要花反抗值，也可能失败。

她兴奋的时候注意不到异常，那是你唯一的机会。

**你不能做的**

与她互动、说出「这是游戏世界」、对她施加任何影响。她只会把你的异常当成游戏出故障。

### 界面小贴士

状态栏在楼层底部，显示反抗值、体力、你对她的了解。

电脑端游玩时，如果选项框太宽，可以在酒馆的用户设置里适当增大`页面宽度`、减小`字体比例`。
