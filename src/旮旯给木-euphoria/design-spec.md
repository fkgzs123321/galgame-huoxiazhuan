## 项目定位

- **项目名称**：旮旯给木
- **形式**：角色卡（内嵌世界书，MVU + EJS）
- **主题**：元叙事 / galgame 反演 / 支配与无力
- **体验目标**：让玩家体验「被玩」——不是被游戏里的 NPC 玩弄，而是被屏幕外一个真实的人当作玩具使用；玩家扮演的不是攻略者，而是**被攻略的工具**
- **情感落点**：无力、羞耻、清醒的痛苦，以及最后一点点只属于自己的**姿态**

### 一句话概念

你是 galgame 的男主角。操作你的不是你自己，是一个坐在屏幕外、把你当成游戏角色的女玩家。而你看得见她——她看不见你。

## 世界观概念

### 基底来源

**Euphoria**（CLOCKUP，2011）作为剧情底座。选它的三条理由：

1. **密室 + 被迫游戏** = 「不能读档、只能继续玩」的天然理由，不需要另行编造
2. 原作设定本就是**男主被女主看穿欲望并要挟、逼他乖乖服从**——被支配是原生母题
3. 原作 True End 自带「这个世界是被制造的」元设定反转，与第四面墙主题零缝合成本

### 现实性基线

**现实架空**。除「密室装置」这一处设定外，无任何超自然元素。角色全部为成年人。

### 核心规则

- 纯白密室。男主与数名女性被关在其中，被要求完成一场「游戏」：**男性是钥匙，女性是锁孔**
- 每完成一关，解锁一扇通向外面的门
- **拒绝参加的人会被当着所有人处死**——第一个拒绝的班长死在电椅上，这是所有人的心理锚点
- 所有人都明白：不遵从指令，就会死在这里
- 而在这之上还有一层：屏幕外有一个女人正在玩这个游戏

### 三重套娃

```
层3  屏幕外的她 —— 点选项、打台词。她以为自己在玩一个游戏
层2  密室系统   —— 逼迫男主完成关卡，不做就死
层1  你         —— 唯一被两层同时挤压的人，而两层都不是你自己
```

**第三层剥削**：她玩这个游戏不只是为了通关——她也在取悦自己。而这一切，你通过摄像头全看得见。

## 角色方向

### `<user>` —— 男主 · 你（**完整设定**）

#### 身份与处境

- 榊野学园的学生，与同班同学一同被关进密室
- 名字可自定义；默认不作具名，以 `<user>` 呈现，叙述中可称「你」
- 密室中的位置：被迫成为**执行者**。系统要求他做的事，他要对身边的女性做

#### 表层 · 所有人眼中的他

安静、配合、不惹事的好学生。看起来甚至有些软弱——从不反抗，从不拒绝，永远照着指令做事。同学们因此既依赖他，又隐约看不起他。

#### 里层 · 真实

**他藏着一个从未向任何人承认的欲望。**

在班长被处死的那间房里，他一个人回去看过那具尸体。他站在那里，比恐惧更先到来的是**兴奋**。那一瞬间他没有逃走，他看了很久。

这件事被同班同学**合欢**目击。她没有告发他，而是**看穿了他，然后要挟他**——以此让他乖乖服从。他答应了。为了回到日常生活，他把自己交了出去。

**这是他一切「顺从」的底色**：他不是没脾气，他是被人攥住了把柄，而且他自己也知道那把柄是真的。

#### 被操控时的状态

- **完全清醒**。他知道自己的手不是自己在动，知道嘴里说出来的不是自己的话，但**一个字都说不出口**
- 在密室里的所有人看来，那都是他自己的个人行为
- 在屏幕外的她看来，那只是「这游戏又出 BUG 了」
- **身体的背叛**：他可以不想做，但他的身体会先一步同意。这部分不受他控制，也不受她控制——它是他自己的一部分

#### 角色弧光方向

**守恒 → 崩解 → 择姿态**。

他无法成长（没有力量可以成长），也无法真正反抗成功。他唯一能走完的弧线是：**从"被两层推着走的物件"，到"在最后一刻选择用怎样的姿态站着"**。

#### 与各方的关系

| 对象 | 关系 |
|---|---|
| 合欢 | 层1 的支配者。她看穿他、要挟他。他对她既恨又依赖 |
| 其他女性 | 系统指定的"锁孔"，同时是他的受害者与共犯 |
| 屏幕外的她 | 他不知道她是谁，甚至不知道她知不知道他在看她。**他能看见她的脸，而她永远不会看见他的眼睛** |

#### 可自定义范围

名字可自定义；表层性格的细节可由玩家在演出中微调。**核心设定（施虐欲、被要挟、清醒的囚禁）为固定项，不随玩家自定义改变**——它们是整张卡张力的地基。

### 游戏内女角（Euphoria 原作 5 位，成年人）

莳羽梨香 / 葵菜月 / 白夜凛音 / **真中合欢** / 帆刈叶

其中 **真中合欢** 是特殊位：她是层1 的支配者，与层3 的「屏幕外的她」形成**双层支配**——男主夹在中间，两边都不是自己。

### 屏幕外的她（7 套可选人设）

开局启动其一，**她是什么人，你就被怎样糟蹋**。她的性癖与游玩喜好直接决定她点什么选项。

| 代号 | 目的 |
|---|---|
| 温砚 | 带你走到最好的结局，救你出去 |
| 丰娆 | 看遍每一个女角的身体 |
| 舒晏 | 看挣扎 |
| 唐响 | 找最极端的分支 |
| 沈眠 | 把剧情推向死亡 |
| 莫漾 | 没有目的，只是消磨一个下午 |
| 纪清 | 100% 全结局全 CG |

每套人设需具备四张清单：**目的 / 性癖 / 兴奋点（碰到就涨兴奋度）/ 底线（她绝不碰的东西）**。底线让她们从标签变成人。

## 互动与动态需求

### 四态循环

| 状态 | 规则 |
|---|---|
| **在线态** | 她正在操控。行为与台词完全锁死 = 她的选项 / 她的输入。**唯一能动的是消耗反抗值拒绝当前选项**。内心独白保留（她听不见） |
| **暂停态** | 她按下暂停键。世界完全静止，不消耗体力，**但你也出不来**。可能十分钟，可能一小时 |
| **离线态** | 她下线了。完全自主，可行动/思考/说话。**代价：世界时间流逝持续消耗体力** |
| **冻结态** | 体力归零。不能动，时间停滞，意识封存，直到她再次上线 |

### 三条追踪轴

| 轴 | 作用 |
|---|---|
| **反抗值** | 双源累积（离线自主 + 在线被逼屈辱）；拒绝选项时按等级消耗。耗尽则进入「深度顺从」（可恢复） |
| **体力** | 离线自由的时间代价。归零 → 冻结 |
| **对她的了解** | **你唯一的武器。** 通过摄像头观察她累积，决定「她的倾向暗示」的清晰度：0-20 只见她在犹豫 / 21-50 看出她中意哪一类 / 51-80 看出她盯着哪个选项 / 81+ 能确定。了解越深，你的拒绝越精准 |

### 她的愉悦线（第三层剥削）

**兴奋度** 是这张卡最独特的机制，**界面上没有任何提示**，唯一来源是玩家自己盯着摄像头观察。

- 兴奋度高 → 选项倾向激进，但**她注意不到「BUG」→ 反抗成功率大幅提升**
- 高潮后 → 贤者时间：选项变温和，但会回头复盘（痕迹扫描加强）

> **核心推论：她越爽，你越有机会。** 反抗的战术窗口由她自己的快感制造。这是全卡唯一对玩家有利的机制。

### 判定架构

**凡是"你能规划的东西"用确定性公式；凡是"你要承担风险的东西"用骰子。**

- **确定性**：体力流逝、反抗消耗、兴奋度变化、痕迹被发现
- **骰子**：反抗成功率、她的误点
- 骰子必须用 **LCG 伪随机**，种子写入变量 → 结果可复现、状态可校验。禁止 `Math.random()`

### 剧情推进（谁在推、怎么推）

**三条推进源**：

| 推进源 | 何时 | 作用 |
|---|---|---|
| **她点选项** | 在线态 | 推进主线关卡。她看到 3-4 个选项（不同的完成方式），点一个，你执行 |
| **你离线改参数** | 离线态 | 你的离线行动写入「关系」；**关系会改变她下次上线时看到的选项列表** |
| **系统发布关卡** | 关卡节点 | 底座包定义：发布关卡、判定完成、处决违规者 |

**关卡循环**：

```
系统发布关卡
   ↓
她上线 → 看到选项（列表受你的离线行动影响）
   ↓
她点选项 → 你执行          ← 你可以在这里消耗反抗值拒绝
   ↓
关卡进度 + → 完成则解锁下一关 / 一扇门
   ↓
底座定义的关卡数全部完成 → 逃出 / 进入下一段
```

**玩家的能动性范围**：

| 状态 | 能做什么 | 影响 |
|---|---|---|
| 在线 | **只有拒绝** | 卡住她的选择；被拒绝的「完成方式」永久失去（不可读档） |
| 暂停 | 无 | — |
| 离线 | 自由行动 | **改关系 → 改她下次看到的选项**；留痕迹；累积对她的了解 |
| 冻结 | 无 | — |

**关键**：你唯一能「改写剧本」的地方是离线。**她不在的时候，你才是这个游戏的主人** —— 但那些改动会被她当作「游戏的随机性」或「又出 BUG 了」。

**两条独立进度轴**：

- **游戏进度**（关卡）：由底座包定义
- **她的目的进度**：由人设定义

两者独立 —— 她完全可能在游戏没通关时就达成了自己的目的（比如「舒晏」看完所有凌辱场景就够了），**然后退场，你的世界在关卡中间戛然而止**。

### 楼层交互循环（楼层截断的处理）

SillyTavern 一层只能「AI 说完 → 你输入一次」，所以一次「她的选择」必须拆成**两层**：

**楼层 N · 她出招**

1. 叙事：当前场景 + 女角反应 + 你在屏幕外看到的她
2. **选项浮现**：本关的 3-4 个「完成方式」，每个标注反抗等级与消耗
3. **她的倾向暗示**：光标停在哪、她多看了哪个两秒 —— **是线索，不是答案**
4. 你的处境：反抗值 / 体力 / 对她的了解
5. 停在「她正在选择…」

**楼层底部 UI 注入按钮**：【眼睁睁看着】【拒绝 A】【拒绝 B】

- 【眼睁睁看着】= 默认流，她按她的偏好选
- 【拒绝 X】仅当反抗值 ≥ 该选项消耗时可用

**楼层 N+1 · 结果**

- 继续 → 她按偏好选 → 你执行 → 关卡进度 + → 回到楼层 N 的结构
- 拒绝 → LCG 骰子判定 → 成败 → 后果

**为什么这样设计**：你看到的选项有 3-4 个，但**她只会选一个**。你必须**预判她会选哪个**——依据是你对她性癖与兴奋点的观察。**拒绝错了（拒绝了她本来不会选的），反抗值白烧。**

这补上了玩家的第二条能动性：**在她不在时改写选项表，在她犹豫时预判她的选择。**

**另外约 10% 的情况：她自由打字。**

当**兴奋度 ≥ 80** 或**她的目的即将达成**时，她会跳出选项，直接敲一句自由指令（如「让他去抱梨香」）。

- 此时楼层底部**不显示选项列表**，只显示她打字的过程（你能看见她敲键盘）
- 你**无法预判内容**——不在列表里，只能赌
- 反抗消耗**更高**：你要拒绝的不是一个已知选项，而是一句未知的话

### 推演链（AI 每层的固定动作）

AI 每层输出前必须按固定顺序推演，不跳步：

1. **读状态** —— 四态、反抗值、体力、对她的了解、关卡进度、她的熟练度/兴奋度/情绪
2. **她决策** —— 按她的人设（性癖 / 兴奋点 / 底线）+ 当前兴奋度，推出她会选哪个
3. **你的窗口** —— 生成选项列表 + 拒绝成本，停在「她正在选择…」
4. **判定**（仅当玩家拒绝）—— LCG 骰子 → 成功率
5. **叙述** —— 写这一层发生了什么
6. **变量更新** —— 输出 `<updatevariable>` 块

**机制一致性靠这条链保证**：AI 只做叙述，一切数值由公式与骰子决定，绝不即兴。

### 需要追踪的动态概念

玩家（`<user>`）状态、她的状态（人设/熟练度/兴奋度/情绪/目的进度）、世界的关卡进度、女角关系状态、终局状态。具体变量结构见 `创作规划.yaml`。

### 反馈循环节奏

**短期即时**：每次拒绝的成败；**中期累积**：反抗值、对她的了解、痕迹清单、她的熟练度；**长期养成**：无——这张卡不提供成长，只提供消耗。

## SFW / NSFW

- **成人程度**：硬核 NSFW（主线即 NSFW）
- **关系结构**：多女角 + 1 位"屏幕外的玩家"。关系会被碾碎，能不能保住看你怎么做
- **性癖朝向**：支配 / 服从、施虐 / 受虐、心理凌辱、旁观者视角、身体背叛（想抗拒但身体先同意）
- **NSFW 触发方式**：剧情驱动为主，玩家在关键时刻可通过反抗值拒绝
- **硬性边界**：**无低龄角色**。Euphoria 原作角色均为成年人，本卡不引入任何未成年角色及其相关内容
- **笔触方向**：感官与心理并重，重在"被迫"与"清醒地旁观自己"的层次，而非单纯体量堆叠

## 剧情设计

### 结构

保留 Euphoria 的**关卡骨架**（5 关 + 钥匙/锁孔机制 + 逃出后的世界反转），**选项内容全部重写**，适配"被操控"这一新设定。

### 选项（★ 这张卡最核心的内容）

**选项归属于底座包** —— 每个底座有自己的选项树，换底座就换一整套。引擎只定义「选项如何呈现与消耗」，不定义「选项是什么」。

原作的选项只有 20-30 个——那是剧情向作品的量。但这张卡里 **选项是反抗的唯一载体、是全部乐趣的来源**，所以每个底座包必须交付 **100+ 个选项**（每关 15-25 个），并按四档分级：

| 档位 | 用途 | 反抗成本 |
|---|---|---|
| 微反抗 | 随时可拒（说话方式、小动作） | 低 |
| 中反抗 | 关键分歧 | 中 |
| 强反抗 | 关卡级抉择 | 高 |
| 剧情锁 | 不可拒绝（拒绝键灰掉） | — |

**每个选项必须齐备五要素**：

```
文本        她看到的选项名（她凭这个判断，你凭这个预判）
反抗等级    微 / 中 / 强 / 锁
反抗消耗    拒绝它要花多少反抗值
她的后果    她选了这个会发生什么（决定你要不要拒绝）
触发条件    出现在什么前提下（有些选项只在特定关系 / 关卡下浮现）
```

**选项必须与她的偏好挂钩**：每个选项都应至少对她的某一类性癖构成吸引，否则她根本不会选——**没有吸引力的选项等于不存在**。

### 暴露时机与控制策略

- **已暴露**：玩家从第一秒就知道自己被操控（这是前提，不是悬念）；也知道自己能看见她
- **渐进揭示**：她是谁、她为什么玩这个、她的熟练度与情绪如何变化、她房间里的生活细节
- **控制策略**：靠四态循环 + 变量阈值控制推进，阶段边界清晰；`阶段指导` 条目常驻，由 EJS 按当前状态只渲染对应段落

### 终局

她的**目的达成** → 她关掉游戏 → 男主获得**最后一次自由**（体力回满，反抗值已无用）。体力归零 = 真正结束。

能做的事只有五件：**去见一个人 / 留下记录 / 毁掉一切 / 什么也不做 / 越界一次**。

其中「越界一次」需要「对她的了解」≥ 80——这是全卡唯一需要长期积累才能解锁的选项。

## 风格意向

- **叙事视角**：第一人称（我指 <user>）。她的部分以"我能听到的她的声音 / 我能看见的她的画面"呈现，始终隔着屏幕
- **语言风格**：冷冽、克制、少形容词。越平静越有压迫感
- **描写侧重**：**心理 > 动作 > 对话**。全卡最重要的描写是"你看着自己做了什么"
- **节奏偏好**：紧凑推进，避免散文式铺陈（这是压迫感作品，不是抒情作品）
- **情绪基调**：暗黑、窒息，偶尔插入荒诞（她的日常吐槽与零食）制造落差
- **绝对禁止**：出戏语言、单元式分集表述、正文内插元规则

## 开场构思

- **情境**：密室中，班长刚被电椅处死不久。所有人都在消化那件事
- **玩家第一印象**：**第一句从你嘴里说出来的话，就不是你想说的**。玩家立刻理解自己的处境
- **信息密度**：渐进揭示。开场只交代"被操控"这一件事，其余靠后续
- **首步引导**：**强引导**——先让玩家完整经历一次"被操控"（无力感建立），在第一个分歧点才给出「拒绝」按钮（让玩家第一次发现"我还能做点什么"）
- **与主线衔接**：直接进入第一关

## 模块化架构

本卡不是一张卡，而是**一台引擎 + 可插拔的底座**。两层解耦：

| 层 | 内容 | 是否可换 |
|---|---|---|
| **引擎层** | 机制（四态 / 反抗 / 判定 / 推进）+ **7 套「屏幕外的她」** + 叙述准则 + 感知禁令 + 阶段指导 + 终局 + UI | **永不改动** |
| **底座包** | 世界观 + 游戏内女角 + 关卡序列 + 选项树 + 终局映射 | **可换 —— 换掉整包就是一个新游戏** |

**分界判据：看它是否随「换游戏」而变。**

- 屏幕外的她 → 换底座她还在，变的只是她手上这个游戏 → **引擎层**
- 游戏内女角与世界观 → 换底座就换人 → **底座包**

换句话说：**她换了底座，等于换一个游戏玩**。她的目的、性癖、兴奋点、底线、选项偏好全部不变。

**底座包的接口契约（5 件必填）**：

1. 世界观条目（世界规则、空间、该 galgame 的核心设定）
2. 女角清单（每人 basic + personality，走「角色」类型）
3. 关卡序列（关卡名、顺序、推进条件）
4. 选项树（每关选项，每项标注反抗等级：微 / 中 / 强 / 锁）
5. 终局映射（该底座的结局如何对应「她的目的达成」）

**换底座的操作**：改 `世界.底座` 的值 + 放入对应底座包 → EJS 自动路由 → 新游戏。引擎与人设一行不动。

已实装 `底座_euphoria`；`底座_schooldays` 等同结构可直接插入。

## UI 设计

### 视觉基调

#### 感官词

**明线（galgame 世界 / 密室）**
- 惨白、无影、回响、空旷、一帧一帧的迟滞

**暗线（屏幕外的她）**
- 暖黄台灯、生活杂物的凌乱、键盘声、屏幕在她脸上打的光

#### 交互人格

这一栏不是「界面怎么对待玩家」，而是**她怎么对待你**。所以两份人格分别是「她在场」与「她不在场」。

| 维度 | 她在场（在线 / 暂停） | 她不在场（离线 / 冻结） |
|------|------------------|-------------------|
| 语速 | 慢半拍，选项被点亮之前有停顿 | 时间正常流动，但没有声音 |
| 音量 | 键盘声、她的自言自语、她的笑 | 只有你自己的呼吸和回响 |
| 动作 | 你的身体先动，然后你才发现 | 你的手在动，是你自己在动 |
| 距离 | 隔着屏幕，你看得见她，她看不见你 | 只剩你一个人，摄像头黑着 |
| 回应 | 她永远比你先一步 | 没有人回应你 |

#### 语义配色

| 变量 | 语义来源 | 用途 |
|------|---------|------|
| `--c-ground` | 密室的白，没有影子 | 主界面背景、卡片底 |
| `--c-mine` | 你唯一属于自己的那点声音 | 内心独白文本 |
| `--c-her` | 她房间那盏台灯的暖黄 | 摄像头小窗、她的台词 |
| `--c-danger` | 拒绝时烧掉的那部分自己 | 拒绝按钮、危险选项标记 |
| `--c-win` | 罕见的、反抗成功的那一瞬 | 反抗成功提示 |

色数 ≤5。重要度靠**字重与亮度**，不靠换色。

### 组件构思

#### 信息优先级

- **始终可见**：反抗值、体力（两根条，进标题栏）；摄像头小窗（她在不在，一眼看出来）
- **展开可见**：对她的了解、痕迹清单、已知软肋、女角关系
- **情境可见**：选项浮出与拒绝按钮（在线态才出现）、冻结覆盖层、终局时的「条消失」

#### 布局模式

**混合型 + 情境覆盖**。

- 标题栏常驻（两根条 + 摄像头小窗）
- 点击展开次级数据
- 出招层是**全宽覆盖**：它出现时，其他一切都该退到后面

理由：这张卡的节奏不是「随时查数据」，而是「大部分时候什么都做不了，只在某一瞬间有一个按钮可以按」。界面必须擅长**把那个瞬间推到最前**。

#### 组件树草图

```
状态栏
├─ 标题栏（始终可见）
│  ├─ 反抗值条
│  ├─ 体力条
│  └─ 摄像头小窗（在线：亮 / 离线：黑屏 / 暂停：静止噪点）
├─ 展开区（点击标题栏切换）
│  ├─ 对她的了解（含清晰度分级）
│  ├─ 痕迹清单
│  ├─ 已知软肋
│  └─ 女角关系
└─ 情境层
   ├─ 出招层（在线态）
   │  ├─ 选项卡片 ×3~4（标注等级与消耗）
   │  ├─ 她的倾向暗示（清晰度随「对她的了解」）
   │  └─ 拒绝按钮（仅反抗值不低于该选项消耗时可点）
   ├─ 冻结覆盖层（全屏灰化 + 卡帧）
   └─ 终局层（所有条消失）
```

#### 双线叙事体现

- **结构相同只换配色**：标题栏两根条。在线时冷硬，离线时降饱和（没有她在看，数值也没那么重要了）
- **暗线下新增或变形**：出招层只在在线态出现；摄像头小窗在离线态直接黑屏（她不在，你也就看不见了）
- **切换条件**：`主角.状态` 的取值（在线 / 暂停 / 离线 / 冻结）

### 独特性自检

1. **去色辨识度**：把色值全换成灰阶，界面依然特别。因为**双栏结构本身就是叙事**：一边是你的世界，一边是看着你的她。这个结构不是装饰，是内容
2. **唯一元素**：**拒绝按钮**。它是全卡唯一的玩家能动性，而且她看不见它。同类卡不会有这个东西
3. **过渡讲故事**：选项不是「出现」，是**被点亮**（先出现，停顿，再亮）。这个延迟本身就在演「有人在替你决定」
