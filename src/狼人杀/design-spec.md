## 一、项目定位

- 项目名称：血月七夜（狼人杀）——最终名待定
- 形式：角色卡（世界书内嵌），MVU + EJS，PNG 打包，ui_mode=frontend
- 主题：真实怪物的封闭空间生存博弈。狼人杀的全部机制真实发生：夜晚真的有人死，白天真的投票处决，死者永不回来。
- 体验目标：**在不知谁是怪物的人群里活下去**。玩家的乐趣 = 信息博弈（观察、指认、结盟、伪装）+ 真实死亡的道德重量（你投出去的可能是无辜的人，她会真的死、死得很惨）+ 极端环境下与 11 名女性的生存关系。
- 情感落点：恐惧、怀疑、以及恐惧催生的亲密——越靠近真相，越不敢信任任何人。

## 二、世界观概念

### 基底

现代世界，唯一超自然物是**狼人**：血统或咬伤传染，血月之夜强制变身，兽性杀人（与发情）。除此之外一切按现实走（现实性基线：雪灾、救援、尸检、法律程序全部真实，只是被封山封路切断了外部介入）。

### 空间

深山温泉旅馆「霞隐庄」（暂名）。暴风雪（现实理由）+ 血月结界（超自然理由）双重封闭：出山者死在雪里，血月期间庄外一步即狼群。

**结构**：本馆（大堂、晚餐厅、厨房、温泉、停灵间、后院审判台）+ **12 间独栋离屋**沿庭院与林缘散布，间隔二三十米——每人一间，独立进出。

**声学现实（隔音问题的答案）**：暴风雪 = 天然声墙。夜里围猎的动静传不出去，紧邻最多有若有若无的「疑听」（分不清是惨叫还是风）——疑听不可验证，与梦同为话术素材。三个后果：①死人是悄悄死的，可能死了几小时才被发现，尸温尸僵是唯一的时间证据（姜芸的专业价值）②雪地脚印 = 第二条物证链：夜里谁走过谁家门口，但雪一直下会覆盖——**取证有时效，清晨头一小时是黄金时间** ③夜里独处无援，落单屋中被围猎时无人会来。

### 血月七夜（时间框架）

血月异常天象连续七夜，每夜狼群必然围猎（守庄之物可阻成扑空夜）。七夜内未分胜负 → 狼胜（熬过七夜狼群即掌控全庄）。实际一局 3-5 轮分胜负。

### 审判传统（处决正当性核心补丁）

霞隐庄所在的古老家族世代守着一桩秘密：此地是狼巢。祖传规矩**银之审判**——血月期间每夜日出前，生者必须交出一名「被指认者」，绑上刑台处决。

- **银验已失效**：血月之力遮蔽银器，白天的狼保持人形、无法试身 → 只能投票处决
- **处决 = 众刑（决策 10）**：投票过半 → 全体生者在审判台共同处决，**轮流交合致死**。功能性自洽：血月期间狼的人形躯体强化、普通刀伤杀不死（银匕是唯一物理解且仅一把），要确保处决的是狼只能用「狼之法」——交合中狼卸防脱力，耗到死。对狼 = 唯一可行处决手段；对无辜者 = 纯粹凌虐谋杀——**冤案时全员是凶手，狼案时全员猎狼狂欢**
- **同罪条款**：祖规拒绝参与处决者与被指认者同判——没人能袖手
- **头狼之性**：被处决的狼有概率垂死暴起带走行刑者一人——行刑顺序 = 参与恐惧
- **以银代众**：持银匕者可一人一刀结束处决（免除众人凌虐），银匕消耗即失去反杀能力
- **死状验真伪**：狼被处决时现原形；无辜者被处决就只是死了 → **冤案真实发生，死状即复盘线索**
- 传统持有人 = 老板娘（名单 1 号），但她也仅是持规矩的人，判定权在脚本（见 §三）

### 狼的设定

- 变身：仅血月之夜，狼形/半狼形；**白天完全人形，无必然破绽（决策 11）**——三条情境性可控破绽：①伤口愈合异常快（昨天割的手今天痊愈）②体能超常（突发状况下的力量/速度露馅）③月出失神（血月升起瞬间的短暂颤抖）；唯一硬例外 = 处决死亡时现原形。血月期间人形躯体强化：普通刀伤杀不死（银匕唯一物理解）
- 知情分层（写 NPC 时逐人定）：**知情狼**（血统觉醒，清醒时知道自己是狼）/**失忆狼**（血统沉睡更深处，连自己是狼都要从身体与梦的异样里猜）——前者会做局，后者连自己都怕
- **兽性 = 发情，夜袭 = 群狼围猎**：每夜 4 狼**全部**发情，狼队血月下相聚、共同选定一名猎物，轮流交合**活活做死**（衰竭/撕裂/窒息）——交合的韵律就是死亡倒计时，杀与性同源。猎杀与留种二选一：留种 = 4 兽尽泄于体内、猎物不死，但被种者**次夜发作**（人格沉没、真死，化为夜行兽——不计狼数，作为夜间游荡威胁存在，白天藏不住兽化特征，大概率被指认处决）
- 减伤通道（狼的扑空夜）：狼毒草汁涂门 / 麻沸散沉睡——被阻当夜无夜袭死亡
- **夜忆清零（全员，含狼）**：清晨醒来昨夜归零。狼白天知道自己「是狼」，但不知道自己夜里干了什么——狼也要偷偷检查自己的身体（指甲里的血肉、酸痛、陌生气味）。显记忆清零逻辑上包含「说不出」；身体痕迹保留但**不可自证来源**（展示伤痕可求信也可被疑为自伤栽赃）
- **梦 = 唯一泄密通道**：清零的是显记忆，兽性从梦里渗——被围猎者做被围猎的梦，狼做围猎的梦（兽的视角，看不清自己的脸），被种者做同样的梦却不知已被种。梦无法验证——白天话术的全部战场架在这个空洞上
- **人死物灭**：守庄之物持有人死亡，物当夜被血月回收，不可继承不可找回，搜出也无用（黎明化灰）；搜尸搜房只剩情报价值——证明死者持物 = 神位曝光

### 白天的话术世界（不可言说之夜）

夜忆清零世界里，白天只有五个信息源，全部写进 NPC 行为条目：

| 信息源 | 性质 | 话术形态 |
|---|---|---|
| 尸体与死状 | 客观硬证物 | 在哪发现、什么痕迹、姜芸的验尸结论（「性事致死」可验、对象永不可知） |
| 梦 | 主观证词、无法验证 | **核心战场**：述梦 / 析梦 / 编梦栽赃——狼也编梦 |
| 身体痕迹 | 半公开 | 酸痛、淤青、咬痕——可展示、不可自证；自伤栽赃合法 |
| 白天行为 | 社交层 | 谁回避谁、谁在搜什么、谁答不上话（好感/怀疑双轴的行为依据） |
| 血月历 | 节奏层 | 「还剩几夜、还剩几人」的算术恐怖 |

**硬规则**：任何 NPC 不会陈述昨夜的具体事件（没有记忆可陈述）；声称「记得昨夜」= 疯话或表演。对话永远差半句、话题到某个词就集体绕开。话术三招：**述梦 / 验身 / 指认链**（死状 → 人际 → 行为三段推理）。NPC 对话按怀疑阶段分层：试探期（旁敲侧击）→ 对峙期（公开指认）→ 审判期（投票陈词）。

## 三、游戏机制（脚本 = 裁判，AI = 演员，玩家 = 自由行动）

### 配置

12 人 = 玩家 + 11 NPC。**4 狼 / 4 民 / 4 神**。
**全员身份由脚本在开场白结束后随机指派**（含玩家，12 人全池），名单本身不预设任何人阵营；三组**先分组后落人、互斥**——「狼是预言家」在结算层不可能发生。

### 守庄之物（神职具现，决策 5）

四件祖传实体物，神职 = 持物，不绑定任何人：

| 物件 | 神位 | 能力与限制 |
|---|---|---|
| 狼感铜镜 | 预言家位 | 夜照一人，**绝对准**（决策 7）；每夜限一人；持镜者夜夜携带全庄最烫的东西，被翻出即暴露 |
| 药炉药囊 | 女巫位 | **毒药一份**（现实毒物，杀任何人；**不限夜晚**，白天任何时机下毒，发作有时间差——死亡时间与进食记录可反推毒源，投毒自带暴露面）＋ **麻沸散一份**（下于房门口/饮水中，整屋沉睡——狼进不来也弄不醒，被动守卫；被下者晨起剧烈头痛 = 曾被下药暴露） |
| 祖传银匕 | 猎人位 | 遇袭可搏命一击（脚本结算成同归或击退）；平时是普通凶器，对人照用 |
| 狼毒草汁 | 守卫位 | 涂门窗，狼嗅之不碰，护一处一夜；**存量约 3 份**，可连涂但耗存量，续采要去后山林缘禁区——拿命换守 |

- **血梦指派**：血月第一夜起，托梦告知「你的命」或「某物藏于何处」——梦的内容彼此不知，「你梦见了什么」是白天的博弈话术（谎报血梦 = 悍跳神职）
- **人死物灭（决策 5）**：持有人死，物当夜被血月回收——神位不可继承；搜出物无用（黎明化灰），搜尸搜房的意义只剩「证明死者持物 = 神位曝光」
- **物的价值锚**：铜镜 = 唯一验狼手段；毒药 = 唯一先手杀狼手段；银匕 = 唯一被袭反杀手段；草汁/麻沸散 = 仅有的扑空夜来源——四件物合起来才扛得住每夜的围猎，死一件好人阵营就永久瘸一条腿

### 神职的信息接力与遗言规则

**记忆清零只清夜晚**——白天照镜的结论是白天的记忆，保留。持物人验完人后，信息传递只有三条通道：

| 通道 | 代价与收益 |
|---|---|
| 嘴说（公开报查验） | 自认持物 = 当夜围猎优先级最高——经典神职两难，跳与不跳都可能是死 |
| 藏（遗书/字条/只给特定人的暗示） | **物灭信息不灭**——她死后信息还在，搜尸搜房的核心动力之一就是找死者遗言 |
| 带进坟墓 | 夜袭死无遗言，信息随她清零 |

- **遗言规则现实化**：处决有遗言（审判台上说完再死）；夜袭无遗言（死了到清晨才被发现）——狼的悍跳空间在处决遗言（假神职遗言），好人的接力靠遗书与冒险公开
- **神职互认无天然通道**：互不相识、隐秘持物，互认只能靠白天社交试探；「跳持物」的时机是好人阵营最大的集体决策
- **信息也会死**：每夜都可能永久损失一条信息线（人死物灭 + 夜袭无遗言）——与「每夜死一人」「人死物灭」并列为危机感三支柱
- **死亡 = 信息归零（决策 9）**：夜袭死者的全部所知（含白天所知）随她消失；信息存活只依赖传递，不依赖人——想留信息，要么冒险嘴说，要么提前留字条

### 经典机制映射与漏洞封堵（复刻清单，脚本自测逐条对照）

| 经典机制/操作/漏洞 | 本卡对应 | 状态 |
|---|---|---|
| 技能顺序（守→刀→巫→预→猎） | 入夜：涂门/下麻沸散（入睡前）→ 狼队围猎（做死/留种）→ 银匕搏命（被袭时）→ 铜镜夜照（独立） | 已定 |
| 处决遗言 / 夜袭无遗言 | 审判台说完再死；围猎死清晨才被发现 | 已定 |
| 猎人死后开枪 | 银匕遇袭当场搏命（同归/击退）——不是死后技能，是搏命 | 已复刻 |
| 预言家藏/跳查验 | 信息接力三通道：嘴说（暴露）/藏遗书/带进坟墓 | 已复刻 |
| 悍跳/对跳/假查验 | 谎报血梦、谎称持镜、假查验结果、处决遗言假神职 | 已复刻 |
| 狼自刀骗药 | 无解药不适用；替代 = 自伤栽赃「我夜里也被袭了」 | 已堵/替代 |
| 狼自爆 | 公开跳狼 = 当场处决，无收益；赌博式自保话术（「处决我啊」）自然存在 | 已堵 |
| 空刀/拖平 | 血月强制发情不可弃猎，每夜必猎——节奏锁死 | 已堵 |
| 警徽流 | 无警徽（决策）；接力靠遗书与冒险公开 | 裁剪 |

### 文风五律（血腥 × 性 × 恐怖的融合语法，写文风条目组的总纲）

三者不是三种调味料轮流撒，是**同一具身体上的三种时间**：

1. **同源律**：兽性一发，性、杀、恐三态同体。写围猎不「先性后杀」——交合的韵律就是死亡倒计时，快感与毁灭同步，狼的温柔与残忍同体（兽性没有恶意，恐怖的正是无恶意）
2. **残留律**：血腥是过去的性，性是未来的血。白天**不写夜，夜在身体上**——淤青的形状、走路的方式、坐下时的迟疑、回避目光的角度
3. **失语律**：恐怖不写「恐怖」，写「大家都在回避的那个词」——对话的半句留白、突然变亲昵或变陌生的称呼、话题绕行的轨迹。记忆清零的世界里，失语本身就是最大的恐怖
4. **温度律**：热夜冷昼——夜的段落用体温、潮湿、腥、颤写；昼的段落用尸斑的青、晨雾的白、干涩的语气写。冷热交替是呼吸节律，同场景内穿插（晚餐的热汤+门口的冷风）是不安感
5. **具体律**：血腥写具体的器官与液体，性写具体的构造与动作，恐怖写具体的物件（多出来的脚印、挪过位的椅子）——三者共享 craft-05 三栏词表（主体/修饰/坐标），混融时不出戏；走 `verify-dirty-ratio.mjs` 校验

## 七、板子扩展路线图（2026-09-27 全面调研：屠边/屠城 × 6-18 人板 × 狼方/神职/第三方变体）
