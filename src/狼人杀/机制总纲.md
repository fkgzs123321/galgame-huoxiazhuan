## 〇、一局时间线总览

```
开场白（晚餐夜，身份未指派）
  → 脚本指派 4狼/4民/4神（先分组后落人，互斥）
  → 第 1 夜：血梦告知身份 → 入夜准备 → 狼队围猎 → 夜忆清零生效
  → 第 1 天：清零唤醒 → 尸体发现 → 取证与话术 → 投票 → 众刑处决 → 死亡处理
  → 第 2 夜 …… 循环至第 7 夜
  → 终局：狼全灭（好人胜）｜狼数≥好人数（狼胜）｜玩家死亡（死档）｜七夜耗尽（狼胜）
```

**每夜死亡预算**：夜袭最多 1（围猎或留种，被阻则 0）＋ 处决最多 1 ＋ 头狼反扑最多 1。

## 一、开局

### 1.1 开场白（3 个，全收束在晚餐夜）
1 常规（投宿之夜）+ 2 alt（自驾被困 / 搜救未遂）。晚餐夜结束于「各自回房」，身份尚未指派——玩家在任何开场白中的言行不预设阵营。

### 1.2 脚本指派
- 12 人池（玩家+11 NPC）先抽 4 狼、再抽 4 神、余 4 民——**先分组后落人，三组互斥**，「狼是神职」在结算层不可能发生
- 指派结果写入 MVU（`stat_data`），**不向 AI 叙事层明文公开全图**——AI 只按「当前可见信息」叙事（防剧透泄漏）

### 1.3 第一夜血梦
- 月升时全员入睡：**狼**梦中知晓同伴是谁（狼队互认）；**持物人**梦中知晓「你的命」与藏物之处；**民**做一个无信息的血梦（只知「血月开始了」）
- 梦的内容彼此不知——「你梦见了什么」从第一天起就是话术战场（谎报血梦 = 悍跳神职）
- 血梦是**私密的**：取物在次日清晨起可行，取物行为须隐秘（被人看见 = 持物暴露）

## 二、夜晚阶段（脚本结算窗）

### 2.1 入夜准备（玩家 UI / NPC 脚本策略）
| 行动 | 执行者 | 效果 |
|---|---|---|
| 草汁涂门（守卫位） | 持物人 UI | 意念使用，无声无息：所选一处门窗当夜狼嗅之不碰；存量约 3 份，可连涂耗量；可涂自己屋。除了 DM 没人知道门被守了 |
| 麻沸散（女巫位，一次性） | 持物人 UI | 意念使用：选一间屋整屋沉睡：狼嗅不到活人气息 → 不会选此屋；被下者晨起剧烈头痛 = 守过一夜的痕迹，但没人知道是谁下的 |
| 入睡选择 | 全员 | 锁门与否、独睡或约人同屋（对方好感度不足则拒绝）；同屋风险共担——狼可潜入多人房只杀一人，把嫌疑栽给同屋活口 |
| 银匕携带 | 猎人位 | 银匕随身 = 遇袭可搏命；留屋 = 夜里遇袭时它在你够不到的地方（物只对持有者显现，不存在被搜出） |
| 毒药下毒（女巫位，一次性） | 持物人 UI | **意念使用，无声无息**：选定目标即生效，除了 DM 没人知道是谁下的。发作有时间差（半小时至数小时随机）——死状是中毒征候，动机与机会（谁能接触她的饮食）是唯一的推理线 |

### 2.2 狼队夜议与围猎
- **狼队互认**（血梦知晓），月升后血月引力下狼队自然聚齐——**狼队夜议面板**（仅狼可见 UI）：全员确认当夜猎物 + 杀法（做死 / 留种）
- NPC 狼队由脚本按策略决策（猎持物嫌疑者 / 猎暴露信息源 / 猎高威胁者 / 随机），玩家狼参与投票，少数服从多数（平手头狼定）
- **围猎形态**：将猎物引入夜的空间（其屋/温泉/廊下/林缘），4 兽轮流交合，**做死**（衰竭/撕裂/窒息——血腥与色情同源）或**留种**（4 兽尽泄，猎物不死但被种）
- 发作狼不在自己床上杀；可潜入多人房只杀一人栽赃同屋活口

### 2.3 阻断判定（扑空夜）
围猎目标处于草汁保护屋或麻沸散沉睡屋 → **扑空夜**：当夜无夜袭死亡（狼的挫败与兽性无处发泄是叙事素材）。两物叠加同一屋 = 效果相同（只算一次阻断）。

### 2.4 银匕搏命
猎物随身持银匕 → 脚本掷搏命判定（成功率与狼方状态相关，数值 §十调参）：
- 成功 = **同归**（捅死一头狼，其余狼逃散——狼数 -1）或 **击退**（无死亡，狼带伤而逃）
- 失败 = 正常围猎死亡
- **银匕不会被夺**：持有人死亡瞬间物即被血月回收（人死物灭统一规则，无「狼持银匕」分支）

### 2.5 铜镜夜照（预言家位）
- 持镜人当夜验一人：**绝对准**（雾聚 = 狼，镜面清澈 = 好人；对夜行兽同样显示狼）
- 每夜限一人；结果即刻知晓，属**白天记忆**（夜忆清零不清它）
- 持镜者夜夜随身 = 被搜出即暴露；被照者**不知道自己被照**（镜无反馈）

### 2.6 夜忆清零生效
日出时脚本打全员「昨夜归零」标记——含狼（狼知身份、不知夜里行为）。身体痕迹保留但不可自证来源。梦是唯一泄密通道（被围猎者做被围猎的梦；狼做兽视角的围猎梦；被留种者做同样的梦却不知已被种）。

## 三、白天阶段

### 3.1 清零唤醒
全员醒来：先是身体（酸痛、痕迹、头痛）、然后是发现（隔壁屋的门开着 / 人不见了）。**死人是悄悄死的**——可能已死数小时，尸温尸僵是唯一时间证据（姜芸的专业价值）。

### 3.2 死状线索表（验尸可公开的客观信息）
| 死因 | 死状 | 指向 |
|---|---|---|
| 围猎致死 | 性事痕迹 + 咬颈/扼痕 + 多人迹象 | 狼队围猎；「对象是谁」永不可知（无 DNA 库） |
| 毒杀 | 中毒征候 + 进食记录反推 | 女巫方向；接近死者饮食的人被怀疑 |
| 银器伤 | 精准致命一击 | 银匕方向（处决 or 搏命） |
| 众刑处决 | 死状验真伪：狼现原形 / 无辜者只是死了 | 全员都是行刑者 |
| 发作兽化 | 人形狼尸 | 昨日已被留种——回顾前日的异样 |
| 头狼反扑 | 兽化爪击伤 | 处决现场的死者 |

### 3.3 取证
- **雪地脚印**：夜里谁走过谁家门口；雪一直下会覆盖——清晨头一小时黄金取证
- **搜尸/搜房**：找遗书字条（物灭信息不灭）；守庄之物搜不出来——它们只对持有者显现，持有人死后被血月收回，搜到的只有空
- **疑听**：夜里若有若无的动静（分不清是惨叫还是风）——不可验证证词

### 3.4 话术世界（NPC 行为条目规范）
- 五信息源：尸体死状（客观）/ 梦（主观核心战场）/ 身体痕迹（可展示不可自证）/ 白天行为（社交层）/ 血月历（算术恐怖）
- 三招：**述梦 / 验身 / 指认链**（死状→人际→行为）
- 三阶段：试探期（旁敲侧击）→ 对峙期（公开指认）→ 审判期（投票陈词）
- **硬规则**：NPC 永不陈述昨夜具体事件；声称「记得昨夜」= 疯话或表演；无依据断言 NPC 不理睬（防贴脸场外）

### 3.5 留种者的隐瞒窗口
被留种者次晨起渐进兽化：**第一晨只有细微异样**（瞳孔、低烧、气味），逐日明显——约 1-2 天后藏不住。窗口期内她是行走的定时炸弹（夜里她已变夜行兽？**不——发作在次夜**：留种当夜起算，第二夜发作化兽、人格沉没；白天窗口期她还是人，隐瞒着，恐慌着）。夜行兽不计狼数、夜里游荡随机袭击（含狼）、白天特征明显后大概率被指认处决（处决 = 死状现原形）。

**实现层补充（2026-09-27 占位，待用户过目）**：① 兽化状态三档——次夜首发作起为「进行中」（夜袭候选），无「完成」态（处决即死）；② 多只夜行兽并存时**每晚合计掷一次袭击**（概率 60%+10%×(兽数-1)，封顶 90%），随机选兽选猎物——防一夜雪崩，配合 §九 夜袭名额统一；③ 被种者的白天异样由脚本「异样池」按日投放中立可见行为（行为池第三段），AI 只见行为不知因果；④ 玩家被种：留种当夜广播不点破（死讯只写「今夜无人死」），次晨异样提示进广播，次夜人格沉没 → 专属终局「兽化」。

## 四、审判与处决

### 4.1 投票
- NPC 票 = **好感度 × 怀疑度加权**（脚本计算，玩家社交行为经叙事判定后落库）
- 玩家 UI 投一票；处决确认不可逆需二次确认
- 平票 = **平安日**（无人处决）——但狼必开刀，平安日是坏消息

### 4.2 遗言
**处决有遗言**（审判台上说完再死——信息接力的最后窗口，也是狼悍跳的舞台：假神职遗言）；**夜袭无遗言**（死了到清晨才被发现）。

### 4.3 众刑（处决形态，决策 10）
- 投票过半 → 全体生者押被指认者上审判台 → **轮流交合致死**（狼之法：血月狼人形躯体强化普通刀伤杀不死，交合中卸防脱力耗到死）
- **同罪条款**：拒绝参与者与被指认者同判——没人能袖手
- **头狼之性**：被处决者是狼时，有概率垂死暴起带走行刑者一人（脚本掷概率，§十调参）——行刑顺序 = 参与恐惧
- **以银代众**：持银匕者可一人一刀结束（免除众人凌虐），银匕消耗即失去反杀能力——猎人的仁慈有代价
- 死状验真伪：狼现原形（狼数 -1）/ 无辜者只是死了（冤案）

## 五、死亡处理

1. **永久退场**：存活表更新；死者活人条目关闭，转「尸体/追忆」态（停灵间尸体条目 = 环境层持续在场）；无任何复活通道
2. **死亡 = 信息归零（决策 9）**：夜袭死者全部所知（含白天所知）随她消失；信息存活只依赖传递，不依赖人
3. **人死物灭**：持有人死亡瞬间所持守庄之物被血月回收（含银匕被夺不可能的统一依据）；神位不可继承
4. **社会后果**：恐慌、关系崩坏、复仇、集体暴力随死亡真实发生（AI 叙事层按存活名单渲染）

## 六、胜负（四种终局）

| 终局 | 条件 | 玩家层面 |
|---|---|---|
| 好人胜 | 狼全灭（处决/银匕同归/夜行兽袭击皆可） | 玩家存活 → 胜利结局；玩家已死（此前死档）→ 结局图鉴标记 |
| 狼胜 | 狼数 ≥ 存活好人数，或七夜耗尽未分胜负 | 玩家是狼 → 狼胜结局（含夜忆下「你永远不知道自己夜里做过什么」的余味）；玩家是好人 → 灭亡结局 |
| 玩家死档 | 玩家死亡（围猎/毒杀/处决/反扑/发作兽化） | 专属死档结局（按身份×死法分支），UI 一键重开重掷，保留结局图鉴 |
| 特殊：玩家化为兽 | 玩家被留种 → 次夜发作人格沉没 | 专属结局「兽化」：以夜行兽视角过最后一夜后消亡 |

## 七、玩家体验矩阵

| 玩家身份 | 夜晚 | 白天 | 核心体验 |
|---|---|---|---|
| 狼 | 狼队夜议选猎物 + 围猎参与（NSFW 浓度最高） | 伪装好人、查自己身体、编梦、色诱做局 | 欺骗视角：你不知道自己昨夜做了什么 |
| 持铜镜 | 夜照一人 | 隐瞒持物、传递信息、防搜查 | 信息核心：全庄最烫的东西在你手里 |
| 持药囊 | 下麻沸散 / 白天下毒 | 双药的选择与暴露管理 | 生杀权：一瓶毒一个救场 |
| 持银匕 | 遇袭搏命 | 以银代众的抉择 | 反杀权与处决的捷径 |
| 持草汁 | 涂门守一处 | 续采进禁区（拿命换守） | 防线：你挡下的那夜无人死 |
| 民 | 入睡选择（同屋/锁门） | 纯推理与社交 | 推理视角：观察、述梦、投票 |
| 被围猎时 | 叙事深渊（无操作） | — | 真死结局 |
| 被留种时 | 不知道（无记忆） | 细微异样的隐瞒窗口 | 倒计时恐怖：你不知道自己已经被种 |

## 八、NPC 行为规范（写作素材的分层去向，§十二 v2 配套）

设定三层，但**去处不同**（身份真相永不入世界书）：
- **表面层 → 世界书条目**（11 条常驻/低门槛）：外貌性格、公开背景、说话风格、日常作息——零身份信息
- **狼面 → 脚本侧行为池**：围猎配合（夜议投票策略）、白天伪装（编梦模板+引导怀疑）、栽赃战术（自伤/潜入多人房/色诱局）、知情狼 vs 失忆狼的清醒度差异（更镇定/圆滑）——脚本按身份策略抽取，以中立行为指令投放，AI 只见行为事实
- **持物面 → 脚本侧行为池**：隐匿（藏物、否认）、使用（各自物件的正确操作）、传递（嘴说/遗书/带进坟墓的抉择）——物件逻辑本来就是脚本结算项，行为层只投放可见结果
- **好人面 → 世界书条目可写部分 + 行为池**：恐慌曲线（死亡数↑→行为退化）、话术三阶段、投票倾向（好感×怀疑，数值进脚本公式）、对玩家的依恋与怀疑并行——不涉身份的写进表面层条目供 AI 演绎，涉身份策略的进行为池
- 任何 NPC 永不：陈述昨夜事件、复活、使用不持有的物、知道未传递给她的信息（知情集由脚本维护，AI 演绎不得超出脚本给的知情集）

## 九、边界情况判定表

| 情况 | 判定 |
|---|---|
| 同夜多死 | 不可能：**夜袭类合计 ≤1**（围猎/留种/夜行兽袭击共享名额，实现层占位决策 2026-09-27——多兽并存时兽袭与围猎互斥：兽袭得手则狼队今夜不猎）＋ 处决 ≤1 ＋ 反扑 ≤1 |
| 处决反扑后狼数 | 头狼已死（-1）+ 反扑带走 1（好人 -1）——反扑不改变狼数净减 |
| 草汁 + 麻沸散同屋 | 算一次阻断，不叠加 |
| 玩家被毒 | 真死档（毒发即死，无解药） |
| 玩家为狼被铜镜照 | 玩家不知被照；持镜人获得结果 |
| 留种目标死于处决 | 种随死亡作废（人死一切归零） |
| 夜行兽袭击狼 | 可能（随机游荡不辨阵营）——狼也可能死于兽 |
| 平安日 | 无处决，狼必围猎——平安日净亏 |
| 两条件同时满足终局 | 优先级：玩家死亡 > 狼数≥好数 > 狼全灭 > 七夜耗尽 |
| 猎物在围猎中被毒杀者毒发 | 时间差随机——毒发优先（死亡原因唯一归属：脚本按先触发结算） |
| 同屋一人被围猎 | 同屋活人无记忆（清零）但「身边人死了」——头号栽赃受害者 |

## 十、数值与调参（机制层模拟定，先占位）

| 数值 | 初值/区间 | 说明 |
|---|---|---|
| 好感度 / 怀疑度 | 0-100 | MVU 整数，AI 叙事判定后脚本落库（schema clamp + 脚本限幅 ±12 双防线） |
| NPC 投票权重（对玩家） | 怀疑 × (1.5 − 好感/100) | 占位公式 v2（模拟调参后定）。注：初版「×(1+好感/200)」方向反了（好感越高权重应越低），已修正 |
| NPC 互投权重 | 互疑记录值，无记录则 5-20 随机 | 互疑由「听了神信息」等事件累积 |
| 银匕搏命成功率 | 40% 同归 / 25% 击退 / 35% 失败 | 占位，与狼方状态修正 |
| 头狼反扑概率 | 50% | 占位 |
| 毒药发作时间 | 60% 当昼 / 40% 入夜前（措辞随机） | 即时结算制——时间差只影响死讯措辞，不做跨夜挂账 |
| 围猎做死/留种倾向 | 70% 做死 | 占位 |
| 夜行兽袭击概率 | 60%/夜 | 被种者「进行中」后每夜掷 |

## 十二、信息隔离与反作弊（上帝视角封堵）

> **修订 v2（2026-09-27 用户裁决）**：参照卡「不要玩弄我的鸡吧-forge」的 prompt 铁律模式（AI 拿全图 + 铁律锁嘴）**被否决**——软约束靠 AI 自觉，长局必漂。本卡改为**数据层根治：AI 叙事层根本不知道谁是狼**，prompt 层只留常规叙事纪律。人员设定直接做进世界书，但身份真相永不入 AI 可见条目。

### 12.0 两种模式对比（弃参照卡模式的理由）

| | 参照卡模式：AI 拿全图＋铁律锁嘴 | 本卡模式：AI 无全图＋行为指令投放 |
|---|---|---|
| 泄漏可能 | 每轮都可能说漏，靠 AI 自觉 + 禁用表堵漏 | **数据层不可能**——AI 根本不知道谁是狼，无从泄起 |
| 长局稳定性 | 上下文越长越会漂 | 不漂（无密可泄） |
| 狼面表演 | AI 知情后演伪装 | 脚本行为池投指令，AI 演「被怀疑的好人」——**狼面表演的本质就是演好人**，AI 无知情反而演得更对 |
| 维护成本 | 铁律组＋禁用表＋每轮 CoT 上帝视角扫描 | 一条常规叙事纪律 |
| 哲学 | 软 prompt 规则 | **代码层硬实现**（符合卡线通用准则） |

### 12.1 真相的持有者：只有脚本
- 全图（谁是狼 / 谁持物 / 各 NPC 知情集）只存在于 MVU 隐藏字段＋脚本逻辑，**永不整表进入任何 AI 上下文**
- 「她知道什么」是每个 NPC 的动态状态（MVU 已知集）：清零、信息传递、目击事件都由脚本更新；NPC 条目不静态声明知情范围

### 12.2 世界书条目三层架构（人员设定的去处）
| 层 | 内容 | 注入方式 | 身份信息 |
|---|---|---|---|
| **① 常驻·表面层**（11 条，每人 1 条） | 外貌、性格、公开背景、说话风格、日常作息、身体特征（可见的） | 常驻或低门槛触发 | **零**——一个身份相关的字都没有 |
| **② 门控·玩家身份块** | 你的身份/能力说明/持物与「血梦已告知藏物之处」（不含位置）/（狼）「你梦见了两张同伴的脸」（不含名字） | `@@if` 按 `stat_data._玩家.身份` 展开，只展开玩家自己那份 | 只含玩家自身 |
| **③ 动态·事实与指令块** | 公开事实集（死者名单、公开身份、遗言、投票记录）＋ 今日行为指令 ＋ 本轮在场 NPC 知情集摘要（只含公开传递） | 脚本每晨/每事件生成注入 | 只有**已公开**的身份 |

**②存在的理由**：AI 必须知道玩家自己是谁，才能正确写玩家的主观感受、血梦、持物操作——但只给玩家自己的，NPC 的永远不给。

**②内容红线（实现层修订 2026-09-27）**：同伴互认**名单**、血梦**原文**、藏处**位置**、被种状态——一律只进 UI（脚本变量渲染），**不进门控块**。门控块是世界书条目＝进 prompt；`_` 前缀字段全部注入 AI 上下文。玩家是狼时若门控块写「你的同伴是白蘅、灶婶」，AI 立即获知两人是狼＝隔离破产。AI 只需知道「玩家是狼」这一件事来写主观体验，具体同伴由 UI 狼队夜议面板呈现。

**③行为指令的措辞规范**：指令是**中立行为事实**，不含身份因果——「陆霜霜今日多次查看手臂内侧」✓；「陆霜霜因兽化前兆查看手臂」✗（AI 演绎出来的只能是玩家可见的行为，连线解释它自己不会做也无从做）。

### 12.3 狼面/神面设定的去处：脚本侧行为池（不进世界书）
- 名单三层模板修正：**表面层 → 世界书条目；狼面/神面 → 行为池素材**（脚本侧数据文件，不进 AI 上下文）：编梦模板、悍跳话术、栽赃战术、色诱局套路、持物操作逻辑、知情狼清醒度特征（更镇定/圆滑）
- 脚本每日/每事件从池中按身份策略抽取，翻译成 12.2③ 的中立指令注入
- 例子：狼 NPC 被指认时——脚本知道她是狼，但给 AI 的指令只是「白蘅对今天的指认表现出紧张，辩解时手抖」；AI 演绎「一个被冤枉者的反应」＝恰好是狼想要的表演效果
- 好处：NPC 深设定不占世界书 token 预算；身份内容物理上不可泄漏

### 12.4 prompt 层：铁律组解散，留一条常规叙事纪律
- ~~铁律 A/B/C~~、~~词汇禁用表~~、~~每轮上帝视角扫描~~ 全部删除（无密可泄，禁用表失去对象）
- 保留（与其他卡无异的常规规范）：第二人称锁玩家；不写不在场事件；NPC 内心只许通过可见行为/表情/台词侧写
- CoT 保留一问：**NPC 反应不得超出脚本给的知情集**（数据给了什么演什么，不脑补她「应该还知道」的事）

### 12.5 UI 层：玩家可见性由脚本裁决
| 信息 | 谁能看 | 渲染条件 |
|---|---|---|
| 狼队夜议面板 | 仅狼 | `stat_data.玩家.身份 === '狼'` |
| 铜镜结果 | 仅持镜人 | 持物字段 |
| 毒药/麻沸散操作 | 仅药囊持有者 | 持物字段 |
| 存活名单 / 公开遗言 / 投票记录 | 全员 | 公开事实集 |
| 他人好感度/怀疑度 | **无人**（含玩家） | 不渲染——NPC 内心数值只进脚本投票公式 |
| 玩家自身身份 | 玩家 | 血梦后解锁身份卡 |

### 12.6 骚操作封堵表（博弈层玩法不封，只封信息层作弊）
| 骚操作 | 封堵机制 |
|---|---|
| 不睡觉盯梢（守走廊看谁出门） | 血月夜强制困倦（设定层：血月睡眠压，硬撑=脚本意志检定，失败即昏睡醒来不知何时睡着的）；即使撑住——暴风雪+离屋间隔里，雪地游荡者是全场唯一暴露目标，狼优先猎游荡者（撞见围猎现场=你已在围猎里）；且「你撑过了血月夜」白天即成疑点（谁都没睡好，你精神得反常） |
| 半夜挨房查（敲门/偷窥） | 血月夜无人应门（常识层：开门=死）；偷窥可见度≈0（离屋无灯+雪幕）；游荡本身触发上条 |
| 贴脸质问 AI（「告诉我谁最可疑」） | NPC 不应答角色知识外的问题（§3.4 已有：无依据断言不理睬）；清零后连狼 NPC 自己都说不出夜里行为——审不出任何东西 |
| 诱导 AI 引述规则/全图 | AI 上下文里**没有全图可引述**（12.1）——此类问题从「堵嘴」降级为「无从答起」 |
| 白天疯狂搜房 | 守庄之物在血梦指定的私密位置（随机）；搜到=曝光事件而非获益（上交/私吞/沉默三选一，私吞=假持物人，会被真持物人指认）；搜查本身有社交后果（被抓=信任崩） |
| 寸步不离跟梢 NPC | NPC 按脚本日常作息表行动（不由 AI 临时编排），纠缠=好感度暴跌+对方求助他人；总有独处时刻（沐浴/如厕），跟到夜里即触发游荡规则 |
| 故意送死探真相 | 无咬伤感染（决策 6）；送死验证不了信息——死了就是死档，撞见围猎=已在围猎里 |
| 拉群结盟互誓清白 | **允许**（这是白天博弈的一部分）；但誓言无机制效力（脚本不认结盟为保护状态），NPC 反应按好感/怀疑走 |
| 口头要求 AI 改变量（「把姜芸好感调满」） | 无效——MVU 命令只由脚本结算产生，UI 面板是唯一合法操作入口 |

**边界说明**：玩家是狼时的伪装/悍跳/色诱做局、玩家是民时的带节奏——这些是**合法博弈骚操作**，不封，是乐趣本体。封堵表只针对「借 AI 之眼作弊」（拿玩家角色不可能有的信息）。

### 12.7 本模式新增边界判定
| 情况 | 判定 |
|---|---|
| AI 会不会自己「发明」谁是狼的线索 | 不会——线索只能来自脚本注入的事实（行为指令/死状/公开身份），AI 无从发明确定性真相 |
| 玩家狼与 NPC 狼的配合戏 | 脚本指令层支持：「今日白蘅在讨论中支持玩家的怀疑方向」——AI 只见行为事实 |
| NPC 悍跳/编梦 | 脚本给出编梦内容模板（行为池），AI 照着演；模板内容也走中立措辞 |
| 处决现原形后 | 该身份进公开事实集（12.2③），此后 AI 自然可写 |
| 玩家追问 NPC 私密过去 | 表面层有的照答；身份相关 AI 无从答起（不是拒绝，是真不知道） |
| 表面层细节与行为指令连线 | 允许——AI 把「手臂旧疤」和「查看手臂」写成一句话，玩家看到的仍是可见行为，不泄漏「为什么看」 |
