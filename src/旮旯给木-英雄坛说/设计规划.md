## 二、原作事实（文曲星 2007 · 多源交叉核对）

来源：百度百科英雄坛说条目、搜狗百科、19yxw / voo0 / bodocs / doyo 四源 NPC 表、9game、RMXP 复刻版更新日志。

### 2.1 系统清单

| 类 | 内容 | 特性 |
|---|---|---|
| **A 先天天赋** | 膂力 / 敏捷 / 根骨 / 悟性 | 创建时 10-30，总和 ≤ 80 |
| **B 技能等级** | 基本功夫 + 门派武功 + 绝招 | 靠潜能买等级；绝招有 CD 与成功率 |
| **C 资源池** | 潜能 / 经验 / 金钱 / 食物 / 饮水 | 可增减、有门槛 |
| **D 派生值** | 攻击 / 命中 / 闪避 / 招架 / 生命上限 / 内力上限 | **纯函数 f(A, B)** |

### 2.2 天赋的四个作用面（原作原文）

| 天赋 | 作用 | 反哺来源 |
|---|---|---|
| **膂力** | 攻击力（百分比加成）、招架、**饭量与水量上限**（终生不改） | 每 10 级**基本拳脚** +1 |
| **敏捷** | 命中率、闪避率（百分比加成） | 每 10 级**基本轻功** +1 |
| **根骨** | 生命上限、内力上限、打坐/冥想速度、恢复速度 | 每 10 级**基本内功** +1 |
| **悟性** | 学武速度、潜能消耗效率、任务奖励高低 | 每 10 级**读书识字** +1 |

> ★ **这一张表就是「属性成长」的全部内容。它不是叙事设定，它是算式。**

### 2.3 其它原作事实（会进契约表的）

| 项 | 内容 |
|---|---|
| **生命三层** | 最大值 / 有效值（受伤 %）/ 当前值。当前值恢复快但不超过有效值；伤及实体 → 有效值下降，恢复极慢（**不可逆损伤**） |
| **内力两层** | 内力蓄存量 / 内力强度（上限）。超过强度的部分叫**真气**；真气充沛到一定程度 → **内力强度永久提高**（不可逆成长） |
| **法力** | 茅山派专属；有「法点」机制（对应内力的「加力」） |
| **年龄** | 14 岁起；22 岁前每涨一岁 +生命 |
| **容貌** | **隐藏属性**，15 岁后才可见 |
| **战斗** | 命中 / 闪避 / 招架 / 伤害；**加力**（用内力提升攻击）；绝招；状态（呆若木鸡等） |
| **婚姻** | 20 岁 + 有房（桃花源）+ 月下老人；**互学武功**；茅山派不可结婚 |
| **门派** | 太极门(武当山) / 雪山派(大雪山) / 花间派(玉女峰) / 伊贺谷(冰火岛) / 红莲教(五指山) / 八卦门(商家堡) / 兽王派(黑森林) / 茅山派(灵心观) / 逍遥派 / 星宿派 |
| **除黑线** | 八大坛（青龙/白虎/朱雀/玄武/天微/紫煞/山岚/地罡）→ 三块三角石板 → 三 BOSS（我是谁 / 道德和尚 / 东方求败） |
| **主线** | 时空转换装置 → 平安小镇；金远见王朝 → 赏善罚恶使者 → 武林大会 |
| **无固定主线** | 原作是 MUD 式开放架构，「你可以完全按照个人喜好决定你在这里的人生」 |

## 三、技能：三层落点

### 3.1 机制层要新增的 4 个能力（`引擎模板/引擎能力/`）

**这四个全部不含「基本拳脚」「太极剑法」任何一个词** —— 过判据 2。

| # | 能力 | 内容 | 为什么现有 E2 不够 |
|---|---|---|---|
| **C1** | **等级制状态** | 离散等级（0-N）+ 递增成本 + 上限 | E2 状态机是连续值（好感度 0-100），没有「级」这个概念 |
| **C2** | **反哺回路** | 状态 A 每 N 档 → 状态 B +1 | E2 只做单向累加，没有「A 驱动 B」的跨状态级联 |
| **C3** | **资源门** | 升级要**消耗**另一种状态（潜能 / 金钱 / 经验） | E3 只有 flag 前置门槛，没有**消耗** |
| **C4** | **派生计算** | `f(天赋, 技能等级) → 战斗属性` | 这是纯函数，**必须代码算，不写进状态、不给 AI** |

### 3.2 契约层（底座填，0 token）

`底座_yingxiong/技能表.yaml` —— 每个技能一行：

```yaml
- 名:       <技能名>
  类:       基本 / 门派 / 绝招
  上限:      <最高等级>
  成本曲线:  <每级潜能消耗>
  反哺:      <每 N 级 → 哪个天赋 +1>   # 基本功夫才有
  前置:      <等级门槛 / 拜师 / 秘籍>
  属门派:    <门派 id>
```

### 3.3 面板层（前端 UI）

| 面板 | 显示 | 为什么必须有 |
|---|---|---|
| 技能列表 | 等级条 / 下一级成本 / 能否学 | 花潜能是玩家的决策 |
| 三入口 | 请教（师傅，耗潜能）/ 自学（秘籍）/ 练功（基本 > 门派时可用） | 原作三种升级路径 |
| 成长预览 | 「再练 3 级，膂力 +1」 | **反哺回路唯一的可玩性就在这里** |

### 3.4 世界书条目（AI 读的）

只放**绝招怎么描写**（效果、画面、气劲），**不放数值、不放公式**。

## 四、属性成长：三条线

```
        ┌──────── 成长（玩家主动）────────┐
        │  花潜能 → 技能等级 +1           │  面板按钮结算
        └──────────────┬─────────────────┘
                       │ 每 10 级
                       ▼
        ┌──────── 反哺（被动·C2）────────┐
        │  对应天赋 +1                    │  面板结算，写变量
        └──────────────┬─────────────────┘
                       │
                       ▼
        ┌──────── 派生（纯计算·C4）──────┐
        │  攻击/命中/闪避/招架/生命上限    │  面板算 → 只读快照给 AI
        └───────────────────────────────┘
```

**判据切分**（「这数值是在帮玩家玩，还是在替 AI 记账？」）：

- **D 类派生值 = 替 AI 记账** → 一行都不进世界书
- **「还差几级天赋 +1」「下一级要多少潜能」= 帮玩家玩** → 面板必须显示
