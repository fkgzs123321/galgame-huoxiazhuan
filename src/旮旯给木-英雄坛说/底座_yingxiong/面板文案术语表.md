# 面板文案术语表

> 用户的原话：**「做成给什么？这分明是任务奖励；砸了怎么办分明是失败惩罚。
> 你这是解释代替专有名词！」**
>
> 这条批评是对的 —— 面板是**游戏 UI**，该用**游戏专有名词**，
> 而不是把名词翻译成一句解释。解释放在 tooltip 或说明页，标签位置只放名词。

---

## 一、已经改掉的（口语解释 → 专有名词）

| 原来（解释） | 改成（名词） | 为什么 |
|---|---|---|
| 做成给什么 / 成了给什么 | **任务奖励** | 这是任务系统的标准字段 |
| 砸了怎么着 | **失败惩罚** | 同上，失败的对应字段 |
| 下一级要 | **升级消耗** | 消耗什么、多少 |
| 养哪个天赋 | **天赋反哺** | 「反哺」是这张卡的既有机制名 |
| 门槛 | **前置条件** | 接取/拜师的标准说法 |
| 谁给的 | **委托人** | 任务发布者的标准字段 |
| 要多少 | **所需进度** | 计数型任务的目标值 |
| 能不能反复做 | **可重复** | 布尔字段 |
| 现在 | **当前等级** | 技能字段 |
| 她摆出来的 | **本轮选项** | 界面分区名 |
| 她要点第 N 条 | **她的选择** | 指她这一轮挑了哪条 |
| 她用过的手段 | **手段记录** | 她用过的记录 |
| 名字 / 状态 / 说明 | 保持（本身就是名词） | — |

## 二、★ 「屏幕外的女人」→ **操控者**

**改的地方**：条目侧（`角色/屏幕外的她/`）、面板文案、记忆与文档里的提法。

**理由**：她是**在屏幕外操控 `<user>` 的那个人**。
「操控者」是**角色定位**，不是比喻；而「屏幕外的女人」把定位说成了一句话。

★ 沿用（不变的部分）：
- 目录名可以留（`角色/屏幕外的她/` 是历史路径，改名会牵动一堆引用）
- 但**面向玩家的文案一律叫「操控者」**

## 三、待定的两个（请用户选）

这两个是**这张卡特有的概念**，没有现成术语，得命名。

### ① 「她的期限」——她还能忍多久（原作是「两年」的时间上限）

| 方案 | 读起来 | 好处 | 坏处 |
|---|---|---|---|
| **耐心** | 耐心 11 月 | 直白，符合「她等不了两年」| 略像情绪值 |
| **余期** | 余期 11 月 | 最短，像游戏字段 | 稍冷 |
| **剩余周目** | 剩余周目 11 | galgame 味最正（周目 = 一轮游玩） | 「月」这个单位要改成「周目」 |
| **幕数** | 还剩 11 幕 | 有戏台味，合武侠 | 要解释「一幕」是什么 |

★ 我的倾向：**耐心** —— 因为它直接对应世界观里的那句话
（「好感满一百才能谈婚嫁，**而她等不了两年**」），
玩家一眼就知道这是**她的忍耐倒计时**，不用额外解释。

### ② 「她的兴致」——她此刻玩得多投入

| 方案 | 读起来 | 好处 |
|---|---|---|
| **投入度** | 投入度：无 / 微动 / 起了 / 明显 / 难忍 | 标准，直观 |
| **专注度** | 专注度：无 | 偏中性 |
| **兴致** | 兴致：无 | 短，但和前一条的「耐心」并列时都像情绪 |
| **沉浸度** | 沉浸度：无 | 最贴 galgame 语境（她沉浸在这个游戏里） |

★ 我的倾向：**投入度**（或是 **沉浸度**）—— 因为它和「耐心」区分得开：
耐心 = 她还愿意忍多久；投入度 = 她此刻玩得多起劲。一个长期，一个当下。

## 四、还有一批同类问题（一并列出来）

| 现在的写法 | 问题 | 建议 |
|---|---|---|
| 「她越兴奋手越不稳，越容易点偏」 | 这是**说明**，不该出现在标签位 | 标签写「熟练度惩罚」，说明移到 tooltip |
| 「★ 失败也是结算 —— 好感掉、线关掉」 | 同上，是设计原则 | 移到说明页；标签位只留「失败惩罚」 |
| 「反哺：下一级就给天赋 +1」 | 半说明半字段 | 拆成「反哺进度」+ 值 |
| 「还 3 级」 | 口语 | 「距反哺 3 级」 |
| 「做」 | 占位符太糙 | 「进行中」/「—」 |
| 「要 1530」 | 缺单位 | 「1530 潜能」 |
| 「看着/拒绝/自定义」 | 这三个是**动作**，可以保留（是按钮语） | 保留 |
| 「这一带能动手的」 | 口语 | 「可交战目标」 |

★ 一条通用原则：**标签位放名词，解释放 tooltip 或说明页。**
「解释代替名词」的根子在**把 tooltip 的内容写进了 label**。
