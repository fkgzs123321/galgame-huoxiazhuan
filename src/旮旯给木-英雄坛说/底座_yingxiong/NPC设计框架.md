# 底座_yingxiong · NPC 设计框架

> 写任何一个 NPC 之前，先把这三件套想清楚。**三件套想不明白就别写他**。

---

## 一、三件套（每个 NPC 都必须有）

### ① 战力 —— 决定他能不能打、几招结束

原作给的是**离散档位**，不是连续值。按档位写，不要自己编数：

| 档位 | 谁是这个档 | 打起来什么感觉 |
|---|---|---|
| **10** | 孩童（小顽童） | 一招 |
| **100** | 平民、门人、伙计、教众 | 两三招。是「能打赢但会掉血」的底 |
| **300** | 有点力气的（卖花妞、中年妇人） | 要出几招 |
| **500** | 镇上有点身份的（公子哥、盐商） | 打得有来有回 |
| **1000** | 有功夫的（何铁手、潘小莲、阿庆嫂） | 要认真打 |
| **1500** | 公门（捕快） | 前期打不过 |
| **10000** | 掌门级（聂隐娘） | 中期的一道墙 |
| **30000** | 怪物级（公孙大娘） | 后期才敢碰 |
| **50000** | 打不过的（顾炎武） | **不是用来打的**，是用来教的 |

★ **战力要和「他是不是用来打的」分开看**：顾炎武战力五万，但他不跟你打，他是教你读书的。
战力只在他真的动手时才有意义。

### ② 技能 —— 他会什么，能教你什么

- **门派归属**决定武功体系（太极门给太极拳、花间派给一剪梅花手…）
- **能不能教**决定他是「师承类」还是「门人类」：
  - 师承类：有**拜师门槛**，达到才教，教完你的武功表里就多一项
  - 门人类：**不教**，只挡路、只切磋。打赢他掉东西，不掉武功
- **绝招**：掌门级以上才有。绝招不是独立等级，是两门武功同时到某个级数后自动可用

### ③ 关系 —— 他与 `<user>` 是什么关系

关系的**类型**决定他在这张卡里的作用：

| 类型 | 作用 | 例子 |
|---|---|---|
| **师承** | 给你武功 | 古松道长、苍月道长、清虚道长 |
| **对手** | 挡路 / 可打 / 掉装备 | 各派门人、采花大盗、官兵 |
| **生意** | 买卖 / 以物易物 | 老裁缝、荷西、杂货贩 |
| **情报** | 告诉你下一步去哪 | 村长、神秘人、茅十七、独行侠 |
| **剧情** | 推进主线的那一下 | 浪人乙、平一指、干将 |
| **氛围** | 构成世界的底子 | 街上的路人 |

★ **关系要写具体画面，不写抽象评价**（这是 `npc.md` 的硬约束）：
- ✗「对 \<user\> 很关心」
- ✓「每次 \<user\> 路过早餐摊都会多给一个包子」

## 二、按 skills 的硬约束（`contents-creation/character/npc.md`）

1. **NPC 不写**性格调色盘、三面性、二次解释
2. **每个 NPC 一个独立文件**
3. **外貌**：只写 1-2 个最显眼的关键特征 + 一句话整体印象。不写万能美人描写
4. **性格**：只提炼 2-3 个核心关键词，**写具体行为不写标签**
5. **关系**：写具体画面
6. **语料**：只保留纯对话，不混动作/表情/心理

---

## 三、这里的字段怎么落

```yaml
功能定位: 一句话说清他是干什么用的（师承 / 对手 / 生意 / 情报 / 剧情 / 氛围）
基础信息:
  姓名 / 年龄 / 性别 / 身份 / 所在       ← 识别信息
  战力: 档位（照上表取）                  ← 三件套①
  技能: 他会什么、能教什么                ← 三件套②
  掉落: 打赢他掉什么（带原作价格）
  拜师门槛: 只有师承类才写
外貌特征: { 整体印象, 关键特征 }
性格核心: { 核心特质, 行为模式 }
与<user>的关系: { 关系, 态度, 互动方式 }   ← 三件套③
语言特征: { 说话风格, 参考语料 }
```
