# 面板职责边界 —— 能做什么，不能做什么

> 用户的原话：**「你到底知不知道我们的现在的游戏的运行逻辑和机制和设定？
> 你全面的掌握了解后再设定啊，你就是臆想！」**
>
> 这句批评成立。我照着「游戏 UI 一般长什么样」去做，**没有照这张卡的设定推**。
> 下面是从**现有设定原文**逐条推出来的边界。**以后动手前先看这一页。**

---

## 一、这张卡到底怎么跑（依据：世界书原文）

### 1. 一层 = 演完 + 出新（`交互循环.yaml`）
```
一层 = 把上一层她点的选项【演完】，再在底部生出本层的【四条】新选项
顺序不能反：先演完，再摆新的
```

### 2. 玩家只有两个动作（`交互循环.yaml` · 底部按钮）
```
· 眼睁睁看着   —— 默认流，她按自己的偏好选
· 拒绝某个选项 —— 仅当反抗值不低于该选项消耗时可用
```
★ **是「拒绝某个选项」，不是笼统的「拒绝」**。拒绝错目标 → 反抗值照扣、什么都没发生。

### 3. 玩家输入只能到内层（`玩家的输入.yaml`）
```
唯一允许的通道：
  只有一条：摁下「拒绝」或「自定义」并扣掉反抗值
  除此之外，玩家输入对她的目的进度、兴奋度、情绪、熟练度没有任何影响
```
```
她不知道有你 —— 她只看见 <user> 做了什么，并认为那是游戏自己的安排
```

### 4. 兴奋度**界面上不显示**（`兴奋度机制.yaml`）
```
兴奋度:
  显示: 界面上没有任何提示，只能靠 <user> 自己盯着摄像头看
```
★ 它的作用是**暗中影响**：高时选项变激进、她注意力下降、反抗成功率上升。

---

## 二、★ 结论：分界线在**「谁的动作」**，不在「面板」

我第一版把这条写成了「面板是监控屏、只有三按钮」—— **那是走极端了**。
用户纠正：**「装备、物品、强化、任务可交互是没问题的，你这么做可以」**。

### 正确的分界

| 谁的一侧 | 面板能否操作 | 例 |
|---|---|---|
| **她的那一侧** | ❌ **不能碰** | 兴奋度、周期（孕/养伤/闭关）、她的倾向、目的进度、熟练度 |
| **`<user>` 那一侧（游戏内行为）** | ✅ **可以代操作** | 装备 / 用物品 / 强化 / 接任务·推进 / 请教 / 动手 / 换穿 |
| **唯一能影响她的通道** | ✅ 但只有三个 | 眼睁睁看着 / 拒绝某个选项 / 自定义 |

★ **为什么 `<user>` 侧能操作**：那是**他在游戏里动手**，玩家替他按键，等同于替他走路。
**这和「改她的状态」是两码事** —— 前者是操作角色，后者是替她做决定。

★ **一条更简的判据**：
> 问「**这一下是他在动，还是她在变？**」
> 他在动 → 面板可以给按钮；
> 她在变 → 面板只能显示。

### 逐处裁定（修订版）

| 我做的 | 裁定 | 依据 |
|---|---|---|
| 四数条显示「投入度」 | ❌ **删** | 那是兴奋度，设定说「界面上没有任何提示」 |
| 兴奋度 −10 / ＋10 / ＋25 | ❌ **删** | 她在变，且「玩家对她没有任何影响」 |
| 周期「起：孕 / 养伤 / 闭关」 | ❌ **删** | 她在变（周期是剧情结果） |
| **物品「装备 / 用掉 / 丢掉」** | ✅ **恢复** | 他在动 |
| **穿着「换上 / 脱下」** | ✅ **恢复** | 他在动 |
| **任务「接取 / 推进 / 放弃」** | ✅ **恢复** | 他在动 |
| **「请教 1 级 / 连请教 5 级」** | ✅ **恢复** | 他在动（去问师父） |
| **「动手」挑对手开打** | ✅ **恢复** | 他在动 |
| **★ 装备强化（新增）** | ✅ **要做** | 他在动（拿材料上强化） |
| **★ 技能强化（新增）** | ✅ **要做** | 他在动（突破等级上限） |
| **出招层三按钮** | ✅ **保留** | 唯一能影响她的通道 |
| 技能 / 物品 / 任务 / 身体 / 关系 / 世界的**显示** | ✅ 保留 | 被看见的内容 |

### 四数条该放什么（从 `处境` 字段推）
出招层自己写了「处境：**反抗值、体力、对她的了解**」——
所以四数条就用这四项（外加岁数／耐心这类时间信息）。
**没有兴奋度。** 也没有「投入度」。

★ 其中**「对她的了解」是个被忽略的重要字段**：
`她不会选一个`（倾向暗示）的**清晰度由 <user> 对她的了解决定**（低=瞎猜／中=过半／高=看得出但不保证）。
**它直接决定玩家能不能赌对** —— 面板必须把它显出来。

---

## 四、那面板凭什么值得看？

去掉臆想交互之后，面板的价值**全在「显示得准」**上：

| 显示什么 | 帮玩家做什么判断 |
|---|---|
| **她摆出的四条 + 各自等级与消耗** | 她要挑哪条？我拦不拦得起？ |
| **她的倾向暗示**（光标停在哪） | 她要选哪一条 —— 这是「赌」的依据 |
| **反抗值** | 拒绝要花多少，我还剩多少 |
| **对她的了解** | 我这把是瞎猜还是看得出 |
| **耐心**（她还愿意忍多久） | 剩多少时间做取舍 |
| 技能 / 物品 / 任务 | 他手上有多少牌，能不能扛过去 |
| 世界（门派 / 地理） | 这一层她可能摆出什么 |

★ **面板做得越好，玩家越能「预判」，而不是越能「控制」。**
这才是这张卡的面板该有的样子。
