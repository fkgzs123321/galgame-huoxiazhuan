## 〇、⚠️ 版本分野（做卡前必须先选）

原作不是"一个"游戏，是**一条版本线**。系统差异很大：

| 版本 | 有什么 | 没有什么 |
|---|---|---|
| **原版（GMUD 之英雄坛说）** | 六大门派、四天赋、基本/门派武功、等级称号、食物饮水、除黑、潜能经验金钱 | 无法术、无婚姻、无家园、无装备打造 |
| **黄金版** | ＋**婚姻**（月下老人）＋**家园桃花源**（买房、家具、翻盖）＋**武器打造**＋**兽王派、茅山派**（法术 + 变身）＋主线剧情 | — |
| **白金版** | ＋**三大 BOSS**（我是谁 / 道德和尚 / 东方求败）＋**逍遥派 + 菜花宝典**；**取消了茅山、兽王**；生死/除恶/战斗改动 | — |
| **RMXP 复刻重制版**（2024 开源） | 把黄金内容并入白金；联机结婚、夫妻请教传授、铸剑谷、八大坛除恶 | — |
| **现代移植版**（微信公众号版，带商城） | ＋**6 个周目**＋**竞技场/云存档**＋**三大神功**（易筋/太玄/九阴）＋**侠客岛**（武功 255 上限）＋丹药炼妖壶＋符文强化 | — |

**本次三处来源冲突（都要你定）**：
1. **结婚对象**（★ 最关键）：
   - 百度百科（黄金版）：「**与另一台文曲星上的人结婚**」→ **联机**
   - RMXP 复刻版原文：「年满 20 岁、已拥有桃花源、非茅山派、未婚 → 与月下老人（商业街）对话，一方选『允婚』另一方选『求婚』」→ **也是联机**
   - 英雄坛回忆站：「**本游戏不能玩家之间结婚，只能与 NPC 结婚**」→ **NPC 路线**（唯一一个这么说的来源）
   → **「NPC 结婚 + 好感度 100% + 两年期限」只出现在这一个来源**，可能是某个改版/手机版。但它是三套里**对做卡最有用**的一整套。
2. **年龄门槛**：百科与复刻版写 **20 岁**，英雄坛回忆站写 **18 岁**。
3. **茅山派能否结婚**：黄金 / 复刻版明确「**茅山派不能结婚**（不羡鸳鸯只羡仙）」。

## 一、四天赋（核心回路）

创建时选，每项 **10-30，总和 ≤ 80**。选定后不能改，但**会被对应技能顶上去**。

| 天赋 | 作用 | 反哺来源 |
|---|---|---|
| **膂力** | 攻击力（百分比加成）、招架、**饭量与水量上限**（终生不改）、**先天 15 以下相貌姣好，15 以上较差** | 每 10 级 **基本拳脚** +1 |
| **敏捷** | 命中率、闪避率、**出手先后** | 每 10 级 **基本轻功** +1 |
| **根骨** | 气血上限、内力上限、打坐冥想速度、恢复速度、**减免物理伤害**、**外貌** | 每 10 级 **基本内功** +1 |
| **悟性** | 学武速度（潜能消耗效率）、**暴击伤害**、法术攻击命中、任务奖励高低 | 每 10 级 **读书识字** +1 |

**门派先天门槛**：雪山派 敏捷 ≥22｜茅山派 悟性 ≥22｜兽王派 悟性 **≤18**。

**悟性 → 学满一门武功需要的潜能 ≈ 1114 万 ÷ 悟性。**

## 二、基本武功（10 种）

| 基本武功 | 作用 | 反哺 |
|---|---|---|
| 基本内功 | ＋气血上限、＋内力上限、＋防御 | 根骨 |
| 基本轻功 | ＋闪避、少许命中 | 敏捷 |
| 基本拳脚 | ＋拳脚类命中和攻击力 | 膂力 |
| 基本剑术 | ＋剑类命中和攻击力 | — |
| 基本刀法 | ＋刀类命中和攻击力 | — |
| 基本杖法 | ＋杖类命中和攻击力 | — |
| 基本鞭法 | ＋鞭类命中和攻击力 | — |
| 基本法术 | ＋法术攻击力和命中（茅山） | — |
| 基本招架 | ＋防御 | — |
| 读书识字 | ＋悟性（**还消耗金钱**） | 悟性 |

**其它**：红莲教义（＋少量攻击/防御/命中/闪避）｜天师正道（＋少量法术攻击命中）｜灵通心诀｜驻颜术（花间）。
**门派差异**：太极内功对内力的成长最高；花间三花聚顶对闪避的成长最高；红莲太祖长拳对攻击力的成长最高。

**练功规则**：门派武功只需学 1 级，勾选后在「练功」里自行练到与基本武功同级 → **省潜能**。练功上限受对应基本武功限制（超 1 级提示「根基不足」）。
**内功和知识类不能练功，只能靠请教。**

## 六、身体与资源

| 项 | 机制 |
|---|---|
| **生命** | **最大值 / 有效值（受伤 %）/ 当前值**。当前值恢复快但不超有效值；**伤及实体 → 有效值下降，恢复极慢**。初始 100 |
| **内力** | 内力蓄存量 / **内力强度**（上限）。超出强度部分叫**真气**；真气充沛到一定程度 → **内力强度永久提高**（不可逆成长） |
| **加力** | 战斗中物理攻击附加的内力，可调；上限跟内功等级相关。**对兵刃的加成只有拳脚的一半**。部分绝招伤害与加力挂钩 |
| **吸气** | 用内力把体力回复到生命上限 |
| **疗伤** | 需内功 30 级以上；把生命上限回复到健康状态 |
| **法力** | 茅山专属；有「法点」（对应内力的加力） |
| **食物 / 饮水** | 左边当前值，右边上限（饭量=膂力决定）。**任一项为 0 → 生命和内力不自然恢复**；食不果腹时**无法轻功传送、无法疗伤打坐** |
| **潜能** | 学习武功的货币。**上限 65535，超过自动归零** |
| **经验** | 决定**可学武功的上限**（见识所限）与战斗技巧 |
| **金钱** | 干活 / 钓鱼 / 打怪；读书识字要花钱 |

## 七、时间与年龄

```
出生 14 岁
游戏中一年长 1 岁
在家中床边喝「女儿红」一瓶 → 时间流逝 3 个月
年龄 +1 岁 → 血量 +20，内力 +20
30 岁后不再加血，60 岁后不再加内
年龄越大，运气越差、出手越先
相貌：出生时已注定；16 岁（一说 15）后才可见；驻颜术 / 商城道具可提升
```
**打坐 / 练功是「挂机过程」，时间计入岁数。**

**修炼的限制**：练功时武功到 99 级起需**闭关突破**，之后每 +10 级闭关一次（现代移植版：单人闭关 4 小时，成功率 80%→70%）。

## 八、★ 婚姻系统（两版本说法不同，**做卡的关键素材**）

### 英雄坛回忆站的说法（NPC 路线）
```
年满 18 岁 → 去「随机地图」找月老（位置随机，野外或山洞里都有可能）
月老介绍女朋友（按门派选）
与女朋友对话 → 她给你任务 → 完成 +好感度，没完成 -好感度
好感度达到 100% → 对话即可结婚
★ 必须在两年之内搞定她，否则她就跟别人跑了！
女朋友的任务有 3 分钟间隔时间
月老若没找到 → 重新进入随机地图继续找
```

### 黄金版的说法（联机路线）
```
20 岁 + 有房（桃花源）+ 月下老人 → 与另一台文曲星上的人结婚
婚后可「互相学习对方的武功」
茅山派不可结婚（不羡鸳鸯只羡仙）
```

### RMXP 复刻版
```
结婚后：夫妻之间可以「请教 / 传授」——把对方的技能存到本地，下次可直接请教
「?性」（第三种性别）：男女通吃，但不可和 ?性 结婚
```

**好感度 / 修为联动**（部分版本）：部分女角是**双修加成**（10%~50%），但「双修」是手游衍生用语，**本卡一律不用，正式名称「互学武功」**。

## 九、战斗

- 命中 / 闪避 / 招架 / 伤害 ｜ **加力**（耗内力提升攻击）｜ 绝招（有 CD 与成功率）｜ 状态：**呆若木鸡**

- **战败后果**：损失**一半潜能** + 一部分经验和金钱，**武功也会变弱**
- 暴击（悟性影响暴击伤害）
- 暗器：战斗中发射**不耗怒气/内力，不受呆若木鸡影响**

## 二十一、★ 主线剧情（2026-09-16 补 · 此前只查到一句带过）

### 起因
```
一个叫 Shadow（黄金版叫「暗黑势力」）的组织，集合天下邪徒，以气制动建起时空之阵，把古今杂糅在一处。
主角被时空之门吸入，伴随着各个时代的英雄人物一起落到这片大陆上，决心击败 Shadow、重整时空。
```

### 黄金版的设定（时间在前作之后数百年）
- 暗黑势力没有被完全消灭，反而**偷学到了所有门派的独门武功**
- 首领是个隐身在黑暗里的人，几乎没人见过他的真面目，人人叫他「**总瓢把子**」
- 他在各派地点设了**秘密据点**，由偷学了高深武功的头目把守；自己固守**暗黑总坛**
- **平安镇村长**曾派死士线人卧底，只拿到**其中一个据点的地图**；功夫不灵光时他不给

### 正典推进（《真·英雄坛说》梗概，最完整的一版）
```
① 被传送到平安镇 → 与街上行人交谈，村长赶来 → 安排住房 + 建议习武
② 武学小有成就 → 村长给第一坛的位置与详细地图，要你消灭坛主并打探下一坛
③ 逐个破坛 → 终于消灭「总瓢把子」
④ ★ 东方求败出现 —— 原来各坛乃至总瓢把子**都是傀儡**，幕后另有隐情
⑤ 击败东方求败 → 禀告村长
⑥ 村长号召：太极门・雪山派・八卦门・伊贺谷・花间派・红莲教・兽王派・茅山派・华剑派・逍遥派左翼
   一齐举办**武林大会**，共同准备进攻**远见岛**（真正的 Shadow 总部）
⑦ 消灭「**我是谁**」和「**谁是我**」两兄弟
⑧ ★ 发现他们也只是被人利用
⑨ ★★ **道德和尚叛变** —— 他才是真正的幕后黑手
⑩ 击败道德和尚。牺牲了许多人，最后也说不清什么是对、什么是错
```

**所以三个 BOSS 的关系是层层剥开的，不是三选一**：
| 顺序 | 是谁 | 揭开什么 |
|---|---|---|
| 一 | 总瓢把子 | 明面上的恶势力头子 |
| 二 | 东方求败 | 揭穿各坛与总瓢把子都是傀儡 |
| 三 | 我是谁 / 谁是我 | 远见岛上的两个，也是被利用的 |
| 四 | **道德和尚** | **真正的幕后黑手**，在各派毫无防备时叛变 |

⚠️ 我此前在 §十「主线与通关」里写的「三种最终 BOSS 按表现触发」是**简化版**（那是攻略圈对进入条件的说法）。
**这一节才是剧情的正体**，两者并存：进哪条线看你的表现，但四条是**同一条线上的层层揭开**。

### 金远见王朝这一边
- 王朝养着**赏善罚恶使者**，每隔一段时日入江湖，为的是那一场**武林大会**
- 使者在准备一本「**赏善罚恶簿**」；江湖上的说法是「能在这个大会上喝碗腊八粥扬名立万，也是人生幸事」
