          mental_state: string; // 精神状态: 正常/美德(具体类型)/折磨(具体类型)

          skills: {
            [SkillName: string]: {
              type: '主动' | '被动';
              tag: '攻击' | '治疗' | '增益' | '减益' | '控制';
              // 核心修改：强制百分比
              val: string; // 格式示例: "DMG -15%, CRIT +5%" (攻击), "Heal 20% Max HP" (治疗), "PROT +15%" (增益)。
            }
          };
          traits: {
            [TraitName: string]: {

            }

               [TrinketName: string]: { desc: string; } // 如 "+10 ACC, +5 Stress"
            }
          };

          affection: number; // 好感度 0-10

          appearance: {

            body: string;   // 身材 (如: 丰满, 伤痕累累)
            pose: string;   // 姿势 (如: 跪伏, 举盾防御, 依偎)
          };
          narrative: {
            thought: string; // 内心想法 (第一人称, 简短, 反应当前心情)

          };
        }

      - **性别限制(重要)**: 仅限 **女性角色(女英雄)** 加入此列表。**严禁**将男性NPC、男性敌人、商店老板等加入名册。
      - **装备与属性联动 (关键)**:
          - 当 `level` 等级提升时，必须同步增加 `stats.atk` (攻击), `stats.crit` (暴击), `stats.prec` (精准), `stats.spd` (速度), `stats.dodge` (闪避) 和 `hp.max` (最大生命值)。
          - 当 `equipment.weapon` 等级提升时，必须同步增加 `stats.atk` (攻击), `stats.crit` (暴击), `stats.spd` (速度)。
          - 当 `equipment.armor` 等级提升时，必须同步增加 `stats.dodge` (闪避) 和 `hp.max` (最大生命值)。
      - **Narrative更新**: 每次该角色在剧情中出现互动时，必须更新 thought 和 action。
      - **Appearance更新**: 
          1. outfit: 更换装备或衣服破损时更新。
          2. pose: 姿势发生明显改变（如从站立变为跪下）时更新。
          3. body: 仅在身体发生永久性变化（如获得伤疤、变异）时更新。

      - 战斗中受到流血/中毒等效果时，更新 conditions 数组
      - **Skill成长性严令 (重要)**: 
          1. **攻击类**: 使用修正值 (如 `DMG -15%`) 随攻击力成长。
          2. **治疗类**: 使用最大生命百分比 (如 `Heal 15% Max HP`) 随生命值成长。
          3. **增益/减益**: 尽量使用百分比 (如 `PROT +20%`, `DMG Received +10%`)。
          4. **例外**: 压力治疗 (Stress Heal) 和 持续伤害 (Blight/Bleed) 可保留固定数值 (因机制特殊)。
          5. **禁止**: 严禁使用模糊词语，严禁在能使用百分比的地方使用固定低数值。
