## 二、原作结构，与「只能选一个」的处置

| 项 | 原作 |
|---|---|
| 时间跨度 | **三周寒假，12/22 ~ 1/7**（原卡这 17 天是对的） |
| 第一周 | **序章** —— 原作为了让新玩家好上手，第一周专门介绍角色与地点（对应原卡「寒假前奏」） |
| 攻略数 | **15 人可选，玩家只能选一个当女朋友**（choose one girl） |
| 时间成本 | **游戏内有钟，去一个地方或见一个人都消耗三周的一部分** |
| 同班同学 | 15 人中 **7 人** |
| 原作核心设计 | 「developing a relationship is never entirely straightforward」 |

### ⭐ 「只能选一个」怎么处置

**用户定案**：「设定只能选一个，但**不影响屏幕外的人和玩家骚操作**」

所以分成两层：

| 层 | 「只能选一个」的效力 |
|---|---|
| **世界层（硬）** | 它是**世界的规则**，不是她的选择。同时推多条线 → 女角之间的关系会崩（原作明写的互斥、嫉妒、破裂） |
| **她/玩家这一层（可以骚）** | **规则约束的是世界，不约束玩法**。她会**试**：同一时段跑两地、卡在锁定前、改数值绕过 ——**这就是突破单元的由来** |

> **这一条让「突破单元」从举例变成了必然。**
> 她想要的是「全」，而世界说「只能一个」——
> **矛盾本身**就是她的玩法，而不是设计者额外塞进去的挑战。

**具体落在哪**：
- T3 阶段表：`攻略上限 = 1`（世界规则）
- 突破单元：「**双保**」等（见 `目的清单.yaml §单元体系`）
- 判定引擎：同时推多条线 → 嫉妒值增长加速 / 关系崩坏风险（世界层的惩罚）
- 但 **她可以反复试** —— 而每次试的成本由 `<user>` 承担

```
身份   《同级生》先负学园三年级 → 《同级生2》体育大学二年级

原作设计意图（这一条最有价值）：
  「运动型阳光美少女 —— 男生平时无法趁虚而入；
    当她遭受运动伤害时，原本充满活力的强悍少女变得柔弱、需要帮助，
    这种反差等于让男主角有『英雄救美』的机会。」
  → 所以她的人气超越了樱木舞，成为《同级生》与《同级生2》的常驻女主角

       主角毕业后，美沙与主角结婚，诞下一子。
```

> **她的特殊之处不是「互斥」，是「她不属于这个镇子」** —— 她有大学、有田径社，

## 八、从原作能直接长出的东西

**三面性示例（鸣泽唯）**——原作只给两句话，就能拆出三面：
```
第一面 · 家里的「妹妹」      触发：美佐子在、有外人在
  语料：「哥，你的围巾。」「我才不是特意等你的。」
  功能：她把「关心」包装成顺手的家务

第二面 · 学校的「没兴趣的人」 触发：校内有其他男生
  语料：「嗯。」「不用了。」
  功能：对男生不感兴趣不是冷淡，是省事

第三面 · 只有他们俩的时候    触发：家里没人、深夜、他出事的时候
  功能：她操心了他十年，但她从来没说过为什么
```

**三面性示例（永岛久美子）**——原作给了「她想住城里」这一个动机：
```
第一面 · 旅馆里的女儿    触发：在旅馆、在母亲面前
  语料：（待写）
  功能：她还没走，因为母亲还在

第二面 · 在镇上的样子    触发：离开旅馆
  功能：她在这里是「想走的人」

第三面 · 提到城里的时候
  功能：她不是在幻想，她在计划
```

> 这两组**完全来自原作**（「叫他哥哥 + 和她住一起」+「对学校男生没兴趣 + 总为他操心」；
> 「想住城里 + 母亲守着旅馆」），**没有一个字来自原卡的 70 字段。**
