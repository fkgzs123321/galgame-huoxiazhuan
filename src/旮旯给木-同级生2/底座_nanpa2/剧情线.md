## 通用规则（攻略总结）

```
① 时间绑定：所有角色专属事件绑定固定「日期 + 时段 + 地点」，没有随机触发
② 好感阈值：Good Ending 需好感 ≥ 80（日常对话 +3 / 选错 -1 / 专属事件 +10）
③ 路线锁定：好感最高的角色进入专属线路，其他角色事件锁死
   → 「没有办法同时走多条线拿多个结局」
④ ⚠️ 警告：若和洋子、泉美、久美子、佐知子以及美里引发【温泉之旅】，
   1 月 6 日绝对不可以回家
⑤ ⚠️ 与美佐子 H 后，唯来房间时主角会自制，不会被唯引诱
```

# 20.1 · 这张矩阵**不花钱**：它在契约层，不在 prompt 层

> 这一节回答一个必须回答的问题：**逐格照搬 15×15，会不会把 token 烧掉？**
