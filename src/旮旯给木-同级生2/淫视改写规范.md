## 二、★ 最关键的一条：淫视只管「写身体」，人设照旧

`by-style/01-淫视/性格调色盘.md` 原文写着：

> 文风只作用于叙述的措辞与视角，不作用于角色本身：外貌尽可写成通身欠肏的骚浪贱相，
> **言行举止、性格与意愿一律照人设走**。

所以 **同一个文件里分两类段落**，处理方式不同：

| 段落 | 怎么处理 |
|---|---|
| **外貌 / 身体 / 感官 / 肉体反应**（外貌.*、感官.*、「身体在说什么」、「她会做什么」里的身体句、「她对你开放到什么程度」） | ★ **淫视重写**：器官作主语、三层落笔、词料、句长 50~80 |
| **人设 / 边界 / 台词 / 关系 / 触发点 / 越界后果 / 用词** | **原样保留**（只做下面的「文字纪律」清洗） |

**判据：这一段去掉之后，人还认得出来是她吗？** 认得出来 → 是身体段，可改；认不出来 → 是人设段，别动。

## 三、逐文件的改写范围

### 3.1 基础信息.yaml
- **改**：`外貌.*` 全部子键（整体/奶子/奶头/屁股/腰腹/腿/逼/反应）、`感官.*`
- **补**：新增 `体型落点:` 一行（照 `by-style/01-淫视/基础信息.md` 的「一、体型落点」取档：丰腴/纤细/高挑/娇小/小奶，可叠加）
- **半改**：`她是谁`、`她的骚`、`骚的反应` → 抽掉身体句重写，**保留人设轴**（例：唯的「被点破」那条轴一个字都不许丢）
- **不动**：`基本信息.*`、`背景设定`、`关系设定`、`特色`（识别特征）

### 3.2 剧情线.yaml
- **改**：每段里的 `身体在说什么:` 下面每一条
- **不动**：`她这一段的边界` / `触发点` / `她的变化` / `这一段的收尾` / 文末的「她不会做的」「她的边缘」
- **不动**：EJS 结构（`<%_ if (天 <= 4) { _%>` 那一串链）与 `说明:` 段

### 3.3 性格调色盘.yaml
- **改**：`衍生.*` 里出现的**身体动作**与**身体信号**（例如「薄棉衬衫底下…」「解开第一粒扣子」这类）
- **不动**：`底色` / `主色调` / `点缀` 的标签与性格描述、`衍生` 里的纯心理行为

### 3.4 好感度_*.yaml（11 档）
- **改**：`她会做什么:` 里带身体描写的条、`她对你开放到什么程度:` 整段、`越界会怎样:` 里 `当场` 一栏的身体句
- **不动**：`_怎么触发` / `区间` / `★ 本档的边界` / `她能做得到` / `她做不到` / `她对你的态度` / `她给你什么` / `她不会做什么` / `越界` 的 `事后` 与 `好感` / `她对你的用词` / `她对你说的话`
- ★ **11 档之间的差别要在身体上分得出来**：低档是「不给你看」，高档是「看得见多少」。同一处身体别在 11 档里用同一套句子。

## 四、硬规则（可数，写完自己量）

1. **破折号 `——` 一处都没有**（本卡 `rules-check.md` 的硬约束）
2. **顿号排比一处都没有** —— 不写「咬嘴唇、咬手背、咬他的肩膀」这种三项以上的 `、` 并列，改成分句
3. **主语是器官／部位**：抽样数一数，身体段里过半句子的主语应该是「两团奶肉」「那截细腰」「两瓣尻肉」「那道肉缝」这类，不是「她」
4. **句长 50~80 字**（对着 🅰️ 的示例量）
5. **词料命中**：每份文件至少命中 5 个 🅱️4 的词（个位数以下 = 没在用素材库）
6. **三层落笔**：一处媚肉落笔要给全「形态 ＋ 受力质地 ＋ 第三层」（被挤到哪 / 温度潮气骚味 / 隔着布透出多少 / 攥紧挤出多少 / 牵着哪处跟着晃），**只写形态 = 白描，不成立**
7. **长度（★ 这条最容易被做错）**：改完的文件 **≥ 2,500 字符、≤ 4,500 字符**。
   - **比原文短 = 不合格**，直接打回。原文件普遍 1,600~2,000 字符，改写应当**加厚到 2.5~2.8 倍**（原文是「事件的骨架 + 一句身体」，要写成「骨架照留 + 身体写足」）
   - 每一档、每一段都要**写满**：11 档好感度不许只改一句话就交，`她对你开放到什么程度` 必须是 250~400 字的一整段
   - 上限 4,500 是硬顶（单条常驻渲染上限 5,000，留余量），撞顶就砍细节不砍层
8. **YAML 键名一个都不许改**（校验器和注册按名字找）
9. **不许删事实**：原名、原年龄、原关系、原事件、原台词全部留下
