# 变量总览（字段速查）
- 时间.日期 / 时间.星期 / 时间.时段
- 玩家.体力 0~100
- 玩家.资金池 0~99999999（元）
- 玩家.全网名声 0~100 / 玩家.性欲 0~100 / 玩家.勃起度 0~100
- 当前目标: '' | 女主名

女主.${名字}.${字段}:
- 身份 / 丈夫 / 家庭 / 名器 / 技能: string（建档固定）
- 吸收量: 0~100（核心指标，体内射精后增长）
- 转化率: 固定（林曼云55/苏婉君95/秦月娥85/白芷若70/陈美兰90/温晓棠60/顾清欢75/许茉65）
- 掌控值: 0~100（=吸收量×转化率/100）
- 丈夫抵抗: 0~100
- 曝光度: 0~100
- 案底: ""|治安拘留|刑事立案|取保候审
- 危机状态: ""|传唤|拘留|立案|诉讼|和解|坐牢（随掌控值下降，按挣扎流派定速）
- 亲密值: 0~100
- 怀孕: 未孕|孕一月~孕八月|临盆
- 生理: 周期天数/周期日/上次月经
- 阶段: 1~5（5=决裂/4=吸收量≥60/3=吸收量≥30/2=吸收量≥1/1=吸收量0）
- 丈夫察觉度: 0~100
- 资源转移: 0~100
- 决裂: bool
- 火葬场进度: ''|傲慢试探|资源封杀|认知崩塌|抛弃一切|极端强制|自毁威胁|替身反噬|终局退场
- 专属: object（每人不同）
- 身体状态.胸部{状态,敏感度} / 阴道{状态,湿润度,敏感度} / 肛门{状态} / 嘴{状态} / 肌肤{状态,体温} / 大腿{状态} / 臀部{状态}
- 心理状态.欲望度 / 羞耻感 / 兴奋 / 依恋 / 精神状态
- 心声: string（第一人称，不出现在叙事）

阶段推导：5=决裂 → 4=吸收量≥60 → 3=吸收量≥30 → 2=吸收量≥1 → 1=吸收量0
