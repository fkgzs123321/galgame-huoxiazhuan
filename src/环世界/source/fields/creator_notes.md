# 环世界角色卡 · 说明文档

## 卡片简介

基于 RimWorld 游戏机制的文字角色扮演卡片。玩家扮演殖民地临时队长，指挥3-5名殖民者在异星求生，最终目标是建造飞船飞向群星。

## 核心特色

- **完整RimWorld机制移植**：12技能、6部位HP、8种生物群落、38种建筑、16种动物、近远程武器战斗、电力系统、温度系统、种植畜牧、科技树、派系贸易
- **14张数据库表**：动物/食物/建筑/武器/装甲/作物/药品/材料等数值表，全部由EJS引擎查表计算，杜绝AI臆造
- **DDL确定性骰子引擎**：基于LCG伪随机+d100判定的可复现技能公式，所有行为（射击/格斗/建造/烹饪/种植/采矿等）走同一套骰子
- **MVU变量系统**：9个命名空间、79个变量字段，每楼层由额外模型负责JSONPatch更新
- **状态栏HTML前端**：5面板布局（殖民地/殖民者/事件/物资/建筑），支持折叠展开、模态框详情、自动刷新
- **永久死亡机制**：殖民者6部位HP，抢救失败即永久死亡，不可复活
- **完整R-18系统**：含NSFW/RJB全机制，关系阶段8级（初识→友好→暧昧→恋爱→攻略完成 / 失恋→决裂→疏离）
- **9大系统控制器**：战斗/烹饪/种植/电力/建筑/科技/派系/疾病/制作/工作/任务/轨道贸易

## 使用方法

### 1. 推荐模型配置

- **主模型**：Claude 3.5 Sonnet 或同等级别（负责叙事生成）
- **额外模型**：GPT-4o-mini 或同等级别（负责变量更新JSONPatch）
- **上下文长度**：建议 16K 以上（42个世界书条目+状态栏+叙事）
- **温度**：0.8（叙事）/ 0.0（变量更新）

### 2. 必需插件

- **ST-Prompt-Template**：EJS模板渲染（处理 @@generate_before 条目）
- **MagVarUpdate (MVU)**：变量管理系统（stat_data 命名空间）
- **StatusPlaceHolderImpl**：状态栏占位符渲染
- **Regex脚本**：自动隐藏XML校验标签（16条规则）

### 3. 开局流程

1. 导入角色卡 + 世界书
2. 开启新对话，首楼会显示开局选择（Biome / 讲述者 / 小队构成）
3. 回复选择后，AI将初始化殖民地并开始叙事
4. 每楼层叙事末尾会显示状态栏 + 变量更新块

### 4. 玩法建议

- 每次指令尽量明确工作分配（"殖民者1去建造，殖民者2去采集"）
- 注意殖民者心情、饱腹、疲劳的平衡
- 优先建立食物来源（种植/畜牧/采集）
- 殖民地财富越高，袭击强度越大——量力而行
- 与派系贸易可获得稀有物资（药品/高级组件/武器）

## 技术架构

### 文件结构

```
source/
├── entries/         EJS控制器与数值表（双目录镜像）
├── fields/          角色卡字段（first_mes/personality/scenario等）
├── html/            状态栏HTML（ES5语法，LF换行，UTF-8）
├── mvu/             MVU变量系统（schema.js/initvar.yaml/update-rules.yaml）
├── regex/           正则脚本（16条隐藏规则）
└── worldbook/       世界书条目镜像副本
```

### 世界书条目（42个）

- 5个核心EJS控制器（Level0/时间/财富/袭击/骰子引擎）
- 8张数值表（动物/食物/建筑/武器/装甲/作物/药品/材料）
- 14个系统控制器（战斗/烹饪/种植/电力/建筑/科技/派系/精神/事件/疾病/制作/工作/任务/轨道贸易）
- 5个角色系统（关系/殖民者预设/生理周期/奴隶/NSFW）
- 3个叙事模块（讲述者/阶段/事件包）
- 4个MVU辅助条目（[initvar]/[mvu_plot]/[mvu_update]/变量列表）
- 3个世界观条目（生物群落/派系定义/世界设定）

### 数据库表（14张）

| 表名 | 用途 |
|------|------|
| global_state | 全局状态（时间/天气/电力/财富） |
| protagonist_info | 主角信息（属性/技能/HP） |
| important_npc | 重要NPC（派系领袖/特殊角色） |
| chronicle | 事件纪要（重要事件记录） |
| colonist_roster | 殖民者花名册 |
| colony_buildings | 殖民地建筑 |
| inventory | 物资库存 |
| animal_roster | 动物花名册 |
| slave_roster | 奴隶花名册 |
| relationship_network | 关系网络 |
| research_progress | 研究进度 |
| quest_log | 任务日志 |
| trade_history | 贸易记录 |
| event_timers | 事件计时器 |

## 已知限制

- 上下文消耗较大（约8K-12K token/轮），建议使用高上下文模型
- NSFW内容需要前端关闭内容过滤
- 状态栏HTML在iframe内运行，部分SillyTavern主题可能影响显示效果
- 永久死亡机制较残酷，建议初次游玩选择"菲比·友好"讲述者
