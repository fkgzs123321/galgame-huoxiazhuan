> 用户问：**除了这些，还有哪些可以建议完善增加的？技能树？还是？**
>
> 下面不是灵感清单，是**按「一个完整游戏引擎该有哪些系统」逐个对照**的结果 ——
> 每一项都过三条判据，并标出「为什么现在缺它是真缺口」。

## 二、逐个说清「为什么缺它是真缺口」

### 7 · 解锁图（用户提到的「技能树」）

**C5 已做的**：「A 和 B 同时到 N 级 → 解锁 C」，一个一个独立判。
**缺的**：**这些解锁之间有顺序** —— 解锁 A 才能谈 B，B 又开出 C。

```
现在：{A,B}→C    {D,E}→F    {G,H}→I     三个互不相干的点
该有：            A → B → C
                       ↘ D → E          一棵有向图，还有环路检测
```

★ **为什么真缺**：英雄坛说的绝招本来就是**有层次的**（基本武功 → 门派武功 → 绝招），
`门派表.yaml` 里的「师承门槛」也是链式的（第一级 → 第二级 → 掌门）。
现在这些链**写在条目正文里，引擎不知道**。所以：
- 面板画不出技能树
- 「还差什么」只能人工读表

**该补 `C6 解锁图`**：前置链、拓扑序（先能学什么）、环路检测（不许 A 依赖 B、B 又依赖 A）、
「从当前状态到目标还差几步」。

### 11 · 任务 ★ 最该补的一个

**现状**：英雄坛说**一半的内容都是任务** ——
除恶（捕快给的十五个目标）／搬石头（经验门槛开放）／女角任务（做了涨好感、没做扣好感）／
剧情任务（村长给图、顾炎武要东西、浪人乙的四个条件）。

**但引擎层一个任务能力都没有。**

★ **为什么真缺**：现在这些任务散在**条目正文**里，后果是：
- 面板显示不了「手上还有几个任务、各差什么」
- 无法判「这个任务能不能接」（前置条件）
- 无法判「做完了给什么」（奖励结算）
- **女角任务尤其要紧** —— 「做成了好感涨，做不成好感掉」是 T3 阶段的唯一推进器，
  但它现在只是一句话，没有可执行的结构

**该补 `E9 任务`**：接取条件 / 进度 / 完成判定 / 奖励 / 失败后果 / 可重复性 / 期限。

### 12 · 交易

**现状**：物品表有**价格**（钢刀 $420、护手钩 $21000），但没有**交易能力**。

★ **为什么真缺**：
- 买：钱够不够、买了之后背包满不满（E7 有了，但没接上）
- 卖：按什么价（原价几折？她改了价格怎么办？）
- 以物易物：原作有大量以物易物（糖葫芦换老花镜、猪肉换菜刀、海外仙丹换金锁子甲）
- 声望折扣：原作改造版有「买东西半价」这种效果 —— 那是**价格修正**，该有位置放

**该补 `E10 交易`**：报价（原价 × 修正）/ 双向成交 / 找零 / 以物易物 / 拒绝理由。

### 13 · 声望与阵营

**现状**：原作**明文有**这个机制（「杀好人降声望、杀坏人升声望」「声望 ≥160 触发东方求败线」）。
`事件/终局.yaml` 里也写了这个条件。但**引擎层没有能力**。

★ **为什么真缺**：它是**跨系统的输入** —— 战斗（打死谁）→ 声望变 → 结局线分叉。
现在这条链是断的：打完不知道声望该怎么动，结局线只能靠 AI 自己记。

**该补 `E11 声望与阵营`**：事件驱动的声望增减表 / 档位 / 阈值触发 / 阵营对立关系。

### 14 · 位移

**现状**：地理条目列了 10 个地点与范围，但**引擎层没有「移动」这个概念**。

★ **为什么真缺**：
- 移动要**消耗时间**（原作：跨区域移动扣时段进度 —— 轻功 ≥40 还少扣一档）
- 随机地图：**走过去的路不认第二次**（这个「不认」是机制，不是描述）
- 「谁在这儿」是按地点算的（人物出现索引）
- 门派内部区域有**门禁**（令牌互锁）

**该补 `E12 位移`**：可达性（从 A 到 B 通不通）/ 消耗（时间或资源）/ 门禁判定 / 随机生成。

## 三、还有一类：**不在引擎层，但这张卡缺**

这些**不该进引擎层**（它们是基线层或面板层的东西），但**这张卡确实没有**：

| 缺的 | 落哪层 | 为什么该做 |
|---|---|---|
| **面板的物品与装备区** | 面板层 | E7/E8 的能力与契约都齐了，UI 还没接（跟上次「请教」「动手」同一个路子） |
| **面板的任务区** | 面板层 | 等 E9 做完再接 |
| **多段开场白 × 8 套人设** | 基线层 | 同级生2 有 11 段，我们只有 1 段。选哪套人设 → 对应的开局 |
| **initvar override** | 基线层 | 配合多段开场白 |
| **开局表单** | 面板层 | 同级的 `opening.html`，让玩家开局时挑人设与门派 |
| **面板组件库** | 面板层 | 面板已经很大了，状态条 / 列表 / 卡片该抽成通用件 |

## 四、我的建议顺序（按「价值 ÷ 工作量」）

| 顺序 | 做什么 | 理由 |
|---|---|---|
| **1** | **E9 任务** | 最大真缺口。英雄坛说一半内容靠它，且女角线的推进器就是任务 |
| **2** | **C6 解锁图** | 用户点名。而且它让「技能树」这个 UI 成为可能 |
| **3** | **面板接上物品与装备** | 能力齐了，只差 UI。做好玩家立刻能用 |
| **4** | **E10 交易** | 物品有了、价格有了，接上才成为经济回路 |
| **5** | **E11 声望与阵营** | 打通「战斗 → 结局线」这条断链 |
| **6** | 多段开场白 + 开局表单 | 体验层，不影响机制完整性 |
| **7** | E12 位移 | 最复杂（随机地图），可以最后做 |

★ **判据不变**：进引擎层的必须过三条判据；过不了的（面板组件、开场白）就归面板层或基线层，别硬塞。
