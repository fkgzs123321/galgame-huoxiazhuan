# 跨题材通用性压力测试

> 用户提的要求：通用层不能只为武侠设计，要经得起
> **仙剑奇侠传 / 武侠 / 仙侠 / 魔法 / 哈利波特 / 魔兽世界 / 遮天 / 火影忍者 / 海贼王** 这些题材的检验。
>
> 方法：拿每个题材**逐个过一遍现有引擎**，找出「这个题材有、但引擎层表达不了」的东西。
> 那些就是**伪通用**的地方。

---

## 一、先说结论：测出 11 处伪通用

| # | 缺口 | 谁需要它 | 通用性 |
|---|---|---|---|
| **1** | **持续状态（增益 / 减益，带时长）** | 魔兽（buff/debuff）・火影（幻术・毒）・几乎全部 | ★★★ |
| **2** | **相克关系（矩阵）** | 火影（忍/体/幻）・海贼（果实）・仙侠（五行）・哈利波特（咒语对撞） | ★★★ |
| **3** | **技能的施展条件与代价** | 哈利波特（念咒+挥杖）・海贼（果实弱点）・仙侠（渡劫反噬） | ★★★ |
| **4** | 嵌套等级（大境界 + 小层次） | 仙侠（练气→筑基→金丹）・火影（下忍→中忍→上忍） | ★★ |
| **5** | 概率突破（突破会失败） | 仙侠（渡劫）・魔兽（附魔失败） | ★★ |
| **6** | 条件组合触发（套装） | 魔兽（套装效果）・侠客行（阵法） | ★★ |
| **7** | 冷却（技能有 CD） | 魔兽・火影 | ★★ |
| **8** | 多单位战斗 | 魔兽（副本）・火影（影分身）・海贼（船战） | ★★ |
| **9** | 先天 / 后天（能不能学） | 火影（血继限界）・仙侠（灵根） | ★ |
| **10** | 装备契合度 / 认主 | 哈利波特（魔杖选人）・仙侠（法宝器灵） | ★ |
| **11** | 技能进化形态 | 海贼（觉醒）・仙侠（功法进阶） | ★ |

**现有引擎哪些是**真通用**（过测试）**：判定、成长（等级+成本+上限）、反哺级联、资源门、派生、解锁图、
战斗回合、装备背包、品质掉落、任务、时间轴。

## 二、逐个题材的体检

### 仙剑奇侠传 / 仙侠 / 遮天

| 这个题材有 | 引擎能不能表达 |
|---|---|
| 法术（不是武功） | ✅ 技能不分类型，能装 |
| 灵气 / 法力（另一套资源） | ✅ 资源表 |
| 灵根 / 资质（决定修炼速度） | ✅ C1 的效率参数 |
| 道侣 / 双修 | ✅ 关系系统 |
| **境界（练气→筑基→金丹→元婴…）** | ⚠️ **嵌套**：大境界里还有一至九层 |
| **渡劫（有失败率，失败掉境界）** | ❌ **突破没有「成不成」** —— C3 只判「够不够」 |
| **法宝（有器灵、会认主、能成长）** | ⚠️ 装备有加成，但没有「绑定」与「随主人成长」 |
| **五行相生相克** | ❌ 没有相克关系 |
| **丹毒 / 心魔（累积型负面状态）** | ❌ 没有持续状态 |

### 哈利波特 / 魔法系列

| 这个题材有 | 引擎能不能表达 |
|---|---|
| 咒语分级（O.W.L. / N.E.W.T.） | ✅ 等级 |
| 魔力值（会耗尽） | ✅ 资源 |
| 学年制（每年升一级） | ✅ 时间轴 |
| **咒语要有条件（念对 + 挥杖动作）** | ❌ **技能只有等级门槛，没有施展条件** |
| **禁咒（威力大但有代价 / 违法）** | ❌ 没有「使用代价」与「合法性」标记 |
| **魔杖选人（不合适的杖效果打折）** | ❌ 装备没有「契合度」 |
| 血统 / 学院（阵营） | ⚠️ E11 阵营（未做） |

### 魔兽世界

| 这个题材有 | 引擎能不能表达 |
|---|---|
| 职业 + 天赋树（多棵树） | ✅ C6 解锁图（但要支持多棵树并存） |
| 物品等级（不只是品质） | ⚠️ 物品只有「品质」，没有「等级」这一维 |
| **套装效果（穿齐一套触发）** | ❌ **缺「条件组合触发」** |
| **冷却时间** | ❌ 技能没有 CD |
| **增益 / 减益（有持续时间）** | ❌ **缺持续状态** |
| 仇恨 / 威胁值 | ⚠️ 战斗是 1v1，没有「目标选择」 |
| 副本 / 团队 | ❌ **缺多单位战斗** |

### 火影忍者

| 这个题材有 | 引擎能不能表达 |
|---|---|
| 查克拉（分量、分属性） | ✅ 资源（属性可作多个资源项） |
| **忍 / 体 / 幻三系相克** | ❌ **缺相克关系** |
| 结印（手势序列） | ❌ 施展条件 |
| **血继限界（天生，学不了）** | ❌ 缺「先天 / 后天」标记 |
| 尾兽（外部资源池） | ⚠️ 资源能装，但没有「外借池」的概念 |
| 影分身（多单位） | ❌ 缺多单位 |
| 秽土转生（复活） | ⚠️ 死亡不是终点 —— 这属于剧情，可以不进引擎 |

### 海贼王

| 这个题材有 | 引擎能不能表达 |
|---|---|
| 恶魔果实（吃一颗得能力） | ✅ 技能 |
| **果实弱点（怕海水）** | ❌ 缺「能力代价 / 弱点」 |
| 霸气（三种，可叠加） | ✅ 技能 + 反哺 |
| 悬赏金（声望的另一种形式） | ⚠️ E11 声望（未做） |
| **果实相克** | ❌ 缺相克关系 |
| **果实觉醒（进化）** | ❌ 缺技能进化 |
| 船 / 伙伴（团队） | ❌ 缺多单位 |

## 三、哪些该补、哪些不该

★ 判据不变（三条），但这里要考虑**第四条：这个缺口的通用面有多宽**。

| 缺口 | 该不该进引擎层 | 理由 |
|---|---|---|
| **持续状态** | ✅ **最该补** | buff/debuff 是**几乎所有游戏**的底层。武侠的「中毒」「内伤」「亢奋」、仙侠的「丹毒」、火影的「幻术」、魔兽的「光环」都是它 |
| **相克关系** | ✅ **该补** | 五行 / 三系 / 属性相克，跨题材极其常见。它是个**矩阵**，不含内容 |
| **施展条件与代价** | ✅ 该补 | 「会这一招」和「能用这一招」是两件事（要念咒 / 要有兵器 / 要用一次扣什么）。哈利波特的禁咒、海贼的果实弱点都靠它 |
| 嵌套等级 | ✅ 该补 | 境界体系是仙侠的骨架。它只是**等级的二级结构**，不含内容 |
| 概率突破 | ✅ 该补 | 「够条件了还要掷一次」是通用形状 |
| 条件组合触发 | ✅ 该补 | 套装 / 阵法 / 组合技 |
| 冷却 | ✅ 该补 | 与持续状态共用「带时长」的机制 |
| 多单位战斗 | ⚠️ 可后做 | 复杂（目标选择、先攻序、范围），且本卡是 1v1 |
| 先天/后天 | ✅ 该补（很小） | 一个 flag，加在技能定义上即可 |
| 装备契合度 | ✅ 该补（很小） | 装备的一个乘数系数 |
| 技能进化 | ⚠️ 可后做 | 本质是「技能 A 满足条件后替换为技能 B」，C6 图能表达大半 |

## 四、按通用面排的补法顺序

```
第 1 批（通用面最宽，一次补完就够用多年）
   E13 持续状态（增益/减益 + 冷却，共用「带时长」的机制）
   E14 相克关系（矩阵）
   C7  施展条件与代价（技能的三层：能不能学 / 能不能用 / 用了扣什么）

第 2 批（结构性强，但题材窄一点）
   C8  嵌套等级与概率突破
   E15 条件组合触发（套装 / 阵法）

第 3 批（本卡用不上，留给别的底座）
   E16 多单位战斗
   E17 先天/后天 + 装备契合度 + 技能进化（三样都是小 flag / 系数）
```

★ **一句话的判断标准**：一个能力如果**三个以上题材都要**，它才是真通用；
只有一两个题材要的，可以先不做，但**别把它写死在底座里** —— 留个口子。
