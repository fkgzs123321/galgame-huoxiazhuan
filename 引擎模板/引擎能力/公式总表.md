## 一、LCG 确定性伪随机（本卡原有）

```
state' = (1664525 × state + 1013904223) mod 2^32
r      = state' / 2^32                 → 0 ~ 1
roll   = r × 100                       → 0 ~ 99.99
d20    = floor(r × 20) + 1             → 1 ~ 20
```

**为什么不用 `Math.random()`**：酒馆楼层**会重渲染**。
用确定性伪随机 → **同一回合重新渲染结果一致**，玩家刷新页面不会变结果。

★ **优势/劣势**（**【主神】**）：
```
优势 = 掷两次取 【小】   （百分骰越小越好，与 roll < rate 的语义一致）
劣势 = 掷两次取 【大】
```

★ **自然极值**（**【主神】**）：`d20 = 20` → 无视修正判大成功；`d20 = 1` → 无视修正判大失败。
→ 目的：**给弱方留一线**（clamp 到 5% 之上仍可能靠自然 20 翻盘）。

## 二、★ 相对修正（**【主神】** 吸收）

```
rel(值, 均值, K, 下限, 上限) = clamp( round( (值 − 均值) / 均值 × K ), 下限, 上限 )
默认 K = 30，下限 −15，上限 +20
```

**它解决的问题**（原文）：
> 属性是**开放数值**（默认 5，后期上千）。
> CoC 的 `1d100 ≤ 属性`、D&D 的 `(属性−10)/2` 都假设属性在**固定小区间**，
> 直接搬会崩 —— **前期必败、后期必成、骰子变噪声**。

**所以所有修正都相对化** —— 只看「**比自己的均值高多少**」。
→ 效果：**一阶撬一阶锁、九阶撬九阶锁，都能是"普通难度"**。

★ **测试验证**（`test-judge.cjs`）：
- 值 = 均值 → 修正 0 ✅
- ×2 → 触及上限；×0.5 → 触及下限 ✅
- **×10 后结果不变**（量纲无关）✅
- 1000 vs 均值 800 → 仍是很小的修正 ✅

## 三、能力值合成（本卡原有 + v2 相对版）

**原有（加权平均 · 权重归一化）**：
```
P = Σ(值 × 权重) / Σ权重        （权重为 0 的项不参与）
```
★ 归一化 → **尺度无关**（属性多少不影响量级）。

**v2 相对版**（**【主神】** 思想的落地）：
```
P_rel = Σ( rel(值, 均值, K) × 权重 ) / Σ权重     → 落在 −15 ~ +20
```
★ **开放数值体系该用 `judgePowerRel`**（绝对值只用来看显示）。

## 四、要求值（本卡原有）

```
R = clamp( base × 难度乘数 + 目标修正 + 阶段修正, 0, 100 )
```
- **难度用乘法不用加法** → 无论基准值多高，**难度感受一致**（基准 20 和基准 200 都"困难"）
- **`阶段修正` 是真实参数**（修掉原卡 bug②：关系阶段修正恒为 0，
  导致"恋爱游戏最核心的状态不参与判定"）

★ **难度档**（**【主神】** 的 DC 对照，可选实现）：
```
简单 DC 10 ｜ 普通 13 ｜ 困难 16 ｜ 极难 20 ｜ 几乎不可能 25
```
★ **难度分位**（**【火影】**）：`轻松 0.3 / 标准 0.5 / 困难 0.65 / 残酷 0.8 / 传说 0.95`
—— 表示"对手该强到超过全体 NPC 的百分之多少"。
**我们生成 NPC 时可用这一套**（难度是**相对世界**的，不是相对动作的）。

## 五、成功率与档位（本卡原有 + v2 扩展）

```
成功率 S = clamp( 50 + (P − R) + 修正合计, 5, 95 )
成败     = roll < S
```

**修正合计** = 相对修正 + 环境修正 + **模板修正**（社交/求爱好感，**【主神】**）

**档位**（★ 由**差值 + 成败联合**决定 —— 修掉原卡 bug①）：
| 条件 | 档 | effect_mult |
|---|---|---|
| 成功 & d ≥ 30 | 大成功 | **2.0** |
| 成功 & d ≥ 15 | 碾压成功 | **1.5** |
| 成功 & d ≥ 10 | 成功 | 1.0 |
| 成功 & d < 10 | 勉强成功 | 0.6 |
| 失败 & d ≤ −30 | 大失败 | **2.0**（反噬） |
| 失败 | 失败 | **0** |

★ **倍率来源**（**【主神】**）：
```
大成功 ×2（战斗=要害/斩杀；社交=好感跃迁；开箱=多一件稀有）
碾压 ×1.5 ｜ 成功 ×1.0 ｜ 失败 ×0 ｜ 大失败 反噬（指向自己）
```

★ **bug①**：原实现 `_tier` 只看差值、`_success` 只看骰子 →
`diff=30` 时 `successRate=80`，若骰值 85 → **「大成功」与「失败」同时成立**。
**修法**：`judgeTier(diff, success)` 两个参数一起收。**测试已覆盖不复发**。

## 六、★★ 对战（**【主神】** 最关键的一条）

```
对手 = 绝对强度差 + 相对修正差

P = clamp( 50 + 强度差 + (我方相对修正 − 敌方相对修正) + 环境差, 5, 95 )

强度差 = clamp( round( (我方强度分 − 敌方强度分) / 10 × 6 ), −40, +40 )
```

**它解决的问题**（原文，这条最要紧）：
> 纯相对修正（属性 vs 自身均值）在「人 vs 任务」成立，
> 但「人 vs 人」会**丢掉绝对强弱** ——
> **全 2 的杂鱼和全 500 的神，属性修正都 ≈ 0**。

★ **强度分**（**【主神】** 的档表）：
```
T0 杂鱼 0 ｜ T1 10 ｜ T2 20 ｜ T3 30 ｜ T4 40 ｜ T5 50
T6 60 ｜ T7 70 ｜ T8 80 ｜ T9 源初 90
每差 1 档 ≈ ±6（百分骰），封顶 ±40（给弱方留一线）
```

★ **测试验证**：双方相对修正都为 0 时，**胜负仍由强度差决定** ✅
（这正是"人 vs 人 不失真"的证明）

## 七、★ 日常行动判定（**【姬侠】** 吸收）

```
最终值 = (随机数 + 天赋加成) × (体力 + 难度加成) / 100

随机数 0~100 ｜ 天赋加成 = 对应天赋值 ｜ 体力 0~100
难度加成：简单 +20 / 普通 +10 / 困难 +0
```

| 最终值 | 结果 | **体力消耗** | 属性获得 |
|---|---|---|---|
| ≥ 80 | 大成功 | **0** | 高 |
| ≥ 60 | 成功 | 5 | 中 |
| ≥ 40 | 一般 | 10 | 低 |
| ≥ 20 | 失败 | 15 | 极低 |
| < 20 | 大失败 | **20** | 无 |

★★★ **三层巧思**：
1. **体力是乘法因子** → 体力低会**拖垮所有行动**（天然的"状态管理"）
2. **成功度 = 体力消耗** → 成功省体力、失败费体力 → **正负反馈闭环**（越弱越累）
3. **一个公式管所有日常**（练武/学习/打杂/探索/汇报/打铁，只换天赋）

★ **测试验证**：体力 95 的成功次数 **>>** 体力 15 ✅

## 八、★ 概率型属性效果（**【姬侠】** 吸收）

```
触发概率 = 属性值 ÷ 2（%）       上限 95
```

| 属性 | 效果 | 要点 |
|---|---|---|
| 心性 | 本次行动**不消耗行动点** | — |
| 魅力 | 好感变化**翻倍** | **只对上升生效**（下降不触发） |

★ **设计要点**：**属性不是"加数值"，是"按概率触发特殊效果"**。
· 玩家**能感知到触发**（有提示文字）
· **只放大好的、不放大坏的** → 手感正面

★ **测试验证**：属性 100 → 实际触发率 ≈ 50% ✅

## 十、强化（本卡原有 + **【主神】** 改造建议）

**本卡现有**：`加成 = 基础 × (1 + 每层倍率 × 层数)`，上限 10 层，每层递增材料。
→ **温和、无赌性**。

**【主神】** 的四段式（**建议采纳**）：
| 区间 | 成功率 | 失败后果 |
|---|---|---|
| +0 ~ +2 | **100%** | 白送 |
| **+3 ~ +6 降级区** | 95% → 75% | 掉 1 级 |
| **+7 ~ +9 归零区** | 62% → 41% | **直接回 +0** |
| **+10 ~ +16 分解区** | 34% → 10% | 💥 **永久消失** |

★★ **保底「垫子计数 N/10」**：
> **只有装备真的被爆掉时计数才 +1**（掉级、归零都不算）
> **攒满 10 → 下一发必成**
> ★ 高玩玩法：**拿垃圾装故意冲爆攒计数**，再用必成的那发推主力装

★ **辅助道具**：**强化符**（+12% 成功率）｜ **保护石**（+7 起可勾，失败不归零不爆装）
★ **操作与兑现分离**：强化只是打 +号，**「结束强化」才结算属性**（每升 4 级加一条词缀）

## 十一、★ 炼丹（**【姬侠】** 吸收，**已落地**）

```
起手品质 = (投药数 − 6) × 5
炉温倍率：0~30 → 0.3~0.5 ｜ 31~70 → 0.5~1.0 ｜ 71~100 → 1.0~1.8
过 100 → 炸炉（全损）
```
**五种操作**（★ 完成度与品质**此消彼长**）：
```
猛火(+25~35温, −品质) ｜ 文火(+微温, +品质+完成) ｜ 投药(−温, ++完成)
冷凝(−30~20温, ++品质) ｜ ★ 淬炼(+品质, −完成度)
```
**产出**：100 → 九转金丹 ｜ 90~99 → 易筋丹 ｜ 75~89 → 培元丹 ｜ 50~74 → 普通丹药

★ **为什么好**：温度是**资源 + 风险**（高倍率 vs 炸炉）；
**完成度与品质此消彼长** → **逼玩家做取舍，而不是无脑点**。

实现：`底座_yingxiong/炼丹.yaml` + 面板「丹房」页签。

## 十二、★ 战斗（**【姬侠】** 的 7 行动 + 克制链）

**行动与耗气**：
```
集气(Q,0) ｜ 防御(W,0) ｜ 轻攻击(E,1) ｜ 重攻击(R,2) ｜ 绝招(T,5) ｜ 嘴炮(Y,0) ｜ 道具(U,0)
伤害：轻 100% ｜ 重 150% ｜ 绝招 300%（无视防御）
气上限 10
```

**克制链**（★ 石头剪刀布式）：
```
防御   → 克制 → 普通攻击（减伤到 15% / 25%）
重攻击 → 克制 → 轻攻击（无效化 + 造成伤害）
绝招   → 克制 → 普通攻击 & 防御（无视防御）
嘴炮   → 克制 → 绝招（无效化）+ 破防（对方气 −1 + 挑衅 2 回合）
```

★ **为什么好**：**不用复杂公式**（只有 100/150/300% 三档），
**靠克制链产生深度** —— **玩家每回合都有得选**（我们的战斗现在只有"打不打"）。

**【姬侠】的场地效果**（持续 3 回合，**对双方生效**）：
```
杀意🔥（伤害×1.5，自己也受 25%）｜ 瘴疠☠️（每回合 −10% 血）｜ 固守🛡️（防御=完全免伤）
气海✨（每回合 +1 气）｜ 缠斗🤝（禁用嘴炮）｜ 回春💚（每回合 +10% 血）
```
★ **改变战局规则，而非单纯加 buff**。

**【姬侠】的敌人风格**：`风(快攻) / 火(爆发) / 林(蓄力) / 山(防守)`
→ **给敌人"行为模式"而非"数值档"**，玩家能读对手。
