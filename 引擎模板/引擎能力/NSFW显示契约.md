> ★ 为什么它是**引擎层**而不是底座内容：

>   「胸前是 C 还是 D」「她叫什么」那才是底座的事。

## 一、为什么要有这一份

我们的变量里早有 `NSFW.身体.基线` 与 `NSFW.身体.即时` 两层（**稳定 vs 场景级**），
层分得对，但**只写了字段名，没写每列该填什么**。结果：

- AI 不知道该填「充血勃起」还是「C 罩杯」→ **填了稳定特征进即时层**
- AI 不知道该写多长 → **写成一整段，把变量撑爆**
- 空值没有约定 → **该填「未变化」的地方留空**，面板显示成空白

★ **V3.738 的每一列都写死了四件事**，照抄：
```
① 填什么（举例）
② 多少字（硬上限）
③ 什么算空（「未变化」/「正常」）
④ ★ 禁止填什么（这是最关键的一条）
```

## 四、周期（可累加状态 · 引擎只提供容器）

★ 引擎层**不认识「怀孕」这个词** —— 它只提供「带周期的可累加状态」。
「孕」是底座填的一个实例（见 `底座_xxx/NSFW契约表.yaml` 的 周期表）。

| 引擎提供 | 底座填 |
|---|---|
| 周期的形状：名 / 总轮 / 叠加上限 / 可中断 / 阶段 / 结束时落账 / 中断后果 | 「孕」9 轮、三阶段、结束多一个人少三个月耐心 |
| 按轮数推当前阶段 | 每个阶段的表现文字 |
| 结束时落账、中断时结算 | 落什么账 |

★ **同一个容器还能装**：伤、闭关、毒、蛊、契约倒计时……
  **凡是「过 N 轮之后自动发生一件事」的，都走这一套。**

## 五、写在面板上的规则

| 区 | 显示什么 | 空的时候 |
|---|---|---|
| **此刻（场景级）** | 即时层里**非空**的那几列，一行一条 | `未变化` |
| **长期（数轮稳定）** | 基线层里**非空**的那几列 | `还没建档` |
| **正在走的周期** | 名 + `已过 / 总轮` + 进度条 + 当前阶段 | `没有在走的` |

★ **三档颜色**（与她的手段/品级同一套色）：
- **基线层**：平常色（它是背景，不该抢眼）
- **即时层**：暖色（它是"刚刚发生"，要看得见）
- **周期**：金色（它是有倒计时的，最需要被注意）
