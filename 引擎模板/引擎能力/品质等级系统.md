# 品质等级系统 · 调研与设计

> 用户的要求：**品质等级不只是装备有，技能也有、任务也有、材料也有、丹药也有等等，
> 全都能按品质等级换不同的颜色。你要不要好好调研下。**
>
> 这条要求指向一个**系统级结论**：**品质不是物品的字段，是一个通用维度。**

---

## 一、调研：主流游戏的品质系统

### 1. 颜色顺序是**行业共识**（这一点几乎没有例外）

| 档位 | 通名 | 颜色 | 色值（约） | 出处 |
|---|---|---|---|---|
| 0 | 粗糙 / 破损 | **灰** | `#9d9d9d` | 魔兽灰装、暗黑白装 |
| 1 | 普通 / 常见 | **白** | `#e8e8e8` | 魔兽白装 |
| 2 | 优秀 / 精良 | **绿** | `#1eff00` | 魔兽绿装、原神 2★ |
| 3 | 稀有 / 珍稀 | **蓝** | `#0070dd` | 魔兽蓝装、剑网3 蓝 |
| 4 | 史诗 / 珍奇 | **紫** | `#a335ee` | 魔兽紫装、原神 4★ |
| 5 | 传说 | **橙** | `#ff8000` | 魔兽橙装、剑网3 橙 |
| 6 | 神器 / 神话 | **金** | `#e6cc80` | 魔兽金，原神 5★ 也走金 |

**关键点**：
- **灰 < 白 < 绿 < 蓝 < 紫 < 橙 < 金** —— 玩家看到颜色就知道好坏，**不用读字**
- 颜色**不带题材色彩**，可以直接用

### 2. 但「档位名」要**跟着题材换**

| 题材 | 档位名怎么叫 |
|---|---|
| 西幻（魔兽 / 暗黑） | 粗糙 / 普通 / 优秀 / 稀有 / 史诗 / 传说 / 神器 |
| 二次元（原神） | 1★ ~ 5★（直接用星级） |
| **武侠**（本卡） | **凡品 / 良品 / 上品 / 精品 / 极品 / 绝品 / 神品** |
| 仙侠 | 凡器 / 法器 / 灵器 / 宝器 / 道器 / 仙器 / 神器 |

★ **本卡选武侠那套**（`凡品 … 神品`），因为底色是武侠。

### 3. 品质**什么都能标**（这是最容易被忽略的一条）

| 能标品质的东西 | 品质在这里意味着什么 |
|---|---|
| **装备 / 兵器** | 加成倍率 |
| **技能 / 武功** | 威力与稀有度（★ **同一门功夫，不同人使出来品级不同**） |
| **任务** | 难度与奖励丰厚程度 |
| **材料 / 药材** | 用途与稀缺度 |
| **丹药** | 药力与副作用 |
| **招式（绝招）** | 冷却与效果 |
| **NPC** | 战力档（原作就是按档标战力的） |

★ **一句话**：**品质 = 稀有度 + 强度档位**，任何「有强弱之分」的东西都能挂它。

### 4. 品质怎么进**引擎层**

现在 `E8 品质与掉落` 只做了「掉落按权重随机 + 品质给倍率」。
要扩成**通用维度**，需要补三件：

| 补什么 | 说明 |
|---|---|
| **① 通用档位表** | 档位表是**参数**（名 / 颜色 / 倍率 / 权重），任何底座换表即可 |
| **② 判定器** | 给一个东西（值 + 类），判它该落哪一档 —— **各类的判定规则由契约给** |
| **③ 配色输出** | 引擎给出**档位 id**，面板负责上色（引擎不写 CSS） |

## 三、各类东西怎么定品质（契约层要给规则）

★ 原则：**规则由契约给，引擎不认识「武功」「丹药」这些词。**

| 类 | 判定规则（写进契约） | 例子 |
|---|---|---|
| **兵器 / 衣裳** | 按**价格**折算：`加成 = 价格 ÷ 100`，价格决定档 | 钢刀 420 文 → 良品；护手钩 21000 文 → 极品 |
| **武功** | 按**师承层级 × 门派地位**：入门基本 → 良品；门派主力 → 上品；镇派绝学 → 精品~极品 | 太极拳 = 上品；万流归一 = 极品 |
| **绝招** | 按**条件严苛度**：单条件 → 上品；双条件 → 精品；三条件以上 → 极品 | 挤字诀（四门同到 80）= 精品 |
| **任务** | 按**前置门槛 + 后果重量**：日常 → 良品；有门槛 → 上品；涉及生死/不可逆 → 极品 | 除恶 = 良品；浪人的仇（输了会死）= 极品 |
| **丹药 / 材料** | 按**获取难度**：镇上买得到 → 良品；要打特定人 → 上品；隐藏线才有 → 极品 | 海外仙丹 = 极品 |
| **NPC** | 用**战力档**直接对到品质档（原本就是按档标的） | 战力 100 → 良品；10000 → 精品 |

## 四、面板怎么用（本次要落地的）

**哪里的颜色都要能看出来**：
| 区域 | 上色的对象 |
|---|---|
| 物品格 | 格子边框 + 图标色（已做，色值要换新表） |
| **技能格** | 环形进度环 + 图标色（**新增**） |
| **任务折叠项** | 左侧色条 + 图标色 + 名称（**新增**） |
| **绝招表** | 每一行的色点 + 名称（**新增**） |
| **可接任务** | 折叠项图标色（**新增**） |
| **可交战目标** | NPC 按战力档上色（**新增**） |
| **品质图例** | 面板里给一行色卡（玩家不用猜） |

★ 一条硬要求：**同类东西在面板任何地方，颜色必须一致**（同一个「上品」到处都是绿的）。
