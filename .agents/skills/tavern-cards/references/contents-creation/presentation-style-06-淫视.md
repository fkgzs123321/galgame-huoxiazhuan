# 淫视（文风）

> **淫视 ＝ 叙述者本身就是一个下流胚子。**
> 它管的是**谁在看、怎么看**，不是「用词多脏」。
> ★ 与另外五种的区别：冷冽 / 无尽骚妈 / 母猪 / 少妇白洁 / 阶段性反差 是**味道**；**淫视是眼睛**。
> ★ 完整条文在技法层 `presentation-craft-01~05`。
>
> ★★ **本条不自己写「怎么写」—— 全部照搬 `_素材库/2026.08.12/1.核心条目` 的原文。**
> 那 5 份的示例就是**密度下限**，写的时候对着它量。

## 〇、五种写错法（**禁止** · 动手前先读）

**① ❌ 禁止白描** —— 只写动作不写肉（没有器官、没有体液、没有感觉、没有脏字）。
★ **正文、条目、规范、预设一律适用** —— 读它的是 AI，**它读出什么，后面就写什么**。
**② ❌ 禁止清单** —— 一栏一行、一段一个短语的登记表。**骨架是清单就是白描**，塞满器官脏字也救不回来。
**③ ❌ 禁止冷冽换壳** —— 短句 ＋ 留白 ＋ 不写欲望。冷冽是五个味道之一，**不是默认底色**。
**④ ❌ 禁止把「事件不越权」用反** —— 它只禁**凭空加动作**，**不禁照实写**；确认了就**完整落笔**。
**⑤ ❌ 禁止只搬结构不搬肉** —— 抄了分栏却把每栏写成短语。**照搬结构 ≠ 照搬内容。**
**⑥ ❌ 禁止把示例的「设定」搬到自己的场景上** ——
`craft-01` 明写着：**示例里的体型、衣物、姿势、动作顺序与她手上正做的那件正事，一概不迁移到别的角色与场景，只取烈度与语感。**
★ 拿示例里的「护士 / 白大褂 / 剑」去套自己的角色 ＝ 没读懂那条。

## 一、四条规则（一句话版）

**① 旁白是下流胚子。** 一切气质、身份与举止都只是被性化解读的材料。
**② 主语是器官，不是「她」。** 不写「她觉得 / 她不知道 / 她经常 / 她心里」。
**③ 放大的是幅度、范围、数量与持续时间，不是形容词的强度。**
**④ 非性场景照样过滤镜；但事件不越权**（不凭空加动作；反之确认了就完整落笔）。

## 三、★ 实样 · 肉体怎么写（照搬 🅱️2）

### 体型落点

体型落点:
  先认定这具身体在哪个维度上偏离寻常，再把那点偏离写成媚肉的具体表现。以下几档可同时命中逐条叠加，示范之外的身体照此自行取落点。
  丰腴写满和溢：骚奶子从领口溢出去堆在锁骨底下、骚尻肉把裙摆从底下鼓开撑出横褶、两片骚腿根嫩肉在并拢时挤得往两侧翻。
  纤细只管腰线以上，写窄和紧：骨架收紧线条利落，纤腰窄到一手能掐，一段皓颈往下锁骨勾出两道浅窝；腰线以下照旧顺着髂骨往外铺开落到肥尻。
  高挑写纵向拉开的距离：跨一步大腿从裙摆底下抽出长长一截，俯身时腰到肥尻的行程比旁人拉得更长，站直了胸前那两团正悬在对视者眼前的高度。
  娇小写尺寸落差：站直了头顶只够到对方胸口，仰起脸说话时整片视野被那两团骚奶子占满；一副窄骨架撑着腰线底下横铺出去的安产型肥尻，两瓣尻肉在身后撅出的宽度比肩还阔。
  小奶写敏感和精致：胸前隆起的弧度刚好填满掌心，浅粉乳尖在布料下顶出两个小点碰一下就挺立充血，小巧弧面绷得紧致挺翘。平坦前胸把锁骨胸口线条衬得更清晰，贴身衣物直接压着乳尖每次呼吸都在上面蹭。
  禁止把紧实、松软、肥腻、纤薄这类互斥的词堆在同一处媚肉上。

### 动态（摆动通则 / 自身动作 / 外力介入 / 小腹屌形）

动态:
  摆动通则:
    每一次摆动都是力把肉推出去再回填，落笔写清被推向哪一侧、荡到哪里停：翻过臀球弧顶折进臀缝，爬上腰窝在髂骨那道骨线上断掉，顺腿根淌到丝袜袜口。走向每次都换。摆动落在积着脂肪的部位，胸、尻、腿根是主要落点。
    一段里的摆动只取胸、尻、腿根中的一处写到底，行程、余颤与回填占满这一段的动态笔墨，别处一律不提。动作停下时这一处摆动一次比一次收小直到停死。
    两团骚奶子各走各的差着半拍，差多少看姿势与承重，这属于胸这一处内部的动静不另占名额。奶大写摆幅、行程与拖长的余颤，两条弧线在交汇处撞在一起挤扁再弹开；奶小写乳尖那一小截的高频错拍，弹回极快尚未定住下一记又落下来，禁止以奶小为由略过胸前动态。布料兜住的那截被勒在里面挤压变形，边缘溢出的那截自由甩荡，两截可以往相反方向走。
    禁用整个人抖了一下、浑身颤了颤、全身的肉都在晃、身上的肉抖动起来这类不指明哪块肉、不给方向与行程的整体颤动，禁用哆嗦、起伏不定、颤个不停，禁用几波几阵一类量词概括摆动次数，禁止把同一处肉的动态拆成前后两个分句分别报告。

  自身动作:
    走路那对奶子被步子送出去甩到最高点把衣料从里头顶起来，坠回去撞在乳丘底下弹开，隔两步才停；弯腰整团骚奶子从领口垂坠下去；抬臂胸前那片肉被牵着往上提。
    一处动了牵出另一处跟着动：坐下去两瓣尻肉被椅面顶得往前挤把腿根整片鼓起来连臀缝都被自身分量压得更深，坐实那一瞬整个人往下沉了半寸；折身取低处的东西时肥尻被这个折角推到腰窝上方撅成全身最高的一处，两条并拢的腿根从两侧把肥厚屄唇挤在一起顶得屄口开合一回；夹腿两瓣腿根嫩肉挤在一起松开时缓缓弹开；伸懒腰衣摆上移暴露一截小腹连胸前那两团都被拉得绷挺，放松下来整个晃回去。
    出招那一下的摆动落在胸：一剑挥出去两团沉坠的骚奶子一并往剑走的那一侧甩过去，甩到最远处被收势拽回来撞在一起挤扁再弹开；腿抬过耳侧劈落时整副安产型骚胯跟着翻起来朝向劈击的反侧。急停、落地与站定那一下的摆动落在尻：下半身刹死了整片尻肉按原速再往前推半寸，荡回来一记又补小半才定住。战斗写的是这具骚躯怎样承受自己发出的力，招式本身与胜负走向照旧连续交代。
    呼吸、吞咽、交叉腿、翻页、靠墙、推眼镜这类普通动作默认都要带出一处媚肉的反应。这些微动跟着正在进行的行为和台词一起构成完整的文字。

  外力介入:
    落在这具骚躯上的任何外力都按本档取摆动，挨打、被撞飞、被推搡、被按住、被抱离地面与衣物被扯住一概在内，不限于性交。
    雄性胯部整个拍上肥尻那一瞬媚肉被压平摊开从接触边缘往两侧溢出，前一波还没填回来下一记爆肏已经砸上去把余颤与新压出的形叠在同一片腻肉上；骨架窄的把肉浪推到边缘折回来在一片腴软尻肉上撞出两股反向的荡动。
    同一记打桩落下去身后那副安产型肥尻整片被砸平又翻出完整肉浪把人钉在原处，上半身却被顶着往前挪，撑床的手掌打滑出去一截。
    肏得狠了两只裹着丝面的骚脚被整个顶离地面，任何体型都能被肏到双足悬空，这身白腻雌肉的分量全吊在插进去的那根粗屌与掐住胯部的那两只手上，悬空的细高跟随每记爆肏在半空甩出弧线。重新落回去那一下整具骚躯往下坠的同时那根屌正往上顶把龟头捅穿到站着时够不到的深度。
    被那双手攥住的一圈软肉从指缝里挤出来一直保持着变形的样子不弹回，手一换位置原先压住的臀肉重新晃起来，新攥住的一处开始堆挤。

  小腹屌形:
    贯穿到底时屌身把腔道往外顶得雪腻小腹上撑出随抽插鼓起又塌下去的狰狞形状，连龟头那圈冠状沟的棱都顶得出来，抽出时整道屌形塌平。脂肪厚的只鼓起一片说不清形状的隆起，禁止因形状模糊而略过小腹。

### 取材时机

取材时机:

  嘴被占着: 嘴上正嗦着含着吮着舔着亲着的工夫照样把话说完，口部动作发出的吸溜、咕啾、啵唧与台词交替码在同一串引号里凑成一整句，嘴上的活一下不停。禁止先沉默做完口部动作再抬头说话。
  撞散: 撞击并不会影响她的说话，而是将具体行为散进她的说话里。撞击只切断句子不换掉说话的人。她原本那句话被叫声劈开后照旧往下接，断口处接破折号或半截词，气顺了从被劈开的地方续上，把她本来要说的那件事说完。
  锚点不掉: 自称、对人的称呼、敬语层级、句法习惯与口癖在任何强度下原样保留，肏得越狠她越往自己最熟的那套措辞里缩。
  禁止: 单字长音独立成句充当台词。她只出声不说话、挨的那一下改由旁白说明。台词、旁白描写、台词三段轮流交替推进同一场撞击。，但必须保持她角色的性格锚点。
  顶出来的闷响: 龟头捣进腹腔深处顶出的是嗝、呃、唔噗这类非自愿的短促闷响，与主动媚叫交替出现。
  轮换主导音: 每段淫叫定一个主导音，齁、噫、喔、唔、呜各领一段，下一段换另一个打头。
  禁止: 以单字连堆充数。纯啊堆砌与啊——！一类固定模板。

多人同场:
  每句话用姓名、人物锚点、目光落点或动作方向指明说给谁听。同一句话可以表面回答面前的人实际讲给旁观者听。
  雌性之间互相接话、拆台、补刀、帮腔与搭台，一个人的淫称被另一个人当场改写，改得比原话更贴她此刻的实情。
  同场雌性的自称、口癖、腔调与淫叫主导音各不相同，一人一套，越是同时开口越要听得出是两个人在说话。
</B3>

## 七、写完逐条过

- [ ] **主语**：数一数以器官／部位为主语的句子占多少（主语还是「她」＝ 重写）
- [ ] **心理陈述**：「她觉得 / 她不知道 / 她经常 / 她心里」有吗（有就删）
- [ ] **句长**：对着第二节的示例量——长句铺到 50~80 字、一个动作不断逗号
- [ ] **破折号 / 顿号排比**：一处都没有吗
- [ ] **放大的是幅度**：写得更狠靠「撞开多远、多久才停、涌出多少」，不是加形容词
- [ ] **非性场景**：赶路、吵架、跑步，有没有照样过上滤镜
- [ ] **没有搬示例的设定**：我写的角色不是护士、手上没有剑
