# 阶段性反差（文风）

> ★ 与 `presentation-common-01-用词.md` 和 `presentation-common-02-素材.md` 同用
> ★ **本条的命根是「段与段之间的手感差异」** —— 同一个场景、同一个人，三段写法必须**一眼能分开**

---

## 一、核心指令

**先定阶段切分点**（用什么变量、跨过多少进下一段）。每段**单独写行为与语言**，
段与段之间**必须有明显手感差异**。转折点要写「**她变了**」的那一刻。**用词尺度跟着阶段走**。

## 二、三件必须做到的事

### ① 器官词密度随阶段递增
```
前期：0 次（只写态度）
中期：2 次（写「隔着布」）
后期：5+ 次（器官 + 状态 + 体液）
```

### ② 台词尺度随阶段放开
```
前期：「你别这样。」「我不是那种人。」「你放开。」
中期：「……你轻点。」「别在这儿。」「一会儿有人。」
后期：「快点捅进来嘛……」「人家等了半天了……」「捅深一点，捅烂了都行。」
```

### ③ 「她变了」的那一刻必须写出来
不是「她慢慢地越来越……」 —— **要有一个具体的时刻**，让玩家看得见她迈过那道线。

---

# 实样（8 组）

## 组 1 · 同一场景的三段（器官词 0 → 2 → 5+）
> **前期**：她把手按住裙摆。「你别这样。」声音是硬的，眼睛看着别处。裙子底下那两条腿并得紧紧的。
>
> **中期**：「……你干什么。」她的手还在推，但力气小多了，推了两下就搭在那儿。裙子已经翻上来了，她自己也看见了，没去拉。内裤早湿了一片，贴在那儿，中间那道缝的形状透得清清楚楚。「一会儿有人进来……你快点。」
>
> **后期**：她自己把裙子撩到腰上，跪下去，抬起头。那个骚逼已经淌得一塌糊涂，两瓣肉翻着往外滴，骚水顺着大腿内侧往下淌到膝盖。奶头在薄衫底下已经硬得顶出来了，她也不遮。「快点捅进来嘛……人家等了半天了……你上次说这周来的。」她的脸红着，可话已经不用人教了。「捅深一点……捅烂了都行。」

## 组 2 · 转折点（写「她变了」的那一刻）
> 之前她每次都会把脸别开。
>
> 这一次没有。
>
> 她看着他。看了三秒 —— **这三秒里没什么事发生，可她知道有件事已经过去了**。
>
> 「……」她张了张嘴，没说出话。然后她低下头，自己把最后那粒扣子解了。
>
> 解完，她抬起头，还是不说话。
>
> 但那三秒没了。

## 组 3 · 同一个动作在三段里的不同写法
```
前期：她端茶的时候手在抖，杯沿碰到托盘，响了一声。她说「抱歉」。
中期：她端茶的时候手不抖了。放在桌上，转身就走，不多站。
后期：她端茶过来，不是放 —— 是递。递到他手边，然后在他旁边坐下，没走。
```
★ **同一个动作（端茶），三段写法完全不同** —— 这就是「手感差异」的意思

## 组 4 · 同一个称呼在三段里
```
前期：她叫他「王老师」。规规矩矩。
中期：她叫他「你」。不叫名字了。
后期：她不叫。要说话就先碰他一下。
```
★ **称呼的变化，比任何身体描写都更能说明她到了哪一段**

## 组 5 · 同一个房间在三段里（空间感）
```
前期：她请他坐，自己坐在对面。两个人中间隔着一张茶几。
中期：她请他坐，自己坐在沙发另一头。茶几被挪开了。
后期：她请他坐，自己先坐下了 —— 坐的是同一张沙发，挨着。
```

## 组 6 · 三段里的沉默（沉默的性质不一样）
```
前期：沉默是因为「不能说」。
中期：沉默是因为「说了也没用」。
后期：沉默是因为「不必说了」。
```
★ **同样的「不说话」，三段的含义完全不同** —— 写的时候要让人读出是哪一种

## 组 7 · 从「抗拒」到「表演性抗拒」
> **真实抗拒期**：她把他的手甩开，退了两步，站在门口。「你走。」
> 那时候她眼睛是红的，手在抖，**她是真的不要**。
>
> **表演性抗拒期**（同一件事，几个月后）：
> 「不行~❤~」
> 她把他的手推开，推得很轻。推完自己先把领口松了一粒。
> 「真的不行~❤~」
> 她说这句的时候，已经坐到他腿上了。
> ★ **同样是「不行」，前期是真的、后期是演的** —— 这一层要写出来

## 组 8 · 尺度跨度总表（一张表看全四段）
| | **第一段** | **第二段** | **第三段** | **第四段** |
|---|---|---|---|---|
| **衣着** | 扣到最上，裙摆压平 | 加了一件里衣 | 只穿一件宽的 | 还是那身最体面的 |
| **距离** | 隔一张桌子 | 坐沙发两头 | 挨着坐 | 坐他腿上 |
| **称呼** | 全名 + 敬称 | 你 | 不叫 | 不叫 |
| **台词脏度** | 0 | 半句 | 整句 | 连着说 |
| **器官词** | 0 | 2 | 5+ | 满 |
| **手在干什么** | 推 | 推一下就搭住 | 主动伸过去 | 按着他的腰 |
| **事后** | 立刻走 | 收拾好再走 | 不走 | 不问 |

★ **这张表就是「阶段切分点」** —— 每一列是一个阶段，**列与列之间必须有可见的差**

## ★ 自查

- [ ] **把任意两段的台词放一起，能不能一眼看出是两段？** 看不出 → 阶段没分开
- [ ] 器官词密度**随阶段递增**（不是每段都一样多）
- [ ] 转折点写了「**她变了**」的**具体那一刻**，不是「越来越……」
- [ ] 同一个动作/称呼/沉默，在三段里的**含义不同**（不只是程度不同）
- [ ] **没有把三段写成「同一段加长版」**
