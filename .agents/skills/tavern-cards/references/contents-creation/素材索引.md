## 六、怎么用（三种）

**① 一比一仿照** —— 换角色名与场景，**骨架 / 句式 / 用词照原样**。适用：密度基准、体型落点、取料。
**② 直接用** —— 原文里**不含具体角色**的动作与画面，**整句搬**。
**③ 按规则新造** —— 只有规则没例子的地方，按规则造，**造完对着 🅰️ 的密度基准量一次**。

---

## 七、四条硬规矩

1. **完全按照本表列的素材来写** —— 不自己发明；拿不准就查第五节那张表
2. **密度不得低于 🅰️ 的「示例·密度与语感基准」** —— 那是**下限**，不是参照点
3. **只取烈度与语感，不取设定** —— 示例里的体型、衣物、姿势、动作顺序与那件正事，**一概不迁移**
4. **禁则先过** —— 第二层的 `限制及要求世界书` 里禁的词与写法，**全卡不许出现**

## 八、写完逐条过

- [ ] **素材来源**：这一段对应第五节表里的哪一节？说不出来 ＝ 大概是自己在发明
- [ ] **词料命中**：命中 `🅱️4` 词料库的词有几个（**个位数 ＝ 没在用**）
- [ ] **句长 / 破折号**：对着 🅰️ 的示例量（50~80 字、破折号与顿号排比 0 处）
- [ ] **三层落笔**：详写那处是「形态 ＋ 受力质地 ＋ 第三层」吗（缺层不成立）
- [ ] **禁则**：过一遍 `限制及要求世界书`，全篇没有它禁的词
- [ ] **没搬设定**：我写的角色不是示例里那个护士，手上也没有剑
