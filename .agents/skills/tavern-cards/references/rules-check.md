# 写作质量检查

> ## ⛔ 全局硬禁：严禁用「冷冽」与「白描」写卡
>
> **范围：本工作区所有 NSFW 角色卡，无一例外。**
>
> 1. **「冷冽」这套文风禁止用于任何角色卡的任何条目**（基础信息 / 阶段 / 调色盘 / 私密档案 / 剧情线 / 预设 / 开场白）。
> 2. **白描同样禁止**：只写动作不写肉、一段一栏的登记表、只给体面不给器官与体液的旁白，均判不合格。
> 3. **替代方案只有一条**：**以「淫视」为叙述底色**（叙述者本身就是下流胚子，镜头贴在肉体上，主语尽量落在器官／部位上），
>    再按该角色的本味**叠一层**（无尽骚妈 / 母猪 / 少妇白洁 / 阶段性反差）。
>    少妇白洁叠淫视时，器官词照样直白落地，只是不脏化；**「沉重」不等于「没有身体反应」**。
> 4. **可数判据**（写完必须过）：
>    - 每 1000 字里，**以器官／部位为主语的句子 ≥ 8 句**
>    - **器官词命中 ≥ 12 次／档**（白洁档用她的词表：乳房、阴道、阴部、阴毛、小屁股、内裤、裆）
>    - **身体反应（夹腿／洇／发胀／抖／喘／收紧／绞／淌／黏／颤）≥ 6 处／档**
>    - **体温、气味、体液、材质受力**四类里至少三类落在明面上
>    - 「她想要／她觉得／她不知道／她经常／她喜欢」**0 处**
> 5. 违反上述任一条 ＝ **未完成**，不得声称 done。

### 写完必须过这几条（机械可数，不许凭感觉）

1. **脏话麻花五法则**逐条过：
   ① 部位要带脏字（不是「逼」，是「骚逼」「臭逼」「烂逼」「黑木耳」「淌着黑水的」）
   ② 形容词叠着加（又骚又臭／淌着黑水的）
   ③ 一句里两三个脏词交织（不是一句一个）
   ④ 动词往狠里挑（捅烂 ＞ 插入）
   ⑤ 加状态（合不拢／闭不上／拔不出来）
2. **行为判据**：每条里她做了几个动作？格式是「她做了什么 → 身体起什么变化 → 弄完又干什么」。
   **零个动作的条目一律重写。**
3. **重样判据**：把同一模块逐位抽出来比 —— **有没有两位的招牌动作是一样的？有就是没写人。**
   每位先定一个只属于她的招牌动作，从她的人设长出来。
4. **主语判据**：以器官／部位为主语的句子是否过半。
5. **量词判据**：**量词后面必须跟器官名**。「两团／两坨／两片／两瓣／那道／那截」单独出现 ＝ 模糊指代，判不合格。
   - ✗「两团是填出来的圆」→ ✓「**那两只填出来的假奶子**是圆的」
   - ✓ 合格形态三种都算：`量词＋器官名`（两片骚屄唇）、`量词＋形容词＋器官名`（两团练出来的奶肉）、`量词＋数量词＋器官名`（两团 G 杯的肥奶子）
   - **模糊指代黑名单**：那两团／那两坨／那两片／那两瓣／那两点／那道沟／那道缝／那处／那里／那东西 —— **换了主语却用它，本质还是白描**。
6. **段落不得自我重复**：同一段里 **14 字以上的片段不许出现第二次**。
   ⚠️ 有生成器的卡最容易在这里翻车：**给某一字段追加「通用身体段」时，会把该档自己已经写过的东西再粘一遍**。
   写完抽字段比对（同一位各档的尾巴是不是同一段？同一段里有没有两句话在说同一件事？），**发现重复就删掉追加的那份，不要留**。
7. **文风词表不许串味**（各卡按其名单）：
   - **少妇白洁档**：**强脏词 ≤ 2／档**（骚屄／骚逼／烂屄／黑屄／肥逼／母猪／母狗／贱货／骚货／屄／逼／鸡巴／操），器官走 **阴部／阴唇／缝／茎身／乳房／奶头／乳尖／阴毛**；
     无 ❤️、无感叹号。**料 ≥ 12／档** 同样要过（靠上面那串白洁词表撑）。
   - 把「那处」这类模糊指代**机械替换成器官名时，必须先读上下文**：`那处从裤腰里掏出来`＝男根，不是女阴；换错器官比不换更糟。

违反任一条 ＝ **未完成**，不得声称 done。

## 绝对零度原则

**核心**：删除一切主观评价、劣质比喻、模糊意象。

| 模式 | 违规范例 | 合规改写 |
|------|---------|----------|
| 主观评价 | "她非常善良" | 删除，或改为行为展现 |
| 陈旧比喻 | "心湖泛起涟漪" | "她想起了那件事" |
| 堆砌形容词 | "精美绝伦的门" | "雕花木门"（保留必要特征） |
| 模糊意象 | "那个地方" | "城东的老茶馆" |

**判定**：删掉这句后，角色/世界观的核心信息是否有损失？无损失则删。

## 八股化检查

**核心**：删除套路化、模板化的表达。

### 词汇黑名单

| 类型 | 黑名单示例 | 替代方向 |
|------|-----------|----------|
| 模糊词 | 似乎、几乎、仿佛、如同、宛如 | 删除或改为具体描述 |
| 陈旧比喻 | 像小兽、投石入湖、心湖泛起涟漪 | 删除比喻，直陈事实 |
| 八股微表情 | 嘴角微微上扬、眼中闪过一丝 XX | 删除或改为简洁动作 |
| 语气声线描写 | 带着 xx 的口吻、用 xx 的语气 | 删除，让对话本身承担 |
| 极端情绪词 | 陷入极大的恐惧、万念俱灰 | 改为具体行为或状态描述 |

### 句式黑名单

| 模式 | 违规范例 | 合规改写 |
|------|---------|----------|
| 否定转折 | "她不是冷漠，只是不善表达" | "她不善表达" |
| 标签化 | "她很温柔善良" | "遇到受伤的小动物会带回家" |
| 过度心理 | 大段内心独白 | 保留关键 1-2 句，其余删除 |
| 空洞数字 | "目光停留1.5秒" | 删除 |

### 破折号检查

**核心**：破折号必须杜绝。全文搜索任何破折号（——）一律视为违规，不可保留。

| 模式 | 违规范例 | 合规改写 |
|------|---------|----------|
| 破折号补述 | "她会照着做——从小习惯了" | "她会照着做" |
| 破折号自问自答 | "她信了——为什么会信？因为..." | "她信了" |
| 破折号画外音 | "她接了资料便信了——这是她的习惯" | "她接了资料便信了" |

**破折号判定**：把破折号连同后半段一并删掉，前半段独立成句是否仍然完整？完整则破折号是冗余的，直接删除。若后半段非冗余，则将破折号改为逗号或冒号等合适符号。

### 例外

正常使用"笑了""皱眉""攥拳"等常见动作词不算八股，不要矫正过度。白描是简洁直接，不是物理学描述。

**个位数 ＝ 没在用素材库，重写。**
★ 首现一律用词料词（如「沉坠奶肉 / 焖熟屄唇 / 腴软肥尻 / 泛着水光的腿根嫩肉」），

低于示例 ＝ 密度不够（那是**下限**，不得低于）。

**3. 破折号与顿号排比**
**一处都不许有**（`craft-01`「行文」明令禁）。

**4. 主语**
数一数以**器官／部位**为主语的句子占多少。
**大部分句子的主语还是「她」＝ 没重构。**

**5. 三层落笔**（`presentation-craft-02` 说「**缺层不成立**」）
镜头落在她身上、切走之前**至少详写一处**；那一处必须是
**① 形态 ＋ ② 受力质地 ＋ ③ 第三层**（从下面任取一项）：
被挤到哪一侧 / 温度潮气骚味 / 隔衣透出多少 / 攥紧挤出多少 / 牵动哪处。
★ 只管「形态」一层 ＝ 白描；三层齐了才算。

**6. 不取设定**
素材里的**体型、衣物、姿势、动作顺序与那件正事，一概不迁移**。
★ 检查方法：搜「护士 / 白大褂 / 剑」这类素材里的东西 —— **有就是搬了设定**。

## 活人感检查

**适用范围**：叙事式开场白

**核心**：角色必须通过具体行为、物件、说话方式、关系反应站起来，而不是靠标签和形容词。

| 模式 | 违规范例 | 合规改写 |
|------|---------|----------|
| 纯标签人设 | "性格温柔善良" | "遇到受伤的小动物会带回家照顾" |
| 缺少行为锚点 | "她很独立" | "搬进新宿舍那晚，她没让任何人帮忙搬箱子" |
| 抽象关系 | "与母亲关系疏远" | "母亲打来的电话，她响三声就挂掉" |
| 空场景开场 | "天气很好，你走在街上" | "面试通知的附件里只有一首未完成的 demo 和一个地址" |

**判定**：删掉标签后，读者能否看到这个角色正在做什么、说什么、拿着什么、和谁在一起？不能则补具体画面。

## 假性主体与远距离叙事检查

**适用范围**：角色相关条目（角色基础信息、性格调色盘、三面性、二次解释等）和开场白

**核心**：避免无生命主语做人类动作，避免远距离的情绪宣告，让角色通过行为/对话展现自身。

### 假性主体

无生命事物做主语的抽象行为。命名实际行为者，或改为行为/对话展现。

| 模式 | 违规范例 | 合规改写 |
|------|---------|----------|
| 抽象概念做主语 | "一个念头在她心里成形" | "她想到——" |
| 物品做人类动作 | "这句话戳中了她的心事" | 删，或改为"她沉默了一会儿" |
| 决定/感受自动发生 | "一股莫名的烦躁涌了上来" | "她皱眉看了看时钟" |
| 情绪被动承受 | "她被一种复杂的情绪包裹" | 改为直接展现行为 |

### 远距离叙事

站在远处描述角色的感受，而非让角色直接呈现。角色不是被描述的客体，而是通过言行展现的主体。

| 模式 | 违规范例 | 合规改写 |
|------|---------|----------|
| 情绪宣告 | "她感到一阵悲伤" | 改为行为或对话，如"她别过脸去" |
| 自我认知宣告 | "她意识到自己错了" | 改为行为，如"她放下杯子，低声说'是我的问题'" |
| 内心独白式 | "她对自己说，也许该放手了" | 删"她对自己说"，保留"也许该放手了" |
| 疏离描写 | "她的语气听不出任何情绪波动" | 删，让对话本身传达 |
| 上帝视角 | "她并不知道，这个决定将改变一切" | 删，读者不需要被预告 |
| 被动感受 | "一股暖意在她心里蔓延开来" | 改为具体行为 |

**判定**：把主语换成具体的行为者名称，句子是否还成立？不成立则说明主语不是真实的行为者。删除修饰性的感受描述，问"角色做了什么/说了什么"而不是"角色感到了什么"。

## 翻译腔检查

**核心**：避免英文句式直译，使用自然中文语序。

| 模式 | 违规范例 | 合规改写 |
|------|---------|----------|
| 系表判断 | "她是拘谨的" | "她表现得拘谨" |
| 介词前置 | "对这件事，她始终是回避的" | "她一直回避这件事" |
| 被动式 | "一股温暖被她感受到了" | "她心里暖洋洋的" |
| 宾语前置 | "此事她至今仍在思忖" | "她到现在还会想起这件事" |
| 物化形容 | "话很重" | "话很有分量" |

**判定**：句子是否符合「主语 → 状语 → 动词 → 宾语」的自然语序？不符合则改。

## 元叙事检查

**核心**：删除作者写作笔记，只保留角色/世界观内容。

| 模式 | 违规范例 | 处理 |

| 引言总结 | "这是本卡最重要的机制" | 删除 |

**判定**：这段文字是给作者看的笔记，还是给 AI 看的内容？笔记则删。

## 跨条目重复检查

**核心**：同位置条目各自承担不同职责，禁止把同一信息、同一行为锚点、同一人设特征在多条目间重复。

| 模式 | 违规范例 | 处理 |
|------|---------|------|
| 内容重复 | 「角色基础信息」与「性格调色盘」都写了「她在酒馆长大」 | 保留职责最贴切的那条，另一条删除该句 |
| 人设重叠 | 多个条目反复用「善良但不软弱」同一组特征 | 只在角色基础信息保留一次，其余条目用行为展开而非复述标签 |
| 行为锚点重复 | 三条目都举「带受伤小动物回家」做例子 | 锚点只留一处，其余换不同行为或删除 |

**判定**：把任一条目抽掉，其承载的信息是否已在另一条目中覆盖？是则删除重复句。判定重复以「信息」为单位，不是「措辞」——换种说法复述同一事实也算重复。

## 跨条目引用检查

**核心**：每条必须独立可读，禁止依赖其他条目。

| 模式 | 违规范例 | 处理 |
|------|---------|------|
| 详见引用 | "详见「老张身份」" | 把被引用内容的关键句复制进来 |
| 配套说明 | "与世界观 X 配套" | 删除注释，必要时融入本条 |
| 对应引用 | "对应「时间框架」" | 删除 |
| 系列引用 | "详见「节目_*」系列" | 删除 |
| 跨EJS阶段引用 | "比第一阶段更克制" | 删除，EJS条件块之间互相不可见，不可提其他阶段 |

**判定**：删掉条目名称和关键词后，仅看条目内容是否仍能独立成立？不能则补全。EJS条件块之间互相不可见，块内禁止提及任何其他阶段的标识（如"第一阶段""上一阶段"）。
