# 可执行预设、模型 Profile 与输出契约

## 作用

把 Prompt 政策和 Assembly 计划变成可复现的可执行 Profile，并定义模型输出怎样被完整接收、解码、校验和降级。基础 Profile 必须独立可运行，高级能力按需启用。

## 读取条件

应用调用生成模型时读取基础 Output Contract；存在预设切换、高级模块、多模型、Prefill、停止词、内部规划或结构化输出时展开完整方法。

## 前置输入

- `Prompt Policy Package`、`Prompt Assembly Contract`。
- 目标模型的真实能力证据、输出路线和 UI/Kernel 所需候选字段。
- 内容模式、兼容档位和降级要求。

## 方法

### 1. 分开素材库与启用 Profile

素材库保存基础核心和可选高级模块；Profile 只引用本次启用的模块、顺序和参数。不要复制整套 Prompt 形成多个难以同步的预设。

- **基础核心**：AI 职责、玩家主权、人物/世界边界、连续性、基础表达、推进规则、输出协议和最终检查。
- **高级扩展**：多视角、题材节奏、群像、结构化候选、多模型任务、内容模式或模型专项适配。

### 2. 定义 Model Profile

记录供应商/本地引擎适配器、模型 ID、能力声明来源、上下文限制、采样参数、停止条件、Prefill 规则、流式能力、结构化输出能力、兼容模式和降级链。能力必须通过目标版本验证，不能从相似模型推断。

参数需要区分作品默认值、用户可调值和不可越过的协议约束。Profile 切换不得改变玩家主权、正式状态权威或内容隔离等跨域不变量。

### 3. 选择 Output Contract

| 类型 | 适用情况 | 主要风险 |
|---|---|---|
| 纯文本 | 正文不携带机器状态，Kernel/其他任务处理确定性数据 | 需明确哪些变化不会从正文自动成为事实 |
| 正文附加块 | 正文后含状态栏、摘要或候选变量 | Marker 污染、截断和解析失败 |
| 结构化 | JSON/Schema 或供应商结构化通道 | 模型能力差异、Schema 演进 |
| 受控混合 | 正文和候选变化分通道 | 协议、同步与降级复杂度更高 |

所有路线都必须把完整 `RawModelResponse` 与 `CandidateChangeSet` 分开。正文里“发生了”不等于状态已提交。

### 4. 版本化契约

Output Contract 至少记录版本、正文通道、允许的候选类型、字段 Schema、必填/可选、未知字段、长度/数量限制、Marker 转义、停止/截断检测和错误代码。Profile 必须显式引用契约版本。

### 5. Decode 与 Validate

只在 Gateway 确认响应完整后解码。步骤是：完整性检查 → 协议识别 → 安全解析 → Schema 校验 → 语义范围检查 → 生成 `CandidateChangeSet` 或失败。解析器不得执行响应中的代码，也不得用宽松正则猜测关键状态。

### 6. 设计确定性降级

- 结构化解析失败：可保留正文供用户查看，但候选变化为空且 revision 不变。
- Profile 能力不匹配：切换到事先声明的兼容 Profile，重新生成使用新 `attemptId`；是否复用 commandId 遵守 Kernel 终态规则。
- 输出被截断：标记 incomplete，不把半个协议块提交。
- 可选高级模块冲突：回退到基础核心，而不是删除玩家主权或事实边界。

降级必须可见、可记录、可测试；不能把错误响应伪装成成功。

### 7. 处理规划与 Prefill

可以要求模型在生成前检查事实、人物、目标和输出协议，但不要求输出隐藏推理。若供应商支持专用 reasoning 配置，记录能力和费用边界。Prefill 只用于明确的格式或续写约束，必须检查目标 API 是否支持，并防止把示例内容误当已发生事实。

## 唯一产物

`Executable Profile Contract`：素材模块引用、启用 Profile、模型能力/参数、版本化 Output Contract、Decode/Validate、Prefill/停止规则、配置版本和降级矩阵。

## 轻量路径与升级

- 单模型纯文本：一个基础 Profile、纯文本契约、截断检测和显式无候选状态。
- 多 Profile、多模型、高级模块、结构化输出或复杂内容模式时增加能力探测、Schema 版本和降级回归。

## 交接与验证

- Profile 与 Assembly 交给 Model Gateway；解码后的候选交给 Kernel 裁定；失败交给 UI 和 Trace。
- 固定同一配置可重放；覆盖完整、未知字段、缺字段、截断、错误 Marker、能力不匹配和降级路径。

## 不负责

不创作 Prompt 政策，不实现 HTTP/流式传输，不定义正式状态规则，也不解释 ST 宏。
