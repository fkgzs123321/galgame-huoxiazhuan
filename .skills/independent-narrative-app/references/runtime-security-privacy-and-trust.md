# 安全、隐私与信任边界

## 作用

说明数据流向、信任边界、权限、密钥、日志、来源和不可信代码处理。所有项目应用基础规则；云同步、插件、远程更新和公开发行再按风险展开。

## 读取条件

所有完整项目读取基础部分。使用 API 密钥、外部传输、用户私密内容、导入资产、脚本/Mod、自动更新、遥测或公开发行时必须展开相应章节。

## 前置输入

- Task Envelope、`Host Foundation Contract`、`Platform-Asset Port Contract`。
- `Model Gateway Contract`、数据/资源清单、导入来源和发布边界。
- 内容模式、日志/诊断需求和第三方服务政策。

## 方法

### 1. 画数据流和信任区

列出玩家输入、角色卡、世界书、Prompt、存档、密钥、模型请求/响应、日志、媒体和更新包经过的组件、存储位置、外部接收方、保留期限和删除入口。标记信任级别与跨边界传输。

“本地运行”不自动等于无外传；远程模型、崩溃上报、字体/CDN 和更新检查都可能联网。

### 2. 密钥与凭据

密钥不得写入内容包、前端 bundle、日志、导出存档或版本库。优先使用系统密钥存储或服务端代理；无法安全保存时明确提示风险和生命周期。显示、复制、替换、撤销和错误反馈都应避免泄漏完整值。

### 3. 最小数据与日志脱敏

只收集完成任务所需数据。诊断默认记录 ID、版本、指纹、耗时和错误码，而非完整私密正文。需要收集 Prompt/响应时取得明确授权、限定范围/时长，并提供查看和删除入口。

### 4. 导入资产与内容来源

保留原始文件、来源、许可/作者信息、哈希和转换记录。导入先解析为数据，不自动执行脚本。未知字段和宏保留并报告；外部 URL、路径和媒体先验证协议、大小、类型及目标位置。

### 5. 不可信代码边界

EJS、脚本、插件、正则、Mod 和内容包内可执行表达式默认惰性。确需执行时采用能力白名单、隔离进程/沙盒、资源限制、明确授权、版本固定和可撤权机制。`iframe` 本身不是完整安全证明。

### 6. 内容模式隔离

SFW/NSFW 或其他模式切换时隔离 Prompt、Lore、缓存、资源、模型路由和存档元数据。关闭模式后清理派生缓存并验证不再注入；不得只隐藏 UI。

### 7. 更新、依赖与供应链

远程更新验证来源、签名/哈希、版本、回滚和最低受支持版本。依赖变更保留锁定与审计证据；不要为了通过构建静默弱化供应链策略。公开发行前记录第三方许可和已知风险。

### 8. 用户权利与事故处理

提供数据导出、局部/全部删除、远程副本说明、权限撤销和凭据轮换。事故流程说明如何冻结更新、保护证据、通知影响范围、恢复和复盘。

## 唯一产物

`Trust-Dataflow Contract`：数据流图、信任边界、数据分类、权限清单、密钥/日志/导入/代码执行策略、保留删除、更新与安全验收要求。

## 轻量路径与升级

- 纯本地无脚本：基础密钥边界、模型外传提示、日志脱敏、来源记录和导出删除。
- 云同步、公开发行、插件/Mod、远程更新或敏感数据时增加威胁建模、权限矩阵、签名和事故演练。

## 交接与验证

- Gateway、Save、Platform、Bridge 和 Release 必须消费本契约；发现新增数据流时回修 owner。
- 检查 bundle/日志/导出包无密钥，越权被拒，模式关闭不泄漏，恶意导入保持惰性，删除与撤权结果可证明。

## 不负责

不替代适用地区的法律、平台政策或专业安全审计，也不以“本地”“加密”或“沙盒”作为未经验证的安全结论。
