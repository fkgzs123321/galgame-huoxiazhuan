# 内容尺度、模式与明确排除

## 作用

由创作者决定 SFW/NSFW 及其他内容尺度、主题权重和排除项，并把多模式需求转化为真实隔离契约。只提供方向和边界，不生成露骨范文。

## 读取条件

确认内容尺度、敏感主题、多模式切换、模型兼容、受众边界或明确不做内容时读取。

## 前置输入

- 作者选择、产品边界和目标体验。
- `Agency Contract`、`Character Portfolio`、`Prompt Policy Package` 的相关决定。
- 目标模型、平台和存档约束。

## 方法

### 1. 让作者选择作品模式

- `SFW-only`：不提供 NSFW 资源和入口。
- `Dual Mode`：SFW/NSFW 或其他模式可切换，必须实际隔离。
- `NSFW Core`：成人内容是主要主题或核心玩法，不必被限制为只服务角色关系。
- 其他尺度：恐怖、暴力、药物、创伤、权力关系等按项目定义。

NSFW 可以是可选、并重、核心或专项主题；Skill 不替作者决定，也不因自身示例边界删除这一设计维度。

### 2. 定义允许、限制和排除

只写方向性分类：允许的主题与表现强度、必须淡出或省略的内容、绝不出现的内容、需要额外确认的情境。角色人格、玩家主权和认知边界继续引用其 owner，不在这里复制。

### 3. 设计真实隔离

只要支持多模式，切换必须共同控制：

- Prompt/Preset Profile 和规划模块。
- Worldbook/Lore 条目与检索范围。
- 历史、摘要、Memory 和上下文。
- 功能入口、资源、多媒体与 UI Projection。
- Model Profile、供应商路由和拒绝/降级策略。
- 输出处理、Save 元数据、旧档加载和导出。

仅隐藏按钮或文本不算隔离。切换时明确旧历史是否可用、是否需要新会话/存档、怎样防止内容泄漏。

### 4. 模型不兼容处理

能力检测后选择：切换兼容模型、降级为允许模式、停止并解释、或关闭该功能。禁止无限重试、伪装成功或把被拒输出写入正式状态。

### 5. 验证边界

为每种模式准备正例、反例、切换和旧档案例；检查 Prompt/Lore/Memory/资源/模型/输出/Save 全链路。

## 唯一产物

`Content Mode Contract`：模式清单、允许/限制/排除、表现尺度、切换策略、隔离矩阵、模型降级、存档边界和验证意图。

## 轻量路径与升级

- 单一固定模式：记录方向与排除项，不制造切换系统。
- 多模式、混合来源、模型能力差异或跨存档切换时升级完整隔离矩阵。

## 交接与验证

- 交给 Prompt、Lore、Profile、Save、Security 和 Behavior Spec。
- 验证模式切换、旧历史、模型拒绝、导出和关闭后均无跨模式泄漏。

## 不负责

不重复定义玩家权利、角色人格和 Prompt 优先级，不实现模型绕过，不替平台提供法律判断。
