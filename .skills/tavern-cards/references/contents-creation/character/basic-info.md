> ★ **本文件只定「结构」（该写哪些维度）** ——
> ★★ **「怎么写」必须同时打开**：`by-style/<套>/基础信息.md`
> （`<套>` ＝ 这张卡选的文风：`01-淫视` / `02-无尽骚妈` / `03-母猪` / `04-少妇白洁` / `05-冷冽` / `06-阶段性反差`）。
> ★ **只读本文件、不读 `by-style` 那份 ＝ 没写完**（写出来必是白描）。
> **维度在所有文风下都一样，变的只有写法。**

## ⚠️⚠️ 先看这条：NSFW 卡的「外貌特征」怎么写（主语判据）

**判据（可数的）**：数一数**以器官／部位为主语的句子**占多少。
★ **大部分句子的主语还是「她 / 她的」＝ 等于没写**（那是白描）。

### ⛔ 光换主语还不够：**不许用模糊指代**（用户 2026-09-21 明确指出）

**「那两团／那两瓣／那道沟／那两点／那处／那里／那东西」这类指代一律禁止。**
换了主语却用模糊指代，**本质还是白描，只是把主语换了个壳**。

**规矩：每一处器官初次出现，必须点出器官名，并带上脏／臭／腥／黑这类定语。**
后面要换说法可以，但**换出来的说法本身也得让人一眼看出是什么器官、什么状态**。

| ❌ 白描（「她」作主语） | ❌ 换了主语但仍是模糊指代 | ✅ 点名器官 ＋ 脏／臭／腥定语 |
|---|---|---|
| 那处是干净的、紧的 | 那两瓣往外翻着，边缘的颜色比别处深上好几度 | **两片骚臭逼的黑瓣**往外翻着，边缘的颜色比别处深上好几度，**缝里黏着一层没干的白浆** |
| 扣子经常开着 | 领口那道沟从锁骨一路敞下去，敞到看不见为止 | **两团骚奶子中间那道焐出油的带奶腥味臭乳沟**从锁骨一路敞下去，敞到看不见为止 |
| 她觉得家里没有别人 | 那两团在薄汗衫里坠着，一进凉气那两点就顶出两个硬凸点 | **两团沉坠的肥奶子**在薄汗衫里晃着，一进凉气**那两个骚奶头**就顶出两个硬凸点 |
| 她不知道 | （别写「她不知道」—— 直接写**他不知道的那样东西本身**） | **那根沤了一天、冠状沟糊着垢的臭屌**就摆在他眼前，他没往那边看 |
| 那两团是填出来的圆 | 那两团 F 杯的**奶肉**（＝**材质词顶替**：读到的是一块肉，器官名被抹掉） | 那两团 F 杯的**骚奶子**｜那两团填出来的**骚奶子** |

★★ **第 5 行这一格是 2026-09-23 用户当场指出的**：`奶肉` 是词料表里「修饰」栏的**材质词**，
**永不得单独指器官**。`肥奶子` 可以（肥是定语，奶子是器官名），`奶肉` 不行（器官名没了）。
**写之前先打开 `../../presentation-craft-05-词汇规范.md` 的「三栏铁律」。**

★ 词从哪来：`../../presentation-common-01-用词.md` 的「脏话麻花」章 ＋
`../../presentation-craft-05-词汇规范.md` 的词料全表 —— **直接取用，不要自己临时编。**

★★ **「她觉得」「她不知道」「她经常」「她喜欢」这四个句式在 NSFW 卡里一律不要** ——
那是替她做心理陈述；**要的是看得见的东西自己说话**。

落点给**方向**，主语判据给**落笔方式**。

角色基础信息包含四个部分：基本信息、外貌特征、背景设定、关系设定。

## 基本信息

姓名、年龄、性别、身份、人物关系及其他身份相关信息。

**约束**：性格相关内容不在基础信息里写，使用"性格调色盘"条目。

## 外貌特征

**约束**：只写偏离 AI 默认认知的特征。判断标准：遮住名字，能否只靠这些特征认出是谁？
- 能 → 写得好
- 不能，放在别的角色身上也成立 → 废话，删掉

写什么：
1. **体型落点**（★ 必写，见下）—— 她的身体在**哪个维度上偏离寻常**
2. 偏离默认的身体特征（异色瞳、疤痕、纹身、义肢、特殊发色等）
3. 标志性装扮（特定校服、制服、饰品、发型等）
4. 能被人记住的细节（习惯戴的东西、特殊的穿衣风格等）

### ★ 体型落点（必写 · 这是技法层的输入）

正文的肉体描写（`presentation-craft-02`）有一条硬要求：
**先认定这具身体在哪个维度上偏离寻常，再把那点偏离写成媚肉的具体表现。**

**这个「方向」必须由条目给** —— 不给，AI 只能用默认美人模板（正是下面「不写什么」里禁的那类词）。

五个可选落点（**可同时命中，逐条叠加**）：

| 落点 | 正文怎么写 |
|---|---|
| **丰腴** | 写**满和溢**：骚奶子溢出领口堆在锁骨底下、骚尻肉把裙摆撑出横褶、腿根并拢时挤出两侧 |
| **纤细** | 只管腰线以上，写**窄和紧**；腰线以下照旧顺着髂骨往外铺到肥尻 |
| **高挑** | 写**纵向拉开的距离**：俯身时腰到肥尻的行程比旁人长、站直了那两团正在对视高度 |
| **娇小** | 写**尺寸落差**：仰脸时视野被那两团占满、窄骨架撑着横铺出去的肥尻 |
| **小奶** | 写**敏感和精致**：弧度刚好填满掌心、乳尖顶出小点、绷得紧致挺翘 |

★ **体型落点 ≠ 识别特征**：前者说「**她的身体怎么写**」，后者说「**怎么认出她是谁**」，两样都要写。
★ **禁止**把「紧实 / 松软 / 肥腻 / 纤薄」这类互斥的词堆在同一处媚肉上。

完整接口见 `character/interface-with-craft.md`。

不写什么：
1. 数据库里的默认值（该种族/国籍/年龄的标准外貌）
2. 万能美人描写（精致、白皙、好看等放在谁身上都行的词）
3. 过度细节（每个五官都写一遍，占 token 又分散注意力）

**约束**：写外貌不是写"美"，是写"特征"。

## 背景设定

只写对角色产生了实际影响的事。不需要事无巨细地列人生年表，只需要写"让这个角色变成现在这个样子"的关键事件。

## 关系设定

**约束**：关系写具体画面，不写抽象评价。
- 错误："深厚的感情"
- 正确："有记忆起就在一起"

## ★★ 所有模块都要写「行为 + 画面」，而且每位一个只属于她的招牌动作

> ★ **这一节来自用户的原始要求，原文照录，不得改写、不得精简：**
>
> 「比如这种，就可以描述的很色很骚，比如经常几天不洗，本来就天天欲求不满，流淫骚水，一两天不换内裤，
> 每天都是整个内裤潮湿，内裤上大面积的黄块粘稠，又骚又臭又腥，还经常用手扣一下，闻一闻，舔一舔，
> 再扣两下臭骚逼，狼叫两声，类似的描述，不就到了吗，其他模块也可以这么有画面有行为的写」
>
> 「高潮的骚比饮水一般她会趴在地上像发情的母狗一样，屁股抬高，骚逼朝天，把地板上喷的骚水用舌头
> 一点一点舔干净吃干净，说了所有模块怎么骚怎么变态，怎么种口味怎么来，怎么具体行为画面感！」

### 判据（写完必须过）

1. **一条里必须有动作。** 格式是「她做了什么 → 身体起什么变化 → 弄完又干什么」。
   - ✗ 不合格：「裆间量少，咸而凉，凑近才有一丝腥气」（只有状态，没有动作）
   - ✓ 合格：「那两天她不肯换内裤，裆上那块布已经潮透，黄白色的一片黏在布面上，坐着的时候她会隔着布用指腹按那处，按出声音来才收手」
2. **器官词直白落地，且要带脏字。** 不是「那处」不是「逼」，是「骚逼」「臭逼」「烂逼」「黑屄」「淌着黑水的」。
   词表与整句示范见 `../../presentation-common-01-用词.md` 的「脏话麻花」章（部位带脏字、形容词叠着加、
   一句两三个脏词交织、动词往狠里挑、加状态）。
3. **要在「人」上分别。** 同一位角色可以反复用她那一套，**但不同角色之间不许重样**。
   每位先定一个**只属于她的招牌动作**（从她的人设长出来），全套模块都围着这个招牌转。
   - ✗ 反面：把「趴下把自己喷的骚水舔干净」抄给十二个人里的八个 —— 那样十二个人糊成一个人。
   - ✓ 正面：记录癖的人完事先量刻度、取样贴标签；好胜记账的人完事先数几股再补练；
     为镜头活的人完事挑帧删了重拍；怕被发现的人完事擦净、把纸巾套袋带走。
4. **越界/变态/重口味不受限。** 她怎么骚、怎么变态、怎么重口就怎么来，只要是从这个人身上长出来的。
