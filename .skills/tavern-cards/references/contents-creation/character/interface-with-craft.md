# 条目层 ↔ 正文层（接口说明）

> **写人物条目时必读。** 这一节解决一个最容易打架的问题：
> `character/` 的固定要求说「外貌只写特征、不写美」，而 `presentation-craft-02` 说「身体要写足、三层落笔」——
> **两条都对，因为它们管的是两个层次。**

---

## 一、两个层次，别混

```
条目层（character/ worldbuilding/ …）  → 静态资料：她是谁
                                         写进世界书，常驻或按需，省 token 是硬约束
正文层（craft- / style- / common-）    → 动态规范：怎么写
                                         管 AI 每次输出的那一段正文
```

★ **判据一句话**：
- **条目层给「锚点与边界」** —— 只写「属于她的、能认出她的、必须写死的东西」
- **正文层给「如何展开」** —— 把锚点铺成一段贴着肉体的描写

**同一个事实只写一处**：条目写「她是丰腴型」，正文不重复这句话，而是写「骚奶子从领口溢出去堆在锁骨底下」。

---

## 二、分工总表

| 维度 | 条目层给什么 | 正文层怎么展开 |
|---|---|---|
| **外貌** | **识别特征**（异色瞳 / 疤痕 / 标志物）＋ **体型落点**（见第三节） | `craft-02`：三层落笔、主轴轮换、按体型落点铺 |
| **身体反应** | 不给（那是正文的事） | `craft-02`：动态、自行反应、生理信号 |
| **性格** | 调色盘（底色 / 主色调 / 点缀）＋ **衍生**（具体场景与行为） | 按衍生演，不按调色盘的标签演 |
| **说话方式** | 三面性的 **语料**（5~10 句纯对话） | `craft-04`：对白加色情滤镜（视角、距离、羞耻的层次） |
| **行为模式** | 三面性的其余四部件（触发 / 能量 / 身体行为 / 功能） | `craft-03`：画面与张力（把行为拍成画面） |
| **关系** | 具体画面（不写抽象评价） | 按画面演，不按评价演 |
| **世界观设定** | `worldbuilding/` 各条 | `craft-06`：判定它该写成定义条 / 素材条 / 禁则条 |

## 三、★ 最需要补的一处：外貌的「体型落点」

`craft-02` 有一条硬要求：

> **体型落点**：先认定这具身体在**哪个维度上偏离寻常**，再把那点偏离写成媚肉的具体表现。

**这个「在哪个维度偏离」，条目必须给** —— 否则 AI 只能用默认美人模板（正好是 `basic-info.md` 明确禁止的「万能美人描写」）。
两条要求就在这一点上接上了：**条目给偏离的方向，正文给偏离的样子。**

所以 `基本信息的「外貌特征」` 里，除了识别特征，还要明确写**体型落点**：

```
外貌特征:
  体型落点: 丰腴型（骚奶子从领口溢出、骚尻肉把裙摆撑出横褶、腿根并拢时挤出两侧）
  识别特征: 左手食指和中指有弹吉他磨出的茧 / 吉他拨片项链 / 领带从来不系好
```

**五个可选落点**（可同时命中，逐条叠加，见 `craft-02`）：

| 落点 | 正文怎么写 |
|---|---|
| **丰腴** | 写**满和溢**：骚奶子溢出、臀肉撑出横褶、腿根挤出 |
| **纤细** | 只管腰线以上，写**窄和紧**；腰线以下照旧顺着髂骨往外铺到肥尻 |
| **高挑** | 写**纵向拉开的距离**：俯身时腰到肥尻的行程比旁人长、站直了那两团正在对视高度 |
| **娇小** | 写**尺寸落差**：仰脸时视野被占满、窄骨架撑着横铺出去的安产型肥尻 |
| **小奶** | 写**敏感和精致**：弧度刚好填满掌心、乳尖顶出小点、绷得紧致挺翘 |

★ **禁止**：把「紧实 / 松软 / 肥腻 / 纤薄」这类互斥的词堆在同一处。

## 四、另外三处互补（不冲突，只是没写明接口）

### 1. 语料 ↔ `craft-04` 对白滤镜

- **条目给**：三面性的**语料**（5~10 句纯对话，必须从调色盘移出）
- **正文给**：同样的语料，在色情场合下**加滤镜** —— 视角、距离、羞耻的层次、句子碎到几分

→ 语料是「**她会怎么说**」（静态样本），craft-04 是「**这么说时怎么拍**」（动态规范）。
★ 语料里**不写 ~❤**（那是文风的活），只写干净的话；滤镜在正文层加。

### 2. 衍生 ↔ `craft-03` 画面与张力

- **条目给**：调色盘的**衍生**（每色 2~3 个具体场景与行为）
- **正文给**：`craft-03` 把这些场景**拍成画面**（张力怎么铺、怎么释放）

### 3. 关系 ↔ 无对应

关系设定写「具体画面」这条来自 `basic-info.md`，正文层没有对应条目 —— **它靠画面本身演**。
★ 注意与 `craft-01` 的「**语言升温，事件不越权**」配合：**关系设定不等于动作已经发生**。

## 五、写条目时的自查（与技法层对齐）

- [ ] **体型落点写了吗** —— 没写，正文只能用默认美人模板（＝ `craft-02` 失效）
- [ ] **识别特征与体型落点是两回事** —— 前者「认出她是谁」，后者「她的身体怎么写」
- [ ] **语料里没有 ~❤** —— 那是文风层的事，不该混进条目
- [ ] **没有把正文层的内容写进条目** —— 条目里出现「三层落笔」「她怎么自慰」这类，就是越层了
- [ ] **同一事实只写一处** —— 条目写了「丰腴」，正文不重复「她是丰腴型」
- [ ] 通用：按 `references/rules.md` 与 `rules-check.md` 过一遍（破折号 / 跨条目引用 / 元叙事）
