## 一、这些范本的结构（看结构，不重写内容）

**条目按题材切，一条一个题材**：`丝袜` / `高跟鞋` / `安产型肥尻` / `唇印相关` / `衣物强化描写` / `露出服装世界观`。
★ 每条里都带**版本号**（V6 / V14 / V17），旧版标「（弃用）」保留 —— 那是版本历史，取用只取现用版。

**一个题材可以拆成「总览 + 属性分条」**（范本：`超熟女世界书`）：`超熟女总览` ＋ 超乳 / 母性 / 肉腿巨臀 / 粗俗习惯 / 气味体液 / 黑屄黑奶 / 包裹监禁。
★ 每条只讲一个维度，条与条之间不重复内容。

**三类条目各司其职**（看范本的划分，不背条文）：

| 类型 | 范本在哪 | 作用 |
|---|---|---|
| 概念 / 性癖条 | 细节、设定、性癖与概念（108 条） | 一个题材可取的东西 |
| 限制 / 禁则条 | 限制及要求世界书（43 条） | 精确到词的禁用表 + 角色定义 |
| 题材库条 | 附赠世界书 5 本 | 整本题材（绿帽 / 母猪 / 超熟女…） |

## 二、裁进自己卡的时候

1. **不整本搬** —— 从范本里挑条目
2. **只取现用版** —— 带「（弃用）」的是历史
3. **按自己卡的世界观改写**
4. **跑校验**：`引擎模板/scripts/verify-prompt-budget.mjs <项目目录>`；
   单条常驻渲染后 ≤ 5,000 字符，且必过 `rules-check.md` 三条（破折号 / 跨条目引用 / 元叙事）

## 三、与本项目既有条目的关系

- **角色条目**怎么写 → `character/` 那一套（已定，不改）
- **世界观 / 时间线 / 区域条目**怎么写 → `worldbuilding/` 那一套（已定，不改）
- **本条只管**：概念 / 性癖 / 限制 / 题材这四类**去哪取范本**
