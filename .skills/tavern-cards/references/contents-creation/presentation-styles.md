> **范围：本工作区所有 NSFW 角色卡，无一例外。**

>    少妇白洁叠淫视时，器官词照样直白落地，只是不脏化；**「沉重」不等于「没有身体反应」**。
> 4. **可数判据**（写完必须过，**跑脚本，不许凭感觉数**）：
>    `node 引擎模板/scripts/verify-dirty-ratio.mjs <项目目录>`
>    - ① **器官指称脏字占比 ≥ 80%**（口径写死在脚本里：只收双字及以上的器官头部词，单字「奶」「乳」不收）
>    - ② **材质词顶替 0 处**（搜 奶肉｜乳肉｜屄肉｜腔肉｜尻肉｜臀肉｜腚肉，不得单独当主语或宾语）
>    - ③ **模糊指代 0 处**（那道疤／那道门缝／那根细绳／那层处女膜不算）
>    - ④ 每 1000 字里，**以器官／部位为主语的句子 ≥ 8 句**
>    - **器官词命中 ≥ 12 次／档**（白洁档用她的词表：乳房、阴道、阴部、阴毛、小屁股、内裤、裆）

>    - 「她想要／她觉得／她不知道／她经常／她喜欢」**0 处**
> 5. 违反上述任一条 ＝ **未完成**，不得声称 done。
> 6. ★★ **材质词顶替主体，与白描同罪**（2026-09-23 用户当场指出后补写）：
>    **把器官名换成表示「肉」的材质词**（奶肉｜乳肉｜屄肉｜腔肉｜尻肉｜臀肉｜腚肉｜媚肉｜淫肉｜雌肉｜贱肉｜嫩肉｜软肉），
>    读者读到的是「一块肉」，**器官名被抹掉了**。它比模糊指代更隐蔽，因为带着脏字感，看着像在写器官，其实没有。
>    - ✗ 那两团 F 杯的**奶肉**　✗ 那两团**假体**　✗ 缝隙里那圈**嫩肉**当主语
>    - ✓ 那两团 F 杯的**骚奶子**　✓ 那两团填出来的**骚奶子**

### 写完必须过这几条（机械可数，不许凭感觉）

1. **脏话麻花五法则**逐条过：
   ① 部位要带脏字（不是「逼」，是「骚逼」「臭逼」「烂逼」「黑木耳」「淌着黑水的」）
   ② 形容词叠着加（又骚又臭／淌着黑水的）
   ③ 一句里两三个脏词交织（不是一句一个）
   ④ 动词往狠里挑（捅烂 ＞ 插入）
   ⑤ 加状态（合不拢／闭不上／拔不出来）
2. **行为判据**：每条里她做了几个动作？格式是「她做了什么 → 身体起什么变化 → 弄完又干什么」。
   **零个动作的条目一律重写。**
3. **重样判据**：把同一模块逐位抽出来比 —— **有没有两位的招牌动作是一样的？有就是没写人。**
   每位先定一个只属于她的招牌动作，从她的人设长出来。
4. **主语判据**：以器官／部位为主语的句子是否过半。

违反任一条 ＝ **未完成**，不得声称 done。

## 五、★★★ 两种场景：新写卡 vs 改卡（**这条最要紧，写错会被反复打回**）

### 一、新写一张卡
**直接用选定的技法与文风写。** 从第一句话开始就按该文风的句式和用词来 —— 不会出现「写着写着变成白描」，**因为底子是新的**。

### 二、改一张已有的卡
**必须「完全重构」，不能在旧底子上改。**

**✗ 错误做法（会被反复打回）：**
- 在原文上换词（把「干净」换成「骚」、把「身体」换成「嫩骚奶」）
- 保留原句的**骨架**，只替换形容词
- 一段一段「润色」

**为什么不行**：旧文的**句式、主语、叙述视角**都还在 —— **你换掉的只是词，底子仍是旧文风**。改完之后读起来仍然「有那层底子在」。
★ **最典型的死法**：**逐部位清单**（`她的样子:` / `她在哪:` / `她穿什么:` / `她的手:`）—— 就算每一行都塞满器官脏字，**骨架还是登记表，还是白描**。

**✓ 正确做法：**
1. **先把原文里的事实抽出来**（她是谁、多大、什么关系、发生过什么、有什么道具）
2. **把原文丢掉** —— 不再看它的句式和用词
3. **只拿事实，按新文风从头写一遍**

### 三、自查（改卡后必做）
- [ ] **在成品里搜旧文风的特征词** —— 搜「干净」「不算大」「XX 岁，XX 公分」这类偏叙述的措辞，**有就是没重构干净**
- [ ] **检查句子主语** —— 主语是「她 / 她的身体」→ 白描残留；**主语是器官 → 对**
- [ ] **读一遍，问自己「这像不像原文改的」** —— 像，就是没重构

★ **判据（可数的）**：**同一段里，数一数「以器官为主语的句子」占多少**。新文风要求「大部分句子以器官/部位为主语」。

### 四、一句话
> **改卡 = 重写，不是润色。抽事实 → 丢原文 → 从零按新文风写。**

## 七、写完必过

- [ ] 「指令」是「如何做」，不是风格分析
- [ ] **实样是用该文风本身写的**，不是用说明文字写的（**这是最容易犯的错**）
- [ ] **该脏的地方没躲**：器官词用了脏字，没被文雅化
- [ ] **脏得起来**：要的是「比参考更刺激一百倍」，**不是克制**
- [ ] **上一条文风的特征没有混进来**（脏词密度、❤ 符号、心理比重）
- [ ] 选了「冷冽」时：**全篇没有一处情绪词**
- [ ] 选了「无尽骚妈」时：**脏度在台词里**，叙述只给体面、交代动作、写旁人反应
- [ ] 选了「母猪」时：**四类每段各出现一次**（动态 / 声音 / 状态 / 体液），器官词不重复同一个
- [ ] 选了「少妇白洁」时：**器官词直白但不脏**（用「乳房/阴道/阴毛」，不是「烂逼/骚水」）
