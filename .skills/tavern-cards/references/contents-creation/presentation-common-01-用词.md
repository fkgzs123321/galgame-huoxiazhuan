# 程度表达与脏话麻花

> **用词的规范**（哪个词用在哪、能不能造、词料库、雅词限额）看 `presentation-craft-05-词汇规范.md` —— 那里有完整的词料库与调用原则。
> 本条只补 craft-05 装不下的两样：**程度表达** 与 **脏话麻花的整句示范**。
> 拟声词表见 `presentation-common-02-素材.md`。

## 程度

- **爽**：爽一百倍、爽得要死、爽到翻白眼、从来没这么爽过、爽到不成人形
- **状态**：烂成泥、操成破布、瘫成一摊、失禁、翻白眼、流口水、魂都飞了、人不人鬼不鬼、脑子一片空白
- **时间感**：没完没了、一直一直、几十下、捅到天亮、来了一波又一波
- **失控**：停不下来、自己往上送、自己掰开、自己求着要、不要脸的自己动

★ 程度词只做**落点**，不替代过程。要写得更狠，改的是「肉被撞开多远、多久才停、涌出多少」，不是在原句前面加一个更猛的程度词（这条与 `presentation-craft-01-叙事总纲.md` 的「表现尺度」同源）。

## 脏话麻花 · 组合法则

① 部位要带脏字（不是「逼」，是「骚逼」「臭逼」「烂逼」）
② 形容词叠着加（「又骚又臭」「淌着黑水的」）
③ 一句里两三个脏词交织（不是一句一个）
④ 动词往狠里挑（捅烂 > 插入）
⑤ 加状态（合不拢／闭不上／拔不出来）

## 脏话麻花 · 整句示范

**入门 · 单器官**
```
把他那根臭鸡巴捅烂我那个淌水的骚逼
你这骚哄哄的臭逼，欠捅的贱货
又骚又臭的烂逼，被捅得合都合不拢
拿那根驴屌捅进那个几天没洗的臊逼里
流着黑水的烂逼，被捣得咕叽咕叽响
捅烂你这个不要脸的骚屄，操成破布
那两片翻出来的黑木耳，一看就是被用烂的
把她按在桌上，从后面整根捅进去，捅到她话都说不成
掐着她那对晃来晃去的骚奶子，一下一下往最里头顶
跪下来自己掰开，把那个淌着骚水的臭逼亮出来
```

**进阶 · 双器官交织**
```
被灌了一肚子的臭精，捂都捂不住，往外淌
屁眼被撑成个洞，翻着肉，闭不上了
这个贱货的骚逼一抽一缩，咬得死紧，拔都拔不出来
舌头贴上去，把那两片外翻的烂肉整个含进嘴里
一手掐着奶头，一手把她的骚逼掰开，往里看
嘴里含着一根，逼里塞着一根，两边都在淌
操着她的骚逼，另一只手两根指头捅进屁眼
奶子上全是牙印，逼里全是白浆，屁股上全是指印 —— 这一身没一处干净的
把她两条腿架在肩上，整根捅到底，捅得她小腹上顶出一个鼓包
从后面顶她的骚逼，顶得那对骚奶子拍在桌面上啪啪响
一边肏她的骚逼一边掰她的屁眼，两个洞一起往外流水
把鸡巴从她逼里拔出来，直接捅进屁眼，捅得她一声都叫不出来
捏着她的奶头往上提，提得那对大奶成了尖的，下面还在被捅
把她的两条腿掰成一字，从正面看那个逼被捅成什么样
```

**重口 · 三词以上交织 + 状态**
```
一头捅着她的烂屁眼，一头拿鸡巴扇她的骚脸，扇得满脸都是自己的骚水
掐着她的下巴把那根东西整根塞进去，捅到嗓子眼，捅得她眼泪口水一起流
把那个被捅熟的肉穴掰开，两瓣唇翻着合不拢，一张一合还在往外吐白浆
把她的头按在胯下，捅到干呕，呕出来的东西她还得自己咽下去
操到一半拔出来，拿那个湿漉漉的龟头扇她的脸 —— 扇完再整根捅回去
把她翻过来骑上去，掐着腰往下摁，摁到整根没入，捅得她话都说不成
那个骚逼已经被操肿了，红得发亮，还是一抽一抽地要，捅进去还在往外挤水
她自己把奶子捧起来送到嘴边，含着奶头吸自己的奶，一边被从后面操
把她的腿掰成一字，从正面捅进去，捅到她看见自己的骚逼被捅成什么样
捅完了拔出来，那个合不拢的洞还在往外吐，吐了一床单
一只手把她两个奶子攥在一起，另一只手在下面抠，嘴还咬着她耳朵
把她按在墙上，一只手掐着她后颈，一只手提着她的腰，从后面往上顶
```

**完整句 · 照这个手感**
```
捅烂你这个骚货的臭逼，让你这一辈子都合不拢
你这个欠操的贱货，看看你自己的逼，湿成什么样了还装正经
跪好了，把那个又骚又臭的烂逼亮出来，自己掰开
连自己的奶头都吸，你说你这具骚肉还有什么不能用的
把你那个被用烂的黑逼掰开给我看，看清楚了，是谁把它操成这样的
一张一合的烂逼，捅进去就咬人，拔出来就淌水 —— 你这个天生的肉便器
从今天起你这张嘴、这个逼、这个屁眼，全归我一个人用
```
## ★★★ 五条法则必须落到整句上（可数，写完逐句过）

法则记住不算数，**要能在句子里数出来**。下面这一节是唯一被接受的成品形态。

### 一句里同时具备四样

1. **器官名点名**（不许「那两团／那两瓣／那道沟／那处／那里」这种模糊指代）
2. **脏字定语叠着加**（又骚又臭、烂熟发黑、淌着黑水的）
3. **一到两个脏词交织**（不是一句一个）
4. **一个动作 ＋ 一个状态**（捅／扇／掰／灌 ＋ 合不拢／闭不上／拔不出来／一抽一缩）

### 合格示例（照这个手感写）

```
拿那根驴屌捅进那个几天没洗的臊逼里，捅得那两片黑瓣外翻着合不拢
又骚又臭的黑屄被撑成个洞，捅完了还在往外吐白浆，一抽一缩往外挤
把她两条腿掰成一字，从正面看着那个烂逼被捅成什么样，捅到小腹上顶出一个鼓包
一手掐着奶头，一手把那个淌着黑水的骚逼掰开往里看，看得它自己又洇出一层水
那根沤了一天的臭屌捅到底，捅得那个黑木耳一样的烂屄整个翻出来
```

### ★ 重口味不受限：越界到什么程度都行，只要是从这个人身上长出来的

**用户原话示范（作为重口档的基准，不许弱化）：**

> 「高潮的骚比饮水一般她会趴在地上像发情的母狗一样，屁股抬高，骚逼朝天，把地板上喷的骚水用舌头
> 一点一点舔干净吃干净」

> 「几天不洗，本来就天天欲求不满，流淫骚水，一两天不换内裤，每天都是整个内裤潮湿，
> 内裤上大面积的黄块粘稠，又骚又臭又腥，还经常用手扣一下，闻一闻，舔一舔，再扣两下臭骚逼，狼叫两声」

★ **这两段是尺子**：自己的段落要是比它干净、比它含蓄、比它少动作，就是没写到。
