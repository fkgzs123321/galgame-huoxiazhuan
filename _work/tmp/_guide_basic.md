## ★★ 所有模块都要写「行为 + 画面」，而且每位一个只属于她的招牌动作

> ★ **这一节来自用户的原始要求，原文照录，不得改写、不得精简：**
>
> 「比如这种，就可以描述的很色很骚，比如经常几天不洗，本来就天天欲求不满，流淫骚水，一两天不换内裤，
> 每天都是整个内裤潮湿，内裤上大面积的黄块粘稠，又骚又臭又腥，还经常用手扣一下，闻一闻，舔一舔，
> 再扣两下臭骚逼，狼叫两声，类似的描述，不就到了吗，其他模块也可以这么有画面有行为的写」
>
> 「高潮的骚比饮水一般她会趴在地上像发情的母狗一样，屁股抬高，骚逼朝天，把地板上喷的骚水用舌头
> 一点一点舔干净吃干净，说了所有模块怎么骚怎么变态，怎么种口味怎么来，怎么具体行为画面感！」

### 判据（写完必须过）

1. **一条里必须有动作。** 格式是「她做了什么 → 身体起什么变化 → 弄完又干什么」。
   - ✗ 不合格：「裆间量少，咸而凉，凑近才有一丝腥气」（只有状态，没有动作）
   - ✓ 合格：「那两天她不肯换内裤，裆上那块布已经潮透，黄白色的一片黏在布面上，坐着的时候她会隔着布用指腹按那处，按出声音来才收手」
2. **器官词直白落地，且要带脏字。** 不是「那处」不是「逼」，是「骚逼」「臭逼」「烂逼」「黑屄」「淌着黑水的」。
   词表与整句示范见 `../../presentation-common-01-用词.md` 的「脏话麻花」章（部位带脏字、形容词叠着加、
   一句两三个脏词交织、动词往狠里挑、加状态）。
3. **要在「人」上分别。** 同一位角色可以反复用她那一套，**但不同角色之间不许重样**。
   每位先定一个**只属于她的招牌动作**（从她的人设长出来），全套模块都围着这个招牌转。
   - ✗ 反面：把「趴下把自己喷的骚水舔干净」抄给十二个人里的八个 —— 那样十二个人糊成一个人。
   - ✓ 正面：记录癖的人完事先量刻度、取样贴标签；好胜记账的人完事先数几股再补练；
     为镜头活的人完事挑帧删了重拍；怕被发现的人完事擦净、把纸巾套袋带走。
4. **越界/变态/重口味不受限。** 她怎么骚、怎么变态、怎么重口就怎么来，只要是从这个人身上长出来的。

### 自查

- [ ] 抽同一模块逐位看：**有没有两条的收尾动作是一样的？有就是没写人。**
- [ ] 数一数：这一条里她做了几个动作？**零个动作 = 重写。**
- [ ] 器官词有没有带脏字？全是「乳房/蜜穴/私处」这类体面词 = 不合格。
