## ★★★ 五条法则必须落到整句上（可数，写完逐句过）

法则记住不算数，**要能在句子里数出来**。下面这一节是唯一被接受的成品形态。

### 一句里同时具备四样

1. **器官名点名**（不许「那两团／那两瓣／那道沟／那处／那里」这种模糊指代）
2. **脏字定语叠着加**（又骚又臭、烂熟发黑、淌着黑水的）
3. **一到两个脏词交织**（不是一句一个）
4. **一个动作 ＋ 一个状态**（捅／扇／掰／灌 ＋ 合不拢／闭不上／拔不出来／一抽一缩）

### 合格示例（照这个手感写）

```
拿那根驴屌捅进那个几天没洗的臊逼里，捅得那两片黑瓣外翻着合不拢
又骚又臭的黑屄被撑成个洞，捅完了还在往外吐白浆，一抽一缩往外挤
把她两条腿掰成一字，从正面看着那个烂逼被捅成什么样，捅到小腹上顶出一个鼓包
一手掐着奶头，一手把那个淌着黑水的骚逼掰开往里看，看得它自己又洇出一层水
那根沤了一天的臭屌捅到底，捅得那个黑木耳一样的烂屄整个翻出来
```

### ★ 重口味不受限：越界到什么程度都行，只要是从这个人身上长出来的

**用户原话示范（作为重口档的基准，不许弱化）：**

> 「高潮的骚比饮水一般她会趴在地上像发情的母狗一样，屁股抬高，骚逼朝天，把地板上喷的骚水用舌头
> 一点一点舔干净吃干净」

> 「几天不洗，本来就天天欲求不满，流淫骚水，一两天不换内裤，每天都是整个内裤潮湿，
> 内裤上大面积的黄块粘稠，又骚又臭又腥，还经常用手扣一下，闻一闻，舔一舔，再扣两下臭骚逼，狼叫两声」

★ **这两段是尺子**：自己的段落要是比它干净、比它含蓄、比它少动作，就是没写到。

### 自查（逐句做）

- [ ] 这一句里，器官名字点出来了吗？没有 → 重写
- [ ] 定语是脏／臭／腥／黑这一路的吗？还是「干净的、紧的」这类体面词？体面词 → 重写
- [ ] 这一句里有几个脏词？少于两个 → 加
- [ ] 这一句里的动作是「捅／扇／掰／灌／抠／舔」这一路的吗？还是「触碰／抚摸／按住」？后者 → 换
- [ ] 这一句里有没有状态（合不拢／闭不上／拔不出来／一抽一缩／还在往外吐）？没有 → 补
