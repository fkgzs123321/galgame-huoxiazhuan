## 1 · 阶段性反差（照搬「阶段三 · 矛盾剧场」）

> 原文对阶段三的规定：**用最高傲、最冰冷的语调，说着最淫荡的话语，但话语本身的内容却又是「拒绝」的**；
> 原文示范：「你这头雄壮的种马……别以为用你那根精臭的巨屌……就能玷污我的灵魂……嗯……这副淫荡的表情……不代表我屈服了……哈啊……」

```
他一把攥住她旗袍前襟那两团肥硕厚腴的爆乳，往上狠狠一揉，
她整个人被推得往后退了半步，脊背抵上冰凉的屏风 ——
可她没推他。她只是把下巴抬了起来，眼皮半垂着看他。

「放肆~❤」
她吐出这两个字的时候，声音是稳的，冷得像在宣判。
可他手掌底下那颗淫荡乳头已经硬得顶起来了，把真丝的料子顶出一个尖 ——
那点变化瞒不过任何人，她自己也清楚。

「你以为……用你那根精臭的巨屌……就能玷污本宫？」
她说这话的时候，旗袍的开衩已经自己滑到腿根，
那两条肥淫肉腿的内侧黏着一层薄汗，亮着，她两条腿却没并上。

他手掌往下移。她呼吸乱了一下 —— 就一下，随即又压回那条冰冷的声线里：
「嗯……你这头雄壮的种马……」
她的腰，就在说这句话的时候，自己往前塌了半寸。
「……这副淫荡的表情，不代表本宫屈服了。哈啊~❤」
```

*（照搬项：**最高傲的语调 + 最淫荡的内容 + 内容本身是拒绝** —— 三层同时在场；
「放肆 / 本宫 / 宣判」是姿态的壳，「精臭的巨屌 / 淫荡乳头 / 肥淫肉腿 / 淫荡的表情」是内容的核；
身体的让步（退半步却没推、开衩自己滑、腰自己塌）只写**现象**，不写她承认。这是阶段三的定义。）*

## 2 · 母猪（照搬「阶段三 · 主动迎合」的语气示范）

> 原文示范：「嗯～……就是这里……齁咿咿咿咿咿咕咕❤️……再……再用力一点……噗咕呜哦哦哦哦哦哦❤️……让人家的骚子宫……也尝尝这根雄壮精壮的巨屌的味道……咿咿咿嗯嗯嗯嗯嗯❤️……好舒服……咕齁齁齁齁哦哦哦❤……」

```
她自己把油焖熟厚肥尻往后撅了起来，撅到那根粗硕狰狞的肉屌整个埋进两瓣肥熟淫尻的缝里，
才肯停。「嗯～……就是这里……齁咿咿咿咿咿咕咕❤️」
她张着嘴，舌头早就自己吐出来了，长长的骚媚舌肉挂在唇边收不回去。

「再……再用力一点……噗咕呜哦哦哦哦哦哦❤️」
她一边叫，一边拿手到后面去够他的腰，够到了就往自己这边按，
按不动就自己往后顶，一下比一下狠，撞得那对肥硕爆乳在旗袍领口里甩得啪啪响。
「让人家的骚子宫……也尝尝这根雄壮精壮的巨屌的味道……咿咿咿嗯嗯嗯嗯嗯❤️」
她说「人家的骚子宫」的时候，声音是甜的 —— 甜得跟她白天开董事会时完全是两个人。

「好舒服……咕齁齁齁齁哦哦哦❤️」
到这一步她的两瓣肥厚逼肉已经翻出来了，一开一合地咬着那根屌，
那处淌出来的油滑熟骚淫水顺着肥淫肉腿的内侧往下爬，爬到她跪着的膝盖那一带积了一小汪。
```

*（照搬项：台词**逐句对标**原文示范的结构 —— 「就是这里」→「再用力一点」→「让人家的骚子宫尝尝」→「好舒服」；
淫语里的自称用「人家」；♥ 用红色实心一个写法；
器官一律按语料库的替换表（骚子宫 / 油焖熟厚肥尻 / 肥厚逼肉 / 油滑熟骚淫水 / 肥硕爆乳）。
★ 原文对阶段三的规定「身心达到高度统一，完全接纳了自己的淫荡本性」—— 所以这一段**没有一丝抗拒**。）*

## 3 · 超熟女（照搬「包裹监禁 · 乳内监禁」+「超乳」）

> 原文规定：**`<user>` 整个人（从头到脚含四肢）被吸入、深埋并封闭于单一身体部位之中**，四肢无法触及该部位以外的任何区域，处于黑暗、无光、窒息状态；
> 乳的体态：摊开时横跨超一米、垂坠至膝盖上方、乳晕大如成年男性胸膛、乳头粗如手腕

```
她往后一靠，靠进那张加宽的沙发里，两团温热肉山就那么摊开来 ——
横跨超过一米的肥硕爆乳铺满了整个座面，把 <user> 整个人吞进去还剩出富余。

那股味先上来：常年贴腹的暗色乳底肉褶焖了一整天的胸汗，混着发酵的奶香，
像热雾一样灌满他整张脸，他每一口呼吸吸进去的都是这个。
乳晕大如成年男性胸膛、暗紫红的，密布着凸起的结节，就在他眼皮子底下发着烫。
那根粗如手腕的乳头抵在他嘴边，顶端松开的乳孔正往外渗着温热拉丝的乳白奶浆，
一点点淌下来，糊在他下半张脸上，流进嘴角。

他想动。他动不了。
他两条胳膊被埋在乳肉里头 —— 左手压在这团的下缘，右手被另一团整个压住，
两只手都够不到乳房以外的任何地方。他探了一下，指尖碰到的是滚烫的肉壁，
再往下还是肉。他整个人就在这两团之间，没光，也没出口。

她低头看了一眼胸口那道被撑开的缝，肥厚手掌整个覆上去，从外面往下按了按。
「别乱动~❤」
那一按，两边的肉从外侧往中间挤，他被往里又塞深了半寸，
塞到他那张脸整个陷进乳根那道常年不见光的肉褶里，
陷进去之后，连她的轮廓都感觉不到了，只剩滚烫的两面肉贴在脸上、胸口上、后背上。
「越动越陷得深~❤」
她说着把身子往前倾了倾 —— 那两座肉山跟着抖了一抖，抖出一整片厚重的浪，
浪从他身上滚过去的时候，他整个人跟着那层肉一起沉了半寸，
那股奶香被这一压，又浓了一层。
```

*（照搬项：**包裹监禁的三条硬规定**全在 —— ①整个人被封在单一部位里 ②四肢绝对触不到该部位以外的任何区域（他探了一下，碰到的是肉，再往下还是肉）③黑暗、无光、窒息；*
*体态四项照搬：横跨超一米 / 乳晕大如成年男性胸膛 / 乳头粗如手腕 / 常年贴腹的暗色肉褶；*
*气味照搬「胸汗 + 发酵奶香 + 热雾灌满」；动作照搬「手掌覆上去往下按」；*
*★ 词汇禁区守住了 —— 通篇没有「结实 / 肌肉 / 粗壮」。）*

## 4 · 绿帽 / NTRS（照搬「叙事焦点」+「越贱越硬」）

> 原文规定：**全部笔墨砸在骚屄被玩、被肏的画面上**；`<user>` 在场时把他**压到最边缘，全文提一句就够**；
> 种付雄性 = **越下等、越肮脏、越不配，那根小废物就越硬**

```
那根凶恶的紫黑肉屌「噗嗤」一声整根捅进她那口焖熟骚屄的时候，她整个人往前一扑，
脸贴上冰凉的桌面，旗袍下摆还挂在腰上没落下来 —— 高开衩从腿根一路开到腰线，
两瓣油焖熟厚肥尻就那么光着撅在空气里，中间那道缝里全是淌出来的油滑熟骚淫水。

接手的是楼下修水管那个 —— 满脸油光，毛孔粗大，工装裤上全是陈年油污，
指甲缝里塞着洗不净的黑泥。那双脏手先攥上她那对肥硕爆乳，
从领口整个掏出来揉，泥垢蹭在白腻奶肉上拖出两道灰痕。

### *啪！！啪！！啪！！*

「哦齁齁齁❤️」
打桩的每一下都撞得那两瓣肥熟淫尻翻出一整片肉浪，浪从手掌根压住的地方荡开，一路推到腿弯，
撞回去的时候整片尻肉被砸平摊在桌面上，摊开再弹回来。
骚屄被撑得满满当当，穴口一圈嫩肉外翻着裹紧屌身进进出出，
抽出去那一下带出来的稠白顺着肥淫肉腿的内侧往下淌，淌到丝袜袜口那儿积了一小圈，
又被下一记撞得溅开。

「大嫂你自己说说，这口逼比你老公那根小废物怎么样？」
「……大~❤……比他的大~❤……」
她偏过头，眼睛半睁着，嘴角挂着被肏到失焦的笑，腮帮子还麻着 —— 因为嘴里刚被塞过。

他坐在沙发那一头，裤子早就湿了一小片。
```

*（照搬项：开篇即肏、**全部笔墨在画面上**；种付雄性的「下等」按原文的正写法（油光、毛孔、油污、指甲缝的黑泥）；*
*台词是「**说给 `<user>` 听的玩法**」（原文原话）；拟声按 `craft-01` 用标题级别独立成段；*
*★ **`<user>` 只在最后一句**，镜头不停留 —— 原文的原话是「全文提一句就够」。）*
