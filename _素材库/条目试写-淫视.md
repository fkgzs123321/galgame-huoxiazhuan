# 一 · 超重熟女

## 条目 1：超重熟女 · 体态

```
超重熟女 · 体态:
  她进门不用打招呼。那身肉先进来 —— 肩膀从门框里侧着蹭过去的时候，门框是让着她的，
  她不必为此收腹，也不必为此道歉。

  胸前那两坨不是挂着的，是坠着的。领口的最低点比她自己的手肘还低，
  走路时一颠一颠，坠到布料承受不住的地方就自己往两边分，
  中间那道沟从锁骨一路敞下去，敞到看不见为止。她是热得慌才解开的扣子 ——
  她的说法是热得慌，可那道沟里焖了一整天的肉香混着汗气，隔一张桌子都闻得到。

  屁股是后来长的。当初那条裙子还合身，现在后裆被撑得只剩一道缝，
  她坐下去的时候两瓣肉先从裙腰底下往外挤出来一圈，坐实了，
  沙发上留下一个完完整整的形 —— 她起身以后那个形还在，边缘往回爬，爬了半分钟没爬平。

  她身上没有一处是硬的。这不是「软」，是**分量**：手臂内侧垂下来那截，抬手就晃两晃才停；
  大腿并起来的时候，两片肉在最上面挤出一道横褶，褶子底下是亮的
  —— 那是走了一路磨出来的。
```

## 条目 2：超重熟女 · 她怎么用这具身体

```
超重熟女 · 她怎么用这具身体:
  她清楚自己压得住场子，也清楚这具身体能压住什么。

  弯腰捡东西的时候她不蹲 —— 她只是把上半身折下去，胸前的两坨跟着一块坠，
  坠到几乎离地。她知道那个角度上，站在她后面的人看见的是什么。
  她捡得很慢，捡起来还要看一眼才直腰。

  她坐下的时候会先往后靠，让那两团摊开在桌沿上，
  然后才开始说话。她说话的时候不看人，看人的是她的身体 ——
  那两团随着她呼吸的节奏在桌沿上压出深浅，一句一顿。

  她最常用的一个动作是解扣子。热了就解，解到第三颗，
  露出一截被内衣勒了一天的软肉和一条压出来的红印。
  那条红印比什么都说明问题：**这具身体被布料勒了一整天，现在它想松口气。**
  她不解释这条印子，也不遮。

  真到那一步她会仰面躺平 —— 那不是为了让谁舒服，
  是她知道自己这具身子的最佳状态是仰着：那两团摊开的时候像两座温热肉山，
  横着铺满整张床；腿一分，中间那片地方就自己开了。
```

# 二 · 绿帽

## 条目 3：绿帽 · 叙事焦点

```
绿帽 · 叙事焦点:
  全部笔墨砸在**她**被玩、被肏的画面上。

  谁在玩她不重要，重要的是被玩的是**他老婆**。
  所以镜头一律贴着她的身子：奶子怎么被从领口掏出来揉，
  骚穴怎么被撑成屌形、穴口那圈嫩肉怎么外翻着裹紧屌身进进出出，
  嘴巴怎么被臭屌塞到变形、腮帮子怎么被顶得凹下去，
  翘臀怎么一巴掌一巴掌拍到发红、红印怎么叠着红印。

  他在场的时候，镜头把他压到画面最边缘 —— 全文提一句就够：
  他坐在哪、他手放在哪、他裤子里那根顶成什么样。**一句话，镜头不停留。**
  他不是主角，他是这场戏的**看客席**。

  他不在场的时候，画面照旧。她照样被玩，叙事主体一点不变。
  区别只在于：这一段结束的时候，她会回到他身边，身上带着没擦干净的痕迹。

  她嘴里塞着东西跟他说话的时候，话要写出来 —— 含含糊糊的、
  被叼着说不清的、说一半被顶断的，全部照写。
  她挨着肏回答他的问题，答得越狼狈，这一段的重量越足。
```

## 条目 4：绿帽 · 越贱越硬

```
绿帽 · 越贱越硬:
  肏他老婆的雄性越下等、越肮脏、越不配，他裤子里那根小废物硬得越厉害。

  下等雄性在各个维度上都是劣等货色 —— 满脸油光、毛孔粗大，
  身上的味道是几天没洗发酵出来的酸，指甲缝里塞着黑泥，
  张嘴就是下流话，脑子里除了肏屄灌精再装不下别的。
  长相烂、身上臭、脑子蠢、人品差，**偏偏裤裆里那根凶恶臭屌硬得很，比他那根小废物粗出好几圈**。

  写的时候不要回避那点脏。那双手伸进她裙底之前先在工装裤上擦了一下 ——
  擦完照样是脏的，指甲缝里的泥垢蹭在她的白腻腿根上，留下两道灰痕。
  那两道痕就是这场戏的价目表：**他老婆身上被什么碰过，明明白白写着。**
```

# 三 · 正常（一个普通女角 · 展示淫视在「不极端」的题材里怎么落笔）

## 条目 5：普通女角 · 出场

```
普通女角 · 出场:
  她从走廊那头走过来的时候，没有什么特别的。三十上下，普通的个子，
  一件棉质衬衫，扣子扣得规规矩矩 —— 可她走路的时候那两团在衬衫里是**动的**，
  每走一步就往上顶一下，把前襟那道平纹顶出一小片鼓，又落回去。

  她抱着一摞文件，所以两只手都是满的。走到他面前停住，抬眼，
  说话的时候身子微微往前倾 —— **这一倾，领口那道缝就开了。**
  她不知道。她在说话，说得很认真，眉头是皱着的。
  而他听着，眼睛落在她说话时胸口那一小片起伏上，
  落在她因为认真而抿紧的唇上，落在她说到一半、下意识把手里的文件往上抱了一下时，
  前襟那道鼓被压平又弹回来的那一下。

  她讲完了，等他回答。他"嗯"了一声。
  她不知道刚才那半分钟里，他一个字都没听进去。
```

## 条目 6：普通女角 · 非性场景也过滤镜（战斗 / 赶路 / 争吵）

```
普通女角 · 非性场景（这一条是给「没在发生性行为」的场合用的）:
  她跑起来的时候抱着的东西会松，所以她跑得很小心 —— 可那具身体跑不快也藏不住：
  胸前两团被步子送出去，甩到最高点把布料从里头顶起来，再坠回去撞在乳丘底下弹开，
  每一步都这样，隔两步才停。

  她跨过那道矮栏的时候整个人是折下去的，重心压在前腿上，
  臀肉在这一个折角上被顶成全身最高的一处 —— 那一下只是一瞬，
  可她落地以后要先把手里的东西重新抱好，**抱的时候两臂一收，胸前那两团就被挤到一起**，
  中间那道沟从衬衫的扭结里挤出来，亮着，她一点都没有察觉。

  她摔倒过。摔倒的时候是先跪下去的，膝盖先着地，
  然后是上半身往前扑 —— 那一扑把衬衫的下摆整个掀起来，
  露出一截后腰和裤腰上头那一圈被勒出来的软。

  ★ **全程没有性行为，全是这一双眼睛在看。**
```

# 这三条放在一起说明的事

| | 淫视怎么落在那 |
|---|---|
| **超重熟女** | 旁白盯的是**分量** —— 不写「丰满」，写「那个形还在，边缘往回爬，爬了半分钟没爬平」 |
| **绿帽** | 旁白盯的是**她身上那点脏** —— 不写「他被背叛」，写「指甲缝里的泥垢蹭出两道灰痕，那就是价目表」 |
| **正常** | 旁白盯的是**她不知道的地方** —— 不写「她很好」，写「她说话的时候身子往前倾，领口那道缝就开了，她不知道」 |

★ **三次都没有写性行为**，可**三次都在色情** —— 这就是「淫视」和另外五个的分界：
**它不需要脱衣服就已经在做这件事了。**
