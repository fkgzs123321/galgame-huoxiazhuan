# 一 · 逐句对照

## 1. 外貌（超重熟女）

**❌ 之前（「她」作主语）**
```
奶: 那两团她自己早就不看了。喂过孩子，又空了这么多年，垂到不能再垂，
    往下坠的重量把胸口的皮拉出一道一道浅痕；那对奶头倒是比年轻时候更大更黑了……
```

**✅ 重写（器官作主语）**
```
奶: 两团垂到底，喂过孩子，又空了这么多年，重量把胸口的皮拉出一道一道浅痕 ——
    ★ 那道浅痕从上往下走，走到奶肉最底下那一段是要折进去的，折进去的地方是暗的。
    ★ 那对奶头比年轻时候更大更黑，深褐色，一圈乳晕摊开得有茶杯口那么大，
    上面浮着几粒小结节 —— ★ 一进凉气那两点就立起来，把薄汗衫顶出两个硬凸点，
    顶出来了，谁也别想看不见。
```

★ 差别：不在句首挂「她 / 她的」，**让器官自己作为主语出现**。

## 2. 性格衍生（面馆老板娘）

**❌ 之前**
```
泼：她不遮掩。热了就把汗衫的扣子解开，擦汗的时候从脖子擦到胸，
    托起那一坨擦下面，当着谁的面都一样。
```

**✅ 重写**
```
泼: ★ 汗衫的扣子热了就解，从最上面那颗开始，解到第三颗的时候
    底下一整片被勒了一天的软肉就自己往外挤出来，挤出的那圈是红的 ——
    ★ 肩上那条毛巾从脖子往下走，走到胸口停下来，一只手把那一坨托起来，
    毛巾往下面那块走；★ 托起来的时候，整团肉是往下坠的，
    坠得分不清哪是胸哪是肚子。★ 这道工序她当着谁都一样做。
```

★ 「**她不遮掩**」这种判断句删掉 —— **动作本身就是不遮掩**。

## 3. 多阶段（图书馆女孩 · 第一档）

**❌ 之前**
```
她能做得到:
  - ★ 把靠里那个位置空出来 —— 理由是「那边灯亮」。
  - ★ 你到的时候她会「嗯」一声，继续低头盖章
她做不到（★ 不许越过去）:
  - 主动跟你说话。★ 除非你问她
她对你开放到什么程度: ★ 零。她连领口歪了都要转身才理。
```

**✅ 重写**
```
能做得到的:
  - ★ 靠里那个位置一天都空着。★ 有人要坐，她说「那边灯坏」——
    可那盏灯整个下午都是亮的
  - ★ 你进来的时候那声「嗯」是从镜片上面下来的，落完就回去了，
    头一直没有抬起来过
做不到的:
  - 开口。★ 那本书摊在手上要翻不翻，翻到一半停在那一页 ——
    ★ 她在等一句问话，等不到就一直停着
  - ★ 手背。那只手一直压在借书证上；★ 你走近的时候，
    指节会往里收一点点，收到把那张证压出一道折
开放到什么程度:
  - ★ 零。★ 可领口歪了那一下 —— 歪了有半分钟，是转过去以后才理的
```

★ **关键是把「她 + 动词」改成「器官/物件 + 动作」**：
- 「她会嗯一声」→「那声『嗯』是从镜片上面下来的」
- 「她的手压在证上」→「那只手一直压在借书证上」（**手**作主语，不是「她」）
- 「她连领口歪了都要转身才理」→「领口歪了有半分钟，是转过去以后才理的」

# 三 · 这次重写用的三条手法

| # | 手法 | 例 |
|---|---|---|
| 1 | **把「她 + 动词」改成「器官/物件 + 动作」** | 「她会嗯一声」→「那声『嗯』是从镜片上面下来的」 |
| 2 | **把判断句改成现象句** | 「她不遮掩」→（删掉）**动作本身就是不遮掩** |
| 3 | **删掉所有「她觉得 / 她不知道 / 她经常 / 她心里」** | 「她觉得家里没有别人」→ **直接写那两团是晃的** |

★ **收工前逐句过一遍**：这一句的主语是什么？**是「她」就改写。**
