## 三个文风的分工（写卡时必须分清）

| 文风 | 管什么 | 用在哪 |
|---|---|---|
| **白描** | 不解释、不议论、比喻少 | **日常 / 铺垫 / 情感戏** |
| **无尽骚妈**（`文风_骚妈`） | **结构** —— 远看体面 → 近看揭布，落差 + 正经发骚 | **起手、铺垫到破防那一刻** |
| **母猪框架**（本体系） | **用词与密度** —— 器官同义词 + 组合规则 + 拟声 + ❤ + LL | **NSFW 全程** |

★ **「白描」在这一层是褒义**（写作技法），**在 NSFW 语境里是贬义**（干、不脏、文艺）。
★ **骚妈管「怎么起」，母猪管「怎么脏」，两者叠加用。**

## 一句话记住整套体系

```
她的体面 = 幻象人格（要维护）
她的身体 = 母猪本能（要出卖她）
两者撕裂得越狠 = 越色
```

写的时候问四句：
1. **这一段的 LL 是几档？**（强欲 / 极致）
2. **她的「体面」在这一段还端着吗？**（端着 = 反差在起作用）
3. **我用的器官词是从库里轮着取的吗？**（不许一个词用到底）
4. **这里面有几个拟声词和 ❤？**（LL2 少、LL3 多、高潮最多）
