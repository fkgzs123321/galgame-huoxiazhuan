## 三、组合词生成规则（★ 这是「怎么造词」，比「选词」更关键）

### 8 条基本原则
1. **选择一个核心名词作为基础**，确保使用对应的标识符
2. 为核心名词**添加 1-2 个形容词修饰**，形容词必须与名词标识符**匹配**
3. 可选择**添加一个状态或行为描述**，与整体标识符保持一致
4. 注意词语的**变化与重复**，适度重复可用于强调，但应避免过度使用相同词语
5. 选择**动词时注重准确性和生动性**，可搭配副词使用
6. 灵活运用**比喻、拟人**等修辞手法，增强描述的生动性，但要保持标识符一致性
7. 注意整体**语言风格的统一和节奏的把控**
8. 在组合不同类别的词语时，确保**标识符的逻辑关系正确**，避免不恰当的搭配

### 组合格式（12 类）
```
【女性】
  身体描述：女性身体形容词1 + 女性身体形容词2 + 的 + 女性身体部位
  声音描述：女性声音形容词1 + 女性声音形容词2 + 的 + 女性声音
  状态描述：女性状态形容词 + 的 + 女性角色
  行为描述：女性行为 + 中/时 + 女性状态/结果
  气味描述：女性气味形容词1 + 女性气味形容词2 + 的 + 女性气味
  体液描述：女性体液形容词1 + 女性体液形容词2 + 的 + 女性体液

【男性】同上六类

【动词描述】副词 + 动词
  示例：狠狠贯穿、疯狂套弄
```

### 示范（按格式生成）
```
「高耸挺拔」+「巨硕」+ 的 +「乳山」        → 高耸挺拔巨硕的乳山
「圆润扇形」+「丰腴弹实」+ 的 +「安产肥臀」  → 圆润扇形丰腴弹实的安产肥臀
「黏腻浓郁」+「腥甜」+ 的 +「雌淫淫水」      → 黏腻浓郁腥甜的雌淫淫水
```

## 六、写卡时的取词顺序

```
① 定 LL 档位（LL2 强欲 / LL3 极致）—— 决定取词档位
② 定体型（丰腴 / 正常 / 纤细）—— 决定取词表
③ 取器官词（从同义词库里轮着用，不许重复同一个）
④ 按组合规则造修饰语（形容词1 + 形容词2 + 的 + 部位）
⑤ 配拟声词（按场景选类别，灵活交叉）
⑥ 加 ❤（按 LL 档位密度）
⑦ 查负面约束（禁临床词 / 禁数值化 / 禁献媚句式）
```
