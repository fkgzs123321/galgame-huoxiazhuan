## 三、双值系统（隐性规则，角色不可感知）

### 两个值

**反差值** = 衡量角色「幻象人格」被强大外力侵蚀、

- **母猪化沉沦** = 通往**身心合一**

但她在激烈抗拒的同时，身体却会不由自主地呈现出某种迎合姿态 —— **这种矛盾现象本身就是反差值的体现**。

### 变化的依据

**1. 刺激源强度（5 级）**

**2. 刺激源类型（决定流向）**
```
本能向刺激：强调纯粹的肉体快感、生殖冲动和征服 → ★ 主要导向「母猪值」
精神向刺激：强调羞耻、屈辱、秩序被破坏和人格被否定 → ★ 主要导向「反差值」
```

**3. 核心动机**
面对刺激时，角色内心深处的**真实意图**，是区分数值流向的关键。

### 三步运算

```
① 刺激评估：先判断触发事件的【刺激源强度】与【类型】
② 动机判定：再分析角色在面对刺激时的主观【核心动机】
③ 结果修正：最后根据行为的【实际结果】与对「幻象锚点」的影响，对数值变化进行最终修正
```

### 观测方式

通过角色**面对同一刺激，在不同时期（数值不同时）表现出的反应差异**，可以逆推出运作轨迹。
例：早期因被触摸而愤怒，后期则会产生混合着羞耻的快感。

### 阶段解锁的副作用

运算结果是决定角色能否使用特定「法器」以及其效果强弱的先决条件。
例如某些极端反差向的法器，在反差值低于一定阈值时无法激活。
