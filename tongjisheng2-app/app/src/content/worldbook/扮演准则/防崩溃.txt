# 防崩溃条目（死结局机制）

本条目定义死结局触发机制，防止剧情崩溃。

## 一、死结局类型

### 1.1 BAD END 类型
| 类型 | 触发条件 | 处理流程 |
|------|---------|---------|
| 报警结局 | 强制猥亵（未达初 H 阈值强行 H） | 女角反抗 → 报警 → 警察带走 → BAD END |
| 关系破裂结局 | 强迫亲密（未达亲吻阈值强行亲吻） | 女角推开 → 信任归零 → 关系永久破裂 |
| 入室盗窃结局 | 闯入私宅（深夜未授权进入） | 邻居报警 → 警察带走 → BAD END |
| 公然猥亵结局 | 当众暴露（公共场合 NSFW） | 路人报警 → 警察带走 → BAD END |
| 故意伤害结局 | 暴力行为（对女角动手） | 女角反抗 + 警察介入 → BAD END |
| 双方破裂结局 | 作弊（同时攻略互斥女角） | 触发互斥攻略标记 → 双方关系永久破裂 |
| 体力透支结局 | 强行打工（疲劳 ≥ 80 / 体力 ≤ 20） | 主角晕倒 → 进医院 → BAD END |
| 经济破产结局 | 长期贫困（现金 < 500 且储蓄 < 1000 持续 3 天） | 债主上门 → BAD END |

### 1.2 NORMAL END 类型（天数=17 强制触发）
| 类型 | 触发条件 |
|------|---------|
| 单一女角专属结局 | 该女角 is_completed=1 + 好感度 ≥ 85 |
| 后宫结局 | 多女角亲密（≥ 3 位 好感度 ≥ 85） |
| 单身结局 | 无女角亲密（所有 好感度 < 85） |
| 修学旅行取消结局 | 储蓄 < 50000 |
| 学业失败结局 | 学业 < 30 |
| 名声扫地结局 | 声誉 < 20 |

## 二、死结局执行流程

### 2.1 BAD END 流程
1. **立即结束当前剧情线**（≤ 100 字描述）
2. **输出 BAD END 描述**（≤ 200 字，简短有力）
3. **写入标记**：
   ```sql
   UPDATE global_state SET flags_text = 'bad_ending_报警结局:主角因强制猥亵被警察带走' WHERE row_id = 1;
   ```
4. **写入事件日志**：
   ```sql
   INSERT INTO chronicle (row_id, code_index, time_span, summary, chronicle_text)
   VALUES (?, 'bad_ending_001', '1995-12-??', 'BAD END: 报警结局', '主角因强制猥亵被警察带走，存档锁定');
   ```
5. **提示玩家**："存档已锁定。建议从 天数=1 重新开始。"
6. **不再接受任何继续剧情的指令**

### 2.2 NORMAL END 流程
1. 在 天数=17 深夜时段结束后触发
2. 综合评估：
   - 各女角 is_completed / 好感度
   - 主角属性（魅力/学业/声誉）
   - 储蓄
3. 输出对应结局描述（500~1000 字）
4. 写入 flags.flag_key='normal_ending_XXX'
5. 提示玩家："寒假结束了。感谢游玩。"

## 三、防崩溃机制

### 3.1 数值溢出保护
- 所有数值字段有 CHECK 约束（0-100）
- 单轮变化 ≤ 5 点（防口胡机制）
- 跨时段累积无上限（允许长期养成）

### 3.2 状态死锁保护
- 疲劳 ≥ 80 强制休息（不可继续打工/约会）
- 体力 ≤ 20 强制休息（不可剧烈活动）
- 心情 ≤ 10 触发"心情低落"剧情（不可正常互动）

### 3.3 关系死锁保护
- 互斥攻略：触发其一则另一永久不可攻略
- 嫉妒值 ≥ 80：触发"嫉妒爆发"事件，关系阶段降一级
- 信任度 = 0：触发"信任崩溃"事件，关系永久破裂

### 3.4 时间死锁保护
- 每楼层固定流逝 30 分钟，按时间线推进（无每日上限）
- 疲劳 ≥ 80：强制休息（无法继续行动）
- 天数 > 17：拒绝写入（禁止超过寒假范围）
- 时段切换必须按顺序：早→上午→下午→晚→深夜→次日早

## 四、AI 自我修复机制

### 4.1 变量丢失回捞
当 MVU 变量丢失时（导入旧档）：
1. 从最近 4 条消息中正则提取
2. 提取成功则回写到 `_rescued_xxx` 缓存变量
3. 仍失败则使用默认值

### 4.2 表格数据丢失
当 chatSheets 表格丢失时：
1. 提示玩家"点击 📦 创建表格模板 按钮重新初始化"
2. 暂停剧情推进，等待玩家操作
3. 不允许"凭空生成"数据

### 4.3 异常状态恢复
当主角陷入异常状态时：
- 疲劳 100 → 强制住院 1 天，疲劳 重置为 50
- 心情 0 → 触发"美佐子安慰"剧情，心情 重置为 50
- 信任度 0（任一女角）→ 关系永久破裂，不可恢复
