# 同级生2 变量更新规则

本文件规定 AI 在 `<UpdateVariable>` 与 `<UpdateTable>` 中更新变量和表格的规则。
所有变量和表格字段都有 DDL CHECK 约束，违反约束会触发 SQLite 错误。

## 一、单轮变化上限（快速参考）

> 详细限制与难度修正参 `世界书/EJS预处理/变量变化幅度控制.txt` 的 `CHANGE_LIMITS` / `validateChange()`。
> 本节为 AI 快速参考上限，实际执行以 `变量变化幅度控制.txt` 为准（单次上限 ±10，含单次/每日/每周三档）。

### 1.1 主角属性（6维）
- 魅力 / 学业 / 体力 / 社交 / 敏感 / 声誉：单轮参考上限 ≤ 5 点
- 详细分档与难度修正：参 `变量变化幅度控制.txt.CHANGE_LIMITS.protagonist_stats`

### 1.2 主角副状态（3）
- 疲劳 / 心情：单轮参考上限 ≤ 5 点
- 现金：单笔参考上限 ≤ 5000（收支分别限制）
- 详细限制：参 `变量变化幅度控制.txt.CHANGE_LIMITS.protagonist_subs`

### 1.3 女角好感度
- 好感度 / 心动值 / 嫉妒值 / 信任度：单轮参考上限 ≤ 5 点
- 详细限制：参 `变量变化幅度控制.txt.CHANGE_LIMITS.heroine_affection`

### 1.4 NSFW 字段
- 暴露程度 / 湿润度 / 兴奋度：单档变化（不跨档跳跃）
- H经验：单轮参考上限 ≤ 5 点
- 详细限制：参 `变量变化幅度控制.txt.CHANGE_LIMITS.nsfw_fields`

### 1.5 跨时段累积
- 跨时段累积变化无上限（如多日累积可让 魅力 从 50 涨到 80）
- 单轮超出参考上限时，以 `变量变化幅度控制.txt.validateChange()` 的判定结果为准

## 四、表格写入规则（DDL 概要，本文件独有）

### 4.1 DDL.global_state（每轮更新）
- UPDATE row_id=1，更新时间/位置/场景；所有字段 NOT NULL。

### 4.2 DDL.protagonist_info（属性变化时）
- UPDATE row_id=1，更新对应字段；数值 0-100（money 例外，≥0）。

### 4.3 DDL.inventory（物品变化时）
- INSERT/UPDATE/DELETE（数量为 0）；item_name 不可重复。

### 4.4 DDL.important_npc（女角状态变化时）
- UPDATE 对应 row_id；好感度 -100~100，关系阶段与 NSFW 字段必须匹配 CHECK 列表。

### 4.5 DDL.chronicle（事件触发时）
- INSERT 新行；code_index 不可重复。

### 4.6 DDL.check_suggestions（选项更新时）
- UPDATE 现有选项 / INSERT 新选项。
