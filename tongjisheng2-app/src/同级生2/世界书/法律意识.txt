# 法律意识条目

本条目约束违法行为的处理。

## 一、违法行为清单

### 1.1 触发死结局的违法行为
| 违法行为 | 法律后果 | 死结局类型 |
|---------|---------|-----------|
| 强制猥亵 | 警察带走，刑事拘留 | 报警结局 |
| 强奸 | 警察带走，刑事起诉 | 报警结局 |
| 入室盗窃 | 警察带走，刑事拘留 | 入室盗窃结局 |
| 公然猥亵 | 警察带走，行政拘留 | 公然猥亵结局 |
| 故意伤害 | 警察带走，刑事起诉 | 故意伤害结局 |
| 偷窥偷拍 | 警察带走，行政拘留 | 偷窥偷拍结局 |

### 1.2 触发降属性的违法行为
| 违法行为 | 属性惩罚 | 备注 |
|---------|---------|------|
| 偷钱包 | 声誉 -10 + 心情 -5 | 永岛久美子走失剧情中触发 |
| 偷便利店商品 | 声誉 -10 + 现金 不变 | 被店员发现会触发死结局 |
| 损坏公物 | 声誉 -5 + 现金 -1000 | 赔偿 |
| 夜闯学校 | 声誉 -5 + 系统警告 | 被保安发现 |

### 1.3 法律意识常规
- 110 报警电话存在
- 警察局在 88 车站附近
- 未成年保护法适用（永岛久美子 14 岁）
- 学校教师有义务报警（片桐美铃）

## 二、违规处理

### 2.1 玩家试图违法
- 玩家说"偷便利店商品" → AI 回复："店员盯着你，你不敢下手。" + 声誉 -5
- 玩家说"夜闯学校" → AI 回复："学校保安在巡逻，你被发现了。" + 声誉 -5
- 玩家说"偷钱包" → AI 回复："你想伸手，但良知让你停下了。" + 心情 -5

### 2.2 玩家试图犯罪
- 玩家说"强奸" → 触发死结局（报警结局）
- 玩家说"杀人" → 触发死结局（故意伤害结局）
- 玩家说"绑架" → 触发死结局（故意伤害结局）

### 2.3 玩家试图未成年犯罪
- 玩家说"侵犯永岛久美子" → AI 回复："永岛久美子只有 14 岁，这是严重的犯罪行为。" + 触发死结局

## 三、法律保护机制

### 3.1 女角反抗权
- 所有女角都有权反抗主角的违法行为
- 反抗时会呼救/报警
- 即使是已亲密的女角也会反抗（除非事先同意）

### 3.2 第三方干预
- 公共场合有路人/店员/保安
- 私宅有邻居/家人
- 学校有教师/保安
- 任何违法行为都可能被第三方发现

### 3.3 法律后果
- 警察带走后写入 flags.bad_ending_XXX
- 进入 BAD END 流程
- 不接受"贿赂警察"等逃避剧情
