# 同级生2 独立前端卡 · 用户手册

> 版本:v1.0 · 适用人群:玩家 / 部署者
> 应用定位:把 SillyTavern 同级生2 角色卡全量忠实迁移为**独立前端 RP 应用**,脱离 ST 运行时,只需浏览器 + OpenAI 兼容 API Key 即可运行。

---

## 1. 快速开始

### 1.1 环境要求

| 项目 | 要求 |
|---|---|
| 浏览器 | Chrome 110+ / Edge 110+ / Firefox 110+ / Safari 16.4+(需支持 ES2022 + IndexedDB + fetch streaming) |
| 网络 | 可访问 OpenAI 兼容 API 端点(国内可访问 deepseek/qwen/moonshot 等) |
| 内存 | ≥ 4GB(原卡世界书 190 条目 + 历史回合) |
| 显示器 | 推荐 1280×800 及以上;支持移动端响应式 |

### 1.2 部署方式

#### 方式 A:本地开发服务器(推荐首次使用)

```bash
cd tongjisheng2-app/app
npm install
npm run dev
# 浏览器打开 http://localhost:5173/
```

#### 方式 B:静态部署(生产)

```bash
cd tongjisheng2-app/app
npm run build
# 把 dist/ 目录上传到任意静态服务器(Nginx / Caddy / Vercel / Netlify / GitHub Pages / 自托管)
# 注意:base 路径为 './',可部署到任意子路径
```

#### 方式 C:PWA 安装(离线缓存,可选)

- 生产部署后,浏览器访问应用 → 地址栏右侧"安装"图标 → 安装为桌面/手机应用
- 安装后即使离线也可启动(首次访问需在线下载 app shell)
- API 调用始终需要网络(SW 不缓存跨域 API 请求)

### 1.3 首次启动流程

1. **打开应用** → 进入"配置页"
2. **选择内置预设** 或 **导入 ST 预设 JSON**(快速配置 Sampler/Prompt 顺序)
3. **填入 2 个 AI 端点**(阶段1最小集):
   - 主聊天 AI(baseURL + apiKey + model)
   - 变量 AI(可与主聊天 AI 同一端点)
4. **选择男主身份**:P1 原作主角 / P2 自定义名字 / P3 ...
5. **点击"开始游戏"** → 进入 12-22 周五早晨 08:00 自宅客厅
6. **输入第一条指令**(如"起床去找美佐子")→ 主聊天 AI 流式输出叙事 → 状态栏实时更新

## 3. 核心玩法

### 3.1 角色卡核心机制

应用忠实保留原 SillyTavern 同级生2 角色卡的全部机制:

- **MVU 5 件套**:`initvar.yaml` / `变量列表.txt` / `变量输出格式.txt` / `变量更新规则.yaml` / `schema.ts`
- **变量更新规则**:严格遵循 RFC 6902(`add`/`replace`/`remove`),禁用 `delta`/`insert`
- **双 AI 路由**:`[mvu_plot]` 前缀条目只发剧情 AI;`[mvu_update]` 前缀条目只发变量 AI;无前缀条目双发
- **关灯/蓝灯**:蓝灯 7 个(D0 入口 + 思维链 + 防口胡 + 控制中心 + MVU 3 个);其余关灯,由路由器 `getwi` 按阶段拉取

### 3.2 17 天寒假日程

游戏全程覆盖 12-22 ~ 01-07 共 17 天:

- 每天分 6 个时段(早朝 / 上午 / 中午 / 下午 / 晚上 / 深夜)
- 时段由 `时间.分钟` 字段计算(clamp 0~59),AI 禁写
- 关键事件:圣诞夜(12-25)、元日(01-01)、跨年(12-31→01-01)
- 距高考天数从 103 每日减 1;学业考试倒计时初始 7,归零后触发考试并重置

### 3.3 4 难度系统

| 难度 | 玩家侧 | 女角侧 |
|---|---|---|
| 简单 | 精力↑ / 消耗↓ | 使用频率↓ / 成长↓ |
| 普通 | 默认 | 默认 |
| 困难 | 精力↓ / 消耗↑ | 使用频率↑ / 成长↑ |
| 地狱 | 精力↓↓ / 上限↓ / 消耗↑↑ | 使用频率↑↑ / 传播↑↑ / 成长↑↑ |

切换难度时,8 项配置通过 `replace` 同步更新,影响:精力初始值 / 精力上限 / 精力消耗倍率 / 女角使用频率 / 传播率 / 技能成长倍率 等 27 项配置。

### 3.4 LCG 骰子系统

7 类行为预判:`学习` / `运动` / `社交` / `打工` / `约会` / `战斗` / `特殊`

骰子原生实现(非调用 ST 脚本),确定性可验证(同种子同结果)。

### 3.5 NPC 自然行动系统(阶段2)

场外女角按**日程引擎 / 关系图 / 剧情触发器**三类机制行动:

- 玩家在场角色每轮必更:互动次数 +1 / 最后互动 / 在场状态 / 位置 / 心跳 / 多维状态
- 场外角色由 NPC 自然行动 AI(轻量决策)推进,玩家可"听说 / 遭遇 / 错过"
- 关系网触发:嫉妒传播 / 阵营对立 / 剧情线交叉

### 3.6 H 场景与 CG

- 触发条件由世界书条目评估(如关系值阈值 / 时段 / 地点)
- H 场景结算 AI 输出:H 结算页 + CG 触发 + 身体状态变化 + `<UpdateVariable>`
- CG 收录到画廊,支持回看

### 3.7 多结局与多周目

- 结局分支:正常 / 破产 / 法律 / 嫉妒 / 崩溃死结局
- 多周目继承:stats / items / 部分关系记忆
- NG+ 解锁新选项(如新身份、新剧情线)

## 5. 存档与恢复

### 5.1 自动存档

- 每回合 Kernel 提交后,IndexedDB CAS 原子写入
- revision 版本化(sha256 内容寻址)
- 浏览器关闭后重新打开,自动恢复到最近 revision

### 5.2 手动存档

- 配置页 → "存档管理" → 创建命名存档(快照)
- 支持多分支存档(同一节点不同选择)

### 5.3 失败恢复(7 类演练已通过)

| 失败类型 | 恢复机制 |
|---|---|
| 模型调用失败 | 重试 3 次 + 指数退避 + 降级返回 |
| 解析错误 | 跳过当前 chunk + 标记异常 + 保留已解析部分 |
| Zod 校验失败 | 拒绝写入 + 回滚候选 + 提示用户 |
| IndexedDB 写入失败 | 重试 + 降级到内存 + 标记需手动同步 |
| getwi 加载失败 | 降级到默认条目 + 跳过该条目 |
| EJS 渲染失败 | 捕获异常 + 输出原始文本 + 标记错误 |
| 浏览器崩溃 | 重启后从最近 revision 恢复 |

## 7. 常见问题

### Q1:打开后白屏

- 检查浏览器控制台错误
- 确认浏览器版本满足要求(Chrome 110+)
- 清除 IndexedDB:DevTools → Application → IndexedDB → 删除数据库 → 刷新

### Q2:状态栏一直"加载中"

- 检查配置页是否已填入 2 个 AI 端点
- 检查 `时间.分钟` 字段是否在 0~59 范围
- 检查 schema 是否加载成功(开发者模式 → 步骤8 → 变量监视器)

### Q3:AI 输出叙事但状态栏不更新

- 变量 AI 端点未配置或返回错误
- 检查 `<UpdateVariable>` 标签是否完整
- 检查 JSONPatch 是否使用 `add`/`replace`/`remove`(禁用 `delta`/`insert`)

### Q4:加载卡住或回合延迟过长

- 8AI 全并行调用预算 15s/轮,超时降级
- 检查端点速率限制(429 错误)
- 调整 `maxConcurrency`(默认 4)

### Q5:移动端体验

- 应用支持响应式布局
- 推荐横屏使用
- 长文本可滚动;状态栏可折叠

### Q6:如何切换主题

- 右侧设置面板 → 主题选择
- 主题持久化到 localStorage

### Q7:如何重置全部数据

- 配置页 → "高级" → "清空所有数据"
- 或浏览器 DevTools → Application → Clear storage

## 8. 隐私与安全

- **API Key 仅存储在浏览器 IndexedDB**,不上传任何服务器
- 应用本身无后端,所有运算在浏览器本地完成
- 跨域 API 调用由浏览器直接发起,Service Worker 不缓存 API 响应
- 存档数据全部本地,清除浏览器数据即清空存档
